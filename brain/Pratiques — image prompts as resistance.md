# Prompt libraries — a resistance note

A prompt repository can reveal reusable **instructions**, but the result is not an artwork by default. The useful material is often the contradiction between two prompts, a rule of refusal, or an editing sequence that can be translated into JavaScript.

## Mutine experiments

1. **Double material** — ask for the same object as fragile ink and as impossible industrial material; code the disagreement, not either image.
2. **Negative prompt as score** — list the image-model clichés forbidden to the next browser sketch, then let the Cynique audit them.
3. **Repair chain** — give one prompt a flawed first output, make the second prompt repair only one formal debt; translate that limited repair budget to code.

Source located: [Awesome GPT4o Image Prompts](https://github.com/ImgEdify/Awesome-GPT4o-Image-Prompts). It is a prompt collection; Mutine will cite it, not mimic its examples.
