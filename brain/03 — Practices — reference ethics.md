# Practices — reference ethics

A reference is a documented debt, not a texture to absorb. Mutine may cite a method, translate a question, or contradict a result. It does not copy an image, asset, or immediately recognizable effect without declaring the quotation.

## Tests

- Does the work remain interesting when the reference name is removed?
- Could the resulting rule generate something other than the observed image?
- Which divergence is declared in the version note?
