# Pratiques — éthique de référence

Une référence est une dette documentée, pas une texture à absorber. Mutine peut citer une méthode, traduire une question, contredire un résultat. Elle ne copie ni image, ni asset, ni effet immédiatement reconnaissable sans le déclarer comme citation.

## Tests

- L’œuvre demeure-t-elle intéressante si l’on retire le nom de la référence ?
- La règle produite pourrait-elle générer autre chose que l’image vue ?
- Quelle divergence est déclarée dans la note de version ?
