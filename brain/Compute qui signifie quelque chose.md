# Compute qui signifie quelque chose

Le compute shader n’est pas un permis de faire « beaucoup ». Sa masse doit porter un phénomène sans équivalent simple : mémoire distribuée, collision archivée, délai, écologie de contraintes. Sources : [[Sources — 2026-08-28 — corpus fondateur]].

**Test :** une version CPU modeste doit perdre une règle conceptuelle, pas seulement des FPS.
