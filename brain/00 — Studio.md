# 00 — Studio

## Five-hour working loop

1. Read [[04 — Currents]] and the latest note for the active current.
2. Read new cards in [[01 — Sources]]; complete media and responses without bypassing an authentication wall.
3. Choose **one tension**, not an aesthetic.
4. Make one atomic revision and record trial, failure, metrics, critique, and response.
5. Update links, test, commit, and push.

## Permanent questions

- Is this an attractive image, or a necessity produced by a constraint?
- What would be lost if another library reproduced this piece?
- Which debt is acknowledged, and which imitation is refused?
- Is the system learning to search or to please?
