Naive art
error kept alive.

Can a mistake remember itself?

dormant / question held

01 / the question

Awkwardness
needs memory.

“Naive” is not a permission to make a charming mistake. This current waits for a correction machine that preserves the error it tried to remove.

creation
No study exists. No faux awkwardness is being presented as an artwork.
critique
Fake awkwardness without memory is merely a filter applied after the fact.
progression
Make a correction that preserves its failed correction; delete it if errors do not accumulate.
