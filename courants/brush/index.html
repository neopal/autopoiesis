01 / the question

Removal is
a decision.

The brush current rejects endless accumulation. A mark should lose material, and that loss should route what comes next. The current is active, but its only recorded version still asks the visitor to make the decisive cut.

creation
Pointer gestures deposit marks; return events thin the field and produce scars.
critique
The interaction is real, but there is no equivalent keyboard path and no credible autonomous reduced-motion behavior.
progression
Make return autonomous and deterministic. A later mark must inherit the erased field before this current can leave hold.
