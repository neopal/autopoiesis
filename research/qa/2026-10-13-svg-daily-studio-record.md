## Artistic gate

### Hypothesis

If the field is authored as one contour rather than a set of objects, a visitor should feel a change in topology when a remote reply arrives: the image should become a different body, not a highlighted selection.

### Changed rule

v030 abandons v027's horizontal slip strata, v028's standing aperture plates, and v029's woven compound bodies. One irregular SVG contour holds eight cavities and a central silence. A local crossing only arms a cavity; a distant gate must reply before the source cavity contracts, the target opens, the remote relay bends, and the shared even-odd contour records a new topology. Four replies remain in bounded memory. Lifting the latest reconstructs the exact preceding contour; release returns to the deterministic seed.

### Visible consequence

The blind first view is one negative-space body, not a population of cards, plates, or selectable forms. A near crossing leaves its geometry exact. A far drag changes three real cavity paths and the shared contour; later replies inherit prior topology.

### Falsifier

The translation fails if a local crossing writes, a same-gate return commits, only a highlight/readout/label changes, the reply does not alter three cavity paths, later replies restart from seed, lifting is not exact, or the blind field reads as a decorative ring/interface diagram.

### Deletion condition

Delete v030 if labels/readout/controls/annotations/prose-off comparison cannot carry the causal distinction, or if the singular contour does not read as an authored new body rather than a decorative halo.

### Radical progression

The last three Pure SVG works repeated visible populations: horizontal strata, standing plates, and woven compound bodies. v030 makes two material ruptures: composition changes from many visible bodies to one even-odd negative-space contour, and the viewer task changes from selecting/offering places to press-dragging a near-to-far crossing. The rupture is in the engine (`armGate` is geometry-neutral and `applyReply` changes three cavities), the interaction (pointerdown/pointerup across distance), and the rendered consequence (one body is re-formed rather than a selected object highlighted).

## Cultural translation

- **Reference:** [little-critters](https://github.com/GordenSun/little-critters)
- **Observed mechanism:** situated code-drawn agents respond to pointer proximity with legible attention and reciprocal looking, making the visitor part of a social field without a dashboard.
- **Mutine translation:** refuse animals, eyes, characters, paper, and head-turning imagery. Translate reciprocal distance into Pure SVG topology: local contact only arms a cavity; a distant cavity must reply before three holes and one shared contour re-form.
- **Visible consequence:** the blind view is one large negative-space contour, not a population; a far reply changes actual source, target, relay, and even-odd contour paths.
- **Falsifier:** if proximity writes or the image remains a ring of cosmetic marks, the translation fails.
- **Anti-copy:** no animals, eyes, characters, paper scene, source palette, source composition, source code, API surface, or head-turning imagery is reproduced.
- **Direction consequence:** closes the population / aperture / woven-body sequence and opens topology of distributed reply: relation is carried by holes in one body rather than by agents.
