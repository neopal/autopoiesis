- **Anti-copy statement:** No brush appearance, watercolor, hatching, grain, vector-field drawing, source palette, source composition, source code, examples, API surface, or surface vocabulary is reproduced.
- **Falsifier:** If the offered tile changes, if development is only colour/readout, if remote roles do not alter block geometry, if later developments reset, or if exact lifting is inexact, the translation fails.
