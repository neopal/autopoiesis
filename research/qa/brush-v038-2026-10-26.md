## Artistic direction

- **Changed rule:** The first seam choice is geometry-neutral. A second non-adjacent seam creates an interval of pressure that peels one lamina, seals another, and sheds a third; the pair is not copied as a mark.
- **Structural rupture:** v037's local Canvas incision/drying, v036's WebGL fault–vent–exit, and v035's directional membrane are abandoned. v038 changes the medium to browser-native DOM/CSS, the composition to nine overlapping skins, the encounter to a paired seam choice, and the memory model to layer-order change.
- **Cultural reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** Programmable pressure, density, and directional behaviour participate in producing geometry rather than merely styling a finished mark.
- **Translated mechanism:** Pressure becomes a relation between two boundaries in a DOM/CSS lamina stack; the interval changes future layer geometry.
- **Anti-copy:** No brush appearance, watercolor, hatching, grain, vector-field marks, source palette, composition, code, examples, API surface, or surface vocabulary is reproduced.
- **Falsifier:** Delete if one seam commits, if the pair is a copied line, if peel/seal/shed are cosmetic, if the stack reads as a control grid, if later spans reset, or if lifting is inexact.
