# Perceptual critique — Handwriting v002

## Observation

The first review found a generic route diagram: red rings named failure, but the later route did not visibly earn its memory. The first-viewport recomposition improved the encounter, but did not solve that perceptual gap by itself.

## Falsifiable move applied

The deterministic engine now preserves each route's pre-memory `draftPoints`. When a later route is actually influenced by an inherited scar, the canvas draws the refused draft as a red dashed counter-path from the pressure segment onward, then draws the darker remembered detour above it. Routes without memory influence do not receive this counter-path.

The move is deliberately not a new visitor control. It exposes a counterfactual already present in the authored process.

## Independent perceptual verdict

- **Strength accepted:** the red dashed draft beside the darker detour makes the relation between refusal and revision visible without relying only on the annotation prose.
- **Failure retained:** the field still reads as a network of straight polyline routes. The red counter-path can become diagram notation instead of handwriting if later stages do not acquire a more singular, less linear form.
- **Decision:** **CHANGE**, not DELETE. Keep the scar mechanism because the adversarial deletion test still changes later geometry and the counter-path gives that causal difference a visible form.
- **Next falsifier:** a later review must be able to identify a scar-shaped detour from the image alone. If the red draft and darker detour cannot be distinguished without reading `ANNOTATIONS / V002`, change the route grammar again rather than adding more labels or red marks.

## Scope boundary

This is a perceptual decision, not a promotion decision. Handwriting v002 remains a candidate autonomous study under critique; it is not declared a finished work or a new period.
