## Changed rule

v019 breaks the last three portrait grammars: v016's raster witness transfer, v017's ordered aperture/refusal, and v018's browser-native serial pressure register. It switches to one inline SVG syntax seal made of nine actual clauses. Tab/arrow attention arms a clause without writing history; Enter, Space, or the control commits a grammatical event that changes actual SVG path geometry: the addressed clause splits and a non-adjacent clause welds the reply. Bounded clause debt changes the next reply choice. Delete lifts only the latest event and reconstructs the exact preceding seal.

## Cultural translation

Reference: [little-critters](https://github.com/GordenSun/little-critters)

- **Observed mechanism:** situated code-drawn agents respond to pointer proximity by changing attention and looking back; local behaviour creates a reciprocal encounter and a memory of being seen.
- **Mutine translation:** refuse animals and look-back. Keyboard attention addresses one clause in a singular syntax seal; commitment splits its SVG path and makes a non-adjacent clause weld a reply. Clause debt changes the next reply.
- **Visible consequence:** the blind first field is one irregular syntax seal, not a face, aperture, raster, membrane, register, or agent crowd. After attention, an actual local notch and distant reply form are visible in the paths.
- **Falsifier:** if the split is an overlay, the remote reply is only a tint, repeated attention ignores clause debt, pointer input commits, or the blind image reads as a generic emblem, the translation fails.
- **Anti-copy:** no animals, eyes, characters, paper scenes, palettes, compositions, or head-turning surface vocabulary are reproduced.
- **Direction consequence:** closes the serial material-register direction and opens syntax-as-self-observation: a portrait as a grammar that can answer itself.

## Radical and perceptual gate

The primary rupture is a medium and encounter switch: serial DOM strands / pointer-independent pressure become one inline SVG syntax seal / keyboard focus followed by discrete grammatical commitment. The first blind view changes representation, composition, shape vocabulary, and viewer task. The deletion condition is to remove v019 if a caption-free comparison cannot find the local split and non-adjacent reply in the seal itself, or if keyboard focus behaves as a cosmetic selector.
