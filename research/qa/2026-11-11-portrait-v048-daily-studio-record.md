## Concept and rupture

The last three portrait works (`v045` loop compiler, `v046` margin compiler, `v047` counterpressure profile) all made a held gesture compile a self-contained image. v048 changes the encounter: arrival is geometry-neutral. A visitor must pass through three distinct threshold witnesses and then depart toward another threshold. Only that departure globally re-produces the raster body, re-poses all seven witnesses, and opens a destination-out cut where no touch landed.

- **Representation:** SVG/DOM/WEBGL portrait grammars → p5.js 1.11.3 Canvas 2D raster compositing.
- **Composition:** loop, margins, and rib profile → one broad asymmetrical body surrounded by seven threshold marks.
- **Viewer task:** draw/compile/reverse → move through situated thresholds and leave.
- **Temporal rule:** presence held inert until departure spends the route; four departures compound and remain liftable.
- **Falsifier:** delete if arrival changes geometry, one station responds locally, departure is only a trail, memory resets, or exact lifting fails.
- **Deletion condition:** delete v048 if caption-free viewing still reads as a profile, line lattice, or dashboard rather than a body made by reciprocal departure.

## Cultural translation

- **Reference:** [little-critters](https://github.com/GordenSun/little-critters)
- **Observed mechanism:** situated agents make proximity legible as reciprocal attention without a dashboard.
- **Mutine translation:** refuse animals, faces, head-turning, and source surface vocabulary; translate reciprocity into a departure rule. Presence notices remain geometry-neutral, while leaving after three distinct threshold contacts re-produces the whole raster body and opens an absence in the interval rather than at the touched site.
- **Visible consequence:** the first view is a broad luminous body in a dark field with seven quiet threshold marks; a valid departure changes all body points and witness stances and opens a real internal cut.
- **Anti-copy:** no animals, faces, character design, paper style, source palette, source composition, source code, examples, API surface, or source imagery is reproduced.
- **Direction consequence:** closes the loop-compiler / margin-compiler / counterpressure-profile sequence and opens reciprocal departure as a new portrait grammar.
