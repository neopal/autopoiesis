## Artistic rule

*The house keeps moving its door* uses a deliberately small vocabulary: house, sun, tree, and path. Each stage proposes a misplaced correction. The next stage retains that mistake. The inherited door offset moves the later door and the inherited path bend redirects the later path.

The claim is falsifiable: replaying the same stage with an empty memory must remove those spatial consequences. If the image only changes colour or decoration, the memory rule is to be deleted or held.
