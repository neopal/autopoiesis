## Creative direction

The last three Naive works used a faceted WebGL plane theatre (v024), a dense pressure sheet (v025), and dispersed SVG witness apertures (v026). v027 makes a medium, representation, and encounter rupture: it abandons the p5/WebGL/SVG field for one browser-native DOM/CSS registration object and replaces direct choice or pressure with a drawn closure threshold.

Eight layered ink plates form one misregistered print. Pointerdown only arms the correction. A sufficiently long loop that returns near its start shifts the whole print and widens a non-local void; open and short loops are refused. Four corrections remain in bounded memory; `Delete` lifts the latest correction exactly and `R` releases the register.

## Cultural translation

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** Pressure, density, grain, and directional fields participate in producing geometry rather than decorating finished geometry.
- **Mutine translation:** Refuse brushes, marks, watercolor, hatching, and the source surface. Translate material pressure into registration debt: a closed correction loop makes one layered DOM print slip as a body while a distant plate receives the wrong opening.
- **Visible consequence:** The blind field is one oversized layered print object, not a witness population or pressure sheet. After a committed loop the whole silhouette drifts and a remote CSS void changes; later loops inherit the misregistered stack.
- **Falsifier:** If an open loop writes, if the endpoint directly chooses the seam, if only a readout or cursor changes, if the remote void is cosmetic, if later corrections restart from baseline, or if the blind field reads as a generic card stack, the translation fails.
- **Anti-copy:** No p5.brush brushes, watercolor appearance, hatching vocabulary, source palette, source composition, examples, or API surface is reproduced.
- **Direction consequence:** Closes the Naive field-of-apertures sequence and opens a registration-error direction in which correction cannot stay local to one material body.
