## Artistic direction

- **Changed rule:** A bounded pressure stroke is refused as a visible trace. Its length, turn, and direction change how one continuous memory plate is produced: the source compresses, a remote contour becomes too certain, another place opens as absence, and a fourth ridge remembers.
- **Cultural reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** Pressure, density, directional behaviour, and fields participate in producing geometry rather than merely styling a completed mark.
- **Mutine translation:** Refuse brush appearance and surface vocabulary. Make pressure alter the naive model's future geometry, then make the model infer the wrong edge remotely.
- **Visible consequence:** The blind view is one continuous off-axis plate with an unresolved aperture. After a valid stroke, the gesture disappears; source compression, remote false contour, separate absence, remembering ridge, and aperture relocation remain in actual rendered geometry.
- **Anti-copy:** No brush appearance, watercolor, hatching, grain, palette, composition, source code, example, API, or surface vocabulary was reproduced.
- **Direction consequence:** v035 closes the recent discrete witness / relief / inheritance sequence and opens `pressure-misread`: naive art tests model failure as continuous negative-field inference.

## Radical progression gate

The last three naive records repeated a situated look/witness/path gesture, discrete model units, non-local reconstruction, and a four-event reversible archive. v035 breaks that grammar in five visible dimensions:

- discrete relief / glyph / tree → one continuous plate with one movable aperture;
- hold / witness / route → bounded pressure drawing whose trace is refused;
- local attention → remote false contour and separate absence;
- model parts → continuous negative field;
- WebGL / Canvas proof / DOM tree → layered Canvas 2D material and ink buffers.

The falsifier is not a caption: if the blind view reads as a generic linefield, waveform, route, relief, or UI, the direction is deleted.
