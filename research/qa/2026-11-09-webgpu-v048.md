## Artistic direction

v048 is a material-topology rupture against the last three WebGPU works:

- v045: broad stratigraphic mass / sustained load;
- v046: diagonal folded ledger / refused cadence;
- v047: asymmetrical absence arch / social gaze.

The new rule is a **continuous pressure shell**. Pressure is not drawn onto a
finished image: it must travel from the lit source port to its deterministic
exit. That route re-produces the whole faceted surface and hands the exit to the
next route as its only valid source. This changes representation (one continuous
surface instead of discrete bodies), composition (open oblique shell), encounter
(two-point pressure travel), temporal memory (source handoff), and medium
(generated WebGL surface mesh).

The selected cultural reference is [p5.brush](https://github.com/acamposuribe/p5.brush).
Its observed mechanism is that pressure, density, direction, fills, and fields
participate in producing geometry. Mutine translates only that causal mechanism
into a stateful pressure route and refuses brush presets, watercolor, hatching,
grain, palette, composition, source code, examples, API surface, and imagery.

## Art gate

- Hypothesis: a valid route will globally change curvature, depth, torsion, facet pressure, and seam lift; wrong origins/exits remain exact.
- Visible consequence: one dark continuous faceted shell, five edge ports, raised route seams, and a source that migrates to the last exit.
- Falsifier: delete if route changes are cosmetic, any port can start the next event, wrong exits commit, memory resets, or the blind work reads as a generic mesh demo.
- Deletion condition: delete if caption-free viewing cannot distinguish v048 from v045–v047 without explanatory prose.
