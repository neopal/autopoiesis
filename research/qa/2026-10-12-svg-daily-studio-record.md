## Concept and radical progression

The last three real Pure SVG records were v026's dispersed polygon choir, v027's continuous slip strata, and v028's standing aperture plates. Their repeated gesture was a single place/event changing a set of vector bodies after attention, pressure, or departure; their repeated metaphor was distributed absence; their visual grammar was an arranged population of independent bodies with a one-step relay.

v029 breaks that invariant in four visible ways:

1. **Composition:** nine irregular compound bodies overlap into one woven cluster around a quiet centre rather than an array, field of rows, or dispersed constellation.
2. **Interaction:** the first place is deliberately non-causal. A second, distant place must answer it; a same-place answer is refused.
3. **Temporal state:** the work holds a pending offer before it can enter memory. Only the two-place transaction becomes a fusion; later pairs inherit the altered field.
4. **Shape vocabulary:** actual even-odd compound SVG paths are re-formed as source, target, and remote relay bodies; no cursor, label, or thread is the carrier of the rule.

## Cultural translation

- **Reference:** [little-critters](https://github.com/GordenSun/little-critters).
- **Observed mechanism:** a situated population responds to pointer proximity with legible attention and reciprocal looking, making the visitor part of a social field without a dashboard. The repository's description and rendered source identify proximity-driven head-turning attention as the operative mechanism.
- **Mutine translation:** invert v028's looking-away departure. A solitary place can only be offered and cannot write; a second non-local place must answer before the seam fuses, changing source, target, and relay bodies. The relation is carried by distance and refusal, not by figures or eyes.
- **Visible consequence:** the blind first render is one woven cluster of nine irregular SVG bodies around a dark centre. The first place leaves the geometry exact; a distant answer changes three actual compound paths, and later answers inherit those changed shapes.
- **Falsifier:** if the first place writes, if a same-place answer commits, if the second place only changes colour or a marker, if only one body changes, if later pairs restart from baseline, or if the blind cluster reads as a generic diagram, the translation fails.
- **Anti-copy:** no animals, characters, eyes, paper scene, source palette, source composition, source code, API surface, or head-turning imagery is reproduced.
- **Direction consequence:** closes Pure SVG's dispersed-population / strata / aperture-array sequence and opens a two-place boundary-negotiation direction: topology is an offer held open until another place answers.

## Art gate

- **Changed rule:** one place arms without writing; only a second non-local place fuses the seam and re-forms a remote relay.
- **Deterministic state:** seed `0x53564729`, nine bodies, four-event memory window, exact replay and lift/release operations.
- **Meaningful interaction:** pointer two-place offer/answer, same-place refusal, keyboard Enter twice / Delete / Escape-R, and equivalent controls.
- **Falsifier and deletion condition:** delete v029 if it reads as a decorative radial diagram, if one place writes, if same-place contact commits, if the relay is cosmetic, if later pairs forget prior fusions, or if exact lifting fails.
