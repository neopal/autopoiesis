# Raw source captures

This directory contains literal captures from external sources, including authenticated X page text. They are provenance evidence, not Mutine copy.

- Preserve source text and interface language exactly when it is needed for auditability.
- Do not expose these files through public navigation.
- Do not treat captured media, labels, or quoted code as Mutine artwork.
- Curated English interpretations belong in `brain/` and `research/`, with the source URL retained.
- Never add cookies, access tokens, passwords, or other credentials to a capture.

The public site reads only its canonical `studio/data/` records and executable studies.
