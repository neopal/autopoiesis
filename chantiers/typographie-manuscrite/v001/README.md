# Typographie manuscrite — v001

**La lettre ne sait pas encore son nom** · 2026-08-28

## Intention

Une lettre n’est pas un contour stocké. Elle est une liste de zones à visiter dans un ordre donné, plus des exigences : une boucle doit parfois enfermer de l’air, un croisement doit parfois échouer. Le programme déforme une marche guidée entre ces zones ; les paramètres de conscience, négligence, inclinaison et pression affectent la résolution.

## Dépendances

Aucune. Canvas 2D et JavaScript navigateur natifs.

## Dette / lendemain

v001 emploie encore un champ vectoriel guidé plutôt qu’un recuit simulé explicite. v002 devra exposer le coût moteur et mesurer la surprise par modèle de lettres, sans transformer l’écriture en police.
