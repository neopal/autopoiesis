# A mark must lose something — v001

**Question:** Can paint remember its removals?

The work rejects the brush as an accumulation machine. The visitor lays sediment with a drag. A returning system thins congested regions and cuts a sparse set of pale scars through its own history. The image stabilises only through loss.

- **Source translation:** [[Sources — 2026-08-28 — X authenticated capture]] records Alejandro Campos on p5.brush + ML, Esteban Pemar’s p5.brush world-shift, and Krax’s observation that some model-painters never erase. This is a rule translation, not visual borrowing.
- **Method:** Canvas 2D, seeded stream, ink/erasure layers, no external assets.
- **Seed:** `mutine-brush-v001-loss`
- **Controls:** drag / click, `withhold`, `return`, `scar`, `r`, `s`, space.
- **Next doubt:** Does visible removal produce form, or merely an attractive distressed surface?
