# v051 — The ring forgets its pressure.

## Hypothesis

If material treats pressure as a phase condition rather than a drawing command, a held rim pulse should only be able to re-produce the ring when the visitor releases inside a quiet interval. The first-render image should be one radial body whose segments and central aperture can change without ever storing the hand path.

## Radical progression gate

The last three Brush works repeat a surface-and-response grammar: v048 is a full-field wash that sends a completed passage to a remote bloom, v049 is an upright folded sheet opened by a held chord, and v050 is a compact relief that keeps a reversible cut. Their repeated gesture is route, hold, or return; their metaphor is matter retaining a hand event as a produced deformation; their visual grammar is wash, sheet, or relief.

v051 breaks that run in six visible ways: the field/sheet/relief becomes one radial material ring; a path becomes a timed rim pulse; pressure no longer leaves a trace or removes a cut but changes a phase condition; the viewer must release at the right time rather than complete a spatial route; the accepted event re-produces the ring's actual segments and aperture; and the memory is a discrete phase-slip sequence rather than a scar or remote answer. The timing is material logic, not interface decoration.

## Changed rule

Pressure is inert until it reaches a deterministic quiet window. Press one of four rim sites, wait at least 240ms, and release between phase `0.34` and `0.49` of a one-second cycle. A short or mistimed release reconstructs the exact prior ring. A valid pulse changes segment inner/outer radii, width, skew, core radius, core skew, and central aperture. Four phase slips compound and remain liftable.

## Visible consequence

The blind first view is a dark, warm radial ring made from twelve unequal produced segments around a central opening. After a valid pulse, the body is not recoloured: selected and neighbouring segments are re-produced, and the central aperture grows or tightens. The hand path is absent. Four accepted slips remain visible as cumulative geometry.

## Cultural translation

The selected cultural reference is `p5-brush` (https://github.com/acamposuribe/p5.brush). Its observed mechanism is that pressure, density, directional behaviour, and vector fields participate in producing geometry rather than decorating a finished mark. Mutine translates that mechanism into a phase lock: pressure does not draw; the *release time* decides whether the ring is allowed to re-produce its geometry. The source's brush surface, watercolor, hatching, grain, palette, composition, code, and API are refused.

## Anti-copy boundary

No p5.brush brush preset, watercolor appearance, hatching vocabulary, grain treatment, source palette, source composition, source code, examples, API surface, or source imagery is reproduced. The work uses p5.js Canvas 2D, an abstract radial ring, a timed state machine, and generated segment geometry in Mutine's own vocabulary.

## Interaction

- Pointer/touch: press near one of four rim sites, wait roughly 420ms, and release.
- A short or mistimed release is refused without changing the material geometry.
- ArrowUp / ArrowRight / ArrowDown / ArrowLeft selects a rim site; Enter / Space performs the same deterministic phase pulse.
- Delete / Backspace lifts the latest phase slip.
- Escape / R / “release the ring” returns the exact quiet seed.
- S saves a PNG.

## Falsifier

Delete v051 if a short or mistimed pulse changes the body, if only colour/readout moves, if the segment and aperture geometry remain unchanged, if later slips reset earlier ones, if lifting is inexact, or if the caption-free ring reads as a generic radial diagram or another version of the recent wash/sheet/relief grammar.

## Deletion condition

Delete the trial if timing is only explanatory prose; if the first-render ring cannot carry its own material grammar without controls; or if the work is merely a radial recolouring of v048–v050 rather than a new temporal encounter.

## Direction consequence

This closes Brush's recent passage / chord / subtraction sequence and opens a phase-material direction: paint can refuse a hand until time itself becomes the production condition. It abandons the stable expectation that a completed gesture is enough.
