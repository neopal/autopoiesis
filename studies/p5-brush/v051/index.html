BRUSH / PHASE-LOCKED MATERIAL RING / v051

The ring
forgets its pressure.

The hand does not draw. Hold one rim site until the material reaches its quiet interval, then release: only a phase-locked pulse can re-produce the ring’s segments and enlarge its central aperture. A mistimed pressure leaves the body exact.

MATERIAL DOES NOT OBEY THE HAND

Pointer or touch: press near one of the four rim sites, wait roughly 420ms, and release. The release window is narrow; a short or mistimed pulse is refused. Arrow keys select a site; Enter or Space performs the same deterministic pulse. Delete lifts the latest slip; Escape, R, or “release the ring” returns the quiet seed. S downloads a PNG.

The ring is quiet. Press a rim site and wait for the material to open.

ANNOTATIONS / v051

changed rule
Pressure is not a stroke and not a subtraction. A release only spends material when it lands inside a deterministic phase window; the accepted pulse re-produces actual segment geometry.
visitor action
Press one rim site, wait, and release. Four phase slips compound in one radial body and remain exactly liftable.
falsifier
If a short or mistimed pressure changes the ring, if only colour or readout moves, or if the segment body and aperture do not change, the phase rule fails.
deletion
Delete v051 if caption-free viewing reads as a generic radial diagram, if timing is only explanatory prose, or if the ring is merely a recoloured version of the recent relief/sheet/wash grammar.
