# Brush v016 — pressure cut

## Status

**Candidate / held.** This is the 2026-09-22 daily tableau for the Brush current. It remains held until a caption-free comparison confirms that the plate reads as a pressure-shaped material object rather than another route field with a new texture.

## Hypothesis

If paint remembers a removal materially, the removal should alter the ontology of the surface: it should make an incision that lifts nearby matter and displaces a ridge, not merely bend a line around an absence.

## Changed rule

v016 abandons the previous horizontal wet-route grammar of seam → wake → tide mark → basin. A visitor pressure path cuts a bounded tiled plate. Cells near the cut pivot to either side, lift by different amounts, change their grain and pigment load, and gather into a raised displaced ridge. The memory is the changed plate state, not a witness painted above it.

## Visible consequence

The first blind encounter is a singular plate/object with a finite incision, two lifted banks, and a displaced ridge. The plate no longer presents a set of continuous routes. After a drag, the cut changes cell angle, lift, grain, edge, and pigment across its neighborhood; the latest lift restores the exact previous plate.

## Interaction and reversibility

Drag across the plate to make one pressure cut. Path length and supplied pressure alter the width and displacement. Enter/Space makes a deterministic keyboard cut, Delete/Backspace lifts only the latest cut, and `release sequence` clears visitor memory and restarts the autonomous sequence. The engine is pure and seeded.

## Cultural translation

- **Reference:** `p5-brush` / p5.brush.
- **Observed mechanism:** programmable material tools make pressure, grain, density, and directional fields alter how geometry is produced rather than being a skin applied after geometry.
- **Mutine translation:** pressure is promoted from a stroke attribute to a topological event: it cuts a plate, changes both banks, and forces displaced material to become a ridge.
- **Falsifier:** if the plate remains a grid with a dark line on top, or if cells do not change angle, lift, grain, and pigment, the material rule is not embodied.
- **Anti-copy:** no p5.brush brushes, watercolor appearance, hatching vocabulary, palette, or API surface is reproduced.
- **Direction consequence:** this closes the Brush current's continuous route-memory grammar and opens a cut-object grammar: pressure, fracture, lifted matter, and a viewer who draws an incision rather than places a point event.

## Falsifier

If the cut only changes colour, if the displaced ridge has no relation to the path, if the two banks do not materially lift or pivot, or if lifting the latest cut fails to reproduce the exact prior cell field, v016 is a decorative diagram.
