# Mutine Brush v054 — The pigment changes hands.

## Hypothesis

A material engine can refuse the surface entirely. If pigment exists as detached deposits, a complete pressure relay should transfer the production rule through every deposit rather than preserve a local stroke.

## Changed rule

Pressure is inert when it is local, straight, weak, or returned to the same seam. A bent relay between two different outer seams re-produces all nine detached deposits and stores the transfer as ordered memory. The hand path disappears; the material relation remains distributed.

## Visible consequence

The first-render blind view is a broken constellation of nine separate SVG pigment deposits, not a ring, relief, vacancy register, or continuous membrane. A valid relay moves, tilts, and re-scales every deposit and leaves a produced relay seam behind them. Four relays compound; reversing their order changes the ledger.

## Interaction

Pointer or touch begins near one outer seam, bends through the field, and releases near a different seam. The deterministic relay button, Enter, and Space provide equivalent non-hover paths. ArrowLeft and ArrowRight choose the relay. Delete lifts the latest transfer. Escape, R, or the release button returns to the quiet ledger. S exports the generated SVG.

## Falsifier

The direction fails if a same-seam, weak, or straight gesture commits; if only a line, colour, readout, or selection changes; if all nine deposits do not change; if relay order is cosmetic; or if lifting cannot restore the exact preceding ledger.

## Deletion condition

Delete v054 if caption-free viewing reads as a target diagram or decorative scatter, if the detached deposits do not visibly carry the transfer, if the relay line is the only evidence, or if the medium switch from Canvas 2D to inline SVG does not change the encounter.

## Cultural translation

- **Reference:** p5.brush — https://github.com/acamposuribe/p5.brush
- **Observed mechanism:** Programmable pressure, density, direction, fill, and vector-field behaviour change how geometry is produced; material is an engine rather than a surface skin.
- **Mutine translation:** Refuse brush presets and visible brush simulation. Make a bent pressure relay between different seams transfer the production rule through every detached deposit; the relay is not a mark but a distributed change of manufacture.
- **Anti-copy:** No p5.brush preset, watercolor appearance, hatching vocabulary, grain treatment, source palette, source composition, source code, examples, API names, or source imagery is reproduced.
- **Direction consequence:** v054 abandons v051's phase-locked ring, v052's vacancy register, and v053's continuous membrane. It opens a detached-material period in which Brush tests whether matter can answer from pieces that never shared a surface.
