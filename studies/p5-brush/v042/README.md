# Brush v042 — The paint cures around the held breath.

## Hypothesis

If duration is treated as material pressure instead of as animation timing, a painting can refuse a passing touch and still remember a bounded dwell as a change in how its raster is produced.

## Changed rule

v042 abandons v041's oblique relief membrane, v040's suspended fragments, and v039's SVG wound. A visitor must dwell inside a bounded time window at one material well. The held well stays geometry-neutral; an accepted dwell produces three remote roles in a single raster cure plate: one zone seals, one fractures, and one bleeds. The raster is rebuilt from deterministic memory after every event.

## Visible consequence

The first blind view is a flat, irregular pigment plate rather than a 3D surface, contour field, or fragment archive. A valid dwell changes actual cell mass, dryness, fracture, and bleed away from the held place. Four cures compound and can be lifted in exact reverse order.

## Interaction

- Pointer/touch: press and hold near a material well; release after the plate accepts the dwell.
- Too short, too long, or off-well: refuse without geometry change.
- `Enter` / `Space`: deterministic accepted dwell.
- `Delete` / `Backspace`: lift the latest cure.
- `Escape` / `R`: release the plate to the quiet seed.
- `S`: save a PNG.

## Falsifier

Delete this direction if a passing touch mutates the plate, if the accepted time window is cosmetic, if the held well changes, if remote roles are only colour or readout, or if later cures reset rather than inherit the altered raster.

## Deletion condition

Delete v042 if caption-free viewing reads as a generic heatmap, terrain, pixel field, or decorative texture, or if duration does not materially change the raster plate's production.

## Cultural translation

The selected p5.brush mechanism is that pressure, density, and fields participate in producing geometry rather than decorating a finished mark. Mutine refuses the library's brush appearance, watercolor, hatching, grain, palette, composition, code, examples, and API surface. It translates material production into a time threshold: held pressure changes future raster production elsewhere.

## Direction consequence

This closes Brush's recent relief / settling / wound vocabulary and opens a phase-change direction: matter is tested through duration, bounded refusal, and a flat raster whose later cells inherit earlier cure events. The new direction is not a new period yet; it needs a connected second experiment and a retrospective before it can be named as one.
