# Brush v038 — The paint opens between layers.

## Hypothesis

If pressure is treated as an interval between material boundaries rather than as a mark, the work should make a gap that changes the order of its skins. The viewer's chosen boundaries should remain only the conditions; the stack should produce the visible peel.

## Changed rule

The last three Brush works repeatedly used a pointer route, a local stroke, or a reversal that still behaved like a continuous pressure gesture. v038 changes the encounter and medium. It is a browser-native DOM/CSS stack of nine irregular laminae. The first seam choice is geometry-neutral. A second, non-adjacent seam creates a pressure span: one layer peels outward, one seals inward, and a third sheds its underside. The pair is not copied into a line.

## Visible consequence

The blind first view is a tilted stack of separate, overlapping material skins around an open interior, not a Canvas sheet, WebGL slab, membrane, or field of chambers. After a valid span, a lamina visibly lifts and rotates, a second closes its cut, a third opens its underside, and the seam pressure remains in later layer geometry. Four pressure spans remain replayable and liftable.

## Interaction

- Choose one seam node; the stack stays geometrically still.
- Choose a non-adjacent second seam; the interval commits a peel, seal, and shed.
- Same or adjacent seams refuse.
- Enter, Space, and `pinch interval` use the deterministic pair.
- Delete or `lift latest` reconstructs the preceding stack.
- Escape, `R`, or `release layers` clears the bounded pressure ledger.
- `S` downloads the current HTML surface.

## Cultural translation

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** programmable drawing tools make pressure, density, and directional behavior part of the production engine; the instrument changes how geometry is produced, rather than merely styling a finished mark.
- **Mutine translation:** refuse brushes, watercolor, hatching, grain, vector-field marks, and the source API. Translate the production logic into a paired seam interval: pressure exists between two boundaries and changes the future order of a DOM/CSS lamina stack.
- **Visible consequence:** the first encounter is a layered cut surface. A committed pair changes actual clip paths, layer positions, rotations, openings, and seals; the chosen pair itself is not rendered as a trace.
- **Falsifier:** if one seam commits, if a seam is copied as a line, if only colour or labels change, if the layer roles do not persist, if the field reads as a control grid, or if lifting is inexact, the translation fails.
- **Anti-copy:** no brush appearance, watercolor, hatching, grain, vector-field drawing, source palette, source composition, source code, examples, API surface, or surface vocabulary is reproduced.
- **Direction consequence:** this closes Brush's crease-sheet / eclipse-slab / reversal-membrane sequence and opens interval-pressure: erasure becomes a relation between boundaries, and the browser's DOM/CSS geometry becomes the material medium.

## Radical progression gate

The last three real Brush records were v037's local Canvas incision and drying, v036's WebGL fault–vent–exit, and v035's directional reversal membrane. Their repeated gesture was pressure delivered as a path, route, or direction; their repeated metaphor was a surface that changes after an input; their visual grammar was one continuous body or slab. v038 refuses the path, replaces it with a paired boundary choice, replaces the continuous body with an overlapping stack, and changes the medium to browser-native DOM/CSS. The new state machine is `quiet → first boundary held → interval committed → lifted/released`, and the visible consequence is a layer-order event rather than a trace, remote role, or drying frontier.

## Falsifier

The translation fails if selecting the first seam changes geometry, if adjacent seams behave like valid intervals, if the pressure span is represented only by a line or glow, if peel/seal/shed are only readout roles, if the next span rebuilds from a quiet seed, or if exact lifting fails.

## Deletion condition

Delete v038 if caption-free viewing cannot show separate material skins and a real interval opening, or if it reads as a decorated menu, generic card grid, or reskinned crease sheet.

## Critique status
