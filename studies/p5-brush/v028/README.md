# Brush v028 — The paint remembers the edge.

## Hypothesis
If material agency can remember removal, a mending gesture should not restore a previous image. It should close one wound in the producing body and make another edge carry the missing absence.

## Changed rule
v027 inverted pressure into a subtractive population law: a scrape fractured detached islands and returned residue elsewhere. v028 inverts that inversion. The field is one continuous SVG reservoir with nine actual wound apertures. A freehand mend offers a route, but resistance chooses which aperture can seal; the saved edge reappears as a non-local opening. The bounded topology remembers four mends.

## Visible consequence
The blind first render is one overlapping painted reservoir, not a population of islands or a cell slab. The wounds are holes in actual compound SVG paths. After a mend, one aperture visibly contracts while a non-local aperture expands and the surrounding bodies shift. The gesture line disappears after release.

## Interaction
Drag between two areas and release to commit a mend. A short tap is refused. Enter, Space, and the mend control use deterministic paths. Delete or “lift latest” reconstructs the exact preceding topology. `R` releases the bounded memory. `S` exports the SVG field.

## Cultural translation
- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** pressure, density, grain, and directional fields are programmable material forces that participate in producing geometry rather than decorating finished geometry.
- **Mutine translation:** invert the previous subtractive population: a mend closes one actual wound and reroutes the missing edge into a non-local opening. Material memory is topology transfer, not a painted surface.
- **Visible consequence:** a continuous reservoir changes its wound geometry after interaction; one hole closes, another opens, and later gestures act on the changed body.
- **Anti-copy:** no p5.brush brushes, watercolor appearance, hatching vocabulary, source palette, composition, examples, or API surface are reproduced.

## Repeated grammar refused
The previous three Brush works were a load-bearing membrane hinge (`v025`), a global threshold slab (`v026`), and a detached-island scrape (`v027`). Their common gesture was a visitor point/path acting on a field by deforming or separating visible material. v028 changes medium from Canvas to semantic SVG, changes representation from field/population to one wound-bearing reservoir, and changes encounter from subtracting to mending with non-local topological debt.

## Falsifier
The translation fails if the pointer directly picks the wound, if the interaction only changes a readout or colour, if no actual aperture closes and opens elsewhere, if later mends restart from baseline, or if the blind field reads as a generic contour chart.

## Deletion condition
Delete v028 if labels-off and controls-off viewing cannot show one continuous reservoir with actual wounds, if the wounds are ornamental overlays rather than path holes, if the non-local aperture does not change, or if lifting the latest mend does not reconstruct the exact preceding topology.
