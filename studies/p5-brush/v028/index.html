A mend does not restore a picture. It closes one wound and makes another place carry the missing edge.

MENDING IS A TRANSFER

Drag through the reservoir and release. The gesture offers a route, but the material chooses which wound can close. Its saved edge reappears elsewhere as a new aperture. Later mends act on this changed topology; Delete or “lift latest” reconstructs the exact preceding wounds.

The reservoir is holding its edges.

ANNOTATIONS / v028

changed rule
Invert v027’s scrape: a freehand mending gesture does not fracture a population. It closes one actual SVG aperture selected by material resistance and opens a non-local wound, carrying the missing edge forward.
visitor action
Drag from one wound toward another and release. Enter, Space, and the mend control use deterministic paths. Delete lifts only the latest mend. R releases bounded memory. S exports the SVG field.
falsifier
If the gesture directly picks the wound, if only a counter or colour changes, if no actual aperture closes and opens elsewhere, or if later mends forget the changed topology, the rule is absent.
deletion
Delete v028 if labels-off and controls-off viewing reads as a generic contour chart, if the wounds are only ornaments, or if lifting the latest mend fails to restore the exact preceding topology.
