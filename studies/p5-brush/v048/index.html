BRUSH / REMOTE REGROWTH WASH / v048

The wash grows
where it was not touched.

A pressure stroke enters the sheet, passes three hidden thresholds, and leaves no scar. The removed force is re-made as a new bloom at a place the hand never reached.

THE GESTURE IS NOT THE MARK

Press near the first gate and drag through the next two, then leave the wash. The provisional route is only a test: on release it disappears. A remote bloom gains actual width, fold, and edge geometry. Pointer, touch, ArrowRight three times then Enter, or “press through the wash” offer equivalent paths. Delete lifts the latest regrowth; Escape, R, or “release the sheet” returns the quiet seed. S downloads a PNG.

The sheet is quiet. Pressure must enter at the first gate.

ANNOTATIONS / v048

changed rule
Abandon islands, clasp, and through-void passage. A stroke is only a pressure probe. If it crosses three gates in order and exits, the route vanishes and an untouched bloom regrows elsewhere.
visitor action
Enter at the first gate, cross the middle gate, cross the last gate, then leave the sheet. Empty ground, wrong order, and incomplete pressure refuse to spend material.
falsifier
If the gesture leaves a local scar, if a gate changes, if the response is only a halo or readout, if every stroke regrows the same bloom, or if later regrowths forget earlier ones, the rule fails.
deletion
Delete v048 if the blind wash reads as another field of islands or a route diagram, if the pressure sequence is only a button label, or if exact lifting fails.
