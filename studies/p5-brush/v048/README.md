# v048 — The wash grows where it was not touched.

## Hypothesis
If a brush treats pressure as a production rule rather than a mark, a complete pressure passage can disappear at release while the wash re-makes the removed force as a new bloom elsewhere. The first-render image should read as one continuous, layered wash before it reads as a route or interaction diagram.

## Changed rule
Abandon v045's opposing clasp, v046's through-void passage, and v047's field of pigment islands. A stroke is only a pressure probe: it must enter the first gate, cross three pressure gates in order, and leave the sheet. The provisional route is not remembered. Only then does an untouched remote bloom change its width, fold, and edge geometry. Four remote regrowths compound and remain liftable.

## Visible consequence
The blind first view is a dark, continuous wash built from nine broad generated bands, grain, and eight irregular blooms. A valid stroke leaves the bands, gates, and gesture site exact. At a remote bloom, actual silhouette width, fold, edge, and internal petal structure change. The pressure is remembered as produced geometry, not as a cursor trail, label, or colour-only state.

## Cultural translation
The selected cultural reference is `p5-brush` (https://github.com/acamposuribe/p5.brush). Its observed mechanism is that pressure, density, direction, and fields are programmable material rules that change how geometry is produced. Mutine translates that mechanism into a gate-conditioned remote regrowth law: the gesture is tested and then erased; an untouched bloom is the place where material is re-produced. No p5.brush brush presets, watercolor appearance, hatching vocabulary, grain treatment, palette, composition, source code, examples, API surface, or source imagery is reproduced.

## Anti-copy boundary

The source mechanism is translated, not imitated: no p5.brush brush presets, watercolor appearance, hatching vocabulary, grain treatment, palette, composition, source code, examples, API surface, or source imagery is reproduced.

## Interaction
Press near the first faint gate and drag through the next two gates, then leave the wash. Pointer and touch use the same ordered stroke state. ArrowRight three times then Enter supplies the keyboard route; the `press through the wash` control supplies an equivalent deterministic event. Wrong order, empty ground, or an early release refuses without geometry change. Delete lifts the latest regrowth. Escape or R releases the sheet. S downloads a PNG.

## Falsifier
Delete v048 if the gesture leaves a local scar; if any gate or visited band changes; if the remote response is only a halo, status, or readout; if every pressure passage regrows the same bloom; if later regrowths reset earlier ones; or if exact lifting fails.

## Deletion condition
Delete the trial if caption-free viewing reads as another island field, clasp, or route diagram; if the three-gate pressure rule is only explanatory prose attached to a button; or if the remote regrowth cannot be distinguished in the first-render blind comparison.

## Direction consequence
This closes Brush's island / monolith / clasp sequence and opens a material-production direction: the current's question moves from paint remembering removal as a scar or displaced answer to paint refusing the hand's mark and re-producing itself at a remote site. It changes medium grammar (continuous raster wash), composition (one field rather than objects), and viewer task (ordered pressure passage rather than attention selection).
