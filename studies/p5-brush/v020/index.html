BRUSH / DIRECTION SWITCH / v020

The brush dries
on the inside.

A drying pulse fractures one helical band and makes the wet bands route around the seam. Material memory is not a stain; it is a changed future.

ONE PULSE, NOT A POINTER

Press the button, D, Enter, or Space. One coherent band dries into separated fragments; the still-wet bands bend around the new seam. Delete or “lift latest” restores the exact preceding coil.

The coil is still wet inside.

ANNOTATIONS / v020

changed rule
Translate p5.brush's material field into a drying obstruction: a pulse fractures one actual helical band, then deflects later wet bands through changed phase and radius.
visitor action
Press the pulse control, D, Enter, or Space to dry one bounded band. Delete or “lift latest” removes only the latest seam; release coil clears visitor memory and restarts the sequence.
falsifier
If the pulse changes only hue or opacity, if the band remains continuous, or if neighbouring bands do not route differently, the coil has not remembered a drying event.
deletion
Delete v020 if labels-off, controls-off viewing reads as a generic torus or as v019's ordinal register. Do not rescue the fracture with explanatory text.
