BRUSH / CLOSED WOUND FIELD / v039

The stain keeps
its holes.

A closed pressure loop is not a mark. It removes a chamber from one continuous field, and the surrounding material remembers how to close around the absence.

ABSENCE IS THE MATERIAL

Draw a loop and return to where you began. An open loop is refused and leaves the contour field exact. A closed loop excavates the nearest chamber as an actual SVG hole; the contours bend and a suture channel thickens. Enter or “remove a chamber” uses a deterministic loop. Delete lifts the latest wound; Escape, R, or “release field” returns to the intact field.

The field is intact. Nothing has been removed.

ANNOTATIONS / v039

changed rule
Switch from a mark, slab, or layer interval to a topological removal. Only a closed pressure loop becomes a wound; the continuous SVG field then rebuilds its contours and channels around the missing chamber.
visitor action
Draw and close one loop. Preview remains geometry-neutral. Enter, Space, and the removal control use a deterministic loop. Delete lifts the latest wound. Escape or R releases the field. S downloads the tableau HTML.
falsifier
If the trace is merely decorative, if an open loop commits, if removal changes only colour or readout, if the SVG field does not retain its holes, or if later wounds forget prior absences, the material translation fails.
deletion
Delete v039 if caption-free viewing reads as a generic contour map, if a hole is not a produced absence, or if the closed-loop encounter is only a disguised button.
