# The stain keeps its holes.

- Current: Brush
- Version: v039
- Status: candidate / held
- Seed: `0x42523939`
- Renderer: deterministic inline SVG topological wound field
- Grammar: `closed-wound-field`

## Hypothesis

Paint can remember removal as topology rather than as a mark. A pressure loop must close before it becomes an event. Once closed, it excavates a chamber from one continuous field; the surviving contours and channels are rebuilt around the missing region.

## Cultural translation

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** pressure, density, directional behavior, and fields participate in producing geometry; material is an engine, not a cosmetic layer.
- **Mutine translation:** refuse brushes, watercolor, hatching, grain, source palette, source composition, source code, examples, and API surface. Translate pressure into a closure threshold: only a closed loop can subtract a chamber from an SVG contour field, after which the surrounding contours and one suture channel are produced from the remembered absence.
- **Visible consequence:** the blind first view is one continuous mineral-like SVG field, not a stack or collection of layers. A committed loop produces an actual even-odd hole, displaced contour paths, and a thickened suture channel. Four holes persist and later removals inherit them.
- **Falsifier:** if an open loop commits, if the trace remains as a decorative stroke, if the wound changes only color/readout, or if later removals reset from the intact field, the translation fails.
- **Anti-copy:** no brush preset, watercolor appearance, hatching vocabulary, grain, source palette, source composition, source code, examples, API names, or surface vocabulary is reproduced.
- **Direction consequence:** closes the Brush sequence of remote slab, local crease, and layer interval; opens a topology-of-removal period in which material agency is tested through enclosure, absence, and field suturing.

## Changed rule

An incomplete pressure loop is geometry-neutral. A closed loop removes the nearest chamber as a real SVG hole and changes the continuous field around it; memory is a list of absences, not a list of traces.

## Visible consequence

The first-render field is a single irregular surface carrying contours, channels, and faint pressure pockets. After removal, the missing chamber is dark and bounded by a broken rim; nearby contour paths bend and one channel thickens. The trace disappears after commit. Four removals remain visible in the deterministic timeline.

## Interaction

- Pointer/touch: draw a closed loop and return near its start.
- Keyboard: `Enter` or `Space` commits the deterministic removal; `Delete`/`Backspace` lifts the latest wound; `Escape`/`R` releases the field; `S` downloads the HTML tableau.
- Controls: remove a chamber, lift latest, release field.
- Incomplete or undersized loops are refused without changing produced geometry.

## Deletion condition

Delete v039 if caption-free viewing reads as a generic contour map, if a loop does not make a real topological absence, if the field has become a disguised control surface, or if lifting cannot reconstruct the exact prior field.
