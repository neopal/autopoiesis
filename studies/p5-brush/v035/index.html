BRUSH / REVERSAL MEMBRANE / v035

The paint remembers
which way you left.

Three movements in one direction load the skin without touching it. A reversal does the damage: the continuous membrane shears, opens a pale void, and carries a stain somewhere the cursor never chose.

A REVERSAL IS THE REMOVAL

Scroll or press an arrow key three times in one direction. Nothing moves yet. Reverse once and the paint commits the stored tension: its strata shear, a void opens, and a stain drifts. The direction of the reversal matters; the pointer's location does not. Enter, Space, and “reverse the skin” use deterministic sequences. Delete lifts the latest reversal; Escape or R releases the ledger.

The skin is quiet.

ANNOTATIONS / v035

changed rule
Abandon pools, plates, ribbons, proximity, and local pressure. A single continuous membrane accumulates directional tension; only an opposite tick after three same-way ticks can alter its actual strata.
visitor action
Scroll or use the arrow keys to load a direction, then reverse. Enter, Space, and the reversal control use the same deterministic event. Delete lifts the latest; Escape or R releases. S downloads a PNG.
falsifier
If a same-direction tick changes geometry, if the cursor location chooses the scar, if reversal changes only colour/readout, or if later reversals forget the membrane's ledger, the translation fails.
deletion
Delete v035 if caption-free viewing cannot show one continuous skin with a structural cut, if reversal is only a disguised button, or if lifting the latest event does not restore the exact preceding membrane.
