# Brush v035 — The paint remembers which way you left.

## Hypothesis

If material resistance is directional rather than local, then a painted skin can accumulate a direction without moving and make the reversal itself the removal event.

## Changed rule

v034 made five observed pools resolve into a remote dry pocket, ridge, and counterflow. v033 made three quiet knocks resolve into remote SVG plates. v031 made a bounded drag refuse a local mark in a closed ribbon. v035 abandons pools, plates, ribbons, proximity, and local pressure. One continuous vertical membrane is built from 31 broad interlocking slices and five derived strata. Three same-direction wheel or arrow ticks load tension without changing geometry. An opposite tick commits the event: the membrane shears, a void opens, and a stain is carried elsewhere.

## Visible consequence

The blind render is a single tall painted skin, not a set of pools or controls. The first three same-direction ticks leave the actual geometry signature unchanged. Only the reversal changes slice top/bottom boundaries, opens dark cut geometry, and places a non-local stain. Later reversals replay from the bounded ledger; lifting rebuilds the exact preceding skin.

## Interaction

- Wheel or ArrowUp/ArrowLeft / ArrowDown/ArrowRight loads a direction.
- Three ticks in one direction arm the membrane; the next opposite tick commits.
- Horizontal swipe provides a touch equivalent without making pointer location causal.
- Enter, Space, and `reverse the skin` use the same deterministic reversal sequence.
- Delete or `lift latest` reconstructs the preceding state.
- Escape, `R`, or `release ledger` clears the bounded ledger.
- `S` downloads a PNG.

## Cultural translation

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** programmable pressure, density, grain, and directional fields are a material engine; the instrument changes how a mark is produced rather than only styling a finished shape.
- **Mutine translation:** refuse brush appearance, watercolor, hatching, and the library API. Translate directional fields into a reversal-only membrane: three same-way ticks load material tension without moving the skin, then an opposite tick changes the production rule by shearing strata, opening a void, and carrying a stain elsewhere.
- **Visible consequence:** same-direction loading is geometry-neutral; reversal changes actual membrane slices, a cut, and a non-local stain. Later reversals inherit the altered skin.
- **Anti-copy:** no source brush, watercolor, hatching, grain, palette, composition, code, example, or API surface is reproduced.

## Repeated grammar refused

The last three Brush works used pools/proximity, a three-knock plate rhythm, and a closed-ribbon drag. v035 changes the viewer task from locating, tapping, or dragging a local material body to loading a direction and reversing course. It changes the representation from embedded objects or plates to one monolithic vertical skin and changes the temporal rule from immediate/threshold commit to reversal-only ontology.

## Falsifier

The translation fails if same-direction loading changes geometry, if the pointer location chooses the scar, if reversal changes only colour or readout, if the blind field reads as a generic chart or scroll interface, if later reversals restart from the seed, or if lifting is inexact.

## Deletion condition

Delete v035 if caption-free viewing cannot show one continuous skin with a structural cut, if reversal is only a disguised button, or if lifting the latest event does not restore the exact preceding membrane.
