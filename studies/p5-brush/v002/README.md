# Brush v002 — A brush returns to its own wound

## Hypothesis

Brush v001 proved that a visitor can deposit and erase marks, but that made the visitor the author of the decisive return. v002 removes that dependency. The brush now paints and cuts its own field on a fixed timeline.

## Rule

Each stage paints four broad strokes, then performs one autonomous return cut. The wound is retained as memory. In later stages, the inherited wound creates a local detour around its own position in the stroke path, in addition to the broader turn. The wound is therefore a material decision with a future consequence, not a pale overlay.

## Falsifier

Build the same stage with an empty memory or with one wound deleted. If the later stroke geometry does not change, the erasure is only decoration and the rule must be deleted or held.

## Process

- fixed seed: `0x42525532`
- eight timed stages
- four strokes per stage
- announced primitive budget: 24
- no visitor input
- refused, memory-free strokes remain dashed red
- accepted strokes are layered in ink and green
- wounds remain as paper cuts with orange/red edges
- reduced motion renders the final remembered state

## Relation to v001

`p5-brush-v001` remains archived as a visitor-operated interaction. This version is not a relabeling of that work: it changes the authorship rule by making the return autonomous and by exposing the erased field as input to the next stroke.

## Critique gate

Do not promote v002 because it looks like brush texture. Promote only if the wounds are legible as cuts and the later stroke direction visibly answers them without relying on the caption.

## Condition of deletion

Delete the autonomous return rule if deletion or empty-memory replay leaves later strokes unchanged, or if the wounds only alter colour and opacity.
