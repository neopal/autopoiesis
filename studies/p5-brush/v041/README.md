# The material answers from behind.

- Current: Brush
- Version: v041
- Status: candidate / held
- Seed: `0x42523431`
- Renderer: deterministic p5.js WEBGL relief membrane
- Grammar: `backface-membrane`

## Hypothesis

A material surface can remember being watched without copying the visitor's mark. If one threshold is held and a separate threshold is crossed, the membrane should produce a remote backface: an answer somewhere the hand did not touch.

## Changed rule

The last three Brush works used a continuous crease, a paired layer interval, and an enclosure that removes a chamber, followed by discrete fragments that settle after an upward lift. v041 abandons direct removal and fragment accumulation. It renders one continuous WebGL relief membrane. A solitary press is geometry-neutral. Only a separated visit between two material thresholds commits; the answer is selected elsewhere and raises a produced backface in the continuous surface.

## Visible consequence

The blind first view is a single oblique relief membrane, not a field of pieces or a wound. After a valid separated visit, the offered and departure places remain materially quiet while a remote backface rises as actual height, seam, and relief geometry. Four remote answers compound in the same surface.

## Interaction

- Pointer/touch: hold near one threshold, move to another, and release.
- Preview is geometry-neutral; a miss or near-self visit is refused.
- Keyboard: `Enter` or `Space` commits a deterministic separated visit; `Delete`/`Backspace` lifts latest; `Escape`/`R` releases; `S` downloads a PNG.
- Controls: offer a look, lift latest, release field.

## Cultural translation

- **Reference:** [little-critters](https://github.com/GordenSun/little-critters)
- **Observed mechanism:** situated code-drawn agents turn proximity into reciprocal attention; the visitor enters a social field and local behavior answers without a dashboard.
- **Mutine translation:** refuse agents, animals, eyes, head-turning, paper scenes, source palette, source composition, source code, examples, and API surface. Translate reciprocal attention into a material relay: a separated visit across two thresholds produces a third, remote backface in one continuous relief membrane.
- **Visible consequence:** the held and departure places stay geometry-neutral while a remote region rises, gains a seam, and changes the surface's relief; four answers persist.
- **Falsifier:** if the pointer's path is copied, if the offer site answers directly, if a near visit commits, if the backface exists only in colour or readout, if the blind view reads as agents/nodes/terrain, or if later visits reset, the translation fails.
- **Anti-copy:** no animals, characters, eyes, paper scene, head-turning gesture, source palette, source composition, source code, examples, API names, or surface vocabulary is reproduced.
- **Direction consequence:** closes Brush's crease / lamina / wound / settling sequence and opens a reciprocal-material direction: matter can answer at a place not touched, through a continuous 3D relief rather than a removed fragment.

## Radical progression gate

The repeated gesture across v038, v039, and v040 was a boundary or discrete piece directly accepting a stroke, enclosure, or lift and changing around that local operation. v041 breaks the invariant in six visible dimensions: one continuous WebGL relief instead of layered SVG/Canvas pieces, a broad oblique membrane instead of a fragment archive, a two-threshold visit instead of an upward removal, a remote backface instead of a local cavity or settling field, reciprocal attention memory instead of absence memory, and a 3D surface whose height actually changes at the unoffered answer.

## Falsifier

Delete v041 if preview changes the membrane, if a near visit commits, if the answer is at the hand, if the remote relief is cosmetic, if the blind view reads as a generic terrain/node field/ornament, or if later visits forget the prior backfaces.

## Deletion condition

Delete v041 if caption-free viewing cannot distinguish a remote-answer membrane from v038's layer interval, v039's wound, or v040's settling archive, or if the material does not visibly answer somewhere other than the offered path.

Candidate / held. The deterministic engine, structural tests, browser matrix, production readback, and independent caption-free perceptual comparison are separate gates. This document records the hypothesis and unresolved doubts without promoting the trial to exhibition-ready.
