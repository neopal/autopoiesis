# Mutine Brush v053 — The paint dries toward the pressure.

## Hypothesis

A brush can be material without preserving a stroke. If a continuous membrane accepts only a settled edge-to-edge passage, the pressure should change the rule that produces the entire skin rather than decorate the place where the pointer travelled.

## Changed rule

Pressure is inert while it is local. A crossing becomes material only when it enters from one edge, exits another edge, and settles before release. The accepted passage re-produces every membrane node and seam along its pressure vector. The hand path disappears; its drying bias remains in ordered memory.

## Visible consequence

The first-render blind view is one continuous asymmetrical pigment membrane, not a grid, ring, relief, or set of vacancies. A valid passage bends the whole skin and its seven embedded seams. Four passages compound; reverse order produces a different skin. A local stripe is never stored.

## Interaction

Pointer or touch starts near a membrane edge, crosses the skin, and releases near another edge. The deterministic passage button, Enter, and Space provide equivalent non-hover paths. Delete lifts the latest crossing. Escape, R, or the release button returns to the quiet membrane. S exports a PNG.

## Falsifier

The direction fails if a same-edge, short, or unsettled passage commits; if only a local stripe, colour, readout, or selection changes; if the entire membrane does not move; if passage order is cosmetic; or if lifting cannot restore the exact preceding skin.

## Deletion condition

Delete v053 if caption-free viewing reads as a decorated field rather than a continuous drying membrane, if the crossing gesture is only an invisible trigger for a generic animation, or if the new skin cannot be distinguished from v050's relief and v052's vacancy register without prose.

## Cultural translation

- **Reference:** p5.brush — https://github.com/acamposuribe/p5.brush
- **Observed mechanism:** Programmable pressure, density, direction, fill, and vector-field behavior change how geometry is produced; material is an engine, not a surface skin.
- **Mutine translation:** Refuse brush presets and visible brush simulation. Make a settled edge-to-edge pressure passage re-produce a continuous membrane globally; pressure changes the next skin, not the current mark.
- **Anti-copy:** No p5.brush preset, watercolor appearance, hatching vocabulary, grain treatment, source palette, source composition, source code, examples, API names, or source imagery is reproduced.
- **Direction consequence:** v053 closes v052's discrete vacancy register, v051's phase-locked ring, and v050's subtractive relief. It opens a continuous-skin period in which the viewer crosses a material body and drying, not erasure, stores the event.
