# Brush v046 — The brush stores its cuts in depth.

## Hypothesis

If material remembers an erasure as a change in depth rather than as a visible trace, a painted mass should only accept a cut that passes through an absence. The visitor's route must disappear while another part of the mass carries its consequence.

## Changed rule

v046 abandons v045's opposing jaw clasp, v044's one-way edge traverse, and v043's two-site witness exchange. The first-render object is a shallow WebGL monolith made from nine irregular volumes around five dark voids. A passage stays geometrically neutral until it starts at an outer bank, enters the central void, and exits the opposite bank. Only then does the engine shift a remote volume in depth, widen a remote void, and tighten seams. Four through-cuts compound and remain liftable.

## Visible consequence

The blind first view is a dark, tilted painted mass with an actual spatial centre: extruded mineral blocks, deep openings, seams, and rear-lit particulate atmosphere. It is not a linefield, a radial clasp, a stripe sheet, or a flat cure plate. A valid through-cut leaves no painted path at the hand; a remote piece steps forward or back, a different void opens, and the changed depth remains in the volume.

## Interaction

- Pointer/touch: begin at an outer bank, pass through the central opening, and release on the opposite bank.
- An interior start, same-bank exit, incomplete route, or bypass refuses without geometry change.
- `ArrowLeft` begins the near-bank route, `ArrowRight` enters the void, and `Enter` exits it; the cut control uses the same deterministic passage.
- `Delete` / `Backspace`: lift the latest depth cut.
- `Escape` / `R`: release the monolith to the quiet seed.
- `S`: save a PNG.

## Falsifier

Delete this direction if the hand path becomes a painted trace, if a route that bypasses the void commits, if the entry or exit bank answers itself, if the remote change exists only as colour or readout, or if later cuts reset earlier depth and openings.

## Deletion condition

Delete v046 if caption-free viewing cannot distinguish the depth-cut monolith from v043–v045, if the void is only a decorative hole, or if the through-absence rule is not materially visible in the produced geometry.

## Cultural translation

The selected `p5-brush` mechanism is a programmable material engine: pressure, density, directional behaviour, and field logic participate in producing geometry rather than decorating a finished mark. Mutine refuses brush presets, watercolor appearance, hatching vocabulary, grain, palette, source code, examples, API surface, and composition. The translation changes the medium and memory model: an erasure becomes a passage through a void, and the material stores it by moving a remote volume in depth instead of preserving the hand's route.

## Radical progression gate

Across v043, v044, and v045 the repeated gestures were a two-site witness exchange, a one-way threshold traverse, and opposing planar compression. v046 breaks the visual grammar and encounter: a WebGL depth-bearing monolith replaces the flat material fields; the visitor must route through an existing absence instead of selecting two sites, crossing one edge, or closing two jaws; and the produced consequence is depth displacement rather than a remote planar crease, seam, powder, or clasp tension. Representation, composition, interaction, temporal behavior, and viewer task all change.

## Direction consequence

This closes the one-way threshold / witness-body / opposing-clasp run and opens subtractive depth: brush matter remembers a removal as a spatial displacement. It is not a declared new period; a connected experiment and retrospective are still required.
