# The stain falls through its own absence.

- Current: Brush
- Version: v040
- Status: candidate / held
- Seed: `0x42523430`
- Renderer: deterministic p5.js Canvas 2D settling archive
- Grammar: `settling-archive`

## Hypothesis

Paint can remember removal as weight rather than as a hole. If one fragment is lifted out of a suspended accumulation, the remaining fragments should carry the missing support as a visible settling event instead of leaving a static gap.

## Changed rule

The last three Brush works used a continuous Canvas incision, a paired DOM/CSS layer interval, and a closed SVG wound. They repeatedly treated paint as one surface or as a relation between boundaries. v040 changes the representation to thirteen discrete material fragments suspended in an offset archive. A press is geometry-neutral. Only an upward drag that exits the archive can lift a fragment; the remaining mass is recomputed under the missing support.

## Visible consequence

The blind first view is a dark, asymmetrical accumulation of irregular pigment fragments, weighted shadows, and quiet cavities rather than a sheet, stack, or contour map. After a valid lift, the removed fragment leaves a dry cavity while neighbouring fragments change position, tilt, and settlement depth. Four absences remain replayable and liftable.

## Interaction

- Pointer/touch: press a fragment, drag upward, and release outside the archive.
- The press and preview remain geometry-neutral; a downward or off-material gesture is refused.
- Keyboard: `Enter` or `Space` lifts the deterministic fragment; `Delete`/`Backspace` lifts latest; `Escape`/`R` releases the archive; `S` downloads a PNG.
- Controls: lift a fragment, lift latest, release archive.

## Cultural translation

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** programmable pressure, density, directional behaviour, and fields participate in producing geometry rather than merely styling a finished mark.
- **Mutine translation:** refuse brushes, watercolor, hatching, grain, source palette, source composition, source code, examples, and API surface. Translate material production into a discrete gravity rule: removing one fragment changes the support field and makes the remaining fragments settle.
- **Visible consequence:** the blind view is an offset archive of produced polygonal fragments. A valid upward lift removes a real fragment and changes the remaining Canvas geometry through position, tilt, shadow, and dry-edge state; later lifts inherit the settled arrangement.
- **Falsifier:** if a press moves geometry, if a downward gesture commits, if the removal is only colour/readout, if remaining fragments do not settle materially, or if later lifts restart from the quiet archive, the translation fails.
- **Anti-copy:** no brush appearance, watercolor, hatching, grain, vector-field drawing, source palette, source composition, source code, examples, API names, or surface vocabulary is reproduced.
- **Direction consequence:** closes the Brush sequence of local crease, layer interval, and topological wound; opens a load-bearing direction in which removal is not a finished void but a force that changes the ontology of the remaining paint.

## Radical progression gate

The repeated gesture across v037, v038, and v039 was a continuous surface or boundary relation that accepted a route, interval, or enclosure and then changed around it. v040 breaks that invariant in five visible ways: discrete fragment representation instead of a fused body, an offset suspended composition instead of a sheet/stack/field, upward lift instead of stroke/pair/loop, a settling memory model instead of drying/layer order/topological absence, and a Canvas 2D archive whose remaining mass moves instead of a local mark or contour.

## Falsifier

Delete v040 if the blind composition reads as a generic node field, tile grid, or physics demo; if a press changes geometry before release; if a downward gesture commits; if the lifted absence is cosmetic; if settling does not alter actual fragment geometry; or if exact lifting does not reconstruct the previous archive.

## Deletion condition

Delete v040 if caption-free viewing cannot distinguish a load-bearing material archive from the previous crease sheet, lamina stack, or wound field, or if the absence is not visibly carried by the remaining mass.

## Critique status

Candidate / held. The deterministic engine, structural tests, browser matrix, production readback, and independent caption-free perceptual comparison are separate gates. This document records the hypothesis and unresolved doubts without promoting the trial to exhibition-ready.
