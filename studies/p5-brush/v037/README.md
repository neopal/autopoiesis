# Brush v037 — The paint hardens at the touch.

## Hypothesis

If paint can remember the pressure that removes it, then the viewer should be able to draw a local incision whose drying changes the material around that incision and alters the next stroke. The hand must not select a remote answer; the contact itself must become the body.

## Changed rule

The last three recorded Brush works used remote consequence: v036's fault–vent–exit opened a distant eclipse in a WebGL slab, v034's proximity census resolved unlooked-for pools, and v033's three knocks relocated a structural answer across SVG plates. v037 inverts that invariant. One continuous pointer stroke is the event. Preview remains geometry-neutral; release commits a local crease along the exact pressure path. Nearby chambers dent, open, and dry, and the next stroke is built on that inherited material state. The medium changes from WebGL object / raster pool / SVG laminate to a p5.js Canvas 2D sheet.

## Visible consequence

The blind render is one irregular, fused pigment sheet with eighteen inset chambers and a dry perimeter, not a slab, route, population, or plate arrangement. A valid stroke creates an actual dark incision along its own path, opens nearby chamber voids, folds the local body, and carries a visible drying frontier into the next stroke. The first four completed strokes remain replayable and liftable.

## Interaction

- Draw one continuous line across the sheet and release.
- Pointer movement shows a pressure preview without changing geometry.
- A short or over-held stroke is refused.
- Enter, Space, and `make a crease` use deterministic pressure lines.
- Delete or `lift latest` reconstructs the preceding sheet.
- Escape, `R`, or `release sheet` clears the bounded crease ledger.
- `S` downloads a PNG.

## Cultural translation

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** programmable drawing tools make pressure, density, and directional fields part of the production engine; the instrument changes how geometry is produced, not merely how a finished mark is styled.
- **Mutine translation:** accept the pressure relation but refuse brush appearance, watercolor, hatching, grain, vector-field marks, and the source API. The stroke is a local incision in a fused material sheet; drying changes adjacent production rules and is inherited by the next stroke.
- **Visible consequence:** the first encounter is a single Canvas 2D sheet. A completed local stroke changes actual chamber geometry, body fold, negative incision, and drying boundary along its own path; later strokes do not restart from wet seed.
- **Falsifier:** if the stroke only changes a halo or readout, if the consequence is remote rather than local, if drying does not affect the next stroke, if the gesture is only a disguised button, or if lifting is inexact, the translation fails.
- **Anti-copy:** no brush appearance, watercolor, hatching, grain, vector-field drawing, source palette, source composition, source code, examples, API surface, or surface vocabulary is reproduced.
- **Direction consequence:** this closes Brush's remote eclipse / proximity pool / dry-seam family and opens a locality-and-drying direction: matter accepts the incision, then changes its own future.

## Repeated grammar refused

The last three Brush records repeatedly made the point of contact causally insufficient and spent attention on a remote role. v037 breaks that rule visibly in code and encounter: contact becomes the cause, continuous drawing replaces station selection, local negative space replaces remote role assignment, and Canvas 2D replaces the recent WebGL object.

## Falsifier

The translation fails if pointer preview changes the geometry, if a short or over-held stroke commits, if the incision is only a coloured line, if adjacent chambers do not change, if the next stroke ignores dried pressure, if a button is the only real path, or if exact lifting fails.

## Deletion condition

Delete v037 if caption-free viewing cannot show one fused sheet with a local cut and drying boundary, or if it reads as a generic line drawing, a set of controls, or a reskinned route field.
