# Mutine Brush v021 — The brush answers under the cut.

## Creative concept

This study makes a field of pigment grains behave like a material memory, not a picture of a stroke. The first encounter is a dense, luminous lattice: a single surface assembled from irregular cells, with a cool under-layer and warm grains that refuse a regular grid. A drag is a rake, not a mark. It removes cells along a real path. The field around that absence bends, and a distant cluster changes its load and tilt as an answer.

The mood is tense and geological: the viewer opens a cut and discovers that the material has a second side. The work is meant to be read before it is explained: surface, cut, distant reply.

## Hypothesis

If removal is represented as a path of missing grains rather than as a drawn trace, and if a distant group changes its actual cell geometry in response, then paint can remember loss as a relation between absence and return rather than as a scar-shaped decoration.

## Changed rule

v021 leaves v020's suspended WebGL coil, v019's ordinal hanging register, and v018's continuous membrane. It changes both representation and encounter:

- representation: deterministic p5.js 2D grain lattice instead of coil, rack, or skin;
- interaction: a pointer drag has to travel a minimum distance before it commits; a tap is refused;
- memory: the committed path deletes actual lattice cells, deflects neighbours, and makes a non-local answer cluster grow.

The response is derived from the drag path but is not placed under the pointer. The field therefore keeps the removal and the answer as two different spatial facts.

## Cultural translation

Reference: [little-critters](https://github.com/GordenSun/little-critters)

Observed mechanism: code-drawn agents use pointer proximity to make attention reciprocal; the visitor's presence becomes part of a situated relation rather than a dashboard command.

Mutine translation: remove the animals and the look-back scene. A rake is a moving witness through a material field. The local witness opens a real absence, while a distant cluster answers by changing its own load and tilt. The relation is carried by cells and memory, not by a character animation or cursor decoration.

Visible consequence: before interaction the blind view is a dense grain lattice; after a rake, empty cells make a readable cut and the far answer cluster becomes visibly raised and skewed.

Falsifier: if the drag only leaves a cursor trail, if the missing path is a coloured overlay, if the distant cells keep their geometry, or if the work reads as a generic grid with a caption-dependent relation, the translation fails.

Anti-copy: no animals, eyes, characters, paper scene, source palette, source composition, or head-turning surface vocabulary is reproduced.

Direction consequence: this opens a material-reciprocity direction for Brush and closes the recent coil/register/membrane grammar. The next viable mutation must not polish the lattice; it must change the medium or the viewer's task again.

## Interaction and replay

- Drag for a committed rake; a short tap is explicitly refused.
- Enter, Space, and “rake the field” commit the same seeded default path.
- Delete or “lift latest” rebuilds the exact preceding frame from bounded event memory.
- R or “release field” clears visitor memory and restarts the deterministic sequence.
- S exports a PNG from the raw tableau.

The engine is deterministic for `SEED = 0x42525541`. Memory is bounded at three rakes. Reduced motion settles the autonomous sequence, but the visitor can still make and lift a rake.

## Falsifier and deletion condition

Delete v021 if the labels-off, controls-off, readout-off image cannot communicate a material cut and a separate answer cluster; if a tap commits; if the answer is only a halo; or if the grain field reads as a generic decorative grid. Do not rescue a failed causal image with annotation prose.
