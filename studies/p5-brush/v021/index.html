BRUSH / DIRECTION SWITCH / v021

The brush answers
under the cut.

A drag is not a stroke. It removes a path of grains, and the missing material returns as a distant answer that changes the field around it.

A DRAG, NOT A BUTTON

Drag across the grain field. A short tap is refused. A real rake opens a path of empty cells; the far side answers by growing and bending its neighbours. Delete or “lift latest” restores the exact preceding field.

The grains are holding their first surface.

ANNOTATIONS / v021

changed rule
Replace v020’s drying coil with a grain lattice. A sustained drag removes actual cells along a path, bends the grains around the scar, and makes a distant cluster answer with increased load and altered tilt.
visitor action
Drag through the field to commit one bounded rake. Enter, Space, or the control use the same deterministic rake; Delete or “lift latest” removes only the latest scar; release field clears memory.
falsifier
If a drag only draws a cursor trail, if the empty path is an overlay, or if the distant answer does not change cell geometry, the lattice has not remembered a removal.
deletion
Delete v021 if labels-off, controls-off viewing reads as a generic grid, if the scars are not legible as missing material, or if the distant answer needs the caption to exist.
