# Brush v045 — The brush makes absence load-bearing.

## Hypothesis

If material agency is an opposition rather than a mark, the brush should refuse one-sided pressure. Two jaws must close against each other before the clasp can spend that force on a remote crease. The visitor's handles should remain unpainted while the material changes elsewhere.

## Changed rule

v045 abandons v044's one-way horizontal pressure threshold, v043's sequential witness handshake, and v042's bounded dwell cure plate. The first jaw can be compressed and released without changing produced geometry. Only a completed left/right opposition commits. The clasp then changes actual panel vertices, seam bends, jaw tension, and an existing opening away from the handles. Four compressions compound and remain liftable.

## Visible consequence

The blind first view is an asymmetric pigment clasp: nine broad generated panels curve around a dark inner absence, with four irregular openings and a produced seam network. It is not a stripe field, a monolithic upright body, or a raster plate. A valid opposed compression leaves the jaw sites unpainted but changes a remote panel, thickens a seam, opens an old absence, and adds a material crease. Later events inherit the altered clasp.

## Interaction

- Pointer/touch: press at either outer jaw, draw inward beyond the inner band, release, then do the same from the opposite side.
- An interior start, incomplete motion, jaw reversal, or one-sided release refuses without geometry change.
- `ArrowLeft` then `ArrowRight`: close the two jaws by keyboard; `Enter` / `Space` or the compression control commits a deterministic opposing closure.
- `Delete` / `Backspace`: lift the latest crease.
- `Escape` / `R`: release the clasp to the quiet seed.
- `S`: save a PNG.

## Falsifier

Delete this direction if one jaw changes the material, if the hand path becomes pigment, if the handles answer themselves, if the remote crease exists only as colour or readout, if the blind form reads as a radial ornament, or if later compressions reset earlier openings.

## Deletion condition

Delete v045 if caption-free viewing cannot distinguish the opposing clasp from v042–v044, if opposition is only a UI story, or if the produced geometry does not move away from the jaws after a valid two-sided closure.

## Cultural translation

The selected `p5-brush` mechanism is a programmable material engine: pressure and directional field logic participate in producing geometry rather than decorating a finished mark. Mutine refuses brush presets, watercolor appearance, hatching vocabulary, grain, palette, source code, examples, API surface, and composition. It inverts the previous one-way scrape into an opposing material law: pressure exists as a load only when two sides close, and the clasp spends it as remote topology and seam geometry.

## Radical progression gate

Across v042, v043, and v044 the repeated gestures were timed stillness, sequential witness exchange, and one-way edge traversal. v045 breaks all three: the blind composition becomes an asymmetric clasp around an absence instead of a raster plate, upright body, or horizontal field; the viewer must make an opposed two-stage compression instead of waiting, visiting two sites, or traversing a threshold; the temporal rule changes from one-sided release to a relation that cannot commit without its opposite. The stable invariant that the hand site receives the answer is retained only as a falsifier: the remote crease is the work.

## Direction consequence

This closes the one-way threshold / witness-body / dwell sequence and opens opposing material logic: brush matter remembers not the mark or the path, but the absence that allowed two pressures to become one load. It is not a declared new period; a connected experiment and retrospective are still required.
