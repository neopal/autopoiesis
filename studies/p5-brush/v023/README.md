# Mutine Brush v023 — The paint turns from the witness.

## Creative concept

v023 abandons Brush's recent field of things that are removed, fractured, or thickened. The first encounter is a dark SVG body made from seven broad pigment stations joined by wet seams. It is neither a grain population nor a continuous noise surface: it is a single folded body whose sections can avert themselves.

The visitor is not asked to paint, press, drag, or wait. Nearness arms one station; leaving the field commits the witness. The station turns away through its actual path geometry, opening a notch, and the later seams bend around that refusal. The work asks whether paint can remember being watched as a changed relation rather than as a mark placed by the visitor.

## Hypothesis

If proximity only arms a material station and departure changes that station's SVG path plus the downstream seam geometry, then paint can remember a reciprocal encounter without turning the visitor into a brush or reducing attention to a cosmetic highlight.

## Changed rule

v023 makes one primary structural rupture relative to Brush v020–v022:

- representation: one connected inline-SVG paint body with seven turning stations instead of a WebGL coil, a grain lattice, or a continuous sampled pigment field;
- encounter: approach-and-depart instead of pulse, drag, or press-and-hold; proximity does not write history;
- memory: a witnessed station averts, opens a true path notch, and bends later stations through inherited seam load; repeated attention to the same station is refused.

The engine stores a bounded sequence of four departure events. Each event is replayed from the seeded station field. The path points, station orientation, notch, and later body coordinates are regenerated from memory. Lifting the latest witness rebuilds the exact preceding geometry.

## Expected visible consequence

Blind, labels-off viewing should first read as one connected folded pigment body, with broad stations joined by pale wet seams. After a departure, the addressed station should visibly turn and open a notch in its silhouette; later stations should no longer sit on the same seam. A second departure at another station should extend the changed body rather than duplicate a local sticker.

## Cultural translation

Reference: [little-critters](https://github.com/GordenSun/little-critters)

Observed mechanism: a population of code-drawn situated agents responds to pointer proximity by changing attention and looking back, making the visitor part of a reciprocal encounter instead of a controller of a dashboard.

Mutine translation: refuse the animals, faces, paper scene, and look-back surface. Translate reciprocity into an abstract paint body: proximity arms one material station, but only leaving commits a turn-away. The station's actual notch and the downstream seam carry the memory of being witnessed.

Visible consequence: approaching without leaving changes no memory; leaving changes an actual SVG station path and bends later seams. Repeating the same station is refused, while a different station changes the body again.

Falsifier: if proximity commits, if departure only changes colour or a marker, if the notch is not in the SVG path, if later seam coordinates stay fixed, or if the blind view reads as seven decorative blobs, the translation fails.

Anti-copy: no animals, characters, eyes, paper style, head-turning scene, source palette, source composition, code, API surface, or surface vocabulary from little-critters is reproduced.

Direction consequence: this closes Brush's pressure / absence / coagulation family and opens a reciprocal-material direction in which paint is altered by the visitor's departure, not by the visitor's stroke. It keeps the current's question—can paint remember its removals?—but replaces removal with a material refusal to remain facing the witness.

## Interaction and replay

- Move near a station, then leave the raw tableau. Proximity arms; departure commits.
- A pointer tap is refused and never writes memory.
- Enter, Space, and “watch the next seam” commit the same seeded next station.
- Delete or “lift latest” removes only the newest departure and rebuilds the exact preceding SVG body.
- R or “release field” clears visitor memory and restores the first station body.
- S exports the current inline SVG.

Seed: `0x42525543`. The engine uses a local seeded PRNG and seven stations joined by deterministic seams. Memory is bounded at four departures. Reduced motion settles the autonomous sequence, while the visitor can still make and lift a witness departure.

## Falsifier and deletion condition

Delete v023 if labels-off, controls-off, readout-off viewing cannot communicate one connected material body and a visible turn-away; if proximity or a tap commits; if the station notch is an overlay; if later seams do not bend; or if the reciprocal rule exists only in the annotation.

## Evidence boundary

This is a candidate / held daily work until the local headless browser matrix, interaction readback, route/readback checks, and an independent caption-free perceptual comparison are observed. Engine tests prove deterministic station geometry and replay; they do not prove that the body reads as reciprocal material memory without the caption.
