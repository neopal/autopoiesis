# v049 — The sheet holds a pressure chord.

## Hypothesis

If material pressure is a production rule rather than a mark, a single hand should be inert while a long two-site chord changes the next internal fold. The first-render image should read as a single folded sheet before it reads as a pressure interface.

## Radical progression gate

The last three Brush records repeat a displaced-answer grammar: v046 routes a cut through a WebGL mass and changes a remote volume, v047 lets one attended island answer at another, and v048 sends a completed gate passage to a remote bloom. Their repeated gesture is approach or passage followed by a non-local response; their repeated metaphor is paint remembering elsewhere; their repeated interaction is a one-sided route. v049 breaks that invariant in five visible ways: it changes Canvas wash / WebGL mass / island field into one portrait-oriented folded sheet; replaces a route with simultaneous two-site pressure; replaces remote response with an internal fault; replaces transient passage with duration; and makes the next accepted lead alternate. No remote bloom or touched route is stored.

## Changed rule

Abandon the wash, island, and through-void passage. A single pressure site cannot spend material. Both edge sites must be held together beyond a deterministic duration threshold, then released. The accepted chord changes only the next internal fold's position, opening, crease, notch, and seam; the two pressure sites remain exact. The next chord must lead from the opposite side. Four fold states compound and remain liftable.

## Visible consequence

The blind first view is a dark, upright sheet of eight irregular interlocking folds with a mineral, rust, mint, and bone edge language. A valid long chord opens a real internal fault in one fold and changes its outline and crease; later chords open other folds with alternating lean. The result is a changed object, not a status light, cursor trail, remote bloom, or colour-only state.

## Cultural translation

The selected cultural reference is `p5-brush` (https://github.com/acamposuribe/p5.brush). Its observed mechanism is that pressure, density, directional behaviour, and vector fields participate in producing geometry rather than decorating a finished mark. Mutine translates that mechanism by making pressure relational and temporal: only a sustained chord between two fixed sites is allowed to produce the next fold's geometry, and the lead side alternates. The source's brush surface vocabulary is refused.

## Anti-copy boundary

No p5.brush brush preset, watercolor appearance, hatching vocabulary, grain treatment, source palette, source composition, source code, examples, API surface, or source imagery is reproduced. The work uses p5.js Canvas 2D, a folded-sheet composition, two-site duration, and internal fault geometry in Mutine's own vocabulary.

## Interaction

- Pointer/touch: press one edge site, press its opposite, hold both beyond the threshold, and release.
- A single site, short hold, or same lead twice refuses without changing the sheet.
- `ArrowLeft` plus `ArrowRight` provides the keyboard chord; the `hold the chord` control provides an equivalent deterministic event.
- `Delete` / `Backspace`: lift the latest fold.
- `Escape` / `R`: release the sheet to the quiet seed.
- `S`: save a PNG.

## Falsifier

Delete v049 if one-sided pressure commits, if a short hold commits, if the pressure sites deform, if a fold changes only in colour or readout, if the alternating lead is ignored, if later folds reset earlier ones, or if exact lifting fails.

## Deletion condition

Delete the trial if caption-free viewing reads as another field, monolith, or route diagram; if duration is only explanatory prose attached to a button; or if the internal fault cannot be distinguished in the first-render blind comparison.

## Direction consequence

This closes Brush's remote-answer sequence and opens an internal material-resistance direction: pressure is no longer a route to elsewhere. It is a timed agreement that changes what the sheet can fold next. The work moves from displaced memory to a local ontology of held duration, with alternating lead as the next structural constraint.
