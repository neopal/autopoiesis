# Brush v043 — The brush asks for a second hand.

## Hypothesis

If situated attention is translated into material time, a brush body can hold a first touch as an unproduced call and only change when another place answers. The result should remember the relation between witnesses rather than imitate either visitor mark.

## Changed rule

v043 abandons v042's bounded dwell cure plate, v041's remote backface membrane, and v040's upward fragment lift. The first touch on one unlabelled edge witness arms a latent call and leaves the produced body exact. A different, sufficiently separated second witness completes the exchange and closes a central fold through one monolithic perforated ink body. Neither witness answers itself. Four exchanges compound in replay state.

## Visible consequence

The first blind view is a centered vertical ink body with a broken edge, four perforations, and open ground; it is neither a raster field, a relief landscape, a fragment archive, nor a route diagram. A first touch changes only latent state. A valid reply changes actual fold paths, shell pressure, and perforation openings inside the body. Later folds inherit the earlier body, and the latest fold can be lifted exactly.

## Interaction

- Pointer/touch: touch one edge witness, then touch a different sufficiently separated witness.
- One touch, a self-reply, a nearby re-touch, or a miss refuses without geometry change.
- `Enter` / `Space`: deterministic two-site exchange.
- `Delete` / `Backspace`: lift the latest fold.
- `Escape` / `R`: release the body to the sealed seed.
- `S`: save a PNG.

## Falsifier

Delete this direction if the first touch changes the body, if a self-reply commits, if the second site only changes a label or counter, if the fold is not actual body geometry, if the blind image reads as a generic node diagram or seal, or if later exchanges reset rather than inherit.

## Deletion condition

Delete v043 if caption-free viewing reads as a click counter, node diagram, or decorative seal, or if a second witness does not materially close the body from within the relation.

## Cultural translation

The selected `little-critters` mechanism is situated agents whose proximity becomes reciprocal attention without a dashboard. Mutine refuses animals, eyes, characters, paper, head-turning, source palette, source composition, source code, examples, and API surface. It translates local attention into a material handshake: the first site is latent, the second site answers, and their relation closes a fold inside the same body rather than producing a remote marker.

## Radical progression gate

Across v040, v041, and v042 the repeated gestures were a produced body that accepted a directional removal, a continuous surface that answered remotely, and a raster plate whose bounded dwell cured remote zones. v043 breaks those invariants in representation, composition, encounter, and memory: it replaces fragments, relief, and cells with one perforated polygon body; replaces lift, separated travel, and timed stillness with a discrete two-site handshake; replaces remote consequence with a fold inside the relation; and introduces a latent pre-geometry call state.

## Direction consequence

This closes the relief / fragment / raster sequence and opens a witness-body direction in which attention is a material relation, not a force applied at a point. It is not a declared new period: a connected experiment and a retrospective are still required.
