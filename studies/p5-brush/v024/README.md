# Mutine Brush v024 — The paint keeps the endpoints.

## Creative concept

v024 leaves Brush's recent grain lattice, coagulating field, and reciprocal station body. The first encounter is one suspended pigment bridge: eleven broad, weathered segments are joined into a single asymmetric body. It is not a grid of agents or a path waiting for a stroke. It is a material relation that only becomes legible when two places answer each other.

The visitor touches one segment, then another. The first touch only holds attention. The second touch completes a pair: the two endpoints remain as changed anchors, while every segment between them is lifted out of the bridge. The later bank inherits the missing interval. The question becomes whether paint can remember a removal as a relation between what stayed and what could no longer stay between it.

## Hypothesis

If the first local attention event is inert and a second, distinct endpoint removes the actual geometry between them while changing both endpoints and the later bank, then paint can remember removal as a reciprocal span rather than as a stroke, cursor trace, or decorative scar.

## Changed rule

v024 creates a structural rupture relative to Brush v021–v023:

- representation: one suspended bridge-body of extruded pigment segments instead of a grain lattice, continuous field, or connected station ribbon;
- encounter: two discrete touches that complete a relation instead of drag, hold, or approach-and-depart; a first touch cannot write memory;
- memory: the endpoints are retained and materially re-anchored, the entire interior interval becomes absent geometry, and the far bank inherits the span's stress.

The engine stores a bounded sequence of four endpoint pairs. Every frame is rebuilt from the seeded segment field and event memory. Removed segments have zero width and height in the engine; they are not darkened survivors. Lifting the latest pair reconstructs the exact preceding bridge signature.

## Expected visible consequence

Blind, labels-off viewing should first read as one broad pigment bridge with a strange suspended arch and joined banks. After a pair is completed, a true empty interval opens through the body; the two selected ends lean and swell, and the bank beyond the second endpoint shifts. A second pair removes a different interval through the already altered bridge rather than adding a sticker to its surface.

## Cultural translation

Reference: [little-critters](https://github.com/GordenSun/little-critters)

Observed mechanism: situated code-drawn agents make pointer proximity a change in attention and create a reciprocal encounter, so the visitor is part of a relation rather than operating a dashboard.

Mutine translation: refuse animals, eyes, paper scene, and look-back imagery. Translate reciprocity into a material endpoint pact: one touched segment only holds attention; a second distinct segment answers and causes the pigment span between them to lift. The endpoints carry the relation's memory through changed geometry and the later bank receives the inherited stress.

Visible consequence: a single touch leaves the bridge and memory unchanged except for a temporary attended endpoint; a second touch creates a real geometric absence between two altered endpoints. Later pairs are computed through the changed bridge.

Falsifier: if the first touch commits, if the missing middle is only an overlay, if either endpoint remains geometrically unchanged, if later pairs ignore the altered bank, or if the blind view reads as a decorative segmented wall, the translation fails.

Anti-copy: no animals, characters, eyes, paper style, head-turning scene, source palette, source composition, code, API surface, or surface vocabulary from little-critters is reproduced.

Direction consequence: this closes Brush's pressure / coagulation / witness sequence and opens a relational-removal direction in which paint remembers not merely what was removed, but which two surviving endpoints made the removal possible.

## Interaction and replay

- Touch one visible segment, then touch another visible segment. The first touch arms; the second commits.
- A repeated touch on the same segment is refused and never writes memory.
- Enter, Space, and “keep two ends” commit the seeded default pair.
- Delete or “lift latest” removes only the newest pair and rebuilds the exact preceding bridge.
- R or “release field” clears visitor memory and restores the first bridge.
- S exports the current p5 canvas as PNG.

Seed: `0x42525544`. The engine uses a local seeded PRNG and eleven segments. Memory is bounded at four pairs. Reduced motion settles the autonomous sequence; interaction can still pair, lift, and release the bridge.

## Falsifier and deletion condition

Delete v024 if labels-off, controls-off viewing cannot communicate one material bridge and a visible missing interval; if the first touch changes memory; if the removed span is an overlay; if the endpoints do not change; if a later pair ignores prior geometry; or if the relation exists only in the annotation.
