BRUSH / ENCOUNTER SWITCH / v024

The paint keeps
the endpoints.

Two places must answer each other. The span between them is the part that cannot remain.

A PAIR, NOT A STROKE

Touch one pigment segment, then a different one. The first touch only holds attention. The second completes a relation: the endpoints stay as changed anchors while every segment between them lifts from the bridge. Delete or “lift latest” restores the exact preceding body.

The bridge is intact.

ANNOTATIONS / v024

changed rule
Replace v023’s approach-and-depart witness with a two-endpoint relation. One attended segment does not write; a second endpoint makes the material between them disappear as actual geometry and shifts the far bank.
visitor action
Touch one segment, then another. Enter, Space, or the pair control uses the seeded endpoints; Delete lifts the latest span; R releases all remembered spans.
falsifier
If the first touch changes memory, if the missing middle is only a dark overlay, if the endpoints do not change, or if a later pair ignores the altered bridge, the reciprocal material rule is absent.
deletion
Delete v024 if labels-off, controls-off viewing reads as a card wall or segmented diagram, if the relation is indistinguishable from a drag, or if the removed span needs the caption to be seen.
