# Brush v036 — The paint opens where you leave it.

## Hypothesis

If material remembers a route rather than a point, then a painted surface can refuse a local wound and open only after the viewer crosses a remote vent and exits the slab.

## Changed rule

v035 made one 2D membrane load directional tension and commit on reversal. v034 made five approached pools resolve into remote dry, ridge, and counterflow roles. v033 made three knocks rewrite distant SVG plates. v036 abandons pools, plates, scroll tension, and local pressure. One shallow WebGL slab has front and underside geometry, five faults, five remote vents, and seven potential apertures. A press only arms a fault; a cross only arms a vent; an exit outside the marked zones commits the eclipse elsewhere.

## Visible consequence

The blind render is one tilted sculptural slab rather than a field of local marks. The press and vent crossing leave its geometry signature exact. A completed exit changes actual remote rib depth, tilt, cut, shed, underside, and aperture depth. Four route events remain liftable and later events rebuild from the bounded eclipse ledger.

## Interaction

- Press a fault marker, cross a distant vent marker, then release outside both zones.
- A press and a vent crossing are geometry-neutral; the exit commits.
- Enter, Space, and `make an eclipse` use deterministic routes.
- Delete or `lift latest` reconstructs the preceding state.
- Escape, `R`, or `release slab` clears the bounded ledger.
- `S` downloads a PNG.

## Cultural translation

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** programmable drawing tools make pressure, density, and directional fields part of the production engine; the instrument changes how geometry is produced, not merely how a finished mark is styled.
- **Mutine translation:** refuse brush appearance, watercolor, hatching, grain, and the source API. Translate material agency into route-dependent subtraction: a completed fault–vent–exit route changes remote depth and negative space, while the local contact points remain causally refused.
- **Visible consequence:** the blind first view is a shallow 3D slab with front, back, and negative aperture geometry. A valid exit changes remote ribs and an actual aperture; weak or incomplete routes remain geometrically still.
- **Anti-copy:** no brush, watercolor, hatching, grain, vector-field drawing, source palette, source composition, source code, examples, API surface, or surface vocabulary is reproduced.
- **Direction consequence:** this closes Brush's pool / plate / reversal-membrane family and opens a subtraction-as-route direction: paint remembers where the viewer left, not where they first touched.

## Repeated grammar refused

The last three recorded Brush works used a 2D directional membrane, a proximity census of pools, and a three-knock SVG laminate. v036 changes medium to p5.js WebGL, representation to a shallow object with front/underside depth, and encounter to a press–cross–exit route whose commit is spatially remote from both contacts.

## Falsifier

The translation fails if a press changes geometry, if a local fault or vent becomes the answer, if exit changes only colour or readout, if the blind object reads as a generic chart or control surface, if later eclipses restart from the quiet slab, or if lifting is inexact.

## Deletion condition

Delete v036 if caption-free viewing cannot show one sculptural slab with a real negative aperture and underside change, or if the route is only a disguised button.
