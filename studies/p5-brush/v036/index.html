BRUSH / ECLIPSE SLAB / v036

The paint opens
where you leave it.

A press is only a fault. Cross a remote vent and leave the slab: the material answers somewhere else, with a real cut through its depth and an underside that sheds.

THE EXIT MAKES THE CUT

Press one of the quiet fault marks, cross a distant vent, then release outside the slab's marked places. The first two acts are geometry-neutral. Only the exit commits an eclipse: one remote rib lifts, another sheds its underside, and a third carries the route. Enter or “make an eclipse” uses a deterministic route. Delete lifts the latest; Escape or R releases the slab.

The slab is unbroken.

ANNOTATIONS / v036

changed rule
Abandon pools, plates, scroll tension, and local pressure. A single shallow 3D slab accepts a three-part route; the completed exit changes remote depth, aperture, and underside geometry.
visitor action
Press a fault, cross a vent, and leave. Enter, Space, and the eclipse control use deterministic routes. Delete lifts the latest eclipse. Escape or R releases the bounded ledger. S downloads a PNG.
falsifier
If a press writes, if the local fault or vent becomes the answer, if the exit changes only colour or readout, if later eclipses restart from the quiet slab, or if lifting is inexact, the translation fails.
deletion
Delete v036 if caption-free viewing cannot show one sculptural slab with a real negative aperture and underside change, or if the route is only a disguised button.
