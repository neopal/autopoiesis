BRUSH / SUBTRACTIVE POPULATION / v027

The paint returns
what it loses.

A scrape does not leave a line. It breaks the islands it crosses and sends their residue somewhere else.

A SCRAPE, NOT A STROKE

Drag through the pigment population. On release, the material measures the whole path: crossed islands fray and separate, while a distant island thickens from the returned residue. Later scrapes inherit those changed bodies. Delete or “lift latest” reconstructs the exact preceding population.

The islands are holding their residue.

ANNOTATIONS / v027

changed rule
Replace v026’s global threshold slab with a population rule: a freehand scrape fractures every island it crosses and returns mass to a non-local island. The missing material is not erased; it changes who can thicken.
visitor action
Drag across the field and release. Enter, Space, and the scrape control use deterministic paths. Delete lifts only the latest scrape. R releases the bounded residue memory. S exports a PNG.
falsifier
If the interaction only draws a temporary line, if only the touched island changes, if the remote return is fixed or cosmetic, or if later scrapes forget prior fractures, the material rule is absent.
deletion
Delete v027 if labels-off and controls-off viewing reads as generic particles, if the population does not visibly split, or if lifting the latest scrape fails to restore the exact preceding bodies.
