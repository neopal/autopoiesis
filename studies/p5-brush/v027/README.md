# Brush v027 — The paint returns what it loses.

## Hypothesis
If material agency is real, a subtractive scrape should change the population that produces the image rather than leave a line on top of it.

## Changed rule
v026 made one pressure sample move a global threshold across a stratified slab. v027 abandons the slab, grid, and local sample. The work is a sparse population of detached pigment islands. A freehand scrape measures a path: every island it crosses fractures and separates, while a non-local island receives the returned residue. Later scrapes replay on the already-fractured population. The archive is bounded to four scrapes.

## Visible consequence
The blind first render is a constellation of irregular filled islands with no surface, grid, route, or enclosing body. After a scrape, the crossed islands visibly split and the remote relay thickens; actual island geometry, fracture cracks, and residue rings change. The temporary path disappears after release.

## Interaction
Drag across the field and release to commit a scrape. A short or repeated scrape is refused. Enter, Space, and the scrape control use deterministic paths. Delete or “lift latest” reconstructs the exact preceding population. `R` releases the bounded residue archive. `S` exports a PNG.

## Cultural translation
- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** pressure, density, grain, and directional fields are programmable material forces that participate in producing geometry rather than decorating finished geometry.
- **Mutine translation:** invert the additive brush mark into a subtractive population law: pressure along a scrape fractures the bodies it crosses and returns their missing mass to a distant body. Material memory is redistribution, not a texture.
- **Visible consequence:** a blind constellation becomes a changed population after interaction: crossed islands separate and a non-local island thickens, with later events inheriting those bodies.
- **Anti-copy:** no p5.brush brushes, watercolor appearance, hatching vocabulary, source palette, composition, examples, or API surface are reproduced.

## Repeated grammar refused
The previous three Brush works were a flat endpoint relation (`v024`), a load-bearing 3D membrane hinge (`v025`), and a global threshold slab (`v026`). Their repeated gesture was a single addressed sample or seam acting on a continuous surface. v027 changes representation to detached islands, changes the viewer task to freehand scraping, and changes memory from deformation/threshold to population fracture and non-local return.

## Falsifier
The translation fails if a scrape only creates a temporary line, if only the touched island changes, if the remote return is fixed or cosmetic, if later scrapes restart from baseline, or if the blind field reads as generic particles or a decorative grid.

## Deletion condition
Delete v027 if labels-off and controls-off viewing cannot show a population of actual detached bodies, if the crossed bodies do not visibly fracture, if residue never changes a non-local island, or if lifting the latest scrape does not reconstruct the exact preceding bodies.
