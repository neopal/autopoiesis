# v047 — The stain answers from elsewhere.

## Hypothesis
If a brush field treats proximity as a social material force, the patch that receives attention can stay exact while an unvisited respondent changes how its edge is produced. The work should read as a field of pigment islands before it reads as an interaction diagram.

## Changed rule
Abandon the path, jaw, and pressure-crossing grammars of v044–v046. Proximity is a transient preview. A completed attention event leaves the approached cell exact and spends the event as a dry notch, altered mass, and tightened seam in a deterministic respondent elsewhere.

## Visible consequence
The blind first view is a warm paper field of sixteen unequal pigment islands joined by a loose seam network. Four accepted attentions leave their source islands untouched while four other islands gain actual concave dry edges, denser bodies, and narrowed seams. The response is stored in geometry, not in a cursor trail, label, or colour-only state.

## Reference translation
The selected cultural reference is `little-critters` (https://github.com/GordenSun/little-critters). Its observed mechanism is situated code-drawn agents whose local behavior turns pointer proximity into reciprocal attention without a dashboard. Mutine translates that mechanism into abstract pigment islands: proximity previews orientation, while a click or tap lets one unvisited island answer with produced dry-edge geometry. Animals, eyes, head-turning, characters, paper scene, source palette, source composition, source code, examples, API surface, and source imagery are refused.

## Interaction
Approach a patch and click or tap it. Pointer, touch, keyboard, and the `attend to a patch` control use the same deterministic event path. ArrowRight focuses the next patch and Enter/Space commits. Delete lifts the latest response. Escape or R releases the field. S downloads a PNG. Empty ground refuses without spending material.

## Falsifier
Delete v047 if proximity paints a scar; if the approached source changes; if the response is only a halo, status, or readout; if every source maps to the same respondent; if the field reads as a generic node diagram or anthropomorphic cast; if later responses reset; or if exact lifting fails.

## Deletion condition
Delete the trial if caption-free viewing cannot distinguish a reciprocal drying field from v044's strata, v045's clasp, and v046's depth monolith, or if reciprocal attention is only explanatory prose attached to a button.

## Direction consequence
This closes Brush's crossing/compression/through-void period and opens a social-material direction: paint remembers removal as a displaced response to situated attention, not as a trace or pressure stored at the hand.
