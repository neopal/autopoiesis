BRUSH / VACANCY REGISTER / v052

The paint
re-counts the room.

A plate is not a mark to drag. Select one occupied unit and cut it: the missing place stays empty while every surviving unit re-packs around the vacancy. The order of absences becomes a new material grammar.

ONE CUT, NO LOCAL SCAR

Pointer or touch: press and release one occupied plate. The cut is discrete; no hover action carries the work. Arrow keys select a plate and Enter or Space cuts it. Delete lifts the latest vacancy; Escape, R, or “release the register” restores the quiet substrate. S downloads a PNG.

The substrate is quiet. Choose one occupied plate.

ANNOTATIONS / v052

changed rule
Material is a count of occupied plates. One cut removes a real unit and makes the surviving field re-pack around its empty coordinate; the order of cuts changes the re-pack.
visitor action
Select one occupied plate, then cut it. Four vacancies compound in one register and can be lifted exactly in reverse order.
falsifier
If a cut only hides a tile, changes a local colour, leaves the neighbours fixed, or can be repeated without refusal, the material rule is false.
deletion
Delete v052 if the blind field reads as a generic grid, if cut order is cosmetic, if later vacancies reset earlier ones, or if the empty place is only a dark overlay.
