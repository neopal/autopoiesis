# v052 — The paint re-counts the room.

## Hypothesis

If material is an occupied register rather than a surface waiting for a stroke, one discrete withdrawal should remove a real unit and force the surviving field to re-pack around the vacancy. The first-render image should be a planar register of unequal plates, not a ring, sheet, relief, wash, or route. The cut order should be visible in the changed geometry.

## Radical progression gate

The last three Brush works repeat a gesture-and-response grammar: v049 holds a two-site chord, v050 reverses a lift into a cut, and v051 waits for a timed release. Their repeated gesture is pressure held until a local condition allows a response; their metaphor is an object storing a hand event as deformation; their visual grammar is a folded sheet, a ribbed relief, or a radial body.

v052 breaks that invariant in six visible ways: the material changes from one centred body to a broad register of independent plates; the interaction changes from hold/release to one discrete cut; pressure no longer deforms the contacted unit but removes it; the answer is a global re-pack of surviving units, not a local scar or phase shift; the memory is a persistent set of vacancies; and the medium remains Canvas 2D while the viewer task becomes selecting a countable occupied place. This is a new vacancy / re-count direction, not a refinement of the radial ring.

## Changed rule

Material is a count of occupied plates. Select one occupied cell and cut it once. The cell becomes an actual vacancy and disappears; every surviving plate is re-produced from the deterministic register with a displacement, scale, angle, and skew response around that empty coordinate. A second cut is evaluated against the already re-packed body. Repeated or empty cells are refused. Four vacancies compound and remain liftable in reverse order.

## Visible consequence

The blind first view is a dark blue-green substrate carrying thirty-five irregular planar plates with coral, cyan, acid, clay, and ink faces. A cut does not leave a cursor scar or recolour a tile: one place is genuinely empty while the remaining plates re-count and shift around it. Reversing two cuts produces a different arrangement. Four empty places remain visible as holes in the register.

## Cultural translation

The selected cultural reference is [`p5-brush`](https://github.com/acamposuribe/p5.brush). Its observed mechanism is a programmable material engine in which pressure, density, directional behaviour, fills, and vector fields participate in producing geometry rather than decorating a finished mark. Mutine translates that production logic into a material register: the visitor does not borrow a brush gesture; one discrete withdrawal changes the production coordinates of every surviving plate. The register remembers the absence, not the hand path.

## Anti-copy boundary

No p5.brush brush preset, watercolor appearance, hatching vocabulary, grain treatment, source palette, source composition, source code, examples, API surface, or source imagery is reproduced. The work uses p5.js Canvas 2D, seeded planar plates, a vacancy state machine, and deterministic global re-packing in Mutine's own vocabulary.

## Interaction

- Pointer/touch: press and release one occupied plate. The cut is discrete; leaving the plate before release refuses the event.
- Arrow keys select a plate; `Enter` / `Space` cuts the selected plate.
- `Delete` / `Backspace` lifts the latest vacancy and reconstructs the exact preceding register.
- `Escape` / `R`: release every vacancy to the deterministic quiet substrate.
- `S`: save a PNG.

## Falsifier

Delete v052 if a cut only hides a tile with a dark overlay, if neighbouring plates remain fixed, if repeated or empty cells commit, if order changes only a label, if later vacancies reset earlier ones, if lifting is inexact, or if the blind field reads as a generic grid rather than a material register.

## Deletion condition

Delete the trial if caption-free viewing cannot distinguish vacancy and global re-packing from v049's sheet, v050's relief, and v051's ring; if the discrete cut is only an interface command; or if the empty place is not legible without the annotations.

## Direction consequence

This closes Brush's phase-lock / subtraction / held-chord sequence and opens vacancy as material agency: paint can remember a removal by changing the coordinates of what remains. The next mutation must test whether a vacancy can become a constraint without returning to a grid or a single centred object.
