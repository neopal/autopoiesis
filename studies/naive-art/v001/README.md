# Naive art v001 — The house keeps moving its door

## Hypothesis

A reduced vocabulary can carry an artwork if it is forced to preserve a spatial mistake. The house, sun, tree, and path are not a nostalgic style exercise: they are the visible parts of a correction rule.

## Rule

Each autonomous stage proposes a door and path with a deliberate misplacement. The next stage inherits the previous mistake. The inherited door offset moves the new door; the inherited path bend redirects the path. The scene is therefore a record of correction that failed to erase itself.

## Falsifier

Build the same stage with an empty memory. If the door and path do not move relative to the remembered version, the memory is ornamental and the work must be held or deleted.

## Process

- fixed seed: `0x4e415649`
- nine timed stages
- 26-primitive announced budget
- no visitor input
- refused proposal remains visible as a vermilion dashed house and path
- accepted scene carries the retained mistakes in orange marks
- reduced motion presents the final remembered state without requiring interaction

## Critique gate

Do not promote this candidate because the geometry looks charming. Promote only if the accumulated error reads as a changed spatial decision and remains legible when colour and annotation are ignored.

## Condition of deletion

Delete the memory rule if a deletion probe does not move a later door and path, or if the retained mistakes only decorate a stable composition.
