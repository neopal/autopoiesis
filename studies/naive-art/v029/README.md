# Mutine Naive Art v029 — The picture joins what never touched

## Hypothesis

If a naive picture treats proximity as a faulty relation rather than a selection, then a visitor's hesitant crossing between distant parts should make the picture join those parts incorrectly and preserve a third echo of the mistake.

## Changed rule

v029 abandons v026's witness apertures, v027's layered registration print, and v028's semantic mark strip. The medium changes to a deterministic Canvas 2D raster picture: twelve irregular cut-paper parts share one warm field instead of forming a score, a route, or a DOM stack.

A pointerdown only arms a first part. A gesture must cross the central seam at least twice, change direction, travel far enough, and release on another distant part before it can write. The picture then misjoins the source and destination and shifts a third remote echo. The source contracts and slips, the destination swells and leans, and the echo tilts away. Four false joins remain in bounded memory; Delete lifts one event and R releases the picture to its seeded composition.

The event lives in actual raster geometry: patch position, scale, tilt, shear, notch, and stamped role change. The cursor, readout, and controls are witnesses, not the cause.

## Cultural translation

- **Reference:** [little-critters](https://github.com/GordenSun/little-critters)
- **Observed mechanism:** situated agents respond to proximity with legible attention and reciprocal looking, making the visitor part of a social field without a dashboard.
- **Mutine translation:** refuse animals, eyes, characters, and the look-back scene. Translate proximity into an error of relation: a single point only arms; a hesitant cross-seam gesture between distant picture parts creates a false join and a remote echo in the canvas.
- **Visible consequence:** the blind first render is one contiguous cut-paper picture of irregular coloured parts. After a valid gesture, three actual bodies move, scale, shear, and tilt; later joins inherit those changes.
- **Falsifier:** delete the direction if a point or shallow drag writes, if the release location merely selects the result, if only the cursor/readout changes, if fewer than three bodies change, if later joins restart from baseline, or if the blind canvas reads as a generic chart.
- **Anti-copy:** no animals, characters, eyes, paper scene, source palette, source composition, source code, or head-turning image is reproduced.
- **Direction consequence:** closes Naive art's witness / registration / mark-strip sequence and opens a raster misrelation direction: the mistake is a spatial join produced by a hesitant gesture, not a moved gap or a corrected layer.

## Visible consequence

Caption-free, controls-off viewing should show a single naive cut-paper picture with an irregular internal rhythm and no diagrammatic grid. After a valid cross-seam gesture, the source, distant relay, and remote echo should be findable as changed silhouettes. The first event is not a cursor trail, local stamp, or changing counter.

## Art gate

- **Seed/state:** `0x4e413239`, twelve patch picture, four-event memory window, deterministic gesture timeline, static preview settles after four retained joins.
- **Expected consequence:** one sufficiently hesitant gesture changes three canvas bodies before the explanation is read.
- **Falsifier:** if crossing and hesitation do not alter actual patch geometry, or if the image reads as a generic chart or tile dashboard, the translation fails.
- **Deletion condition:** after two independent labels-off and controls-off comparisons, delete v029 if the three changed bodies cannot be found at 390px, if release is indistinguishable from clicking the button, or if lifting does not reconstruct the exact preceding picture.

## Evidence method

The pure engine is replayable from `0x4e413239`. Browser probes exercise arming without writing, shallow-gesture refusal, a real multi-crossing pointer gesture, Enter/button equivalence, Delete/lift, R/release, blind preview, reduced motion, and all five required viewport sizes.

## Reproduction

Open `index.html`. Press on a coloured part, drag across the centre, reverse direction twice, travel to another part, and release. A shallow gesture is refused. Enter or **make the false join** performs the deterministic equivalent. Delete lifts the latest false join. R releases the bounded memory.
