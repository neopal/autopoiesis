# Naive art v014 — The mistake refuses a room

Status: daily candidate, held for independent caption-free perceptual review.

## Hypothesis

A naive drawing can keep a mistake alive without correcting it or turning it into a branch. If a retained wrong turn removes a piece of the scene, the drawing should make memory feel like a material absence: the house loses a room, the ground is notched, and the missing fragment remains visibly displaced instead of being repaired.

## Cultural translation

The selected reference is p5.brush. Its observed mechanism is that material changes how geometry is produced and remembered, rather than decorating an already fixed shape. Mutine refuses the brush library's brushes, watercolor, hatching, palette, and API surface. The translated naive-art rule is: a remembered mistake punctures a flat picture, lifts the missing fragment, and forces the remaining house/ground geometry to be re-cut around the absence.

## Changed rule

v010–v013 kept one route grammar: a line approaches a point, changes lane, and leaves downstream as bypass, bridge, seam, or fork. v014 deletes the route bundle. Each retained correction is now a five-sided puncture with a material target, a missing room, a displaced fragment, and a cumulative house shift. The same record is replayed through object, ground, and fragment geometry; the image is no longer a route diagram.

## Visible consequence

- the first encounter is one oversized paper scene, not a proposal/consequence diptych;
- remembered cuts appear as actual negative spaces in the house or ground;
- every cut lifts a fragment and nudges the house, so the picture rebuilds rather than merely gaining a mark;
- pointer position chooses the material target, polarity, depth, lift, and angle;
- undo reconstructs the exact preceding geometry; release clears visitor memory and restarts the seeded sequence.

## Art gate

- **Seed/state:** `0x4e413134`, sixteen deterministic stages; reduced motion/static preview settles on stage 16 with the latest five tears retained in the finite structural window.
- **Expected consequence:** adding one tear changes `scene.tearRecords`, cutout polygon coordinates, displaced fragment coordinates, ground notches, and house shift together.
- **Falsifier:** if labels, readout, cut markers, and prose are removed and the field reads as a normal house with decorative stickers, the material rule is not carried.
- **Deletion condition:** delete v014 if two caption-free comparisons cannot identify the missing-room / lifted-fragment / re-cut-scene grammar, or if the visitor gesture changes only a counter.

## Interaction

Click the field to remove a normalized piece of the paper scene. `Enter`/`Space` and **tear a room** add the same bounded visitor record. **undo latest** removes the newest record and reconstructs the earlier field. **release sequence** clears visitor memory and restarts the seeded sequence.
