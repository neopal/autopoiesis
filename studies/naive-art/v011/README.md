# Naive art v011 — The mistake keeps a bump

Status: daily candidate, held for independent caption-free perceptual review.

## Hypothesis

A naive drawing can keep a mistake alive without correcting it or turning it into a symbol. If a retained wrong turn rises into a small vertical excursion, the drawing should make memory feel like a changed contour rather than a decorative scar. The roof edge, ground, and walking route should each approach, lift, crest, descend, and return downstream.

## Changed rule

v010 made each retained correction an approach/sidestep/alongside/return bypass. v011 abandons that lateral grammar. Each retained correction now becomes a five-phase bump record: approach, lift, crest, descent, and return. The same record is replayed from three origins — the roof edge, the ground, and the route — while the return moves the next cursor downstream. The mistake no longer takes a side road; it briefly changes altitude.

## Visible consequence

- the proposal panel is a direct house with a straight ground and route;
- the consequence panel gives the roof edge, ground, and walking route the same vertical excursion grammar;
- the visitor's x position chooses width, duration, and tilt while y chooses upward/downward polarity and height;
- the visitor can place a bounded bump, and undo reconstructs the exact previous geometry;
- static preview and reduced motion settle on the final seeded stage without interaction.

## Art gate

- **Seed/state:** `0x4e413131`, sixteen deterministic stages; `static=1` settles on stage 16 with the latest six autonomous bumps retained in the finite structural window.
- **Expected consequence:** adding one bump changes `scene.bumpRecords`, the house bump line, ground bump line, route coordinates, and downstream roof return together.
- **Falsifier:** if labels, readout, bridge, bump dots, and all prose are removed and the kept panel reads as an ornament over unchanged lines, the changed rule is not perceptually carried.
- **Deletion condition:** delete v011 if two caption-free comparisons cannot identify a repeated lift, crest, descent, and return in the roof, ground, and route, or if the visitor gesture changes only a counter.

## Interaction

Click the field to place a normalized bump. The x position changes width, duration, and tilt; the y position chooses upward/downward polarity and height. `Enter`/`Space` and **keep the bump** add the same bounded visitor record. **undo latest** removes the newest record and reconstructs the earlier field. **release sequence** clears visitor memory and restarts the seeded sequence.
