# v033 — The proof misheard itself.

## Hypothesis

If a naive picture is treated as a proof sheet rather than an image of a thing, then attention can become a wrong witness: the visitor offers a sequence without directly writing the answer, and the sheet misremembers the sequence somewhere else.

## Changed rule

v033 abandons v032's branch organism, node topology, and pointer-selected path. It replaces them with one oversized line of invented glyphs rendered in p5.js Canvas 2D. Three distinct keyboard witnesses are listened to but do not change the geometry. Only a complete witness commits a remote misread: one glyph changes form, a distant glyph inherits the old form, a fourth glyph opens as a blank, and the proof line breaks.

## Visible consequence

The first-render blind view is a single typographic register sheet, not a population, tree, orbit, chart, or panel system. A committed witness changes actual glyph geometry and the baseline interruption. The typed digits never appear in the artwork. Four committed errors remain bounded and are replayed into later sheets; lifting reconstructs the exact preceding sheet.

## Interaction

- Type `1`–`6`, or press the six witness keys, to listen to a token.
- Enter / Space commits the three-token witness.
- Delete / Backspace lifts the latest committed error.
- Escape / `R` releases the proof.
- Pointer/touch on the sheet chooses a witness according to the horizontal position; it does not commit by itself.

Partial and repeated witnesses are refused and remain geometrically exact.

## Cultural translation

- **Reference:** [little-critters](https://github.com/GordenSun/little-critters)
- **Observed mechanism:** situated agents respond to proximity with legible attention and reciprocal consequence; the visitor participates in a social field without a dashboard.
- **Mutine translation:** refuse animals, eyes, characters, paper, and head-turning; translate reciprocal attention into a proof that listens to a sequence and misreads it at a distant glyph.
- **Anti-copy:** no animals, characters, eyes, scene, source palette, composition, code, API surface, or head-turning image is reproduced.

## Falsifier

Delete v033 if the keyboard only behaves as a button, if a token writes visible content, if the local witness becomes the answer, if the changed glyph/blank/baseline are cosmetic, if the first field reads as an input widget or generic text diagram, or if replay/lifting is inexact.

## Deletion condition

Delete the direction if caption-free viewing does not read as one continuous proof sheet with a materially displaced error, or if the work is only a reskinned route/tree/orbit from v029–v032.

## Direction consequence

This closes the naive current's populated spatial-organism sequence and opens a typographic error direction: the mistake is now a wrong witness embedded in a page, with keyboard attention as the encounter and a blank as the remembered absence.
