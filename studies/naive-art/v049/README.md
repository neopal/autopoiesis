# Naive art v049 — The model kneads the missing answer.

## Hypothesis

If a naive model treats material resistance as evidence, then a visitor's opposed, turning pressure should remain geometry-neutral until release. Once the pressure has turned against the field three times, the model must spend the entire answer on a wrong seam: every SVG cell changes, and an unjustified pair fuses into a visible fold.

## Last-three comparison and structural rupture

The last three Naive works were v048's reciprocal Canvas ecology, v047's horizontal proof strip, and v046's suspended WEBGL vessel. Their repeated gesture was a visitor acting in one place while the model displaced or globalised an error through a field, strip, or object; four errors accumulated and could be lifted.

v049 makes a material and encounter switch:

- **Representation / medium:** a Canvas ecology, proof strip, and WEBGL vessel become a generated SVG topology of twelve unequal cells, actual apertures, and produced joins. The work is path geometry, not a drawn scene or a remote fragment.
- **Composition / shape vocabulary:** bands, witnesses, and throats become a compact irregular body of angular cells whose seams and empty apertures are the image. There is no crowd, register, or architectural opening to read first.
- **Encounter:** proximity, correction drag, and stillness become a pressure argument. The visitor pushes, turns against resistance, pushes again, and releases; pointer, touch, keyboard, and the deterministic fold control are equivalent paths.
- **Causal / memory rule:** the gesture is inert while it is in motion. Release after enough pressure, opposition, resistance, and turns changes the topology globally. The model does not remember a source position: it chooses a wrong pair to join from the pressure signature and the accumulated fold order. Four topology errors compound and can be lifted exactly.

The rupture is visible in code (`commitPressure`, `materialise`, `foldPair`), interaction (counterpressure rather than selecting, holding, or crossing a source), and rendered consequence (all twelve cells and three apertures are regenerated, with a real SVG join and altered topology).

## Changed rule

Pressure is not a mark or a local edit. When the pressure turns against the field three times and survives a resistance threshold, the naive model treats the struggle as evidence and folds the whole topology around a seam that was never there. Fold order changes which cells are joined.

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** programmable pressure, density, direction, and vector fields participate in producing geometry rather than decorating a finished mark. Material is an engine for how form is made.
- **Mutine translation:** refuse brushes, watercolor, hatching, grain, source palette, source composition, source code, examples, and API surface. Translate material production into a naive inference rule: only opposed pressure that turns against a field can change topology, and the model chooses a non-local seam from the pressure signature rather than preserving the visitor's path.
- **Visible consequence:** the blind first view is a dark violet ground carrying a compact irregular SVG body of twelve pale angular cells, three actual apertures, and quiet seams. A valid release changes every cell's position, angle, scale, notch, phase, and pressure depth; two cells become a produced fold join. Four folds compound and remain liftable.
- **Falsifier:** delete if pressure only draws a trace, if weak, unopposed, unsettled, or straight gestures commit, if only one cell changes, if the join is a line annotation, if every gesture chooses the same pair, if memory resets, if lifting is inexact, or if the blind view reads as v048's crowd, v047's strip, or a generic mosaic.
- **Anti-copy:** no brush preset, watercolor appearance, hatching vocabulary, grain treatment, source palette, source composition, source code, examples, API surface, or source imagery is reproduced.
- **Direction consequence:** closes Naive's reciprocal attention / misprint / stillness sequence and opens pressure-as-belief: model failure is no longer a displaced copy or stale stare but a topology reconstructed from the wrong material evidence.

## Visible consequence

With labels, readout, controls, hint, and prose hidden, the first view is a bruised violet field carrying twelve unequal angular cells. Pale seams, three dark apertures, and a restrained ambient field make a compact body without a privileged target. As the visitor pushes and turns, a dashed trace is provisional only. A valid release regenerates the whole SVG: every cell drifts, its scale and angle change, the touched path is not preserved, and an incorrect pair becomes one warm folded join. Four such errors compound without storing the pointer path.

## Interaction

- **Pointer / touch:** press anywhere in the field, make a turning counterpressure path, and release. Three direction changes and sufficient resistance are required; a short, straight, weak, or unopposed path is refused.
- **Keyboard:** focus the field, use `ArrowLeft` / `ArrowRight` to move the focus ring, `Enter` or `Space` to perform the deterministic pressure fold, `Delete` / `Backspace` to lift the latest fold, and `Escape` / `R` to release memory.
- **Controls:** **make a fold** performs the next deterministic pressure signature; **lift last fold** reconstructs the preceding topology; **release the pressure** clears memory.
- `?preview=1&static=1&blind=1` renders four settled topology folds while hiding all editorial furniture and controls.

## Deletion condition

Delete v049 if caption-free viewing cannot distinguish pressure topology from v046–v048's vessel, proof strip, and reciprocal field; if the path is only a cursor trail; if any refused gesture commits; if the topology does not change globally; if the join is cosmetic; if order is not structural; if later memory resets; if exact lifting fails; or if the first view collapses into a generic grid, mosaic, or interface.
