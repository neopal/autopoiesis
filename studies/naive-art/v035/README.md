# Naive art v035 — The model mistakes the hole.

## Hypothesis

If a model is taught a bounded pressure gesture but is forbidden to preserve the gesture as an image, it will invent a remote contour and misrecognise a different place as absence. The mistake should be visible as changed plate geometry, not as a status message.

## Changed rule

v035 leaves v034's faceted relief, v033's typographic proof, and v032's semantic inheritance tree. A bounded pressure stroke is refused as a trace. Its length, turn, and direction become production pressure: the source compresses, a remote anchor receives a false contour, a separate anchor loses body, and a fourth ridge remembers the error. The memory is carried by one continuous plate with a movable aperture rather than by a population of model parts.

## Cultural translation

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** pressure, density, directional behaviour, and fields can participate in producing geometry rather than styling a completed mark.
- **Mutine translation:** refuse brush appearance and surface vocabulary; make pressure alter the model's future geometry, then make the model infer the wrong edge remotely.
- **Anti-copy:** no brush, watercolor, hatching, grain, palette, composition, source code, example, API, or surface vocabulary is reproduced.

## Visible consequence

The first blind view is one continuous off-axis memory plate with an unresolved aperture. A valid gesture disappears after release. The actual plate changes away from its source: one contour overgrows, another becomes a hole, a fourth ridge keeps the pressure, and the aperture relocates. Later gestures begin from that changed geometry. Labels and readout are not required to see the difference.

## Interaction

- A pointer/touch gesture previews without committing geometry.
- At least three points and a bounded normalized length are required.
- Enter, Space, or **let the model misread** performs deterministic strokes from the seed timeline.
- Delete lifts the latest error exactly; Escape or R releases the plate.
- `?preview=1&static=1&blind=1` renders four settled errors with editorial furniture hidden.

## Falsifier

Delete v035 if the gesture survives as a visible trail, if only colour/readout changes, if the nearest contour is always the answer, if the remote contour or aperture is cosmetic, if later strokes reset, or if lifting is inexact.

## Deletion condition

Delete this direction if a caption-free first encounter reads as a generic linefield, grid, waveform, route, relief, or control panel rather than one singular memory plate whose absence has been materially misread.

## Direction consequence

This opens `pressure-misread`: naive art now tests model failure as a wrong spatial inference in a continuous negative field. It closes the recent discrete witness / relief / inheritance grammar and leaves open a future collision with refusal or self-modifying media.
