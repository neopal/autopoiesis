# Naive art v039 — The model counts the quiet cells.

## Hypothesis

If a naive picture treats one marked cell as evidence, then the error should not be a cursor echo or a local answer. The selected cell should remain geometrically quiet while a low-resolution inference plate spends that evidence in a remote patch, opens a false void, and lets a neighbouring edge remember the miscount.

## Changed rule

v039 is a material and encounter rupture relative to v038's witness cut-outs, v037's three-mark pressure print, and v036's false accordion. The medium becomes one p5.js Canvas 2D cellular raster: 26 by 18 weighted cells form a crooked, connected plate rather than discrete cut-outs, stamps, or browser folds. Marking a cell is geometry-neutral. Enter, Space, or the action control commits a single-cell reading; the marked cell remains exact, but a remote patch swells into the wrong value, a distant cell becomes a false void, and a third edge carries the cadence. Four miscounts compound and can be lifted exactly.

## Interaction

- Pointer/touch: tap or click one cell to mark it; marking alone never changes geometry.
- Keyboard: `Enter` or `Space` commits the marked cell, or uses the next deterministic reading; `Delete` / `Backspace` lifts the latest error; `Escape` / `R` releases the plate.
- Controls: **miscount the quiet cell** commits a deterministic reading; **lift last error** reconstructs the exact prior plate; **release the plate** clears memory.
- `?preview=1&static=1&blind=1` renders four settled cellular errors with editorial furniture and controls hidden.

## Falsifier

Delete v039 if marking changes geometry, if the selected cell answers directly, if the wrong patch or void is only colour/readout, if the blind raster reads as a generic chart or cellular automaton, if later errors reset, or if exact lifting fails.

## Deletion condition

Delete this direction if caption-free viewing cannot distinguish the cellular plate from v038's cut-out field, v037's pressure print, and v036's browser page, or if the error is not materially produced in the cell geometry.
