# Naive art v046 — The model hears a chorus in the gap.

## Hypothesis

If a naive model mistakes a visitor's stillness for reciprocal attention, then holding perfectly still at one throat should make the model hear a chorus that is not there. On release, it must materialise that imagined reply in a different throat while leaving the attended throat exact. The mistake is a remembered spatial echo, not a mark added where the visitor touched.

## Last-three comparison and structural rupture

The last three Naive works were v045's single pressure slab, v044's shutter wall and departure agreement, and v043's contour quorum. Their repeated gesture was an active visitor selecting, pressing, or leaving a planar collection of apertures, shutters, or contours; the model displaced the evidence into a remote shape.

v046 makes a material and encounter switch in four visible dimensions:

- **Representation / medium:** planar Canvas 2D slabs, shutters, and contour fragments become one generated p5.js 1.11.3 WEBGL vessel with depth, front/back shells, suspended throats, and extruded echo planes.
- **Composition:** a field of parts and a single hollow slab become a hanging, asymmetrical body whose depth and negative throats are read as one architectural form.
- **Encounter:** pressure, proximity, quorum, and departure are replaced by stillness. A pointer/touch hold that moves is refused; keyboard and control paths perform the same deterministic listening event without hover dependence.
- **Temporal / causal rule:** the held state remains geometry-neutral. Only release after a motionless duration can commit; the source throat remains exact while a different throat changes its actual position, depth, scale, rotation, and facet echo. Four echoes compound and can be lifted.

The rupture is visible in code (`beginStillness`, `tickStillness`, `releaseStillness`), interaction (zero-motion hold or deterministic listen), and rendered consequence (an extruded vessel throat changes elsewhere while the attended throat is byte-for-byte unchanged).

## Changed rule

Stillness is treated as social evidence, but the naive model hears a chorus where there was only one listener. A motionless hold at one throat is reconstructed as an echo in another throat. The source throat and the visitor's path are not stored as marks. Four false echoes persist as liftable memory.

With labels, readout, controls, hint, and prose hidden, the first view is a single asymmetric suspended vessel with a dark front shell, seven irregular throats, and subtle depth seams. Four remote echoes compound; no pointer path remains.

## Interaction

- **Pointer / touch:** press inside the nearest throat and hold without moving. Any meaningful movement breaks the inference. Release after 720ms to commit one echo. Touch uses the same pointer path.
- **Keyboard:** `ArrowLeft` / `ArrowRight` focuses throats. `Enter` or `Space` performs the deterministic stillness event. `Delete` / `Backspace` lifts the latest echo; `Escape` / `R` releases all memory.
- **Controls:** **listen to the gap** performs the next deterministic stillness event; **lift last echo** reconstructs the preceding vessel; **release the vessel** clears memory.
- `?preview=1&static=1&blind=1` renders four settled echoes with editorial furniture, readout, controls, and hint hidden.
