# Naive art v042 — The model turns the answer into the wrong volume.

## Hypothesis

If a naive model treats a change in viewpoint as a correction, then a scan that reverses direction should not repair the object. It should spend the reversal as evidence in a different depth: the visited solid remains exact while remote solids slide, shear, and hollow. The error is not a mark on the surface; it is a wrong volume that remembers how it was read.

## Last-three comparison and structural rupture

The last three Naive works were v041's browser-native sentence of wrong words, v040's continuous pressure-cast relief, and v039's cellular inference plate. Their repeated gesture was local evidence offered to a surface and then displaced into remote geometry, with discrete memory layered onto a mostly front-facing field.

v042 breaks that grammar in three visible dimensions:

- **Representation / medium:** browser DOM text, raster cells, and Canvas relief become a p5.js WebGL volume of nine solid blocks around an absent core.
- **Composition:** scattered sentence, plate, and broad relief become an oblique, depth-bearing object whose occlusion and negative core must be read spatially.
- **Encounter / time:** touching a word, pressing a band, or marking a cell becomes a signed scan: one direction is latent, and only reversal commits a non-local depth error.

The rupture is visible in code (`WEBGL`, solid block geometry, depth and rotation mutations), interaction (pointer/touch or Arrow keys must reverse a scan), and rendered consequence (remote block z-depth, dimensions, rotation, and role change while the scan's source remains exact).

## Changed rule

A one-way depth scan is geometrically neutral. Only a reversal can be committed. The naive model then misregisters three remote solids as `misregistered`, `sheared`, and `hollowed`; the solid that supplied the scan remains exact. Four reversed scans compound and can be lifted one at a time.

## Cultural translation

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** pressure, density, direction, and field logic participate in producing geometry rather than decorating a finished mark.
- **Mutine translation:** refuse brush marks, watercolor, hatching, grain, palette, composition, source code, examples, and API surface. Translate directional material agency into a wrong-volume law: a scan stays latent until it reverses, then its directional pressure is spent in remote depth, not at the viewed solid.
- **Visible consequence:** the blind view is an oblique cluster of nine solid blocks around a dark missing core. After reversal, the observed block stays exact while remote blocks change depth, width, height, rotation, surface role, and opacity; four errors remain visible.
- **Falsifier:** if one-way scanning changes geometry, if reversal only changes a readout, if the viewed block answers itself, if the work reads as a flat stack or generic 3D demo, if later errors reset, or if lifting is inexact, the translation fails.
- **Anti-copy:** no p5.brush preset, brush appearance, watercolor, hatching vocabulary, grain treatment, palette, composition, source code, API surface, or source imagery is reproduced.
- **Direction consequence:** closes Naive's sentence / relief / cellular evidence sequence and opens wrong-volume reconstruction: model failure becomes an error of depth and viewpoint rather than another displaced mark on a planar field.

## Visible consequence

With labels, readout, controls, hint, and prose hidden, the first view is a dark oblique volume with nine irregular solids and a missing core. A valid reversal leaves the source solid exact; elsewhere, one block jumps in depth and rotates, one shears and narrows, and one hollows and fades. The viewer can see the new state without a caption because occlusion, silhouette, and the central void change.

## Interaction

- **Pointer / touch:** drag in one direction, then reverse before release. A one-way drag is refused; a reversed drag commits. Pointer events are shared by mouse and touch.
- **Keyboard:** `ArrowDown` / `ArrowUp` provide the same signed scan; `Enter` or `Space` commits; `Delete` / `Backspace` lifts the latest error; `Escape` / `R` releases the volume.
- **Controls:** **reverse the model** performs a deterministic scan/reversal; **lift last error** reconstructs the previous volume; **release the volume** clears memory.
- `?preview=1&static=1&blind=1` renders four settled errors with editorial furniture and controls hidden.

## Deletion condition

Delete v042 if caption-free viewing cannot distinguish the wrong volume from v039–v041's plate, relief, and sentence; if the source solid changes; if a one-way scan commits; if remote depth is cosmetic; if the first view is only a generic 3D block demo; if later reversals reset; or if exact lifting fails.
