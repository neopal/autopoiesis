# Naive art v015 — The picture copies the wrong thing

Status: daily candidate, held for independent caption-free perceptual review.

## Hypothesis

A naive drawing can remember a mistake as a failed transmission between pictures. If one panel leans toward an encounter, a distant panel copies the wrong motif, and a third panel loses a pictorial slot, the image should show memory as a relation between scenes rather than as another route, branch, or puncture.

## Cultural translation

The selected reference is `little-critters`. Its observed mechanism is situated reciprocity: proximity changes attention and the field answers the visitor. Mutine refuses animals, characters, paper scenes, head-turning animation, source palette, composition, and surface style. The translated naive-art rule is: four childlike picture panels form a family; a remembered look makes a nearby picture lean, sends a wrong motif to a distant picture, and leaves a real blank slot in a third.

## Changed rule

v010–v013 used an approach/consequence route grammar, while v014 used one paper scene with material absence. v015 changes representation and encounter: one scene becomes four related picture slips, and a visitor no longer tears or redirects an object. The gesture is `look → local misread → distant wrong copy → blank slot`. The answer is carried by actual panel rotation, copied motif geometry, and omitted pictorial geometry.

## Visible consequence

- the first encounter is a four-panel picture-strip rather than one house or route field;
- a remembered event rotates a local panel's composition, not just its label;
- a distant panel receives a displaced copy of a motif;
- a third panel omits the same motif and leaves an outlined paper vacancy;
- pointer, Enter, and Space add the same bounded misread; undo reconstructs the exact prior panel state; release restarts the seeded sequence.

## Art gate

- **Seed/state:** `0x4e413135`, eighteen deterministic stages; reduced motion/static preview settles on the final five-event memory window.
- **Expected consequence:** one misread changes panel turn, reply geometry, and missing-slot geometry together.
- **Falsifier:** if labels and readout are removed and the result reads as four decorative cards, or if interaction changes only counters/colour, the translation fails.
- **Deletion condition:** delete v015 if two caption-free comparisons cannot identify local lean, distant wrong copy, and real blank slot, or if the four-panel grammar collapses into another single-scene route.

## Interaction

Click the field to place a bounded misread. `Enter`/`Space` and **misread this** place the same deterministic visitor event. **undo latest** removes the newest record and reconstructs the earlier panel arrangement. **release sequence** clears visitor memory and restarts the seeded sequence.
