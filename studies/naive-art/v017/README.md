# Naive art v017 — The pile mistakes your shadow

Status: daily candidate, held for independent caption-free perceptual review.

## Hypothesis

A naive picture can remember a mistake as a wrong assignment inside one assembled object. If a visitor stays with the pile long enough, the nearest block should mistake the visitor for a distant block: the attended block carries a false face, the distant block inherits the wrong identity, and the supports expose an actual gap. The memory should live in the pile's geometry, not in an annotation.

## Cultural translation

The selected reference is `little-critters`. Its observed mechanism is situated reciprocity: proximity changes attention and code-drawn agents look back. v016 inverted that mechanism by refusing presence and making departure causal. v017 explicitly inverts v016's refusal: sustained presence is accepted, but the reply is not a look-back. The pile misaddresses the visitor as a distant block and materially rebalances itself. Animals, characters, eyes, paper style, source palette, composition, and surface vocabulary are refused.

## Changed rule

v014 used a single punctured scene, v015 used distributed picture panels, and v016 used isolated SVG forms committed by departure. v017 changes representation, composition, encounter, and temporal behavior together:

- inline SVG forms become one deterministic Canvas 2D pile of irregular blocks;
- isolated bodies become a single lopsided stack whose supports carry visible load;
- departure is replaced by sustained attention: pointer proximity arms a witness, a hold commits the event;
- a wrong identity is not copied as a fragment: it is cut into a block face, inherited by a distant block, and paid for by a real gap in the support structure.

The gesture is `presence arms → hold → wrong face → distant inheritance → pile gap`.

## Visible consequence

- the blind field is one assembled, tilted pile rather than panels, routes, or a loose population;
- pointer movement alone leaves the pile unchanged;
- sustained pointer attention changes block geometry and leaves an exposed gap;
- the addressed block carries a false face with a changed cut, a distant block inherits the wrong identity as a new interior construction, and a support shifts under the load;
- Enter/Space and **hold attention** commit the same deterministic event; undo restores the exact preceding pile; release restarts the seeded sequence.

## Art gate

- **Seed/state:** `0x4e413137`, sixteen deterministic stages, four-event visible memory window; reduced motion/static preview settles on the final retained state.
- **Expected consequence:** one sustained attention event changes the addressed block, a distant block, and the pile's support gap together.
- **Falsifier:** if labels/readout are removed and the work reads as a decorative block pattern, if movement without a hold changes the pile, or if the false face/inherited identity/gap is only recolouring, the translation fails.
- **Deletion condition:** delete v017 if two caption-free comparisons cannot distinguish sustained attention from departure, or if the blind view collapses back into panels, routes, isolated forms, or an explanatory diagram.

## Interaction

Move into the pile: a witness is armed but the image stays unchanged. Hold pointer attention: after a bounded dwell, the pile commits a deterministic misaddress. `Enter`/`Space` and **hold attention** place the same default event. **undo latest** removes the newest event and reconstructs the earlier pile. **release sequence** clears visitor memory and restarts the seeded sequence.
