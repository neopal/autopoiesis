# Naive art v018 — The picture forgets the hinge

Status: daily candidate, held for independent caption-free perceptual review.

## Hypothesis

A naive picture can remember a mistake as a wrong relationship rather than a wrong object. If a visitor drags one part toward another, the nearest panel should misread the destination: its original hinge opens, while a distant false hinge carries the stolen direction. The memory must live in the sculpture's joints and panel geometry, not in a cursor or caption.

## Cultural translation

The selected reference is `little-critters`. Its observed mechanism is situated reciprocity: proximity changes attention and code-drawn agents look back. v018 refuses the look-back and translates proximity into misassigned adjacency: a drag across the sculpture makes the nearest panel borrow a distant neighbour, opens its true joint, and grows a false hinge elsewhere. No animals, characters, eyes, paper style, source palette, composition, or surface vocabulary are reproduced.

## Changed rule

v015 used distributed picture panels, v016 used isolated SVG forms committed by departure, and v017 used a load-bearing Canvas pile committed by sustained attention. v018 changes representation, composition, encounter, and temporal behavior together:

- the pile becomes one crooked hinged paper mechanism with a visible spine of joints;
- sustained presence is replaced by a directional drag that names a mistaken destination;
- the nearest panel drifts away from its true hinge and opens a real gap;
- a distant false hinge bridges the wrong pair and carries a borrowed mark from the source panel;
- undo removes only the latest misremembered joint and reconstructs the exact previous sculpture.

The gesture is `drag across → wrong neighbour → true hinge opens → false hinge carries direction`.

## Visible consequence

- the blind field is one connected, dark-ground paper sculpture rather than a pile, picture strip, or loose form population;
- a short click or pointer movement changes no geometry;
- a meaningful drag changes one panel's drift and the state of two actual joints;
- the original hinge opens visibly while a distant hinge grows a bent bridge and borrowed mark;
- Enter/Space and **make wrong fold** commit the same deterministic event; undo restores the exact preceding sculpture; release restarts the seeded sequence.

## Art gate

- **Seed/state:** `0x4e413138`, seventeen deterministic stages, four-event visible memory window; reduced motion/static preview settles on the final retained state.
- **Expected consequence:** one drag changes a panel, an original joint, and a distant false joint together.
- **Falsifier:** if labels/readout are removed and the work reads as a decorative panel array, if a short click changes the sculpture, or if the open and false hinges are only recolouring, the translation fails.
- **Deletion condition:** delete v018 if two caption-free comparisons cannot distinguish a directional drag from v017's sustained attention, or if the blind view collapses back into a pile, picture strip, or diagram.

## Interaction

Drag from one region of the sculpture toward another. A short click is refused. A meaningful drag commits one bounded misremembered hinge. `Enter`/`Space` and **make wrong fold** place the same default event. **undo latest** removes the newest event and reconstructs the earlier sculpture. **release sequence** clears visitor memory and restarts the seeded sequence.
