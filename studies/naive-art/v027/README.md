# Mutine Naive Art v027 — The correction shifts the whole print

## Hypothesis

If a naive picture treats correction as material pressure rather than a local edit, closing a return gesture should misregister the entire print and preserve an error in a plate the visitor did not touch.

## Changed rule

v027 abandons v024's faceted WebGL theatre, v025's dense pressure sheet, and v026's dispersed SVG witness apertures. The tableau is now one browser-native DOM/CSS registration object: eight layered ink plates share one rough silhouette and one displaced opening.

Pointerdown only arms a gesture. A pointer path commits only when it is long enough and returns near its beginning. The closed loop does not stamp at its endpoint. Instead, a deterministic material rule chooses a seam, drifts every layer through registration debt, and widens a non-local void in a remote plate. Four corrections remain in bounded memory; Delete lifts the latest exact state and R releases the register.

The event must live in CSS geometry: `transform`, `clip-path`, and the remote void change. The readout, crosshairs, and temporary route are witnesses to the event, not its cause.

## Cultural translation

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** pressure, density, grain, and directional fields participate in producing geometry rather than decorating finished geometry.
- **Mutine translation:** refuse brushes, marks, watercolor, and the source surface. Translate material pressure into registration debt: a closed correction loop makes one layered DOM print slip as a body, while a distant plate receives the wrong opening.
- **Visible consequence:** the blind first render is one large rough print object, not a field of witnesses, a plane theatre, or a pressure sheet. After a committed loop, the whole silhouette drifts and a remote void changes its actual CSS polygon; later loops act on the already misregistered stack.
- **Falsifier:** delete the direction if an open loop writes, if the pointer location directly selects the seam, if only a readout or cursor changes, if the remote void is cosmetic, if later corrections restart from baseline, or if the blind field reads as a generic card stack or chart.
- **Anti-copy:** no p5.brush brushes, watercolor appearance, hatching vocabulary, source palette, source composition, examples, or API surface is reproduced.
- **Direction consequence:** closes Naive art's field-of-apertures sequence and opens a registration-error direction in which the picture is one material body whose correction cannot stay local.

## Visible consequence

The first-render blind view is an oversized, layered print with a rough crop, a displaced central opening, and registration marks. A pointer loop that returns to its beginning changes the body itself. An open or short loop is refused without changing memory or geometry.

## Deletion condition

After two independent labels-off and controls-off comparisons, delete v027 if the blind body reads as a generic stacked card, if closing the loop cannot be distinguished from clicking a button, if the remote opening is only an accent, or if lifting fails to reconstruct the exact preceding print.

## Evidence method

The pure engine is replayable from `0x4e413237`. Browser probes exercise pointerdown (no write), an open loop (refusal), a closed loop (registration commit), Enter/button equivalence, Delete/lift, R/release, blind preview, and all five required viewport sizes in normal and reduced-motion modes.

## Reproduction

Open `index.html`. Draw a long loop on the print and return close to its starting point. `Enter` or **close the correction** performs the deterministic equivalent. `Delete` lifts the latest correction. `R` releases the bounded register.
