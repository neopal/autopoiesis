# Naive art v047 — The model keeps the wrong correction.

## Hypothesis

If a naive model treats a correction as material that must be carried forward, then a correction dragged across one proof strip should not be printed where it began. When released after enough travel and pressure, it must become a real offset fragment in a different slot while the source remains exact. The mistake is a remembered placement error, not a decorative trace.

## Last-three comparison and structural rupture

The last three Naive works were v046's suspended WEBGL vessel and stillness, v045's single pressure slab, and v044's shutter wall and departure. Their repeated grammar was a spatial object made from apertures or throats: the visitor selected a place, the model displaced evidence into another place, and four remote forms accumulated.

v047 makes a medium and encounter switch:

- **Representation / medium:** a suspended 3D vessel, planar slab, and shutter wall become a long p5.js Canvas 2D proof ledger made from a continuous register strip and nine abstract proof fragments.
- **Composition:** a singular body with deep openings becomes a horizontal sequence with no centre, no cavity, and no architectural mass; the reading is an imperfect print run.
- **Encounter:** stillness, pressure return, and departure become a long correction drag followed by release. A pointer, touch gesture, keyboard trace, or control action performs the same structural operation.
- **Temporal / causal rule:** the travelled correction remains geometry-neutral while it is in motion. Only release after crossing the strip with sufficient pressure commits a material misprint elsewhere. Four wrong placements compound and can be lifted exactly.

The rupture is visible in code (`beginCorrection`, `tickCorrection`, `releaseCorrection`), interaction (travel across a strip rather than holding one site), and rendered consequence (a target proof fragment gains offset, phase, scale, and angle while the source fragment remains byte-for-byte unchanged).

## Changed rule

A correction is not stored at its source. The naive model copies the material answer into a later slot it believes is equivalent. The source stays exact; the wrong target becomes an actual misregistered proof fragment. Four misprints persist as liftable memory.

## Cultural translation

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** programmable pressure, density, direction, and fields participate in producing geometry rather than merely styling a finished mark. The library makes material a rendering and field engine.
- **Mutine translation:** refuse brushes, watercolor, hatching, grain, and their source surface. Translate material production into a naive copy error: pressure and travel are prerequisites for a correction to become geometry, but release prints that geometry in a different proof slot.
- **Visible consequence:** the blind first view is a dark, warm register strip with nine irregular fragments. A valid drag leaves its source fragment exact and makes another fragment visibly offset, re-phased, widened, and misregistered. Four misprints compound and remain liftable.
- **Falsifier:** delete if the correction remains a cursor trail, if weak or short drags commit, if the source changes, if the misprint is only colour/readout, if all releases coincide, if memory resets, or if the strip reads as the previous vessel/slab/wall grammar.
- **Anti-copy:** no brush presets, watercolor appearance, hatching vocabulary, grain treatment, source palette, composition, source code, API surface, examples, or imagery are reproduced.
- **Direction consequence:** closes Naive's stillness / pressure / departure sequence and opens copy-error as material memory: model failure is now a wrong print placement on a proof ledger, with a new task of crossing and releasing.

## Visible consequence

With labels, readout, controls, hint, and prose hidden, the first view is a warm horizontal proof strip on a bruised violet ground. Nine pale fragments sit in a loose register, each with a different internal bar rhythm. After a valid correction drag, the source fragment remains unchanged. A different fragment gains an actual coral overprint, shifted phase, altered proportions, and a visible registration scar. Four misprints accumulate without preserving the pointer path.

## Interaction

- **Pointer / touch:** press near a fragment, drag across the proof strip, and release. Travel is measured from the press point; pointer pressure is read when available and a deterministic fallback is used for mouse input. Short or weak corrections are refused.
- **Keyboard:** `ArrowLeft` / `ArrowRight` chooses the source fragment. `Enter` or `Space` performs the deterministic correction trace. `Delete` / `Backspace` lifts the latest misprint; `Escape` / `R` releases all memory.
- **Controls:** **send a correction** performs the next deterministic trace; **lift last misprint** reconstructs the preceding ledger; **release the ledger** clears memory.
- `?preview=1&static=1&blind=1` renders four settled misprints while hiding all editorial furniture and controls.

## Deletion condition

Delete v047 if caption-free viewing cannot distinguish the misprint ledger from v044–v046's wall, slab, and suspended vessel; if a short or weak correction commits; if the source fragment changes; if misprints are only decoration; if later memory resets; if exact lifting fails; or if dragging across the strip is only a cosmetic cursor gesture.
