# Mutine Naive Art v028 — The picture misremembers the gap

## Hypothesis

If a naive picture treats attention as a partial reading rather than a control, then looking at a mark and leaving it should make the picture keep the wrong absence: the attended mark vacates, a remote mark repeats its sign, and an echo mark carries the reply.

## Changed rule

v028 abandons v025's dense pressure body, v026's dispersed witness apertures, and v027's layered registration print. The representation changes to a semantic DOM score strip: three ordered lines of marks, not a canvas, SVG population, or clipped stack.

Pointerenter only arms a mark. Pointerleave is the causal threshold. A look shorter than 420ms is refused. A sustained look followed by departure stores a deterministic event whose source mark vacates, a non-local mark mishears the source glyph, a third mark echoes it, and a fourth place becomes the new gap. Four events remain in bounded memory; later events replay over the already misremembered strip. Delete lifts one event and R releases the strip to its seeded notation.

The event must live in actual semantic mark content and geometry: glyph text, role, span, rotation, spacing nudge, and the relocated blank change. The readout and accent rules are witnesses, not the cause.

## Cultural translation

- **Reference:** [little-critters](https://github.com/GordenSun/little-critters)
- **Observed mechanism:** situated agents respond to proximity by changing attention and looking back, making the visitor part of a reciprocal relation rather than a dashboard operator.
- **Mutine translation:** refuse animals, eyes, characters, and the look-back scene. Translate situated attention into a naive act of reading: a mark is only observed while the visitor is near it, but departure makes the notation mishear that attention and distribute the mistake to a remote mark and a displaced gap.
- **Visible consequence:** the blind first render is a three-line semantic mark strip. After a sustained leave, the source becomes a blank, a distant mark repeats the source glyph, an echo symbol appears elsewhere, and the gap migrates; later events inherit those changed marks.
- **Falsifier:** delete the direction if focus or pointer location writes history, if a short visit commits, if only the readout or colour changes, if the gap does not move in the marks, if later events restart from baseline, or if the blind strip reads as a generic chart.
- **Anti-copy:** no animals, characters, eyes, paper scene, source palette, source composition, source code, or head-turning image is reproduced.
- **Direction consequence:** closes Naive art's pressure/aperture/registration object sequence and opens an error-of-reading direction: discrete marks, departure as causality, semantic DOM as medium, and absence as a movable state.

## Visible consequence

Caption-free, controls-off viewing should show one continuous three-line notation with four uneven spaces. After a valid departure, one mark disappears, a repeated mark appears away from it, and a small echo changes a third line. The first event is not a cursor trail, a local stamp, or a changing counter.

## Art gate

- **Seed/state:** `0x4e413238`, four-event memory window, deterministic timeline, reduced-motion/static preview settles after four retained observations.
- **Expected consequence:** one sustained look changes the semantic mark strip before the explanation is read.
- **Falsifier:** if the mark glyphs and blank positions do not change together, or if the image reads as a generic data chart, the translation fails.
- **Deletion condition:** after two independent labels-off and controls-off comparisons, delete v028 if the misheard glyph and relocated gap cannot be found at 390px, if pointerleave is indistinguishable from clicking the button, or if lifting does not reconstruct the exact preceding strip.

## Evidence method

The pure engine is replayable from `0x4e413238`. Browser probes exercise pointerenter without writing, short departure refusal, sustained departure commit, Enter/button equivalence, Delete/lift, R/release, blind preview, reduced motion, and all five required viewport sizes.

## Reproduction

Open `index.html`. Hover a mark for at least 420ms and leave it. A short glance is refused. Enter or **mishear the active mark** performs the deterministic equivalent. Delete lifts the latest observation. R releases the bounded memory.
