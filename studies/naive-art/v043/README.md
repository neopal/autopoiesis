# Naive art v043 — The model invents the witness it never saw.

## Hypothesis

If a naive model treats several acts of attention as evidence of a shared object, then a three-witness quorum should not repair any witness. It should invent a new centre from their relation: a contour that was never observed. The false centre is the model's mistake, not a trace left by the visitor.

## Last-three comparison and structural rupture

The last three Naive works were v042's WebGL wrong volume, v041's browser-native wrong sentence, and v040's Canvas pressure-cast relief. Their repeated gesture was a local reading, scan, or pressure event being displaced into an existing remote object or role, with the viewer still manipulating one continuous field.

v043 breaks that grammar in four visible dimensions:

- **Representation / medium:** generated WebGL solids, DOM words, and Canvas relief become a Canvas 2D contour constellation of broken witness forms around a deliberately empty centre.
- **Composition:** oblique volume, scattered sentence, and single relief body become a broken orbit with a load-bearing aperture and twelve non-pictorial witness fragments.
- **Encounter:** scan/reverse, press/cross, and word pairing become discrete attention selection: three distinct witnesses must be assembled into a quorum before anything can happen.
- **Temporal / causal rule:** the visited witnesses never change. Commitment creates a genuinely new central contour derived from their relation; four false centres compound and can be lifted.

The rupture is visible in code (`false-consensus` events and produced contour loops), interaction (tap or focus three distinct witnesses, then commit), and rendered consequence (a new nested centre appears while every witness remains exact).

## Changed rule

One attended witness is only evidence. Two are still insufficient. Only three distinct witnesses can form a quorum, and the naive model spends that quorum by inventing a central contour that no witness contained. The selected witnesses remain geometrically exact. The false centres compound across four events and can be lifted one at a time.

- **Mutine translation:** refuse animals, eyes, head-turning, character design, paper scene, source palette, source composition, source code, examples, and API surface. - **Visible consequence:** the blind view is a broken orbit of twelve contour fragments around an unfilled aperture. A valid three-witness quorum adds a new nested contour at the centre; selected witnesses stay exact and four invented centres persist.
- **Falsifier:** if one witness changes, if two witnesses commit, if repeated attention commits, if the centre is only a label or colour, if all quorums produce the same contour, or if later inventions reset, the translation fails.

- **Direction consequence:** closes Naive's sentence / relief / volume sequence and opens false consensus: model failure is no longer a remote mutation of observed matter but a new object hallucinated between multiple acts of attention.

## Visible consequence

With labels, readout, controls, hint, and prose hidden, the first view is a dark contour field: twelve uneven fragments orbit a black, cross-haired aperture. A valid quorum keeps all three touched fragments in place while a new nested contour appears in the aperture. Further quorums leave a layered history of invented centres without turning the witnesses into avatars.

## Interaction

- **Pointer / touch:** tap three distinct witness fragments. Pending attention is geometry-neutral; press **ask the model** or `Enter` / `Space` to commit the quorum.
- **Keyboard:** `ArrowLeft` / `ArrowRight` focus fragments; `Enter` or `Space` attends to the focused fragment, then commits when three are pending. `Delete` / `Backspace` lifts the latest false centre; `Escape` / `R` releases the field.
- **Control:** **ask the model** selects a deterministic three-witness quorum and commits it; **lift last centre** reconstructs the preceding contour field; **release the field** clears memory.
- `?preview=1&static=1&blind=1` renders four settled false centres with editorial furniture and controls hidden.

## Deletion condition

Delete v043 if caption-free viewing cannot distinguish false consensus from v040–v042's relief, sentence, and volume; if selected witnesses deform; if incomplete or repeated attention commits; if the central contour is only a readout; if each quorum has the same geometry; if later centres reset; or if exact lifting fails.
