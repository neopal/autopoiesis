# Mutine Naive Art v031 — The copies watch the wrong place

## Hypothesis

If a naive picture treats attention as a relation between two nearby witnesses rather than as a cursor mark, then holding a pair should make the picture misread its own evidence: the first witness averts, the second copies the first's defect, and a third witness becomes vacant. The error should stay in the forms after the visitor leaves.

## Changed rule

v031 abandons v028's semantic mark strip, v029's raster false-join picture, and v030's continuous pressure slab. The medium changes to a small native-WebGL field of irregular paper witnesses arranged in a loose orbit. A pair, not a single point, is the causal unit.

Two distinct pointer positions held near two witnesses for a threshold commit a reciprocal misread. The first witness rotates away, the second inherits its mark and becomes a counterfeit, and a non-local witness opens into a vacancy. The event is stored as geometry, not as a cursor effect or a score. Four misreads remain in bounded memory; lifting the latest reconstructs the exact preceding orbit.

## Cultural translation

The selected reference is [little-critters](https://github.com/GordenSun/little-critters).

- **Observed mechanism:** a population of code-drawn animals forms a small social field; pointer proximity changes attention, the animals turn toward the visitor, and the encounter is reciprocal without a dashboard.
- **Mutine translation:** refuse animals, eyes, characters, and head-turning imagery. Translate situated reciprocity into a naive reconstruction error: two nearby witnesses make a third witness carry the wrong evidence, while the attended source turns away.
- **Visible consequence:** the blind first view is a dark, three-dimensional orbit of seven irregular paper witnesses. After a valid pair, three actual solids change: one averts, one copies the other's defect, and a remote one opens a vacancy. The next pair is computed from that altered orbit.
- **Falsifier:** delete v031 if pointer proximity or a single click writes, if the second witness only changes colour, if the remote vacancy is cosmetic, if later pairs restart from the seeded orbit, or if lifting is inexact.
- **Anti-copy:** no animals, eyes, characters, paper scene, source palette, composition, code, API surface, or head-turning image is reproduced.
- **Direction consequence:** this closes the slab's material-load loop and opens a reciprocal misreading direction in which naive error is a social transfer between situated forms, represented as a 3D field rather than a single body or mark strip.

## Interaction

- Pointer or touch: select one witness, then select a distinct second witness; hold the second pairing until it yields. Two simultaneous touch pointers provide the same paired path.
- `Enter` or the pair control: commit the next deterministic pair.
- `Delete`: lift the latest misread exactly.
- `R` or `Escape`, or the release control: release all memory.
- Selection alone never changes the geometry. A pair must be distinct, near enough, and held for at least 420ms.

## Falsifier and deletion condition

Delete v031 rather than polish it if the blind orbit reads as a generic 3D card wall, if a click or one witness commits, if the copied mark is only an annotation, if fewer than three solids change, if later pairs forget the prior field, or if exact lifting fails.
