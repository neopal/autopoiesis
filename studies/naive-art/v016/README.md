# Naive art v016 — The mistake waits until you leave

Status: daily candidate, held for independent caption-free perceptual review.

## Hypothesis

A naive drawing can remember a mistake as an absence caused by departure rather than attention. If presence is refused, then leaving the field should cut one loose form, misplace a wrong fragment into a distant form, and hollow a third form; the image should show memory as a consequence of absence, not as an immediate reply.

## Cultural translation

The selected reference is `little-critters`. Its observed mechanism is situated reciprocity: proximity changes attention and the field answers the visitor. Mutine refuses animals, characters, paper scenes, head-turning animation, source palette, composition, and surface style. The translated naive-art rule inverts the previous translation: proximity is ignored, and only pointer departure commits a three-form material event — source notch, wrong fragment, third hollow.

## Changed rule

v013–v015 moved through forks, punctures, and picture-panel copy errors. v016 changes both medium and encounter: discrete SVG forms replace canvas panels and scenes, and the visitor's presence is refused until the visitor leaves. The gesture is `presence refused → departure → source cut → wrong fragment arrives → third form hollows`. The answer is carried by actual SVG geometry, not a readout or a reply marker.

## Visible consequence

- pointer entry and proximity do nothing visible;
- leaving the field cuts a notch from one form;
- a distant form receives a wrong fragment copied from the source kind;
- a third form loses its inner mark and becomes visibly hollow;

## Art gate

- **Seed/state:** `0x4e413136`, eighteen deterministic stages; reduced motion/static preview settles on the final five-event memory window.
- **Expected consequence:** one departure changes source silhouette, distant fragment geometry, and third-form interior occupancy together.
- **Falsifier:** if labels and readout are removed and the field reads as decorated blobs, if presence itself changes the image, or if the wrong fragment/hollow is only a colour overlay, the translation fails.
- **Deletion condition:** delete v016 if two caption-free comparisons cannot identify departure → cut → wrong fragment → hollow, or if the SVG field collapses back into panels, routes, or a single-scene metaphor.

## Interaction

Move into the field: nothing happens. Leave the field: a bounded departure is committed. `Enter`/`Space` and **leave a trace** place the same deterministic visitor event. **undo latest** removes the newest departure and reconstructs the earlier form arrangement. **release sequence** clears visitor memory and restarts the seeded sequence.
