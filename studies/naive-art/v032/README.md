# Mutine Naive Art v032 — The branch learned the wrong family

## Hypothesis

If a naive picture treats attention as a path through inheritance rather than a point or pair, then a complete three-stop route should teach the picture a false family relation: one branch loses its parent, another inherits the wrong parent and copies the first branch's notch, and a remote branch opens as an orphan gap. The mistake should remain in the topology after the visitor stops choosing.

## Changed rule

v032 abandons v031's native-WebGL orbit and paired reciprocal gaze, v030's sustained pressure slab, and v029's cross-seam false join. The medium switches to a browser-native DOM tree made from irregular branch witnesses and actual parent edges. The causal unit is a three-stop path, not a click, dwell, or pair.

A visitor chooses three distinct witnesses by touch, pointer, keyboard digits, or the deterministic path control. The first two choices are geometry-neutral. When the path closes, the first witness becomes unparented, the second is assigned a non-local wrong parent and copies the source notch, the third keeps a visible memory of the route, and a remote witness opens as an orphan gap. Four topology mutations remain liftable; later paths are applied to the altered tree.

## Cultural translation

The selected reference is [little-critters](https://github.com/GordenSun/little-critters).

- **Observed mechanism:** a population of code-drawn animals forms a small social field; pointer proximity changes attention, the animals look back, and local behavior becomes reciprocal without a dashboard.
- **Mutine translation:** refuse animals, eyes, characters, paper, and head-turning. Translate situated attention into naive inheritance: a three-stop path is remembered as a false parent relation inside a branch tree, with the visible consequence distributed to a remote orphan.
- **Visible consequence:** the blind first view is a sparse, irregular DOM branch tree rather than an orbit, slab, or cut-paper picture. After a valid path, actual edges and node states change: one connection is severed, one is rerouted to a non-local parent, one node records the path, and a remote gap opens.
- **Falsifier:** delete v032 if a single selection changes geometry, if the path is only a progress indicator, if the wrong parent is only a label or colour, if the remote gap is cosmetic, if later paths restart from the seed tree, or if lifting is inexact.
- **Anti-copy:** no animals, eyes, character designs, paper scene, source palette, source composition, source code, examples, API surface, or head-turning image is reproduced.
- **Direction consequence:** this closes the orbit / pressure-slab / false-join family and opens a topology-and-inheritance direction: naive error is now a changed parent relation in a semantic browser-native tree, not a changed surface or a remote mark.

## Interaction

- Pointer or touch: choose three distinct branch witnesses. The first two choices only arm a path; closing the third commits.
- Keyboard: focus the field, press `1`–`9` to choose witnesses, `Enter` or `Space` to commit the next deterministic path, `Delete` to lift the latest, `R` or `Escape` to release memory.
- Buttons: the path, lift, and release controls share the same deterministic state engine.
- Selection never writes geometry. Only a complete three-stop path changes the topology.

## Falsifier and deletion condition

Delete v032 rather than polish it if the blind tree reads as a generic node diagram or interface, if a single choice commits, if the changed parent is not visible in edges, if fewer than three selected roles plus one remote gap change actual geometry, if later paths forget the altered tree, or if exact lifting fails.
