# Mutine Naive Art v026 — The picture miscounts its witnesses

## Hypothesis

If attention is treated as evidence rather than control, a naive picture can make a visible mistake about who was seen: focus should remain reversible and non-causal, while a committed miscount should alter the focused witness, a wrongly counted witness, and a third echo body.

## Changed rule

v026 leaves v023's continuous route, v024's faceted theatre, and v025's global pressure aperture. The tableau is a browser-native SVG field of nine irregular witness apertures around a quiet absence. Tab, pointer selection, or keys 1–9 only focus a witness. Enter, Space, or the commit control performs the new rule: the field deliberately assigns the attention to a different witness and changes a third witness as an echo. Up to four miscounts remain replayable; Delete lifts the latest exact state and R releases the bounded count.

The event must live in SVG path geometry. The readout and accent strokes are witnesses to the event, not its cause.

## Cultural translation

- **Reference:** [little-critters](https://github.com/GordenSun/little-critters)
- **Observed mechanism:** situated agents make pointer proximity legible as attention and return the visitor's presence through a local change in looking.
- **Mutine translation:** remove animals and reciprocal looking. A witness can be focused without writing; only an explicit commit makes the picture miscount that attention and distribute the error to a remote witness and an echo.
- **Anti-copy:** no animals, eyes, character designs, paper scene, source composition, source palette, source code, or head-turning image is reproduced.

## Visible consequence

The blind first render is a dispersed SVG population of irregular apertures, not a route, plane theatre, pressure sheet, or dashboard. After a commit, three actual path silhouettes change. One is the attended witness, one is the wrong witness the picture counted, and one carries an echo. Later commits act on the already changed geometry.

## Falsifier

Delete this direction if focus writes history, if the commit changes only class names, colour, or a counter, if fewer than three SVG bodies change, if later events restart from the baseline, or if the blind view reads as a generic polygon scatter whose relation requires this caption.

## Deletion condition

If the miscount cannot be found in the caption-free silhouettes at 390px, or if keyboard focus and Enter do not provide the same causal path as the visible button, v026 remains a spike and must not be promoted.

## Reproduction

The deterministic seed is `0x4e413236`. Open `index.html`, tab to a witness, and press Enter or Space. `Delete` lifts the latest event. `R` releases memory. The engine is pure and exported for tests; `sketch.js` is the browser adapter.
