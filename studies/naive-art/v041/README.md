# Naive art v041 — The model keeps the wrong word.

## Hypothesis

If a naive model treats a situated encounter as language evidence, then one word should not be allowed to correct itself. A first word becomes a latent witness; a different reply makes the sentence spend the relation in a distant word, where the model substitutes, splits, and echoes the wrong phrase.

## Changed rule

v041 is a structural and perceptual rupture relative to v040's continuous pressure-cast relief, v039's cellular raster plate, and v038's witness cut-out field. The medium becomes a browser-native typographic sentence made from actual interactive word buttons rather than Canvas bands, raster cells, or cut-out masses. The viewer no longer presses, marks, or leaves a surface: they touch one word and answer with another. The witnessed pair stays geometrically exact while three remote words materially change their text, position, scale, rotation, spacing, and echo. Four mishearings compound and can be lifted exactly.

## Cultural translation

- **Reference:** [little-critters](https://github.com/GordenSun/little-critters)
- **Observed mechanism:** a population of code-drawn agents makes pointer proximity legible as attention; the visitor enters a local field and the field answers without a dashboard.
- **Mutine translation:** refuse animals, eyes, characters, paper scenes, head-turning, source palette, source composition, source code, examples, and API surface. Translate situated reciprocity into a sentence relation: the first word is only a latent witness, a different word replies, and the naive model mishears the relation in three remote words.
- **Visible consequence:** the blind view is a scattered, oversized typographic sentence. The first witness changes no geometry; a valid reply replaces one distant word, splits another into a marked phrase, and leaves a fading echo elsewhere. Four relations persist as actual DOM text and layout.
- **Falsifier:** if a word answers itself, if the first touch changes geometry, if the remote roles are only colour or readout, if the blind field reads as a generic node diagram or typographic poster, or if later inferences reset, the translation fails.
- **Anti-copy:** no animals, eyes, head-turning scene, paper style, character design, source palette, source composition, source code, examples, API surface, or surface vocabulary is reproduced.

## Visible consequence

With labels, readout, controls, hint, annotations, and prose hidden, the first view is a dark typographic field whose words form one unstable sentence. After a valid two-word relation, the two touched words stay exact while three other words become a wrong synonym, a split phrase, and a fading duplicate. The sentence remembers four errors as text and layout rather than as a counter.

## Interaction

- Pointer/touch: touch one word, then a different sufficiently distant word. The first touch is latent; the second completes the relation. A self-reply and a too-near reply are refused.
- Keyboard: focus a word and press `Enter` / `Space` to make a deterministic relation; `ArrowLeft` / `ArrowRight` arms the neighbouring word; `Delete` / `Backspace` lifts the latest inference; `Escape` / `R` releases the sentence.
- Controls: **make the wrong inference** commits a deterministic pair; **lift last inference** reconstructs the exact previous sentence; **release the sentence** clears memory.
- `?preview=1&static=1&blind=1` renders four settled inferences with editorial furniture and controls hidden.

## Deletion condition

Delete v041 if caption-free viewing cannot distinguish the typographic sentence from v038-v040's cut-out, raster, and relief grammars; if the first witness changes; if a word replies to itself; if remote changes are cosmetic; if the work collapses into a generic poster or node diagram; or if exact lifting fails.

## Direction consequence

This opens `misheard-sentence`: Naive art moves from material reconstruction failure to language reconstruction failure. It closes the recent field / plate / mould family and forces the current toward browser-native text, paired attention, discrete reply, and memory carried by changed words rather than changed surfaces.
