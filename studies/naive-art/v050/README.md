# Naive art v050 — The answer returns to the room you ignored.

## Hypothesis

If situated attention is reciprocal, then a naive model should not simply mirror where the visitor looks. After three distinct attentions, it should misattribute the answer to an unobserved station and re-compose the whole sentence around that false certainty.

## Last-three comparison and structural rupture

The last three Naive works were v049's pressure topology, v048's reciprocal witness field, and v047's proof strip. Their repeated grammar was a visitor acting through a field while the model globalised a remembered error into a body, ecology, or register; each could accumulate four events and lift them.

v050 makes a medium and encounter switch:

- **Representation / medium:** generated SVG topology, Canvas ecology, and proof strip become browser-native DOM words with CSS positioning. The sentence is the image; no canvas, SVG, imported font, or body carries it.
- **Composition / shape vocabulary:** compact cells and situated witnesses become nine large, quiet word fragments dispersed across a pale sheet. The sentence almost forms, then refuses to settle.
- **Encounter:** pressure, proximity notices, and path crossing become approach-and-release. Pointer/touch proximity, focus/keyboard, and the deterministic attention control share the same engine.
- **Causal / memory rule:** one visit is only staged. Three distinct visits commit a misattributed consensus: every word is re-produced, attention order changes the reflow, and a false answer is inserted at a station the trio did not attend. Four sentence errors compound and lift exactly.

The rupture is visible in code (`attend`, `materialise`, `findShadow`), interaction (approach a word and release rather than pushing or crossing a shape), and rendered consequence (all nine DOM words reflow and a false word occupies an unobserved room).

## Changed rule

Reciprocal attention is inverted into misattribution. The model records three different rooms, then answers from the room outside the record. The visitor's pointer path is not stored; only the order of attended stations changes the sentence that survives.

## Visible consequence

With controls, readout, hint, and prose hidden, the first view is a pale sheet carrying nine dark words that nearly make a sentence. A pointer approach gives only a temporary near relation. After three distinct releases, the model rewrites every word's position, scale, weight, and rotation and places one italic rust answer in a room that was not attended. The visitor's route is absent from the settled composition. Four such misreadings compound without losing exact lift.

## Interaction

- **Pointer / touch:** press in the field, move near a word, and release. Three distinct word rooms are required; a repeated room is refused.
- **Keyboard:** focus the field, use `ArrowLeft` / `ArrowRight` to move the focus room, `Enter` or `Space` to attend, `Delete` / `Backspace` to lift the latest answer, and `Escape` / `R` to empty memory.
- **Controls:** **attend the next room** performs the next deterministic trio; **lift last answer** reconstructs the preceding sentence; **empty the memory** returns to the quiet field.
- `?preview=1&static=1&blind=1` renders four settled misattributions while hiding all editorial furniture and controls.

## Deletion condition

Delete v050 if caption-free viewing cannot distinguish misattributed DOM language from v047–v049's strip, witness field, and pressure topology; if pointer proximity is only a highlight; if repeated attention commits; if the false answer is not structurally unobserved; if the sentence does not reflow globally; if order is not structural; if memory resets; if exact lifting fails; or if the first view collapses into a generic word grid or interface.
