# Naive art v037 — The mistake cures the wrong edge.

## Hypothesis

If pressure is understood as a relation between three marks rather than as a stroke, a naive model will preserve the pressure while misreading where the relation belongs. The selected marks should not become the answer: an unchosen stamp must swell, another must collapse into a vacancy, and a third must keep a ridge. The error must survive captions-off viewing as a changed raster print.

## Changed rule

v037 leaves v036's false accordion page, v035's pressure plate, and v034's faceted reconstruction. The medium becomes a deterministic p5.js Canvas 2D print made from thirteen uneven geometric stamps. A three-mark chord is an offer, not a local mark. When the third mark closes the relation, the print refuses to preserve the chord and produces a false imprint, vacancy, and pressure ridge elsewhere. Four misprints remain liftable; later chords inherit the wrong print.

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)

- **Mutine translation:** refuse brush appearance, stroke trails, watercolor, hatching, grain, palette, and source surface vocabulary. Translate material pressure into a three-mark relation whose closure changes remote stamp geometry in a naive raster print.
- **Anti-copy:** no brush preset, watercolor appearance, hatching vocabulary, grain, source palette, source composition, source code, examples, API surface, or mark vocabulary is reproduced.

## Visible consequence

The first blind view is a skewed print of thirteen uneven planar stamps. It must not read as a page, relief, plate, grid, route, or dashboard. After a valid three-mark chord, the chosen marks lose ink and turn slightly; an unchosen stamp becomes a larger false imprint, another contracts into a dark vacancy, and a third carries a pressure ridge. Four errors remain visible in the settled blind view.

## Interaction

- Pointer/touch: tap three distinct stamps; the first two taps are geometry-neutral, and the third closes a chord.
- Keyboard: `Enter` or `Space` performs the next deterministic pressure chord.
- Controls: **misread the relation** commits the deterministic chord; **lift last error** reconstructs the exact prior print; **release the print** clears memory and pending taps.
- A repeated mark, incomplete chord, or light pressure is refused without geometry change.
- `?preview=1&static=1&blind=1` renders four settled misprints with editorial furniture hidden.

## Falsifier

Delete v037 if the selected trio is always the answer, if the pressure chord becomes a visible decorative stroke, if the false imprint, vacancy, or ridge exists only in colour/readout, if later chords reset, or if exact lifting fails.

## Deletion condition

Delete this direction if caption-free viewing cannot distinguish the pressure misprint from v036's page, v035's plate, and v034's relief, or if the first encounter reads as a generic grid, route, waveform, brush simulation, or control panel.
