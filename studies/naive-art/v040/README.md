# Naive art v040 — The model hardens the soft mistake.

## Hypothesis

If a naive model treats pressure as material evidence, then the pressure should not simply darken the place where it lands. A bounded gesture should be accepted as a moulding instruction and then harden the wrong part of the next form. The pressed band must stay quiet; the error must become produced geometry elsewhere.

## Changed rule

v040 is a structural and perceptual rupture relative to v039's cellular miscount, v038's witness absence, and v037's pressure misprint. The medium becomes one continuous p5.js Canvas 2D relief made from eleven broad, overlapping bands rather than a cell plate, cut-out population, or stamp board. The viewer no longer marks a unit and commits a reading: they press one band and sweep across its surface. A bounded pressure sweep leaves the touched band exact, hardens a remote cast, underforms another band, and leaves a third with a memory ridge. Four casts compound and can be lifted exactly.

## Cultural translation

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** programmable pressure, density, directional behaviour, and fields participate in producing geometry rather than merely styling a finished mark.
- **Mutine translation:** refuse brushes, watercolor, hatching, grain, source palette, source composition, source code, examples, and API surface. Translate material production into a naive model rule: pressure is accepted as evidence, but the next reconstruction hardens that evidence into a remote cast while leaving the pressed band unchanged.
- **Visible consequence:** the blind view is one crooked relief body, not a grid. A valid pressure sweep produces an overcast remote band, an underformed band, and a memory ridge through actual shape, offset, depth, bend, notch, tilt, and hardness changes.
- **Falsifier:** if the pressed band changes, if short or overlong gestures commit, if remote roles exist only in colour or readout, if the relief reads as a generic layered card stack, or if later casts reset, the translation fails.
- **Anti-copy:** no brushes, watercolor appearance, hatching vocabulary, grain treatment, source palette, source composition, source code, API, or surface style is reproduced.

## Visible consequence

With labels, readout, controls, hint, annotations, and prose hidden, the first view is a single irregular relief object with a heavy shadow and broad soft bands. After a valid press-and-cross gesture, the band under pressure remains geometrically identical while a distant band becomes too hard and angular, another loses body, and a third stores a diagonal ridge. The work remembers four material mistakes as shape.

## Interaction

- Pointer/touch: press one band and sweep a bounded distance across the mould before release. A short press and an overlong sweep are refused.
- Keyboard: `Enter` or `Space` commits a deterministic pressure cast; `ArrowUp` / `ArrowDown` selects a band; `Delete` / `Backspace` lifts the latest cast; `Escape` / `R` releases the mould.
- Controls: **press the wrong band** commits a deterministic cast; **lift last cast** reconstructs the exact previous relief; **release the mould** clears memory.
- `?preview=1&static=1&blind=1` renders four settled pressure casts with editorial furniture and controls hidden.

## Deletion condition

Delete v040 if caption-free viewing cannot distinguish the relief object from v037-v039's field grammars, if pressure is merely a cosmetic marker, if the touched band is the answer, if the cast is local, if a weak or overlong gesture commits, or if exact lifting fails.

## Direction consequence

This opens `pressure-cast-relief`: naive error becomes a material reconstruction failure in which evidence hardens into the wrong next form. It closes the recent cellular / witness / misprint family and forces the current toward a single-object encounter, continuous pressure gesture, and memory carried by deformation rather than distributed units.
