# Naive art v034 — The model fills the missing side.

## Hypothesis

A model that receives careful local attention will make a more visible mistake away from the place it was asked to reconstruct: it will copy one observed facet into the least-watched side and leave a third facet absent.

## Changed rule

v034 changes the viewer's gaze into a false reconstruction. Holding one facet is geometry-neutral. On release after a minimum dwell, the relief does not alter the held facet alone: the least-observed facet inherits its relief, a third facet becomes a physical absence, and a fourth ridge carries the memory forward. The bounded memory of four reconstructions is replayed deterministically.

## Visible consequence

The first render is one low, uneven WebGL bas-relief of nine facets, not a population or diagram. A valid hold changes actual height, tilt, relief, depth, and notch values in the solids. The remote false copy and missing facet remain visible after the readout, controls, and prose are hidden; later looks choose from the inherited attention history.

## Interaction

- Pointer/touch: press and hold one facet for at least 420ms, then release.
- Keyboard: focus the field, press `1`–`9` to arm one facet, then `Enter` or `Space` to commit the deterministic dwell.
- Controls: facet keys arm without writing; `let it fill the gap` commits; `lift last reconstruction` restores the exact prior frame; `release the model` clears memory.
- A short press, a repeated facet selection, or an invalid facet is refused without geometry change.

## Cultural translation

- **Reference:** [little-critters](https://github.com/GordenSun/little-critters)
- **Observed mechanism:** situated agents respond to proximity with legible attention, look back, and make the visitor part of a reciprocal field without a dashboard.
- **Mutine translation:** refuse animals, eyes, characters, and head-turning. A single relief facet receives attention, but the model answers through the least-watched side: it fabricates a false copy and leaves an absence elsewhere.
- **Anti-copy statement:** no animals, paper scene, source palette, composition, source code, API surface, or head-turning image is reproduced.
- **Direction consequence:** this closes the recent proof/tree vocabulary and opens a failed-reconstruction direction in which attention is not a local mark but a biased model of absent evidence.

## Falsifier

Delete the direction if the work reads as a generic 3D tile grid, if holding changes only a highlight or readout, if the selected facet itself is always the answer, if the false copy and missing side are only colour, if attention history does not alter later choices, or if exact lifting fails.

## Deletion condition

Delete v034 if its caption-free blind view collapses into v033's typographic register, v032's branch diagram, a decorative orbit, a dashboard, or a generic 3D interface rather than one failed model with a material absence.

## Critique before promotion

- **Model critic:** the relief must read as one body before nine facets; the copy and absence must be structural.
- **Perceptual critic:** with labels, readout, controls, hint, annotations, and prose hidden, the first view must break from v033 and v032 in medium, shape vocabulary, and viewer task.
- **Interaction critic:** a look is an offer, not a click; a complete dwell commits the remote error, while lift reconstructs the exact prior relief.
- **Cultural critic:** reciprocity is translated as a wrong model of unseen evidence, not as an animal scene or cursor-following.
- **Cynic:** delete if the solids do not carry the error without explanation.
