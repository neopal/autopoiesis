# Naive art v002 — The correction walks outside

Status: daily candidate, held for independent perceptual critique.

## Hypothesis

A reduced house vocabulary can carry a work when the retained mistake changes the place where the house is allowed to stand. The naive image is not a style filter; it is a spatial argument made with a few blunt shapes.

## Changed rule

v001 kept a misplaced door and bent a path. v002 changes the rule: every correction becomes a displacement vector. Later houses inherit the vector, so the kept house moves away from its proposal and its path must leave the threshold at a different angle. The refused proposal and kept consequence remain separated at every viewport, including the narrow stacked composition.

## Visible consequence

- the coral proposal has one wrong threshold and a dashed route;
- the blue-and-ochre kept house is physically shifted by accumulated corrections;
- the kept doorway and route are therefore displaced, not decorated with a memory glyph;
- a single threshold trace runs from the refused doorway to the kept doorway as part of the composition;
- a pointer or keyboard correction adds a real vector to the frame, and undo removes it again.

## Art gate

- **Seed/state:** `0x4e413032`, nine deterministic stages; `static=1` settles on stage 09 with eight retained corrections.
- **Expected consequence:** deleting one retained correction changes house position, doorway position, and path bend.
- **Falsifier:** if the deletion probe changes only the trace colour or a label, the memory rule is ornamental.
- **Deletion condition:** delete this direction if a caption-free observer cannot identify the same changed doorway and route in two separate comparisons.

## Interaction

`place a correction` and Enter/Space on the field add a normalized visitor correction and pause the sequence. `undo last` removes the latest correction; `release sequence` clears the intervention and restarts the seeded route. Reduced motion and `static=1` show the final remembered state without requiring input.

## Public loop

`creation → critique → progression`

The v001 record remains intact as lineage. This is one daily work for the Naive art current, not a second work inferred from the earlier refused/kept states.
