# Naive art v045 — The model fills the hole you did not make.

## Hypothesis

If a naive model mistakes material pressure for a request to repair the place where pressure arrived, then a strong dwell that returns across one aperture should leave that source aperture exact while growing a membrane in a different chamber. The model's error is a wrong reconstruction of material evidence, not a mark laid on top of the slab.

## Last-three comparison and structural rupture

The last three Naive works were v044's shutter wall and departure agreement, v043's contour quorum, and v042's WebGL wrong volume. Their repeated gesture was local attention being selected, scanned, or left and then displaced into a remote geometric object while the viewer handled a field of parts.

v045 breaks that grammar in four visible dimensions:

- **Representation / medium:** a wall of hinged shutters, a contour orbit, and an oblique block cluster become one continuous Canvas 2D slab with six embedded apertures and generated false membranes.
- **Composition:** staggered field, broken orbit, and volume become a single asymmetrical object with a load-bearing silhouette and cavities; the object is read as a whole before its openings.
- **Encounter:** continuous proximity, quorum selection, departure, and scan reversal are replaced by a pressure gesture: enter one aperture, dwell, push across it, return, and release.
- **Temporal / causal rule:** the gesture is geometry-neutral while it is happening. Release commits only when pressure is strong and the trace returns against itself; the source cavity stays exact while a different cavity gains a material membrane. Four membranes compound and can be lifted.

The rupture is visible in code (`beginPressure`, `pressureSample`, `releasePressure`), interaction (pointer/touch or keyboard pressure path), and rendered consequence (an actual polygonal membrane seals an untouched cavity).

## Changed rule

Pressure is treated as evidence, but the naive model cannot keep its location. A strong dwell-and-return trace at one aperture is reconstructed as a false membrane in another aperture. The source cavity and all six base cavities remain geometrically exact. Four false seals persist as liftable memory.

## Cultural translation

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** programmable pressure, density, direction, and fields participate in producing geometry rather than merely styling a finished mark.
- **Mutine translation:** refuse brushes, watercolor, hatching, grain, source palette, source composition, source code, examples, and API surface. Translate material production into a naive reconstruction law: pressure is accepted only after a strong dwell and a return, then it produces an independent membrane in a different cavity while the source remains unchanged.
- **Visible consequence:** the blind view is a single warm slab with six irregular apertures. A valid pressure trace leaves its source aperture exact and grows a visible filled membrane in another chamber; four seals compound as different polygonal errors.
- **Falsifier:** delete if the input trace changes the source cavity, if weak or one-way gestures commit, if the membrane is only colour or readout, if every gesture seals the same shape, if the first view reads as a field of cards or a brush demo, if later seals reset, or if lifting is inexact.
- **Anti-copy:** no brushes, watercolor appearance, hatching vocabulary, grain treatment, source palette, source composition, source code, API, or surface style is reproduced.
- **Direction consequence:** closes Naive's departure / false-centre / wrong-volume evidence sequence and opens pressure membrane: model failure becomes a material reconstruction error in a single object, with pressure and return as the viewer's new task.

## Visible consequence

With labels, readout, controls, hint, and prose hidden, the first view is a large asymmetrical slab with a dark interior and six uneven openings. A strong dwell-and-return gesture at one opening does not deform it. On release, a new polygonal membrane appears in another opening and remains as part of the object's wrong reconstruction. Four membranes compound and remain liftable.

## Interaction

- **Pointer / touch:** press inside an aperture, push through it, return across the starting side, and release. Pointer pressure is derived from the movement when hardware pressure is unavailable.
- **Keyboard:** `ArrowLeft` / `ArrowRight` focus apertures. `Enter` or `Space` performs the deterministic dwell-and-return trace for the focused aperture. `Delete` / `Backspace` lifts the latest membrane; `Escape` / `R` releases the slab.
- **Controls:** **press the model** performs the next deterministic trace; **lift last membrane** reconstructs the preceding slab; **release the slab** clears memory.
- `?preview=1&static=1&blind=1` renders four settled membranes with editorial furniture and controls hidden.

## Deletion condition

Delete v045 if caption-free viewing cannot distinguish the single-object pressure reconstruction from v042–v044's volume, contour, and shutter grammars; if a weak or one-way trace commits; if the source aperture changes; if the membrane is cosmetic; if every trace produces the same geometry; if later memory resets; or if exact lifting fails.
