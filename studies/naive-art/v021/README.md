# Naive art v021 — The map answers in the wrong room

Status: daily candidate, held for independent caption-free perceptual review.

## Hypothesis

A naive picture can remember a mistake as a misaddressed answer rather than a damaged object. If a visitor attends to one situated room, that room should open a real doorway while a distant room closes the doorway it was never asked to close. The memory must live in the map's topology, not in a counter, tint, or caption.

## Cultural translation

The selected reference is `little-critters`. Its observed mechanism is situated reciprocity: proximity becomes legible attention, and local agents look back so the visitor enters a relation rather than a control panel. v021 removes the animals and the look-back scene. Proximity arms one room; a committed look opens that room's boundary and makes a distant room answer with a wrong closure. No animals, characters, eyes, paper scene, source palette, composition, or surface vocabulary is reproduced.

## Changed rule

v018 used one connected hinged object, v019 one continuous weather mural, and v020 one pressure print sheet. v021 changes representation, composition, encounter, and memory together:

- the paper sheet becomes one inline SVG floor-plan-like field of seven disjoint rooms around a central absence;
- pointer proximity arms a situated room but does not write history;
- a click, Enter, Space, or `look into a room` commits attention;
- the attended room receives an actual boundary opening;
- a distant room returns the wrong answer as an actual blocked doorway;
- lifting the latest look reconstructs the exact earlier topology.

The gesture is `attention → opening → wrong reply → topology remembers`.

## Visible consequence

- the blind field is an irregular map of separate rooms and negative space, not a panorama, hinge, or print register;
- moving near a room only arms it; the map does not change until attention is committed;
- a committed look changes two room boundaries at once: one opening and one distant closure;
- the wrong answer accumulates in a bounded four-event memory window; undo removes only the latest answer; release returns to the seeded map.

## Art gate

- **Seed/state:** `0x4e413231`, seventeen deterministic stages, four-event visible memory window; reduced motion/static preview settles on the final retained state.
- **Expected consequence:** one committed look changes the topology of two different rooms, and the source/receiver relation is visible without prose.
- **Falsifier:** if proximity alone changes geometry, if a doorway is only a tint or icon, if the distant closure is only a marker, or if the blind field reads as a generic room-card grid, the translation fails.
- **Deletion condition:** delete v021 if two caption-free comparisons cannot distinguish `attention → wrong reply → topology` from v020's pressure transfer, or if the opening/closure relation depends on labels and readout.

## Interaction

Move near a room to arm it. Click a room, press **look into a room**, or focus the map and use `Enter`/`Space` to commit the same deterministic attention event. `Delete`/ **lift latest look** removes only the newest remembered answer. `R`/ **release the map** clears visitor memory. `S` saves the current inline SVG.
