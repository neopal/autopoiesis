SELF PORTRAIT / WEBGL MEDIUM SWITCH / v032

The portrait refuses
to be continuous.

It holds one answer in silence, then makes the body hinge only when its next answer disagrees.

A CONTRADICTION IS THE MATERIAL

Point, tap, or use the four arrows to offer a direction. The first offer is withheld. Repeating it is refused. A different second offer folds the object through a new axis, opens its central void, and leaves the incompatible decision in the body.

The hinge is waiting for a first proposal.

ANNOTATIONS / v032

changed rule
Abandon v031's pressure membrane, v030's decision population, and v029's delegated shell. The portrait becomes a three-dimensional refusal object. Surface pressure and proximity do nothing by themselves; only two different directional proposals may create a hinge revision.
visitor action
Offer one direction by pointer or key, then offer a different one. Repeat is refused. Delete lifts the latest contradiction; R or Escape releases the body to its quiet seed. The four arrow buttons are equivalent to the pointer and keyboard paths.
falsifier
If a single proposal changes the body, a repeated proposal commits, the touched location becomes the answer, or a contradiction changes only colour/readout, the inversion fails.
deletion
Delete v032 if the caption-free first view reads as a generic 3D ornament, or if the incompatible proposals cannot be found as actual fold, axis, facet, and void changes without the furniture.
