# Self portrait v032 — The portrait refuses to be continuous.

## Hypothesis

A self-portrait can expose code's decisions by preserving an incompatibility instead of depicting a face or accumulating attention. If the first directional proposal is withheld and a different second proposal is the only valid cause, the code can portray its own refusal as an actual hinge: a changed axis, fold, facet field, and central void.

## Changed rule

v032 abandons v031's pressure membrane, v030's decision population, and v029's delegated SVG shell. The medium becomes a deterministic p5.js WebGL object: two asymmetrical planes suspended around a negative seam. Surface pressure and proximity are refused as causes. The first proposal is geometrically silent; repeating it is refused; only a different second proposal commits a contradiction-hinge. Four revisions remain liftable, and later contradictions inherit the changed body.

## Cultural translation

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** programmable pressure, density, and directional fields participate in producing geometry rather than decorating finished geometry.
- **Mutine translation:** invert the mechanism. Refuse brushes, watercolor, hatching, grain, source palette, composition, code, and API surface. Pressure and surface are not allowed to produce the portrait. Instead, two incompatible directional proposals are required before the object may fold; the contradiction changes the body's axis, facet relief, and central void.
- **Visible consequence:** the blind first render is a suspended two-plane hinge around a dark seam. A first proposal leaves it exact; a different second proposal changes actual 3D fold, axis, facet lift/cut, and void scale. The contradiction persists into later revisions.
- **Falsifier:** if a single proposal changes geometry, repetition commits, the pointer location becomes the answer, or the contradiction exists only in colour/readout, the inversion fails.
- **Anti-copy:** no brush appearance, watercolor, hatching, grain, source palette, source composition, source code, API surface, or surface vocabulary is reproduced.

## Visible consequence

The first encounter should read as a dark, suspended refusal object—not a face, band field, shell, population, chart, or control panel. The body is made of two unequal planes with an oblique seam, sparse facet plates, and an offset halo. A committed contradiction produces a visible fold and changes the negative seam, not merely its annotation.

## Interaction and memory

- Tap or click a direction, or use arrow keys `1`–`4`.
- The first proposal is held without geometry; repeating it is refused.
- A different second proposal commits the hinge revision.
- `Enter` / `Space` repeats the selected direction; `Delete` / `Backspace` lifts the latest revision; `R` / `Escape` releases to the deterministic seed.
- Four contradiction snapshots remain bounded and the same proposal sequence replays the same body.
- The state bridge is exposed as `window.__mutinePortraitV032` for deterministic browser QA.

## Radical progression

The last three portrait works repeated a visitor-addressed causal structure: a pressure hold changed remote bands (v031), a pulse reordered a decision population (v030), and a three-station quorum delegated a shell edge (v029). v032 breaks that structure in three visible dimensions: it switches from flat field/list/shell to a 3D hinged object, from pressure/visit/pulse to paired directional contradiction, and from remote consequence to a local topology that is only permitted after incompatible proposals. The new capability is not another way to move attention; it is a body that refuses coherence until the visitor makes two answers disagree.

## Direction consequence

This is an explicit inversion of the p5.brush material-agency translation: material pressure is denied as an authoring cause, and contradiction becomes the material. It closes the recent pressure / population / delegated-edge family and opens a refusal-object direction for Self portrait. The next work must change the hinge's medium or encounter rather than refine this object.

## Critique

- **Object critic:** the two planes must read as one authored suspended body before they read as a 3D primitive demo; the seam and asymmetrical facet rhythm must carry the composition.
- **Interaction critic:** one offer must stay silent, repetition must refuse, and only an incompatible pair may fold the body.
- **Perceptual critic:** with labels, readout, controls, hint, and prose hidden, the first view must break from v031's membrane, v030's population, and v029's shell.
- **Causal critic:** axis, facet relief, and void scale must change in the rendered object, not only in metadata.
- **Cynic:** delete v032 if it reads as a generic 3D ornament, if the contradiction is a disguised button, or if exact lifting does not restore the preceding body.
