# v045 — Loop compiler

## Hypothesis

A self-portrait can portray code's decisions as a rule that edits itself. If the visitor encloses the generated form with one closed trace, the trace should not become a local scar: it should compile a new production grammar into the loop that made the trace possible.

## Radical progression

The last three portrait works were Canvas 2D fields of situated panels, pressure channels, and departures. Their repeated gesture was to visit, load, or contradict a spatial unit and receive a non-local geometry change. v045 abandons that field grammar. It is one three-dimensional self-contained loop, uses WebGL rather than Canvas 2D, and asks for a closed loop rather than site selection, pressure crossing, or leaving. The accepted event is local to the work's own rule: the form rewrites itself.

The visible rupture is in representation (faceted 3D loop), composition (one object with an aperture rather than a field), encounter (enclose rather than select/drag/depart), and temporal state (a stroke is provisional until closure, then becomes a compiled revision). The four compiled revisions persist and are liftable.

## Cultural translation

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** a programmable material engine treats pressure, density, directional behaviour, and fields as production rules that change how geometry is generated rather than decorating a finished mark.
- **Mutine translation:** pressure becomes compilation. A closed trace is evidence that a rule has enclosed itself; its winding and magnitude rewrite the loop's twist, aperture, depth, shear, phase, and facet grammar. Open or cancelled traces are refused.
- **Visible consequence:** a blind view of one faceted three-dimensional loop. Each accepted closure materially changes the loop's volume and facet rhythm; clockwise and counter-clockwise closures produce different structures.
- **Falsifier:** if an open trace commits, if the trace only paints a scar, if winding is cosmetic, if later compilations reset, or if lifting is inexact, the translation fails.
- **Anti-copy:** no p5.brush preset, brush appearance, watercolor, hatching vocabulary, grain treatment, palette, composition, source code, examples, API surface, or source imagery is reproduced.
- **Direction consequence:** closes the portrait's recent remote-answer and field grammar. Opens self-modifying material: code portrays its own decisions by allowing a completed gesture to edit the rule that generated the current object.

## Changed rule

Only a closed loop with sufficient area and length can compile. Its geometry is not painted onto the form. Its winding controls the direction of the new rule; its magnitude changes the strength of the rewrite. Four compiled states compound and can be lifted exactly.

## Interaction

Pointer or touch: draw one closed loop around the object and release. Enter / Space performs a deterministic closed trace. Delete / Backspace lifts the latest compiled state. Escape releases the compiler. Reduced motion removes ambient camera drift without changing the state machine.

## Deletion condition

Delete v045 if caption-free viewing reads as a generic torus, if closure is only prose attached to a button, if winding does not materially alter the body, or if an open trace compiles.
