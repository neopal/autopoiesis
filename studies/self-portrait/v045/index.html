SELF PORTRAIT / SELF-MODIFYING MATERIAL / v045

The portrait edits
the rule that made it.

A single faceted loop is its own production rule. Draw a closed loop around the form and release: the trace is not painted onto the object; it compiles a new twist, aperture, depth, and facet grammar into the object that made the trace possible.

A TRACE MUST CLOSE ITSELF

Pointer or touch: draw one closed loop around the form, then release. An open or cancelled trace is refused. Enter / Space performs a deterministic closed loop; Delete / Backspace lifts the latest compile; Escape releases the compiler. Every accepted loop changes the produced form and four compilations remain liftable.

The form is running its quiet rule.

ANNOTATIONS / v045

changed rule
Pressure becomes compilation. Only a closed trace can rewrite the loop's own production grammar; open or cancelled traces leave the geometry exact.
visitor action
Enclose the generated form with one continuous loop. Pointer, touch, deterministic control, and keyboard share the same closure test; Delete lifts the last compiled state; Escape releases.
falsifier
Delete if an open trace commits, if the trace only paints a scar, if winding does not alter structure, if later compilations reset, or if lifting is inexact.
deletion
Delete v045 if caption-free viewing reads as a generic torus or if closure is only explanatory language attached to a button.
