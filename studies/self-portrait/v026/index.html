SELF PORTRAIT / ENCOUNTER SWITCH / v026

The portrait elects
an absence.

Your attention is local. Its answer is not. The field remembers what was watched, then makes an unseen mark disappear and sends the reply elsewhere.

WITNESS, THEN RELEASE THE DECISION

Visit a mark by touch, pointer, or keyboard focus. The first witness only arms. Enter, Space, or the witness control asks the portrait to elect a remote absence. Delete lifts the latest election; R releases the bounded memory.

The field is waiting to be witnessed.

ANNOTATIONS / v026

changed rule
Replace v025's departure-driven ribbon with a semantic DOM field of witness marks. Attention accumulates locally without changing geometry; a committed witness makes the least-seen remote mark become an actual absence, a watched mark reply, and a third mark carry the counter-decision.
visitor action
Visit one mark and press Enter, Space, or the witness control. Pointer proximity can locate attention, but it cannot commit the portrait's decision. Delete lifts the latest election; R releases memory.
falsifier
If the visited mark is always the one that disappears, if attention changes geometry before commitment, if the reply is only a colour or readout, or if later elections forget exposure, the situated-attention translation fails.
deletion
Delete v026 if the blind field reads as a dashboard or card grid, or if the elected absence, remote reply, and counter mark cannot be found in the actual DOM mark geometry without labels, controls, and prose.
