# Self portrait v029 — The portrait gives the edge away.

## Hypothesis

If a portrait treats attention as a social condition rather than a direct tool, then three distinct visits can make the image answer away from the visitor's location: the shell will contract at the most-watched boundary, swell at a remote boundary, and open a third cut.

## Changed rule

v029 abandons v026's discrete witness marks, v027's pair counter-reading, and v028's self-modifying folded volume. The work is one native SVG compound path with two even-odd apertures. Visiting a boundary station only increments an invisible attention ledger. A quorum of three distinct stations triggers a derived role election: donor, receiver, and cut. The compound path is rebuilt from those roles, and later quorums inherit the altered attention and geometry.

## Visible consequence

The first render is a single skewed shell with a diagonal aperture, a smaller cut, and a bright uneven rim. A valid quorum changes three actual geometric conditions: one edge recedes, a remote edge protrudes, and a third aperture opens. The temporary station markers are not the artwork; the path is.

## Interaction and memory

- Visit three distinct numbered boundary stations by pointer, touch, or keys `1`–`5`.
- A partial quorum is geometry-neutral.
- Press `Enter`, `Space`, or **complete the quorum** to commit the delegation.
- `Delete` / `Backspace` lifts the latest delegation exactly.
- `R` / `Escape` releases attention and returns to the deterministic seed shell.
- Four delegations remain liftable; the same seed and same sequence replay the same geometry.

## Falsifier

The translation fails if a single station changes the body, if the touched station is always the answer, if the change is only a halo or readout, if the compound SVG path remains unchanged, or if later quorums ignore attention history.

## Deletion condition

Delete v029 if the blind field reads as a generic icon, face, card grid, or diagram, or if the donor contraction, remote receiver, and third cut cannot be found in the silhouette without labels, controls, annotations, and prose.

## Cultural translation

- **Reference:** [little-critters](https://github.com/GordenSun/little-critters)
- **Observed mechanism:** situated agents respond to proximity with legible attention and reciprocal consequence; the visitor participates in a social field without a dashboard.
- **Mutine translation:** refuse animals, eyes, characters, and the look-back scene. Treat the self-portrait as a continuous shell whose boundary stations accumulate local attention, then force a non-local three-role election.
- **Anti-copy:** no animals, character designs, paper scene, head-turning image, palette, composition, source code, or API surface is reproduced.
- **Direction consequence:** opens a social-topology direction for Self portrait: attention is represented by a continuous body and an edge-transfer event, not by a witness mark, pair, or fold.
