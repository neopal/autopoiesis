# Self portrait / v019

## Status

**Candidate / held.** This is the 2026-10-03 daily tableau for the Self portrait current. It remains held until an independent caption-free comparison confirms that the syntax seal reads as a self carrying reciprocal decisions, rather than a decorative emblem.

## Creative record

- **Hypothesis:** code can portray its own decisions by making attention a grammatical relation: the clause that receives attention must split, a distant clause must answer in its own geometry, and the next available reply must change.
- **Changed rule:** one keyboard-attended clause in a single SVG syntax seal opens a real path notch and changes its transform. A non-adjacent clause welds the reply into its path and inherits a changed angle/scale. Attention debt raises tension across the seal.
- **Visible consequence:** the first-render field is one irregular syntax seal, not a face, aperture, raster, membrane, register, or agent crowd. After attention, an actual clause splits and a distant clause grows a changed reply form; repeating attention chooses a different reply.
- **Deterministic state:** `SEED = 0x53504639`; `STAGES = 14`; `MEMORY_LIMIT = 4`; `CLAUSE_COUNT = 9`; `PRIMITIVE_BUDGET = 36`. The pure engine is replayable.
- **Interaction:** Tab or arrow keys move and arm attention without writing history. Enter, Space, or the attend control commits the same deterministic event. Pointer attention is refused. `Delete` lifts the latest reply; `R` releases the syntax.
- **Falsifier:** if the local split is only an overlay, the remote reply is only a colour change, repeated attention ignores clause debt, or the blind image reads as a generic emblem, the translation is not embodied.
- **Deletion condition:** delete v019 if a caption-free pair cannot find the local split and non-adjacent reply in the seal itself, or if the keyboard task feels like a cosmetic selector.

## Lineage and radical progression

`portrait-2026-10-02` → v019: v018's browser-native serial register, v017's ordered aperture, and v016's raster witness field are abandoned. The representation changes to one inline SVG syntax seal; the composition changes from strands/aperture/raster to one interlocked carved form; the encounter changes from position-independent pressure or proximity-then-gaze to keyboard attention followed by commitment; the memory model changes from material cuts and refusal debt to clause debt that rewrites a distant reply.

The repeated gesture in the last three portrait works was attention acting on one coherent image and receiving a local or remote geometric response. v019 breaks that invariant by making the viewer navigate a grammar rather than approach a picture: focus is a relation, Enter is a decision, and the reply is carried by a non-adjacent clause.

## Cultural translation

The selected reference is **little-critters**. Its observed mechanism is that situated code-drawn agents respond to proximity by changing attention and looking back, so simple local behavior creates a reciprocal encounter and a memory of being seen.

Mutine's translation refuses animals, eyes, characters, paper scenes, palettes, compositions, and head-turning surface vocabulary. In this portrait current, a clause becomes the situated listener. Keyboard attention addresses it without making it a mascot; commitment splits its own SVG path and makes a distant clause weld a reply. The seal remembers attention through changed clause debt and later reply choice. This opens a syntax-as-self-observation direction and closes the serial material register.

## Evidence boundary

The focused unit tests prove deterministic attention, actual local path-state change, non-cosmetic remote response, remembered debt, finite memory, and exact restoration. Browser and independent caption-free perceptual evidence must be recorded separately; until those gates are observed, this work stays held.
