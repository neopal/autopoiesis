SELF PORTRAIT / LOCAL MEMORY / v041

The portrait edits
the witness.

Thirteen shutters hold their own rules. Attention is latent while it is brief. Stay with one long enough and that shutter changes its internal geometry, not as a response elsewhere but as a local revision of what it is.

A GLANCE IS NOT YET AN EVENT

Press and hold a shutter, then release after its threshold. The shutter you watched folds its own geometry and adds a new internal segment. ArrowUp / ArrowDown chooses a shutter; Enter / Space watches it for a deterministic duration. Delete lifts the latest fold; R / Escape releases the field.

The shutters are waiting for sustained attention.

ANNOTATIONS / v041

changed rule
Attention is geometry-neutral before the dwell threshold. A completed watch edits the watched shutter itself: its fold, dimensions, angle, offset, and internal segment grammar change locally.
visitor action
Press and hold one shutter by pointer or touch, or choose one and use the watch control / Enter. Brief attention is refused. Delete / Backspace lifts the latest local fold; R / Escape releases the deterministic seed.
falsifier
If waiting only changes colour, if a brief look folds, if the watched shutter stays exact, if every shutter edits identically, or if later edits reset, the translation fails.
deletion
Delete v041 if caption-free viewing reads as a generic accordion or if sustained attention is only a timer wrapped around decoration rather than a visible self-editing rule.
