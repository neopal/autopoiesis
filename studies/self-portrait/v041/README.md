# v041 — Attention shutters

## Hypothesis

A self-portrait can expose its own decision rule without making the visitor select a face or receive a remote answer. If each local shutter remembers sustained attention, then the act of watching should become a visible edit to the watched shutter's internal grammar.

## Changed rule

Attention is geometry-neutral below a deterministic dwell threshold (`0.64s`). A completed watch edits the watched shutter itself: position, dimensions, angle, split, offset, state, and segment count change locally. Four edits compound and can be lifted exactly.

## Cultural translation

- **Reference:** [little-critters](https://github.com/GordenSun/little-critters)
- **Observed mechanism:** situated agents make proximity legible as reciprocal attention; local behaviour can answer the visitor without a dashboard.
- **Mutine translation:** refuse animals, eyes, head-turning, characters, paper scene, source palette, source composition, source code, examples, and API surface. Translate reciprocal attention into thirteen browser-native shutters that keep local memory of being watched and rewrite their own internal rule after sustained observation.
- **Visible consequence:** the blind first view is an oblique stack of dark, irregular shutters on a paper field. A valid watch does not send a mark elsewhere: the watched shutter gains a segment and changes its own fold, proportions, angle, and offset. Four local edits remain visible.
- **Falsifier:** if a brief look folds, if waiting changes only colour, if the watched shutter stays geometrically exact, if all shutters edit identically, or if later folds reset, the translation fails.

## Deletion condition

Delete v041 if the caption-free view reads as a generic accordion or if sustained attention is merely a timer wrapped around decoration rather than a visible local self-editing rule.

## Interaction

Pointer and touch press-and-hold a shutter. The watch control and Enter / Space provide an equivalent deterministic duration. ArrowUp / ArrowDown changes the selected shutter. Delete / Backspace lifts the latest fold; R / Escape releases the deterministic seed.
