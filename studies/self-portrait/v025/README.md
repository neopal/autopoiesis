# Self portrait v025 — The portrait saves your detour.

## Hypothesis

A self-portrait can portray its own decisions more honestly when the visitor's presence is situated in a field but does not directly address the geometry that changes. The portrait should remember a route as a detour, not as a decorative trace.

## Changed rule

v025 abandons v024's centered self-measuring membrane, v023's single observed solid, and v022's branching atlas. A wide, asymmetrical decision ribbon is made of connected cut segments. Traversal accumulates attention without writing geometry. Leaving the ribbon commits the encounter: the code selects a non-local segment to open into a real gap, and a second remote segment bends in reply. Four departures remain in bounded memory; lifting the latest reconstructs the prior ribbon exactly.

## Cultural translation

- **Reference:** [little-critters](https://github.com/GordenSun/little-critters)
- **Observed mechanism:** situated code-drawn agents respond to proximity by changing attention and looking back, making the visitor part of a reciprocal encounter rather than a dashboard operator.
- **Mutine translation:** refuse animals, eyes, and head-turning scenes. Translate situated reciprocity into a decision-ribbon law: the visitor's route accumulates local attention, but departure makes an unaddressed segment detour and a remote segment reply.
- **Visible consequence:** the blind view is an asymmetrical connected ribbon, not a face or population. After departure, an actual cut opens away from the directly observed area and a remote segment bends; later departures inherit bounded memory.
- **Anti-copy:** no animals, character designs, paper scene, source palette, composition, API surface, or head-turning image is reproduced.

## Visible consequence

The first render is a wide score-like material field: thirteen uneven slabs attach to one underlying spine, with a dark negative seam running through them. Interaction is not hover styling. A route is only armed while the pointer is inside. On leaving, the ribbon changes its own geometry: one segment splits, another folds, and a memory stitch spans the non-local relation.

## Interaction

- Pointer/touch traverse the field; pointer departure commits the route.
- `Enter` / `Space` or **leave a detour** submit deterministic routes.
- `Delete` lifts the latest departure and reconstructs the preceding geometry.
- `R` or **release attention** clears bounded memory.
- `S` downloads the current deterministic state.

## Falsifier

The translation fails if proximity changes geometry immediately, if departure always opens the same segment, if the reply is only a colour/overlay, if later departures ignore memory, or if the blind view reads as a generic chart, card array, or decorative line score.

## Deletion condition

Delete v025 if the cut-and-reply cannot be found in the segment geometry with labels, readout, controls, and prose hidden; if the route is cosmetic; or if the work collapses into the same centered object grammar as v022–v024.

## Evidence boundary

This candidate is held pending independent caption-free perceptual comparison, full local/production browser matrices, deployment readback, and provider revision linkage. The artifact and deterministic engine are real; those remaining gates are not implied by the source record.
