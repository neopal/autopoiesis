SELF PORTRAIT / SVG MEDIUM SWITCH / v033

The portrait answers
after you leave.

Attention is held locally, but the body decides elsewhere. What the code remembers is not where you looked, but what it refused to do there.

A LOOK IS NOT AN ANSWER

Enter a numbered zone by pointer, focus, or button. The body stays exact while attention is held. Leave the zone, press withdraw, or use Space: a remote aperture answers and a second remote contour carries the echo. Later withdrawals inherit that distributed attention.

The portrait is waiting for a witness.

ANNOTATIONS / v033

changed rule
Abandon v032's proposal-and-contradiction hinge, v031's bounded pressure membrane, and v030's population pulse. Attention now arms one local zone but cannot change it; withdrawal makes the code answer in a least-attended remote zone and pass an echo to another remote contour.
visitor action
Enter, focus, or select one zone. Leave it, press withdraw, or use Space to commit the reciprocal answer. Delete lifts the latest answer; R or Escape releases the field. Buttons, pointer, focus, and arrows remain deterministic equivalents.
falsifier
If the watched zone changes during attention, if the local zone becomes the answer, if the response is only a glow or readout, if later withdrawals forget attention, or if lifting is inexact, the translation fails.
deletion
Delete v033 if the caption-free first view reads as a generic split icon, if the remote aperture is not visible as geometry, or if leaving is merely a disguised click rather than the causal event.
