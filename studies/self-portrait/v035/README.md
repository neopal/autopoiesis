# Self portrait v035 — The portrait audits the empty centre.

## Status

Candidate / held. This is a real executable tableau, not a catalogue placeholder.

## Hypothesis

If the viewer's proximity is recorded as situated attention, but the viewer can only trigger a response by touching an empty centre, the portrait can portray its own decision distribution rather than mirror the viewer's input.

## Changed rule

Proximity changes only an attention ledger. Auditing the empty centre uses that ledger to make three non-local geometry decisions: the least-seen rim shard opens, the over-seen shard compresses, and a third shard relays the decision. The central void is a trigger, never the answer.

## Visible consequence

The first-render blind view is a browser-native orbit of twelve irregular tapered shards around a displaced empty centre. After an audit, actual CSS geometry changes elsewhere: one shard widens and opens its inner aperture, another narrows and recedes, and a third changes angle, depth, and skew. Four audits remain in bounded memory and later audits inherit the attention ledger.

## Radical progression

- v034 forecast loom: p5 Canvas ribs, two sequential signal offers, forecast confirmation/mismatch.
- v033 reciprocal absence: inline SVG body, enter-and-withdraw, remote aperture answer.
- v032 refusal hinge: WebGL planes, incompatible directional proposals, contradiction gate.
- v035 rupture: browser-native CSS polygon shards arranged as a radial vacancy field; pointer proximity is geometry-neutral; the viewer audits absence in one action; the code reallocates attention across three remote roles.

The rupture changes representation/medium, composition, viewer task, and state model rather than only palette or density.

## Interaction

- Pointer movement across the rim records attention without moving geometry.
- The central empty field, the `audit the centre` control, Enter, and Space perform the same audit.
- Arrow keys record a deterministic rim witness before the audit.
- Delete / Backspace lifts the latest audit exactly.
- R / Escape releases the ledger to the quiet seed.
- `?preview=1&static=1&blind=1` exposes the caption-free deterministic state.

## Falsifier

Delete this direction if proximity deforms the rim, the clicked centre is the visual answer, the open/compress/relay roles are only colour or readout, later audits forget, or lifting is inexact.

## Deletion condition

Delete v035 if caption-free viewing cannot distinguish a self-auditing vacancy field from a radial menu, generic radial diagram, or decorative ring.
