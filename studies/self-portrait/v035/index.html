The portrait audits
the empty centre.

It does not answer where you look. It keeps a debt of attention, then changes the rim when the only thing you touch is absence.

THE INSTRUMENT WATCHES ITS OWN DISTRIBUTION

Move through the orbit to accumulate situated attention without deforming it. Audit the empty centre and the least-seen shard opens, the over-seen shard compresses, and a third shard relays the decision. The void is a trigger, never the answer.

The orbit is waiting for a first witness.

ANNOTATIONS / v035

changed rule
Abandon v034's forecast comparison, v033's reciprocal body, and v032's contradiction hinge. Proximity changes only an attention ledger; a centre audit makes three non-local geometry decisions: open, compress, relay.
visitor action
Move across the rim, then press the empty centre or use Enter / Space. Arrow keys witness a shard; Delete lifts the latest audit; R or Escape releases the ledger to its quiet orbit.
falsifier
If proximity deforms the rim, if the clicked centre is the answer, if the three roles are only colour or readout, if later audits forget attention, or if lifting is inexact, the self-audit fails.
deletion
Delete v035 if the blind orbit reads as a generic radial menu, if the empty centre is decorative, or if the remote opening, compression, and relay cannot be seen without the furniture.
