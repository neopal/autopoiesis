SELF PORTRAIT / RECIPROCAL DEPARTURE / v048

The portrait
only appears after you leave.

Presence is not a mark. The body watches a route of thresholds without changing; only when the witness moves on does the portrait re-produce itself, opening a cut where no touch landed. What code remembers is not who arrived, but the shape of a departure.

ARRIVAL IS NOT AN ANSWER

Pointer or touch: pass through three different threshold marks, then release toward another mark. A single arrival is held without geometry. Arrow keys visit thresholds; Enter / Space departs, Delete lifts the latest body, and Escape releases the memory. Four departures remain reversible.

The portrait is waiting for a witness to leave.

ANNOTATIONS / v048

changed rule
Presence is geometry-neutral. Only a departure after three distinct threshold notices re-produces the entire raster body and opens a new internal cut.
visitor action
Move through three threshold marks and leave toward another. The portrait records the relation between arrivals and departure, not the place that was touched.
falsifier
Delete if approach changes the body, if one station responds locally, if a cursor trail carries the meaning, if later departures reset, or if lifting is inexact.
deletion
Delete v048 if caption-free viewing still reads as a profile, line lattice, or interface rather than a body made by reciprocal departure.
