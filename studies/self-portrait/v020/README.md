# Self portrait / v020

## Status

**Candidate / held.** This is the 2026-10-04 daily tableau for the Self portrait current. It remains held until an independent caption-free comparison confirms that the relief reads as a self choosing its own fracture rather than a decorative stack.

## Creative record

- **Hypothesis:** code can portray its own decisions by making material resistance select the next visible break; the viewer supplies pressure but not a target.
- **Changed rule:** a measured hold loads the entire relief. Releasing beyond the threshold makes the lowest-resistance rib yield, opens a true geometric gap, and redistributes load through neighbouring ribs.
- **Visible consequence:** the first-render field is one oblique layered material relief, not a face, aperture, register, syntax seal, or agent population. After a yield, one rib is physically split and the rest of the relief shears around the missing room.
- **Deterministic state:** `SEED = 0x53504640`; `STAGES = 18`; `MEMORY_LIMIT = 4`; `RIB_COUNT = 13`; `PRIMITIVE_BUDGET = 104`. The pure engine is replayable.
- **Interaction:** a canvas hold or `Space` hold arms pressure; release commits only after the hold threshold. A short tap is refused. The yield control commits the seeded pressure cue. `Delete` lifts the latest yield; `R` releases the bounded load.
- **Falsifier:** if the event is only a glow or counter, if the same rib always yields, if a tap commits, or if the relief remains a decorative stack, the translation is not embodied.
- **Deletion condition:** delete v020 if a caption-free pair cannot find the self-chosen gap and inherited shear in the relief itself, or if holding feels like a cosmetic trigger.

## Lineage and radical progression

`portrait-2026-10-03` → v020: v017's ordered aperture, v018's serial pressure register, and v019's syntax seal are abandoned. The representation changes from selected blades/strands/clauses to one oblique material relief; the composition changes from local figures and grammar nodes to a single load-bearing object; the encounter changes from attention navigation to measured pressure and release; the memory model changes from refusal/cut/clause debt to material resistance that chooses the next fracture.

The repeated gesture in the last three portrait works was attention acting on a chosen part and receiving a local or remote geometric answer. v020 breaks that invariant: the visitor cannot address a rib, and the portrait's own resistance decides where it yields.

## Cultural translation

The selected reference is **p5.brush**. Its observed mechanism is that pressure, density, grain, and fields are programmable material forces: material changes how geometry is produced and remembered rather than decorating finished geometry.

Mutine refuses p5.brush's brushes, watercolor appearance, hatching, palette, API, examples, and composition. In this portrait current, pressure becomes a whole-object load. Release is the event; the lowest-resistance rib opens a real gap, neighbouring ribs inherit shear, and the next fracture is changed by that remembered load. This opens a material-agency direction for Self portrait and closes the selected-witness/syntax family.

## Evidence boundary

The focused unit tests prove deterministic material yield, resistance-dependent reply selection, bounded memory, actual gap state, and exact restoration. Browser and independent caption-free perceptual evidence must be recorded separately; until those gates are observed, this work stays held.
