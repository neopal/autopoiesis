SELF PORTRAIT / ENCOUNTER SWITCH / v027

The portrait refuses
the first answer.

Offer two parts of the image. Code will not answer from either one. Its own third register opens the counter-reading.

PAIR, THEN ASK

Touch or focus two numbered apertures, then press Enter, Space, or the button. One aperture alone is refused. Delete lifts the latest answer; R releases the bounded ledger.

The portrait is waiting for two registers.

ANNOTATIONS / v027

changed rule
Abandon v026's scattered witness field and remote absence election. The portrait becomes one raster counterportrait with six internal registers. A solitary offer is refused; a pair opens a negotiation, but an unchosen register becomes the visible answer.
visitor action
Offer two different registers by touch, pointer, keyboard focus, or number keys 1–6. Ask with Enter, Space, or the control. Delete lifts the latest counter-reading; R releases memory.
falsifier
If a single offer changes geometry, if the chosen pair itself is always the answer, if the counter-reading is only a label or glow, or if the next answer ignores the ledger, the self-decision rule fails.
deletion
Delete v027 if the blind raster reads as a dashboard, face, or generic grid, or if the split body, counter aperture, and residue cannot be found in the pixels without labels, controls, and prose.
