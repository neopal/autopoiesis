# Self portrait v027 — The portrait refuses the first answer.

## Hypothesis

Code can portray its own decisions by refusing a direct answer to a visitor's first offer. If two situated parts of the image are placed in relation, the portrait should not simply highlight those parts: it should choose an unoffered internal register and make that counter-reading visible.

## Changed rule

v027 abandons v026's scattered semantic witness field and remote absence election, v025's decision ribbon, and v024's resistance membrane. The medium becomes one deterministic raster counterportrait drawn with p5.js on a canvas. Six irregular internal registers make a single dense body rather than a field of marks. One register is refused as an incomplete offer. A pair opens a negotiation; the portrait's own checksum elects an unchosen third register as the counter-reading, while the pair leaves pressure and a fourth register keeps residue. Four counter-readings remain in bounded memory. Delete stores one exact undo state and reconstructs the preceding raster geometry.

## Cultural translation

- **Reference:** [little-critters](https://github.com/GordenSun/little-critters)
- **Observed mechanism:** a population of situated code-drawn agents responds to proximity with legible attention and reciprocal looking, making the visitor part of a social field without a dashboard.
- **Mutine translation:** refuse animals, eyes, characters, and the look-back scene. Translate situated reciprocity into a negotiation between internal registers: a lone offer cannot answer itself, two offers are compared, and a remote unoffered register performs the portrait's answer.
- **Visible consequence:** the first render is one block-like raster body with six embedded apertures. After a committed pair, the two offered registers scar and thin, an unchosen counter aperture opens and shifts, and a fourth register keeps a dark residue that changes the next checksum.
- **Anti-copy:** no animals, character designs, paper scene, source palette, source composition, source code, API surface, or head-turning image is reproduced.

## Visible consequence

The blind view should read first as a single asymmetrical raster object: pale slabs, dark cuts, a tilted seam, and a small family of internal apertures. It is not a face, card array, line field, or diagram. A pair submission changes pixels in three different places: the offered pair tightens, the counter-reading opens away from it, and residue darkens another register. Later pair submissions inherit that residue and move the internal counter-reading.

## Interaction

- Offer one register with pointer, touch, keyboard focus, or number key. A solitary offer arms but does not change geometry.
- Offer a second, different register, then press `Enter`, `Space`, or **ask the portrait** to commit.
- `Delete` lifts the latest counter-reading and restores the exact preceding geometry.
- `R` or **release the registers** clears bounded memory.
- `S` downloads the current deterministic state as JSON.

## Falsifier

The translation fails if a lone offer changes pixels, if the chosen pair is always the visible answer, if the counter aperture is only a label, glow, or readout, if later pair submissions ignore residue, or if the blind canvas reads as a generic dashboard, face, or grid.

## Deletion condition

Delete v027 if the counter-reading cannot be found in the canvas geometry with labels, readout, controls, and prose hidden; if p5.js is only a cosmetic wrapper around a fixed image; if the pair does not materially alter the raster body; or if the work collapses back into the witness field, ribbon, or membrane grammar.

## Radical progression

The last three portrait works all asked the visitor to traverse or witness a visible structure and wait for a non-local geometric answer. v027 changes the viewer task from visiting to composing a pair, changes the medium from semantic DOM/CSS to raster canvas, changes the composition from a distributed field to one dense counterportrait body, and changes memory from exposure/election to a bounded negotiation ledger with a checksum-selected third register. The old invariant — the visitor's addressed place is the event's center — is deliberately broken.

## Evidence boundary
