## Hypothesis

If a self-portrait can delay production, then the selected witness can remain unchanged while the code exposes its own decision rule in remote geometry.

## Changed rule

Abandon v036's continuous resistance cast. A discrete witness selection changes only a latent development load. When development is allowed, the board sends the decision elsewhere: one remote tile thickens, one erases, and one registers a displaced trace. The selected witness remains exact.

A witness offer adds only a thin registration mark. Development changes actual remote block mass, scale, cut geometry, and offset. Four developments remain liftable.

## Interaction

- Click a tile or use Arrow keys to choose a witness; the offer is geometry-neutral.
- Press Enter / Space or use `develop negative` to change three remote tiles.
- Delete / Backspace lifts the latest development exactly.
- R / Escape releases the plate to its quiet deterministic seed.
- `?preview=1&static=1&blind=1` exposes the caption-free settled state.
