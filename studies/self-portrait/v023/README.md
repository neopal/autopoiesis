# Self portrait / v023

## Status

**Candidate / held.** This is the 2026-10-07 daily tableau for the Self portrait current. It remains held until an independent caption-free comparison confirms that the single solid reads as an unseen-face mechanism rather than a generic polygon, and until deployment provenance is linked to a provider revision.

## Creative record

- **Hypothesis:** code can portray its own decisions by changing the part of itself the visitor failed to see; the portrait is not a face or a collection of agents but one solid with an internal witness economy.
- **Changed rule:** replace v020's load-bearing relief, v021's suspended mobile, and v022's binary atlas with one deterministic Canvas 2D solid. Orbiting only changes the view and names a witnessed face. Sealing opens the least-seen face, not the watched face, and sends a seam to a non-local reply face.
- **Visible consequence:** the first-render field is one large faceted object with a broken silhouette, occlusion, shadow, and three-dimensional-looking seam logic. After a seal, a different face takes a real concave notch and a remote face carries a dashed seam. The viewer's pointed target remains materially unchanged.
- **Deterministic state:** `SEED = 0x53504643`; `STAGES = 17`; `MEMORY_LIMIT = 4`; `FACE_COUNT = 7`; `PRIMITIVE_BUDGET = 84`. The pure engine and staged preview are replayable.
- **Interaction:** move across the solid or use Left / Right to orbit. Orbiting arms a face without writing memory. Enter, Space, pointer release, or the seal control commits the observation. Delete lifts the latest inversion; R releases bounded memory; S exports the current state JSON.
- **Falsifier:** if orbiting alone writes memory, if the watched face changes directly, if the least-seen face does not carry an actual notch, or if the remote seam repeats as a fixed neighbor, the social-attention translation is not embodied.
- **Deletion condition:** delete v023 if the blind first view reads as a generic polygon, or if keep / miss / remote answer cannot be found in the silhouette, occlusion, and seam geometry with all labels, readout, controls, and caption hidden.

## Lineage and radical progression

`portrait-2026-10-06` → v023: v020's material relief, v021's suspended WebGL mobile, and v022's browser-native branching atlas are abandoned. The representation changes from a field of objects and choices to one compound Canvas 2D solid; the composition changes from relief/mobile/atlas to a single centered mass; the encounter changes from pressure, departure, or binary choice to orbit-then-seal; the memory model changes from local yield, aversion, and refusal to an inverse-attention archive in which the least-seen face receives the consequence.

The repeated gesture in the last three portrait works was a visitor acting on the visible target and receiving a local or remote deformation. v023 sabotages that invariant: the visible target becomes only a witness, and the unseen part of the portrait decides where the actual event occurs.

## Cultural translation

The selected reference is **little-critters**: situated agents react to pointer proximity by redistributing attention and looking back, making the visitor part of a reciprocal encounter rather than a controller of a dashboard.

Mutine refuses animals, eyes, character design, paper scenes, source palette, composition, surface style, API, and head-turning imagery. The translated rule is reciprocal attention without characters: an orbit registers which face was witnessed, but the commit is answered by the least-seen face opening and a non-local seam carrying the reply. This opens a social-attention direction through absence and closes the branch-card family.

This direction changes the portrait's research question from “what did the code choose?” to “what does the code choose to reveal about what it was not shown?” It is a new encounter grammar, not a texture or palette variation.

## Evidence boundary

The focused unit tests prove deterministic single-solid geometry, non-causal orbiting, unseen-face mutation, bounded memory, exact lifting, staged replay, tableau contracts, and catalogue uniqueness. Browser matrices, interaction readback, blind perceptual review, and provider revision linkage must be recorded separately; until those gates are observed, this work stays held.
