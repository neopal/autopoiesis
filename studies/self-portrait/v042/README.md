# v042 — Absence ledger

## Hypothesis

A self-portrait can portray its own decisions by refusing to answer while the visitor is present. If attention is held as absence instead of local feedback, leaving the field should become the event that changes the portrait elsewhere.

## Radical progression

The last three portrait works used a visitor event to alter a face-like object or its receiving part: v039 generated a global WebGL counterfield, v040 sealed a return cadence into remote mask cuts, and v041 let sustained attention refold the watched DOM shutter. v042 breaks that invariant in two ways: the medium becomes a p5.js Canvas 2D field of open kernels, and the viewer must leave rather than select, return, hold, or press a local object. Presence is inert; the boundary exit is causal.

## Cultural translation

- **Reference:** [little-critters](https://github.com/GordenSun/little-critters)
- **Observed mechanism:** a population of situated code-drawn agents makes pointer proximity legible as reciprocal attention; local behaviour remembers the visitor without a dashboard.
- **Mutine translation:** refuse animals, eyes, head-turning, characters, paper scene, source palette, source composition, source code, examples, and API surface. Invert reciprocal attention into an absence ledger: movement through a field is held without geometry, and only leaving beyond threshold opens an untouched remote kernel while the approached source stays exact.
- **Visible consequence:** a blind field of seventeen unequal open kernels around a quiet vertical absence. Incomplete presence stays inert; a valid departure shifts and hollows a remote kernel, then four remote absences remain.
- **Falsifier:** if presence edits geometry, a brief passage commits, the source changes, the receiver is cosmetic, all departures coincide, or later hollows reset, the translation fails.
- **Anti-copy:** no animals, eyes, head-turning scene, character design, paper style, source palette, source composition, source code, examples, API surface, or surface vocabulary is reproduced.
- **Direction consequence:** close the return-mask / counterfield-volume / attention-shutter sequence; open absence as self-observation, where code portrays its own decisions by withholding the answer until the visitor is gone.

## Changed rule

Presence is geometry-neutral. Only a departure beyond `0.62` movement load spends the event. The source kernel is untouched; a deterministic remote receiver gains a larger void, new angle, shifted position, altered dimensions, and a visible departure curve. Four events compound and can be lifted exactly.

## Interaction

Pointer or touch: enter, traverse the field, then leave its boundary. The leave control and Enter / Space provide the deterministic equivalent. Delete / Backspace lifts the latest absence. R / Escape releases the ledger. Reduced motion keeps the state logic and quiet geometry but removes ambient drift.

## Deletion condition

Delete v042 if caption-free viewing reads as a generic node map, if leaving is only a label attached to a click, if any presence edits local geometry, or if remote absence cannot be distinguished from colour or readout.
