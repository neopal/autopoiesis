SELF PORTRAIT / ABSENT MEMORY / v042

The portrait
leaves the room.

Seventeen decision kernels register the visitor without becoming a face. While you are present, nothing commits. Leave after crossing the field and the portrait opens somewhere you did not touch.

ABSENCE IS THE INSTRUMENT

Enter the canvas and move through several kernels, then let the pointer leave its boundary. Presence is held without geometry; departure is the event. The field chooses a remote kernel to open. On touch, lift your finger to leave. Enter / Space performs a deterministic departure; Delete lifts the latest absence; R / Escape releases the ledger.

The field is waiting for you to leave.

ANNOTATIONS / v042

changed rule
Presence is geometry-neutral. Only a departure beyond the movement threshold spends the event, opening a hollow in an untouched remote kernel while the approached site remains exact.
visitor action
Enter, move through the field, and leave by pointer, touch, or the deterministic leave control. ArrowUp / ArrowDown changes the departure seed; Enter / Space commits it. Delete / Backspace lifts the latest absence; R / Escape releases the ledger.
falsifier
If presence edits a local kernel, if a brief or incomplete passage commits, if the receiver is cosmetic, if all departures coincide, or if later absences reset, the translation fails.
deletion
Delete v042 if caption-free viewing reads as a generic node map or if leaving is merely a label attached to a click rather than a visible causal event.
