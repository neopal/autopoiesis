# Self portrait / v018

## Status

**Candidate / held.** This is the 2026-10-02 daily tableau for the Self portrait current. It remains held until an independent caption-free comparison confirms that the pressure register reads as a self carrying its own material decisions, rather than a decorative data chart.

## Creative record

- **Hypothesis:** code can portray its own decisions by making a prior pressure alter the geometry-producing rule of the next event, without returning to a face, aperture, raster, or continuous membrane.
- **Changed rule:** a discrete pressure command opens a true interval in one browser-native strand. The removed span is not painted over: the two actual DOM halves separate. A distant strand thickens and lengthens, while intervening strands inherit a small bend and increased resistance.
- **Visible consequence:** the first-render field is a horizontal register of uneven material strands. After pressure, one strand contains a legible negative cut, a remote strand carries extra load, and the field around the cut bends. A repeated pressure at the same strand meets remembered resistance and chooses a different reply.
- **Deterministic state:** `SEED = 0x53504638`; `STAGES = 15`; `MEMORY_LIMIT = 4`; `STRAND_COUNT = 17`; `PRIMITIVE_BUDGET = 68`. The pure engine is replayable.
- **Interaction:** pointer taps are refused. The pressure command, Enter, or Space commits the same deterministic event. `lift latest cut` rebuilds the exact preceding register; `release the register` returns to the autonomous sequence.
- **Falsifier:** if the cut is only a coloured overlay, the distant reply is only an accent, intervening geometry does not move, or repeated pressure behaves as if resistance did not exist, the translation is not embodied.
- **Deletion condition:** delete v018 if a caption-free pair sees a generic chart or static stripe ornament instead of a self carrying a changed material rule.

## Lineage and radical progression

`portrait-2026-09-27` → v018: v017's ordered aperture, v016's raster witness field, and v015's continuous pressure membrane are abandoned. The representation changes from canvas to browser-native DOM geometry; the composition changes from central object to serial horizontal register; the encounter changes from proximity-then-gaze to a position-independent pressure command; and the memory model changes from refusal debt to actual negative intervals plus inherited load.

The repeated gesture in the last three portrait works was a visitor attending to, pressing, or approaching one coherent image and receiving a local or remote response inside a face-like field. v018 breaks that invariant. It refuses pointer position, removes the face/aperture metaphor, and makes the portrait a serial account of its own rendering pressure: the work carries a cut forward into the next geometry.

## Cultural translation

The selected reference is **p5.brush**. Its observed mechanism is that pressure, density, grain, and directional fields are material engines: material changes how geometry is produced and remembered, not merely how a finished mark is coloured.

Mutine's translation refuses p5.brush's brushes, watercolor appearance, hatching vocabulary, API surface, source palette, and example compositions. In this portrait current, pressure becomes a geometry-producing register. A command cuts actual DOM intervals, a distant strand inherits load, and resistance changes the next reply. This opens a material-agency direction for Self portrait while closing the aperture/refusal family.

## Evidence boundary

The focused unit tests prove deterministic pressure, actual cut geometry, non-cosmetic remote response, remembered resistance, finite memory, and exact restoration. Browser and independent caption-free perceptual evidence must be recorded separately; until those gates are observed, this work stays held.
