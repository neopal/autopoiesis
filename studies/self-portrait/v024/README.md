## Creative record

- **Hypothesis:** code can portray its own decisions by refusing to let the visitor choose the visible break; a gesture becomes a measurement that the portrait's internal resistance interprets.
- **Changed rule:** replace v023's single observed Canvas solid with one browser-native SVG membrane of nine irregular nested contours. The visitor supplies a stroke vector and length, but the membrane's resistance chooses the contour that ruptures. A non-local contour receives a relay, and the changed field affects the next choice.
- **Visible consequence:** the first-render field is a nested contour membrane around a central absence, not a face, card atlas, mobile, relief, route bundle, or compound solid. A committed stroke opens a real contour gap, shifts that contour's eccentricity, and sends a broken relay to another ring. Later strains inherit the changed resistance field.
- **Deterministic state:** `SEED = 0x53504644`; `STAGES = 17`; `MEMORY_LIMIT = 4`; `RING_COUNT = 9`; `PRIMITIVE_BUDGET = 72`. The pure engine and staged preview are replayable.
- **Interaction:** drag across the membrane and release. A short stroke is refused. Enter, Space, or the strain control submits a deterministic stroke; Delete lifts the latest rupture; R releases bounded strain memory; S downloads the current state as JSON.
- **Falsifier:** if the stroke is merely rendered as a cursor trace, if pointer location directly selects the changed ring, if the relay is fixed or cosmetic, or if later strains ignore the changed field, the p5.brush translation is not embodied.
- **Deletion condition:** delete v024 if the blind first view reads as another object, relief, route bundle, atlas, or generic linefield, or if rupture, relay, and exact lifting cannot be found in the contour geometry with labels, readout, controls, and prose hidden.

## Lineage and radical progression

`portrait-2026-10-07` → v024: v020's load-bearing relief, v021's suspended mobile, v022's binary atlas, and v023's single faceted Canvas solid are abandoned. The representation changes to browser-native SVG paths; the composition changes from one filled mass to nested openable contours around a void; the encounter changes from orbit-then-seal to draw-and-release; the memory model changes from unseen-face inversion to measured strain that changes the future resistance field.

The repeated gesture in the last three portrait works was the visitor addressing a visible or witnessed object and receiving a geometric answer. v024 removes the target. The pointer supplies a vector only; the code's own resistance decides where the event becomes visible. This is a new medium, composition, interaction, and causal relation rather than a palette or density variation.

## Cultural translation

The selected reference is **p5.brush**. Its observed mechanism is that pressure, directional fields, custom brushes, and drawing state participate in producing geometry rather than decorating finished geometry.

Mutine refuses p5.brush's brushes, watercolor appearance, hatching vocabulary, source palette, source composition, examples, and API surface. The translated rule is a self portrait that treats a visitor stroke as a measurement: internal resistance chooses a contour to rupture, a non-local ring receives the relay, and the updated field changes the next decision. The work keeps the mechanism of material agency while changing medium, image grammar, and viewer task.

This opens a material-agency branch for Self portrait through self-measurement and closes the direct-target / unseen-face family. The reference remains a causal seed, not a visual template.
