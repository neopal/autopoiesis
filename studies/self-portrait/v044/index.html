SELF PORTRAIT / CONTRADICTION AS MATERIAL / v044

The portrait
refuses the answer.

Eleven decision panels hold an unfinished register. Choosing a side is not yet a mark. Only three distinct choices that disagree can make the portrait split an unchosen panel, leaving the witnesses exactly where they were.

A DECISION IS NOT A MARK

Click or touch a panel, then choose left or right. Three distinct panels form a latent proposition. Commit only a contradiction: unanimous choices are refused, while a mixed decision is remembered as a new split elsewhere. Arrow keys select; Up / Down choose a side; Enter commits; Delete lifts the latest split; Escape releases.

The portrait is withholding an answer.

ANNOTATIONS / v044

changed rule
Material agency is inverted: force never directly shapes a panel. Three distinct choices must disagree before the register alters an unchosen panel's topology; the chosen witnesses remain exact.
visitor action
Select a panel, choose left or right, repeat on two other panels, then commit. Pointer, touch, buttons, and keyboard share the same contradiction state machine; Delete / Backspace lifts the latest split; Escape releases.
falsifier
If a single choice commits, if unanimous agreement commits, if a witness changes, if the remote split is only colour or readout, if later splits reset, or if lifting is inexact, the translation fails.
deletion
Delete v044 if caption-free viewing reads as another field of lines or if contradiction is only explanatory language attached to buttons.
