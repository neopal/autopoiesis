SELF PORTRAIT / DIRECTION SWITCH / v022

The portrait argues
with its branch.

A code self-image is not a face. It is a decision that remembers the possibility it refused, then lets that refusal choose where the next answer appears.

CHOOSE A CONTRADICTION

Tap the left or right half of the atlas, use the two choice controls, or arm a side with the arrow keys and commit with Enter. The selected branch opens, the other contracts, and a remote branch answers. Delete lifts the latest refusal; R releases the memory.

The atlas is holding two incompatible beginnings.

ANNOTATIONS / v022

changed rule
Replace v019's syntax seal, v020's load-bearing relief, and v021's approach/departure mobile with a browser-native branching atlas. A binary choice opens one actual card, contracts the refused card, and moves a non-local counter-branch.
visitor action
Choose left or right. Arrow keys can arm without writing; Enter or Space commits. Delete lifts the latest refusal and R releases the bounded decision memory.
falsifier
If the two choices only recolour fixed cards, if the refused possibility does not change the next active branch, if the reply is always in the same place, or if the field reads as a decorative card grid, the translation fails.
deletion
Delete v022 if the blind atlas cannot show keep / refuse / remote answer through its shapes alone, or if repeating a choice produces the same geometry and reply as the first choice.
