SELF PORTRAIT / SELF-TYPESETTING / v046

The portrait
leaves its margins.

A generated manuscript is its own material. Mark three different words and the pressure does not scar the marked word: it rewrites the page's measure, line gap, and reading direction. The portrait is the page learning where it can still fit.

A PAGE MUST BE PRESSED INTO A NEW MEASURE

Pointer or touch: press and release three different words. The mark stays provisional until the page has enough pressure; then compile the margin. Arrow keys move the focus, Enter / Space marks a word, Delete lifts the latest rewrite, and Escape releases the page. Four lineations remain reversible.

The page is keeping its first margin.

ANNOTATIONS / v046

changed rule
Pressure is not pigment on a finished page. Three distinct marginal marks can rewrite the document's measure, line gap, and writing direction; incomplete or shallow pressure leaves the typeset body exact.
visitor action
Mark three different words by pointer, touch, keyboard, or the deterministic control. Compile the lineation, lift the latest rewrite, or release to the quiet manuscript. The mark is a line-break claim, not a cosmetic highlight.
falsifier
Delete if a local word changes before compilation, if shallow pressure commits, if mark order is cosmetic, if later lineations reset, or if lifting is inexact.
deletion
Delete v046 if caption-free viewing reads as a styled web page rather than a self-rewriting typeset object whose visible grammar changes through the encounter.
