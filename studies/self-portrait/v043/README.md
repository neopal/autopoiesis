# v043 — Resistance portrait

## Hypothesis

A self-portrait can portray its own decisions as material resistance rather than as a face or a witness field. If the viewer presses along the portrait's grain, the trace should stay latent until it crosses a real threshold; then the material should re-produce an untouched channel and leave the contacted channel exact.

## Radical progression

The last three portrait works used a Canvas absence field (v042), a DOM shutter field (v041), and a planar return mask (v040). Their repeated gesture was to visit a discrete site, wait or depart, and let an open/closed mark answer. v043 changes the medium grammar to one continuous pressure slab, the encounter to a directional drag, and the causal material to travel + grain alignment + resistance. It is not a new field of kernels, a local fold, or a boundary exit: the viewer must push through a material threshold, and the portrait re-forms its own remote substrate.

## Cultural translation

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** natural drawing tools treat pressure, density, directional behaviour, and vector fields as production rules that change how geometry is generated rather than decorating a finished mark.
- **Mutine translation:** refuse brush presets, watercolor appearance, hatching vocabulary, grain treatment, source palette, source composition, source code, examples, and API surface. Translate material agency into a resistance portrait: a grain-aligned crossing remains geometry-neutral while it loads; completion re-produces an untouched channel with new contour count, density, angle, phase, and mass, while the contacted channel stays exact.
- **Visible consequence:** a blind view of one dark contiguous slab made from nine overlapping pressure channels. A valid crossing leaves no local scar and changes the actual remote channel; four recasts compound.
- **Falsifier:** if the trace paints itself, if a short or misaligned crossing commits, if the source changes, if the remote response is only a colour or readout, or if later recasts reset, the translation fails.
- **Anti-copy:** no p5.brush preset, brush appearance, watercolor, hatching vocabulary, source palette, source composition, source code, examples, API surface, or source imagery is reproduced.
- **Direction consequence:** closes the portrait's return / shutter / absence sequence and opens self-observation as material self-production: code shows what it refuses and how it re-makes a decision elsewhere.

## Changed rule

Material is not a skin over geometry. A pressure crossing is latent until `travel >= 0.58`, `alignment >= 0.66`, and `pressure >= 0.62`. Only then is the event spent in an untouched remote channel; the source channel remains exact. Four events compound and can be lifted exactly.

## Interaction

Pointer or touch: press, drag along the slab grain, then release. The deterministic press control and Enter / Space share the same valid event. Delete / Backspace lifts the latest recast. R / Escape releases the portrait. Reduced motion preserves the state machine and removes ambient grain drift.

## Deletion condition

Delete v043 if caption-free viewing reads as a generic ribbon field, if resistance is only prose attached to a drag, if any local scar appears at the hand, or if the remote recast is cosmetic.
