# Self portrait v031 — The portrait keeps the gap in its checksum.

## Hypothesis

A self-portrait can expose code's decision-making without depicting a face or staging a population. If pressure is treated as a material load, the code can show where its own calibration fails: the place being measured stays quiet while remote bands open, inherit, and shed geometry.

## Changed rule

v031 abandons v030's semantic decision rows, v029's delegated boundary shell, and v028's folded WebGL volume. The medium becomes a single p5.js Canvas 2D diagnostic membrane: thirteen irregular scored bands are produced by a deterministic field. A bounded pressure hold (140–720ms) is the only causal event. A valid hold never edits the local probe site; it changes three remote bands and adds load to the next reading. Four revisions remain liftable, and later probes inherit the changed membrane.

## Cultural translation

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** programmable pressure, density, and directional fields participate in producing geometry rather than decorating finished geometry.
- **Mutine translation:** refuse brushes, watercolor, hatching, grain, source palette, composition, code, and API surface. Translate material agency into calibration resistance: a pressure hold changes the production parameters of remote bands, and the accumulated load changes later revisions.
- **Visible consequence:** the blind first render is one asymmetrical raster membrane of scored bands. A valid hold leaves the measured area local but changes actual remote band gaps, height, bend, width, density, and contour inheritance. The resulting load persists into the next frame.
- **Anti-copy:** no brush appearance, watercolor, hatching, grain, source palette, source composition, source code, API surface, or surface vocabulary is reproduced.

## Visible consequence

The first encounter should read as one diagnostic plate or membrane, not a face, bar chart, card list, or dashboard. After a valid pressure hold, an opening grows in one remote band, another inherits a changed contour and density, and a third sheds height and bends. These are raster geometries, not status-only annotations. The touched area is not privileged.

## Interaction

- Hold anywhere in the canvas and release.
- A weak hold under 140ms or an over-held probe beyond 720ms refuses without geometry or memory change.
- Enter, Space, or **probe the membrane** commits the deterministic 260ms probe.
- Delete/Backspace or **lift latest probe** reconstructs the exact preceding membrane.
- R/Escape or **release the checksum** clears bounded memory and returns to the quiet seed.
- The state bridge is exposed as `window.__mutinePortraitV031` for browser QA and deterministic replay.

## Falsifier

The translation fails if pressure outside the calibration window commits, if the touched band directly becomes the answer, if remote roles exist only as colour or readout, if later probes restart from the seed membrane, if a valid probe does not change actual geometry, or if the blind field reads as a generic chart, face, dashboard, or decorative raster.

## Deletion condition

Delete v031 if the checksum membrane cannot hold attention without its caption, if its gap/open/inherit consequences are not materially visible, if pressure is only a disguised button, or if exact lifting cannot restore the preceding raster geometry.

## Radical progression

The last three portrait works repeated a visitor-addressed structure: a folded volume interpreted a stroke, a shell delegated an edge after a quorum, and a DOM population crossed after a pulse. v031 changes at least two perceptual dimensions at once: from object/row topology to one continuous raster membrane, and from traverse/visit/tap to bounded pressure timing. It removes the recent invariant that the viewer's addressed location is the event's centre. The new capability is a self-portrait that leaves the local measurement intact while its own remote calibration changes.

## Direction consequence

The p5.brush reference opens a resistance-as-calibration direction for Self portrait and closes the recent volume/shell/population family. A future work must not repeat this band membrane or pressure-window encounter without changing medium, representation, and memory.
