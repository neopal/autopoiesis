# Self portrait / v016

## Status

**Candidate / held.** This is the 2026-09-25 daily tableau for the Self portrait current. It remains held until an independent caption-free perceptual comparison confirms that the raster field reads as an image redistributing its own witness rather than a decorated dot portrait.

## Creative record

- **Hypothesis:** code can portray its own decisions by making a population of local image cells remember where attention was placed, not by adding another route, plate, or wound to a face.
- **Changed rule:** a sustained witness withdraws density from the nearest raster patch and transfers it to a distant patch. Local resistance increases, so repeating attention at the same place changes the next transfer rather than replaying the same mark.
- **Visible consequence:** the first-render field is a dense, oblique raster portrait made from small cells rather than an outline or membrane. After interaction, a real patch thins and opens, a distant patch swells, and repeated attention changes both the geometry and the transfer mass.
- **Deterministic state:** `SEED = 0x53504636`; `STAGES = 15`; `MEMORY_LIMIT = 5`; `ATTENTION_THRESHOLD = 0.65`; `PRIMITIVE_BUDGET = 72`. The engine is pure and replayable.
- **Interaction:** pointer movement only arms a witness. Hold and release, click/tap, or Enter/Space commits attention at the armed location. `lift latest witness` rebuilds the exact preceding raster; `release the image` returns to the autonomous sequence.
- **Falsifier:** if the watched patch only changes tint, the receiver only receives a marker, or a second witness behaves as if the first never happened, the translation is not embodied.
- **Deletion condition:** delete v016 if a caption-free pair sees a decorative dot field instead of an image that can withdraw one patch and transfer its density elsewhere.

## Lineage and radical progression

`portrait-2026-09-24` → v016: v015's pressure membrane, v014's reciprocal plates, and v013's folded routes are abandoned. This work changes representation from continuous geometry to a raster population, changes the viewer task from pressing to sustained local attention, and changes temporal behaviour from material scars to a bounded social memory of witness transfer.

The repeated gesture in the last three portrait works was a visitor event changing one coherent face or one of its parts: routes folded, plates answered, and a membrane yielded. v016 breaks that invariant. There is no contour, no plate, no wound, and no local reply. A field of image cells redistributes its own density after being watched.

## Cultural translation

The selected reference is **little-critters**. Its observed mechanism is a population of situated agents whose proximity to the pointer changes attention and produces a reciprocal encounter.

Mutine's translation refuses animals, characters, eyes, paper style, head-turning scene, source palette, composition, and surface vocabulary. In this portrait current, situated attention becomes a witness token inside a raster image: the nearest patch withdraws density, a distant patch inherits it, and the local resistance map changes the next collective decision. This opens a social-attention direction without reproducing the source scene.

## Evidence boundary

The focused unit tests prove bounded attention, structural source withdrawal, distant receiver growth, resistance memory, finite history, deterministic timeline settling, and exact restoration. Browser and independent caption-free perceptual evidence must be recorded separately; until those gates are observed, this work stays held.
