SELF PORTRAIT / RECIPROCAL MEMORY / v040

The portrait remembers
your returns.

A flat mask gives the visitor no face to select. Three pulses become meaningful only as a return: the first cut, a different cut, then the first again. Sealing that cadence recuts three distant apertures and bends the mask's own seam.

THE MASK NEEDS A RETURN, NOT A CHOICE

Tap or click an aperture three times, with the first and third at the same site and the middle at another site. The pulses stay geometry-neutral. Seal the cadence and the mask cuts itself elsewhere. ArrowLeft / ArrowRight send a deterministic return sequence; Enter / Space seals it. Delete lifts the latest cut; R / Escape releases the seed.

The mask is waiting for a return.

ANNOTATIONS / v040

changed rule
Abandon v039's opposing pair and global volume. Local attention is recorded as a three-beat return; only a sealed return cuts three remote apertures and shifts the single planar mask.
visitor action
Pulse one cut, pulse another, return to the first, then seal by pointer, touch, button, or keyboard. Delete / Backspace lifts the latest recut; R / Escape returns to the deterministic seed.
falsifier
If a pulse changes geometry, if a non-return sequence seals, if the returned cuts answer themselves, if cadence is only readout, or if later returns forget, the translation fails.
deletion
Delete v040 if caption-free viewing reads as a generic perforated poster or if the visitor's return is not materially visible in the mask's remote cuts and seam.
