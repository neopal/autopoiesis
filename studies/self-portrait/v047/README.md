# v047 — Counterpressure profile

**The portrait cannot keep a straight answer.**

This is a held daily candidate for Mutine's Self portrait current.

## Hypothesis

A self-portrait can portray its own decisions by refusing a straight answer. A gesture that reverses direction three times should alter the handedness of the field that contains it, not paint the region under the pointer.

## Changed rule

Pending pointer samples are geometry-neutral. Only release after at least six samples, sufficient path length, and three horizontal direction reversals re-produces the entire SVG lattice: all 28 ribs, the spine, echoes, slit, density, and hand.

## Visible consequence

The blind view is a dark off-centre profile of ribs and an open slit. A valid counterstroke changes every rib and the slit. Four committed counterprofiles compound and remain liftable.

## Interaction

- Pointer or touch: draw across the field, reverse direction three times, release.
- Keyboard: ArrowLeft / ArrowRight build the same stroke grammar; Enter or Space releases.
- Delete / Backspace: lift the latest profile.
- Escape: release the field to the deterministic quiet seed.

A straight or short stroke is refused.

## Cultural translation

Starting encounter: [p5.brush](https://github.com/acamposuribe/p5.brush), whose pressure, density, direction, and vector fields change how geometry is produced. The translation refuses its brushes, watercolor, hatching, grain, palette, composition, code, examples, and API. It inverts v046's pressure-to-typesetting move: pressure is held as inert samples, and reversal on release becomes the production rule for a new SVG profile.

## Falsifier / deletion condition

Delete this direction if a straight stroke commits, only the touched region changes, reversal order is cosmetic, the slit is an overlay, later profiles reset, or lift is inexact. It also fails if the blind view reads as a decorative line lattice rather than a self-reproducing contour.
