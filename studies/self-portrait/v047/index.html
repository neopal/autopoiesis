SELF PORTRAIT / COUNTERPRESSURE / v047

The portrait
cannot keep a straight answer.

The profile is not a line waiting for a brush. It is a field that notices when pressure changes direction. A counterstroke released through the empty margin turns its reversals into a new contour; the whole portrait moves, not the place that was touched.

A STRAIGHT STROKE IS NOT AN ANSWER

Pointer or touch: draw across the field and reverse direction three times before releasing. A straight or short stroke is refused. Arrow keys build the same reversal grammar; Enter / Space releases it, Delete lifts the latest rewrite, and Escape releases the memory. Four counterprofiles remain reversible.

The portrait is keeping its first contour.

ANNOTATIONS / v047

changed rule
Pressure is inverted: holding or drawing does not paint the profile. Only a released stroke that reverses direction three times can rewrite the whole SVG lattice.
visitor action
Draw across the negative field, reverse three times, and release. The counterstroke is a relation, not a selected object; the portrait re-produces every rib and keeps the stroke only as memory.
falsifier
Delete if a straight stroke commits, if the touched region alone changes, if reversal order is cosmetic, if later profiles reset, or if lifting is inexact.
deletion
Delete v047 if caption-free viewing reads as a decorative line lattice rather than a self-portrait whose contour is rewritten by counterpressure.
