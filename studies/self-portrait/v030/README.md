# Self portrait v030 — The portrait keeps a second opinion.

## Hypothesis

If a self-portrait is a population of decisions rather than a face or shell, then a single act of attention can make the least-attended decision cross the document and become an actual second opinion. The work should portray code by exposing the order it chooses and revises.

## Changed rule

v030 abandons v029's boundary quorum, v028's self-modifying fold volume, and v027's pair counter-reading. The work is now a semantic DOM population of fifteen decision rows. One pulse does not select a local target: the least-attended row is promoted into a remote position, while the displaced row receives the counter-state. The actual list order, widths, charges, and states change together. Four pulses remain liftable.

## Visible consequence

The first render is an irregular typographic population around a tilted axis, not a shell, face, grid, or canvas. A valid pulse visibly crosses one decision to a non-local position and displaces another row. Later pulses begin from the changed DOM order. The rows are the work; the readout and controls are only a threshold for the encounter.

## Interaction and memory

- Tap once anywhere in the field, press `Enter` / `Space`, or choose **ask once**.
- A single pulse is causal; the pointer location is not a direct target.
- `Delete` / `Backspace` lifts the latest pulse exactly.
- `R` / `Escape` releases the population to the deterministic seed.
- Four pulse snapshots remain bounded and the same seed plus sequence replays the same order.

## Falsifier

The translation fails if the touched row is always the answer, if the DOM order does not change, if the second opinion is only a colour or readout, if the displacement does not persist into later pulses, or if the blind field reads as a dashboard or generic card list.

## Deletion condition

Delete v030 if the blind field reads as a dashboard, card list, or typographic poster, or if the second opinion cannot be found as an actual crossing and displaced row without labels, controls, annotations, and prose.

## Cultural translation

- **Reference:** [little-critters](https://github.com/GordenSun/little-critters)
- **Observed mechanism:** situated agents respond to proximity with legible attention and reciprocal consequence; a visitor participates in a small social field without a dashboard.
- **Mutine translation:** refuse animals, eyes, characters, paper, and head-turning. Translate the population into decisions: local attention is remembered by each row, but one global pulse lets the least-attended decision cross the document and make the code's second opinion visible.
- **Visible consequence:** actual semantic list order, row geometry, and role states change; the point of contact does not choose the answer.
- **Falsifier:** if the work follows a pointer target, if the rows only receive decorative attention, or if later pulses reset the order, the translation fails.
- **Anti-copy:** no animals, character designs, paper scene, head-turning image, source palette, source composition, source code, example, or API surface is reproduced.
- **Direction consequence:** closes Self portrait's witness-field / fold-grammar / delegated-edge family and opens a decision-population direction: self-observation becomes a visible, revisable document order rather than a body that looks back.
