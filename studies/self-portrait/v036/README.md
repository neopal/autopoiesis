# Self portrait v036 — The portrait hardens where it resists.

## Status

Candidate / held. This is a real executable tableau, not a catalogue placeholder.

## Hypothesis

If a viewer's pressure is stored as material resistance rather than rendered as an immediate mark, the portrait can portray its own decisions through the geometry it produces next.

## Changed rule

A pressure path changes only a resistance ledger. On release, the ledger selects three roles away from the contact point: one stratum hardens, one fractures, and a third binds the event. The next geometry is produced by accumulated material memory, not by copying the gesture.

## Visible consequence

The first-render blind view is a Canvas 2D specimen of nine irregular strata: a vertical cast with cuts, offsets, and a bright internal fault. During a drag the specimen stays geometrically exact. On release, actual geometry changes elsewhere — width/depth harden, a notch and split fracture, and a diagonal bridge binds — and four casts remain liftable.

## Radical progression

- v035 attention orbit: browser-native CSS shards, proximity ledger, absence audit.
- v034 forecast loom: Canvas ribs, sequential signal comparison, predictive error.
- v033 reciprocal absence: inline SVG body, enter-and-withdraw, remote aperture.
- v036 rupture: Canvas 2D raster specimen, pressure-path encounter, and material production rule. The viewer no longer witnesses a field or offers a signal; they load resistance into a cast and release it into a new remote geometry.

The rupture changes representation, composition, viewer task, temporal grammar, and shape vocabulary rather than only palette or density.

## Interaction

- Drag across the specimen to load resistance without moving the strata.
- Release to cast the stored material memory into harden / fracture / bind roles.
- Arrow keys load deterministic directional probes; Enter / Space casts.
- Delete / Backspace lifts the latest cast exactly.
- R / Escape releases the material to the quiet seed.
- `?preview=1&static=1&blind=1` exposes the caption-free deterministic state.

## Falsifier

Delete this direction if the probe draws itself, if the contact point becomes the visual answer, if hardening, fracture, or binding is only colour, if later casts forget resistance, or if lifting is inexact.

## Deletion condition

Delete v036 if caption-free viewing cannot distinguish a self-portrait whose next geometry is produced by stored resistance from a bar chart, decorative stack, or brush simulation.
