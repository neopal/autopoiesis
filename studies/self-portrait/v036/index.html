Drag across the cast to accumulate pressure without moving its geometry. Release and the stored load decides a remote material event. The contact point is only a probe; the portrait describes itself through what it does to the next cast.

Abandon v035's attention orbit, v034's forecast loom, and v033's reciprocal body. A pressure path changes only a resistance ledger; release turns that material memory into three remote roles: harden, fracture, bind.

If the probe draws itself, if the contact point becomes the answer, if hardening, fracture, or binding is only colour, if later casts forget resistance, or if lifting is inexact, the material translation fails.
