# Self portrait v039 — The portrait turns the field against itself

## Status

Candidate / held. This is a real executable tableau, not a catalogue placeholder.

## Hypothesis

If a self-portrait is generated by a material field, then the viewer should not be able to mark it directly. Only an opposition between two unequal pressures should be able to rewrite the field that makes the portrait.

## Changed rule

v039 abandons v038's situated clause, gaze, departure, and remote closure/opening/echo roles. The medium changes to a browser-native WebGL volume of twenty-two faceted ribbons. A left and right pressure are geometry-neutral offers. When both sides are armed, their signed difference becomes a counterfield that regenerates every ribbon and the volume's twist, fold, rise, yaw, and pitch. The work does not answer in a remote part; it rewrites its own production field globally.

This is a state and encounter rupture: from entering and leaving one clause to pairing opposing sides, and from inline SVG syntax to a three-dimensional GPU-produced volume. Pointer/touch and Arrow keys offer equivalent side-pairing paths; Enter / Space produces the field; Delete lifts the last production; R / Escape releases the seed.

## Visible consequence

The first-render blind view is a dark, faceted vertical volume whose surface is made from interwoven ribbon panels, not a readable sentence, grid, or route sheet. A single side offer leaves the geometry exact. An unequal pair changes the curvature, phase, width, depth, and global pose of all twenty-two ribbons and accumulates up to four productions.

## Cultural translation

Source: [p5.brush](https://github.com/acamposuribe/p5.brush).

- **Observed mechanism:** programmable material tools and vector fields redirect the geometry of strokes; the field participates in producing the mark rather than styling a finished shape.
- **Mutine translation:** refuse brushes, watercolor, hatching, grain, palette, composition, source code, examples, and API surface. Translate field participation into a self-portrait whose two opposing pressure offers become a signed counterfield that regenerates its entire volume.
- **Visible consequence:** The offered sides do not draw or deform the volume. Only the produced pair changes every ribbon's curvature and the volume's own twist/fold parameters, so the engine's production rule becomes visible in the object.
- **Falsifier:** Delete if one side alone produces, if an offer changes geometry, if production only changes colour/camera/readout, if every ribbon is not regenerated, if the volume reads as a generic 3D ribbon sculpture, or if later productions reset.
- **Anti-copy statement:** No p5.brush brush appearance, watercolor, hatching, grain, vector-field preset, source palette, source composition, source code, example, API surface, or surface vocabulary is reproduced.
- **Direction consequence:** Closes the Self portrait sequence of attention orbit, resistance cast, latent negative, and departing syntax; opens a field-authorship direction in which code portrays itself by exposing the global rule that produces its geometry.

## Deletion condition

Delete v039 if caption-free viewing cannot distinguish the counterfield volume from a generic 3D ribbon sculpture or linefield, if the pair is cosmetic, or if the global production rule is not materially visible in the rendered geometry.
