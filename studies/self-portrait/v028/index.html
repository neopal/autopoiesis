SELF PORTRAIT / MEDIUM SWITCH / v028

The portrait changes
its grammar.

Give the volume a crooked sentence. It will not replay the path. It will rewrite the rule that folds its own body.

DRAG, THEN RELEASE

Trace three or more points across the volume. The path is read for turns, not location. A hinge folds, a remote counterfold answers, and a relay plate changes the next grammar. Enter, Space, and the button use the same deterministic gesture.

The volume is waiting for a sentence.

ANNOTATIONS / v028

changed rule
Abandon v027's pair negotiation, v026's witness field, and v024's ring rupture. The portrait becomes a suspended WebGL volume of folded plates. A gesture is parsed as grammar; the code selects a non-local hinge, counterfold, and relay, then changes the rule used by the next gesture.
visitor action
Drag across at least three distinct points and release. A short path is refused. Enter or Space commits a deterministic path; Delete lifts the latest fold; R or Escape releases the bounded grammar.
falsifier
If the pointer location directly selects the visible hinge, if the path is only a drawn trace, if the rule name changes without changing plate geometry, or if later folds restart from the original grammar, the self-decision translation fails.
deletion
Delete v028 if the blind field reads as a generic 3D demo, a stack of cards, or a decorative animation, or if the hinge, counterfold, relay, and inherited rule cannot be found in the volume without labels, controls, and prose.
