# Self portrait v028 — The portrait changes its grammar.

## Hypothesis

Code can portray its own decisions by making the representation itself choose what the next input means. A visitor's crooked gesture is not a mark to preserve: it is parsed by the current folding grammar, which changes the volume and mutates the rule used by the next gesture.

## Changed rule

v028 abandons v027's pair negotiation, v026's scattered witness field, and v024's nested contour rupture. The medium becomes a browser-native WebGL volume of eleven suspended folded plates. A gesture with at least three points is measured for length, turns, curvature, and direction. The code chooses a non-local hinge, counterfold, and relay plate from that signature. The next gesture is interpreted by a changed rule index, so the portrait does not merely accumulate marks: it changes its own grammar.

## Cultural translation

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** pressure, direction, density, and material state participate in producing geometry rather than decorating finished geometry.
- **Mutine translation:** refuse brushes, watercolor, hatching, grain, and the library's API surface. Translate material agency into a self-portrait whose current grammar parses a gesture into a non-local hinge, counterfold, and relay; the resulting fold mutates the grammar of the next gesture.
- **Visible consequence:** the blind first render is an impossible suspended volume of asymmetrical folded plates. After a valid traverse, three non-local plate geometries change, the path itself disappears, and the rule used for the next traverse changes. Later folds inherit the changed volume and grammar.
- **Anti-copy:** no source brush, watercolor appearance, hatching vocabulary, palette, composition, example, code, or API surface is reproduced.

## Visible consequence

The first encounter should read as a single dark volume with a pale, folded interior—not as eleven cards, a face, a graph, or a generic 3D demo. The visitor's path is transient. On release, a hinge rises and creases, a remote counterfold drops, and a relay plate shifts sideways. The next deterministic gesture is interpreted through a different fold rule, and the resulting volume carries both changes.

## Interaction

- Drag across three or more points and release. The volume measures the path; it does not use the pointer location as a direct target.
- A short or two-point gesture is refused without memory or geometry change.
- Enter, Space, or **fold the grammar** commits the deterministic path used by the timeline.
- Delete or **lift latest fold** reconstructs the exact preceding volume.
- R, Escape, or **release the grammar** clears the bounded memory and restores the stage's quiet grammar.
- S downloads the current deterministic state as JSON.

## Falsifier

The translation fails if the cursor location directly chooses the visible hinge, if the path remains as a decorative trace, if the rule label changes without changing geometry, if later gestures restart from the quiet volume, or if the blind field reads as a generic 3D demo, stack of cards, or decorative animation.

## Deletion condition

Delete v028 if the blind folded volume cannot hold attention without its caption, if the hinge/counterfold/relay are not materially visible, if the next grammar does not affect geometry, or if exact lifting cannot restore the preceding volume.

## Radical progression

The last three recorded portrait works repeated a visitor-addressed structure: witness a field, pair registers, or offer a stroke and wait for a non-local answer. v028 changes the medium to WebGL, the composition to one suspended volume, the encounter to a traversed gesture, and the temporal model to a self-modifying grammar. The old invariant—that the visitor's addressed place is the event's center—is removed. The new capability is that the portrait changes the rule by which it will understand its next input.

## Direction consequence

The p5.brush reference opens a material-agency branch for Self portrait, but it is translated into grammar rather than surface. This closes the recent register/absence/rupture family and opens a self-modifying volume direction. A future work must not repeat this stack or this gesture parser merely with different colors.
