HANDWRITING / ENCOUNTER SWITCH / v021

The sentence
looks back.

A letter is not waiting to be read. It notices a nearness, turns toward the departure, and leaves a changed reply somewhere else in the sentence.

APPROACH, THEN LEAVE

Move toward one glyph to arm it. Leave the field to commit a reciprocal glance: the approached letter turns, a distant letter answers, and the next reply is changed by attention already spent. Enter or “turn toward” uses a deterministic witness.

The sentence is unobserved.

ANNOTATIONS / v021

changed rule
Abandon the pressure slab, vertical channels, and SVG lock-up. Twenty glyphs orbit a listening void; proximity arms one witness, departure makes it turn, and a non-adjacent glyph answers through actual letter geometry.
visitor action
Approach a letter and leave the field. A tap is refused. Enter, Space, or the control commits the seeded witness; Delete lifts the latest glance; R releases the sentence.
falsifier
If proximity writes without departure, if the reply is only a glow or line, if the remote letter does not move, or if each glance returns the same partner, reciprocity has not become a syntax rule.
deletion
Delete v021 if the blind field reads as an ornamental text ring, if the turn is not visible in the letters, or if the caption is needed to reveal that one letter answered another.
