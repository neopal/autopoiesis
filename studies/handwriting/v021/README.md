# Handwriting v021 — The sentence looks back.

## State

`v021` is a daily work candidate, recorded as **candidate / held**. It is not a finished period or an exhibition-ready claim.

## Hypothesis

If language is a social field rather than a fixed inscription, approaching one letter should arm attention without changing the sentence. Leaving the field should make that letter turn toward the departure and cause a distant letter to answer. The accumulated attention debt should alter where the next answer lands.

## Changed rule

The work abandons v018's subtractive SVG lock-up, v019's vertical phoneme channels, and v020's pressure slab. Twenty actual glyphs orbit a central listening void in three eccentric rings. Pointer proximity only arms a witness. A departure, Enter, Space, or the deterministic control commits a reciprocal glance: the approached glyph changes its angle, orbit, scale, and facing; a non-adjacent glyph changes its own geometry and carries a reference back to the witness. Bounded attention debt changes the next reply partner. The latest glance can be lifted exactly.

This is not a cursor halo or a line drawn between letters. The social rule is carried by glyph geometry: one letter turns, another letter answers, and the response is not fixed across repeated attention.

## Cultural translation

- **Reference:** `little-critters` — https://github.com/GordenSun/little-critters
- **Observed mechanism:** situated code-drawn agents respond to pointer proximity by changing attention and looking back, making the visitor part of a reciprocal encounter rather than a controller of a dashboard.
- **Mutine translation:** refuse animals and head-turning imagery. Make letters situated witnesses around a listening void: nearness arms one glyph, departure makes it turn, and a non-adjacent glyph answers through changed letter geometry. Attention debt changes the next reply.
- **Visible consequence:** the blind field is an orbital sentence around a void. After a committed departure, one glyph visibly turns and widens its orbit, a distant glyph turns back, and a bridge of syntax appears between their actual positions. Repeating attention does not select the same reply.
- **Falsifier:** if proximity commits, if the reply is only a glow or bridge, if the remote glyph does not move, if repeated attention returns the same partner, or if the blind field reads as an ornamental text ring, the translation fails.
- **Anti-copy:** no animals, eyes, paper scene, source palette, source composition, character design, API surface, or head-turning surface vocabulary is reproduced.
- **Direction consequence:** closes the pressure/shelf/channel family and opens a reciprocal syntax direction in which handwriting is a population of situated witnesses rather than a slab, shelf, or addressed list.

## Visitor action

Move toward one letter to arm it, then leave the field to commit its return. A tap is refused. **Turn toward**, `Enter`, or `Space` uses a deterministic witness. **Lift latest** or `Delete` restores the exact preceding sentence. **Release glances** or `R` clears the bounded memory. `S` captures a PNG.

## Falsifier

Hide labels, readout, controls, captions, bridges, and editorial furniture. If the first field still reads as an ornamental text ring, if a turn does not visibly alter the letters, or if the second attention returns the same partner, the reciprocal-syntax translation is not embodied.

## Deletion condition

Delete v021 if proximity writes without departure, if the turn or remote answer is a cosmetic highlight, if lifting fails to restore the exact preceding signature, if pointer taps commit, or if the blind encounter needs explanatory prose to reveal that one letter answered another.

## Direction consequence

This closes v020's inherited-pressure slab and the previous channel, shelf, and counter grammars. It opens a social-syntax direction: a sentence can carry local attention and non-local reply as geometry. The next viable work must either make reply alter readable word identity or abandon the orbital witness field before returning to pressure.

## Critique response

The progression critic required a break after three works that organized letters as a lock-up, a channel population, or a pressure slab. The new work changes composition (single slab to three orbital rings around a void), encounter (drag pressure to approach/depart attention), shape vocabulary (deformation fields to turned glyphs and reciprocal bridges), and temporal rule (material resistance to bounded social reply debt). The perceptual and browser gates remain open; this record stays **candidate / held** until the caption-free blind comparison, responsive browser matrix, production readback, and provider revision verification are observed.
