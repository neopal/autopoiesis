HANDWRITING / MEDIUM SWITCH / v023

The reader
moves the break.

A sentence is a field of places. Read past one, return through it, and the line gives that place to a distant word.

READ THE WHOLE FIELD

Use the wheel, arrow keys, or the buttons to move the reading window. Forward travel only arms attention. A return is the cause: the actual word flow reorders and a non-local word is rewritten. A tap is refused.

The line is intact.

ANNOTATIONS / v023

changed rule
Abandon the pressure slab, orbital witness field, and separated word stones. Browser-native words now flow through four vertical reading lanes; only a travelled return can exchange two places and rewrite the distant reply.
visitor action
Read forward, then reverse direction. Wheel, Arrow keys, and the reading buttons are equivalent paths. Enter or Space performs the deterministic return; Delete lifts it; R releases the line.
falsifier
If moving only changes an aperture, if the return does not change actual word order and text, if every reply is fixed, or if a tap commits, attention has not become a typographic rule.
deletion
Delete v023 if the blind field reads as a four-column poster, if the changed break needs the caption to be seen, or if the reading return is only a disguised button.
