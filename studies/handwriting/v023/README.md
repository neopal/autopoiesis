# Handwriting v023 — The reader moves the break.

## State

`v023` is a daily work candidate, recorded as **candidate / held**. It is not a finished period or an exhibition-ready claim.

## Hypothesis

If handwriting is a reading system rather than an inscription, its smallest material should be the place where a line breaks. The visitor's attention can move through the sentence, but only a return through a place should make that place exchange with a distant word. The changed line must then remember the return and choose a different answer later.

## Changed rule

The work abandons v020's pressure slab, v021's orbital witness field, and v022's separated word stones. Sixteen actual browser-native words form one continuous typographic corridor through four vertical reading lanes. Their positions, line membership, and text are DOM state, not an SVG or canvas drawing.

A one-way reading pass only arms the current place. A tap is refused. When the reader reverses after travelling, the return exchanges two actual word slots and rewrites a non-adjacent word. Later returns use the bounded history of line debt to choose a different reply. Delete lifts the latest return and reconstructs the exact preceding sentence.

The browser is the medium switch: `span` words, CSS `writing-mode`, line placement, and text reflow carry the language-bearing geometry. The reading aperture is only a witness of attention; it cannot make the event happen.

## Cultural translation

- **Reference:** `little-critters` — https://github.com/GordenSun/little-critters
- **Observed mechanism:** situated code-drawn agents respond to pointer proximity by changing attention and looking back, making the visitor part of a reciprocal encounter rather than a controller of a dashboard.
- **Mutine translation:** refuse animals, eyes, and head-turning imagery. Translate situated reciprocity into reading direction: the visitor's moving attention arms a local word-place, but only a return makes that place exchange with a distant word and rewrite the reply.
- **Visible consequence:** the blind field is one continuous sentence-corridor of actual DOM words. Forward motion leaves the sentence unchanged; after a return, two words occupy exchanged positions and the distant word becomes a new word. Later returns choose a different remote partner.
- **Falsifier:** if moving only changes the aperture, if a one-way pass or tap commits, if the return does not alter real word order and text, if every reply is fixed, or if the blind field reads as four decorative columns, the translation fails.
- **Anti-copy:** no animals, characters, eyes, paper style, source palette, source composition, head-turning scene, API surface, code, or surface vocabulary from little-critters is reproduced.
- **Direction consequence:** closes Handwriting's pressure / orbit / countertype sequence and opens a reading-as-topology direction where language remembers not a mark or glance, but the place a reader crossed twice. It abandons the stable glyph-object as the next invariant.

## Visitor action

Use the wheel, Arrow keys, or the directional controls to read forward. Reverse direction after at least three steps; the return is the causal gesture. A tap is refused. `Enter` or `Space` performs a deterministic return; `Delete` lifts the latest; `R` releases the line. A touch sweep is meaningful only when it contributes to the same directional reading path.

## Radical progression gate

The rupture is structural, not cosmetic:

- **Representation:** separated SVG letter stones become semantic DOM words flowing through a typographic corridor.
- **Composition:** quarry rows, pressure slab, and orbital rings become a single reading field with a moving line break.
- **Encounter:** drag and approach/depart attention become directional reading and reversal; the return, not the pointer contact, is causal.
- **Temporal rule:** pressure and reciprocal-glance memory become line debt: the place crossed twice is reallocated and a later return chooses another remote reply.
- **Medium:** inline SVG and p5 Canvas are abandoned for browser-native text and CSS writing-mode.

The work can do something v020–v022 could not: it makes the reader's reversal alter the sentence's actual DOM order and word identity without painting a trace, drawing a connector, or selecting a letter.

## Falsifier

Hide labels, readout, controls, captions, and editorial furniture. If the first field reads as four unrelated columns, if a forward pass changes the sentence, if a return is only an aperture or color event, if the remote word does not change, or if a second return chooses the same partner, the social-attention translation is not embodied.

## Deletion condition

Delete v023 if the line-break change is cosmetic, if the words do not move in the DOM tableau, if lifting fails to restore an exact signature, if pointer taps or one-way passes commit, or if the blind encounter needs explanatory prose to reveal that reading became a causal material.

## Critique response

The progression critic required a new visual grammar after three works that made letters into a slab, an orbital population, or independent stones. This work changes medium, composition, viewer task, and memory model together. It remains **held** until browser matrices, interaction readback, production verification, and independent caption-free perceptual comparison are observed.
