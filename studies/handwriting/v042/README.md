# Handwriting v042 — Hinge Ligature

## Hypothesis

A letter can be a route when its opening is a structural mouth rather than an ornament. If two mouths are connected and the temporary join is discarded, the system should be forced to spend the relation elsewhere: an untouched pair of routes should become one new ligature.

## Changed rule

v042 abandons v041's negative gaps, v040's held pressure rack, and v039's route-reading sheet. Eight generated SVG stroke routes form one interlocked body. A pointer/touch connection from one open mouth to a distinct second mouth stays geometry-neutral while pending. Only a complete release fuses two untouched remote routes into an actual new path grammar; the visited mouths remain exact.

The cultural mechanism is translated from p5.brush: directional material behaviour is allowed to participate in geometry production, but the visible join is refused. Direction selects a remote fusion, not a brush mark, texture, or decorative trail.

## Visible consequence

Blind first view: one dark, oblique typographic body made from eight open stroke routes, with a load-bearing throat and small structural mouths. After a valid bind, the temporary path vanishes; a remote route gains a second produced path, thicker geometry, a kink, and a hinge notch. Four fusions compound and remain liftable.

## Interaction

- Pointer or touch: drag from one open mouth to another distinct mouth and release.
- Keyboard: focus the field, use ArrowRight to arm and choose a second mouth, then Enter or Space to commit.
- `bind 1—5`: deterministic equivalent action.
- Delete / Backspace: lift the latest fusion exactly.
- Escape / `R`: release to the deterministic quiet body.

## Falsifier

Delete if a temporary connection paints the body, if an incomplete or repeated pair commits, if either touched mouth changes, if the remote fusion is only colour/readout, if every pair produces the same geometry, or if the blind body reads as a generic route diagram or type specimen.

## Deletion condition

Delete v042 if caption-free viewing cannot distinguish hinge ligature from v039–v041, if the mouth is only an instruction label, or if the remote route geometry does not visibly carry the relation.

## Direction consequence

This closes the negative-syntax / pressure-debt / route-traversal family and opens **displaced joining**: handwriting is no longer a set of marks or absences to read. It is a body whose openings can alter the topology of an unvisited route.

## Provenance and anti-copy

Reference: [p5.brush](https://github.com/acamposuribe/p5.brush).

Observed mechanism: material parameters such as pressure, direction, and field behaviour can alter how geometry is produced, instead of styling a finished stroke.

Mutine translation: reject brush presets, watercolor, hatching, grain, palette, composition, source code, examples, and API surface. Invert the mechanism into a non-local ligature law: the visitor's join is ephemeral, while an untouched remote pair fuses into new SVG geometry.

Anti-copy: no p5.brush brush, visual surface, example, source code, API, palette, composition, or imagery is reproduced.
