HANDWRITING / TEMPORAL SYNTAX / v032

The sentence arrives
after the mark.

A letter is not the place you touch. It is the delay that lets another letter answer.

MAKE A CADENCE

Tap three different letters within one short rhythm. The first two beats only enter the score; the third commits a tempo-shaped rewrite at a distance. The touched letters stay themselves. Enter or Space plays a deterministic cadence; Delete lifts the latest one; R or Escape releases the bounded memory.

The score is quiet. No beat has been heard.

ANNOTATIONS / v032

changed rule
Abandon v031's spatial route, v030's sentence-wide refusal, and v029's wandering census. Twelve letters now form a three-column typographic score: time, not path, selects the event. A completed cadence changes an echo, a silence, and an afterbeat elsewhere.
visitor action
Tap three distinct glyphs inside 1400ms. Even, rising, and falling gaps route the rewrite differently. Enter, Space, and the cadence control use deterministic cadences; Delete lifts the latest event; R or Escape releases four-event memory.
falsifier
If a single tap changes the score, if the tapped letters answer themselves, if tempo only changes a label, if the blank is cosmetic, if later cadences forget, or if the first view reads as a route map or sentence poster, the translation fails.
deletion
Delete v032 if the canvas is only a type specimen with buttons, if the remote echo, real silence, or baseline displacement cannot be seen without prose, or if lifting cannot reconstruct the exact preceding score.
