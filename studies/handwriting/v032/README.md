# Handwriting v032 — The sentence arrives after the mark.

## Hypothesis

If a typographic field is governed by tempo rather than path, then a letter can become a delayed instruction: three distinct beats should alter a remote typographic measure while the touched letters stay themselves.

## Changed rule

Abandon v031's spatial route organism, v030's sentence-wide refusal, and v029's wandering attention census. Twelve letters form a three-column canvas score. A cadence is inert until three distinct letters are tapped inside 1400ms. The gaps classify the tempo; only then does the score rewrite an echo, a silence, and an afterbeat elsewhere.

## Visible consequence

The blind first view is a large, sparse typographic score built from the letters of `ARCHIVE SLATE`, not a line field or a sentence poster. The first two beats show only temporary rings. A completed cadence leaves the touched glyphs unchanged while a remote glyph inherits the source form, a different glyph becomes an actual blank counterform, and a third shifts its baseline. The latest four cadence events remain liftable; later events rebuild from the altered score.

## Interaction

Tap three different glyphs in one short rhythm. The first two taps are geometry-neutral. A third tap commits if the total span is at most 1400ms. Even, rising, and falling gaps route the remote rewrite differently. Enter, Space, and the play-cadence control perform deterministic equivalents. Delete or Backspace lifts the latest cadence. R or Escape releases the bounded memory. A canvas fallback is used through p5.js 1.11.3; the engine itself is deterministic and replayable.

## Falsifier

Delete this direction if one tap changes geometry, if duplicate letters can beat twice, if the tapped glyphs are the only answer, if tempo changes only a label, if the silence is decorative, if later cadences restart from the seed, or if exact lifting fails.

## Deletion condition

Delete v032 if caption-free viewing cannot show a typographic score with a real remote echo, a real blank, and a displaced afterbeat after one valid cadence, or if the canvas is only a type specimen with buttons.

## Critique status

Candidate / held. The structural engine, deterministic replay, and interaction contract are recorded. The perceptual art gate remains open until caption-free local and production browser evidence proves that the canvas reads as a temporal score rather than a decorated type specimen.

## Direction consequence

This closes Handwriting's route / refusal / attention sequence and opens a temporal-syntax direction: the current's unit is now a cadence, not a glyph location. It changes the viewer task from crossing or wandering through language to composing a short time relation whose meaning appears elsewhere.
