# Handwriting v038 — The alphabet votes from the margins

## Hypothesis

If a letter is treated as a situated participant rather than a drawable mark, a visitor can offer a token without owning the place where it becomes visible. The browser's text layout becomes the medium: the offered token remains absent, while a remote receiver, a hollow echo, and a witness word make the social rule legible.

## Changed rule

v038 abandons v037's pressure seam, v036's phoneme ecology, and v035's pressure casting rack. The visitor does not draw, drag, or edit a local glyph. A three-letter keyboard token is geometry-neutral while pending. Only Enter, Space, or the ratify control commits it. The engine routes the token to three other typographic slots; the source slot remains exact.

This is a material switch from Canvas/SVG/WebGL surfaces to browser-native DOM text and CSS layout, and an encounter switch from pointer pressure to a discrete keyboard token. The new state model is a ratification history, not an elapsed gesture or a spatial path.

## Visible consequence

The first-render blind view is a dark, asymmetrical lexicon of seven oversized words arranged as one leaning typographic field. After a valid token, the local offer is still not printed. Three remote words change actual text, position, tracking, scale, notch, and weight. Four ratifications compound in the DOM and Delete reconstructs the previous field exactly.

## Falsifier

Delete the direction if a partial token changes geometry, if the local offer prints, if remote edits are only colour/readout, if the blind field reads as a word cloud or dashboard, if the keyboard is merely a cosmetic control, or if later ratifications forget.

## Deletion condition

Delete v038 if caption-free viewing cannot distinguish the browser-native lexicon from the preceding fragment ecology, pressure casting rack, and pressure seam, or if remote ratification is not materially produced by DOM text and layout.
