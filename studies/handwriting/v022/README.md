# Handwriting v022 — Pressure changes the word.

## State

`v022` is a daily work candidate, recorded as **candidate / held**. It is not a finished period or an exhibition-ready claim.

## Hypothesis

If language is material rather than inscription, pressure should not draw on top of a sentence. A traveled gesture should make the crossed letters yield as geometry and identity, then transfer the load to a remote word. Resistance already stored in the sentence should change where the next retyping happens.

## Changed rule

The work abandons v019's vertical phoneme channels, v020's pressure slab, and v021's orbital witness field. Eighteen actual SVG glyphs form three separated word-stone strata: `MATTER / MAKES / MEANING`. Each letter sits in its own irregular mineral cell rather than on a shared baseline.

A short tap is refused. A traveled pointer path commits on release. The crossed glyphs change their position, rotation, scale, and character; one non-adjacent glyph is retyped as the remote reply. Neighbouring stones shear. A bounded resistance value is carried into the next pressure. Delete lifts the latest event and reconstructs the exact preceding quarry.

The p5.js layer is only the paper/grain atmosphere. The language-bearing geometry is inline SVG so the medium itself changes from v021's Canvas orbital field to browser-native vector type.

## Cultural translation

- **Reference:** `p5-brush` — https://github.com/acamposuribe/p5.brush
- **Observed mechanism:** programmable drawing tools treat pressure, density, grain, and vector fields as material forces; material changes how geometry is produced and remembered rather than decorating finished geometry.
- **Mutine translation:** refuse brushes, watercolor, hatching, and the library's surface vocabulary. Translate pressure into language-as-material: a traveled path makes crossed glyph stones yield and retypes a distant word-stone, while accumulated resistance changes later geometry.
- **Visible consequence:** the blind field is a separated quarry of actual letters, not a line, ring, slab, or brush trail. After release, crossed letters are visibly displaced and retyped, a remote letter changes its own geometry, and the next pressure responds differently.
- **Falsifier:** if the gesture is only an overlay, if letters keep their identity and geometry, if the remote reply is only a colour change, if a tap commits, or if later pressure ignores resistance, the translation fails.
- **Anti-copy:** no p5.brush brushes, watercolor appearance, hatching vocabulary, source palette, API surface, example composition, or source mark-making is reproduced.
- **Direction consequence:** closes the orbital reciprocal-syntax family and opens a material-language direction where handwriting is a set of load-bearing word stones. It abandons the stable shared-baseline sentence as the next invariant.

## Visitor action

Drag across the field and release. A tap does nothing. **Press the word**, `Enter`, or `Space` uses a deterministic pressure path; **lift latest** or `Delete` restores the preceding quarry; **release pressure** or `R` clears bounded memory. `S` captures a PNG.

## Radical progression gate

The rupture is structural, not cosmetic:

- **Representation:** orbital Canvas glyphs become separated SVG word stones with actual vector cells.
- **Encounter:** approach/depart attention becomes a traveled material pressure whose release is causal; taps are refused.
- **Temporal rule:** reciprocal attention debt becomes inherited resistance that changes retyping and deformation.
- **Language rule:** pressure changes letter identity as well as position, so the sentence can become a different sentence-object.

The work can do something v019–v021 could not: it can alter the sentence's visible alphabetic identity through a path-dependent material event without drawing a persistent line over the text.

## Falsifier

Hide labels, readout, controls, captions, and editorial furniture. If the first field reads only as a decorative word grid, if a committed path leaves letters unchanged, if the remote answer is not visible in a glyph, or if a second pressure is indistinguishable from the first, the translation is not embodied.

## Deletion condition

Delete v022 if pressure is cosmetic, if the SVG is only a static poster with a generic drag effect, if lifting fails to restore an exact signature, if pointer taps commit, or if the caption is necessary to see that language changed.

## Critique response

The progression critic required a break after a pressure slab and an orbital witness field. This work changes composition, medium, interaction, shape vocabulary, and memory model together. The candidate remains **held** until the browser matrix, interaction readback, production verification, and independent caption-free perceptual comparison are observed.
