# The gap keeps an elsewhere.

## Hypothesis

A letter can be situated without being a glyph on a line. If a visitor's attention is treated as a temporary witness, the sentence may answer from elsewhere only after that witness leaves.

## Changed rule

v034 abandons v033's material SVG plate, v032's canvas cadence score, and v031's route organism. The work is a browser-native double register of fourteen fragments. Approaching one fragment records attention but does not move it. Departure chooses a least-witnessed fragment in the other register and changes its actual position, scale, angle, and weight. The source never answers itself.

## Cultural translation

- **Reference:** [little-critters](https://github.com/GordenSun/little-critters)
- **Observed mechanism:** situated code-drawn agents respond to proximity through legible reciprocal attention; local behaviour makes the visitor part of a social field without a dashboard.
- **Mutine translation:** refuse animals, eyes, characters, paper, head-turning, source palette, composition, source code, and API surface. Translate proximity into a typographic witness: attention stays geometrically neutral, then departure produces a remote answer in a separate register.
- **Visible consequence:** the attended fragment remains exact while it is witnessed; leaving makes an unobserved remote fragment move, strengthen, and become the visible answer, while a second fragment carries a diminished echo.
- **Falsifier:** if the visitor only moves a decorative cursor, if the attended fragment changes before departure, or if the remote answer is only colour or prose, the translation fails.
- **Anti-copy statement:** no animals, character designs, paper scene, head-turning image, source palette, source composition, source code, examples, API surface, or surface vocabulary is reproduced.

## Visible consequence

The first-render blind view is a dark, asymmetrical field of large browser-native word fragments split into two registers by a tilted empty seam. There is no route, plate, grid, or canvas score. After a witnessed departure, an actual remote fragment shifts across its register, an echo loosens elsewhere, and the source remains where it was. Four departures remain in memory and later answers are rebuilt from the altered register.

## Interaction

- Pointer movement or directional focus witnesses a fragment without changing geometry.
- Leaving the field commits one remote answer.
- Enter, Space, or **leave a witness** performs a deterministic departure.
- Delete lifts the latest departure; R or Escape releases the register.
- Static previews replay four departures but disable controls.

## Radical progression gate

The primary rupture is a medium and encounter switch: SVG and Canvas typographic plates become semantic browser-native text fragments, and choosing a letter or cadence becomes a temporary social relation that only resolves on departure. The composition switches from plate/score/route to an asymmetrical double register with a vertical absence; the temporal rule switches from immediate selection/cadence to presence-without-mutation followed by remote answer. The new work can do something the previous three could not: it separates being witnessed from being changed, then makes the answer happen in another register.

## Falsifier

If attention moves the watched fragment, if the source answers itself, if the remote answer is only a colour/readout effect, or if the work still reads as a route, score, or plate, the hypothesis fails.

## Deletion condition

Delete v034 if caption-free viewing cannot distinguish the double register from a decorated word collage, route diagram, or interface; if later departures reset; or if lifting is not exact.

## Critique and deletion condition

Delete v034 if caption-free viewing reads as a decorated word collage, route diagram, or interface; if attention moves the watched fragment; if the source answers itself; if the other register does not change actual text geometry; if memory resets; or if lifting is not exact. Hold the work as `candidate / held` until local and production browser evidence and independent caption-free perceptual review exist.
