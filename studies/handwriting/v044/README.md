# Handwriting v044 — The load makes the line.

## Hypothesis

If material changes the rule that produces the next form, then a typographic carrier can remember load without turning that load into a decorative mark. Three distinct load locations should be geometrically neutral while pending; their order should become a mold that re-forms the carrier, baseline, and letters together on release.

## Changed rule

v044 abandons v043's social room and remote layout reply, v042's mouth-to-mouth ligature, and v041's negative-gap reading. It switches back to a single Canvas 2D carrier, but not to v040's local pressure chamber: the visitor does not hold a glyph and does not receive a remote answer. A drag through three distinct load wells stores an ordered material condition. Only release casts that condition into one continuous carrier, changing its curve, tension, and every token's position, angle, scale, width, and counter. The load is consumed as production history, not painted as texture.

## Visible consequence

The blind first view is a dark, asymmetrical typographic beam carrying the phrase `MATTER / ROUTE` as twelve large tokens on one continuous carrier. Five small load wells sit below the beam as an instrumental edge, not a dashboard. After a valid cast, the beam bends and thickens, and all twelve tokens re-form around its changed geometry. Four casts compound into one inherited carrier; lifting a cast replays the remaining history exactly.

## Interaction

- Pointer or touch: drag through three distinct load wells, then release.
- Pending loads leave the carrier exact; an incomplete or repeated load is refused.
- Keyboard: focus the field, use ArrowRight to load a well, then Enter or Space to cast the deterministic center sequence.
- `cast center`: deterministic equivalent action.
- Delete / Backspace: lift the latest cast exactly.
- Escape / `R`: release the archive to the quiet seed.
- Static previews replay four casts and remove furniture and controls.

## Cultural translation

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** p5.brush treats pressure, density, directional behaviour, and vector fields as programmable material instruments: the instrument changes how geometry is produced rather than merely decorating a finished mark.
- **Mutine translation:** refuse brush presets, watercolor, hatching, grain, source palette, source composition, source code, examples, and API surface. Translate material agency into a typographic carrier: an ordered three-well load becomes a mold that changes how the next baseline and every letter are produced. The source wells do not answer themselves.
- **Visible consequence:** a pending load does not move the phrase. A committed load re-forms the single carrier and twelve actual token geometries—position, angle, scale, width, counter, and carrier tension—and later casts inherit the changed field.
- **Falsifier:** If pending input moves geometry, if the wells only alter a readout or colour, if the load order does not change the carrier, if the letters remain a finished word with a skin, or if later casts restart from the seed, the translation fails.
- **Anti-copy:** No p5.brush brush preset, watercolor appearance, hatching vocabulary, grain, palette, composition, source code, examples, API surface, or source imagery is reproduced.

## Radical progression gate

The last three Handwriting records shared a non-local language event inside a distributed typographic field: v041 read gaps, v042 fused remote routes, and v043 made one attended text voice reflow two others. v044 breaks that family in five visible dimensions:

1. **Representation / medium:** generated SVG and DOM text become Canvas 2D glyphs and a continuous carrier.
2. **Composition:** the distributed absence, route body, and social room become one load-bearing beam with a lower material rail.
3. **Encounter:** the visitor no longer attends, joins, or watches a panel; they drag an ordered physical condition through wells and release it.
4. **Temporal behaviour:** the work changes from remote reply to material accumulation: each cast re-produces the next field from the full inherited history.
5. **Viewer task:** the question is no longer which voice or gap answers; it is whether a line can be made by a material condition that is absent from the finished mark.

The work can do something the previous three could not: it makes the same ordered load produce a changed carrier grammar across the whole typographic body, while keeping pending causality and exact lifting visible in the image/system.

## Falsifier

Delete v044 if caption-free viewing reads as a decorative word poster, a generic slider/control surface, or a route diagram; if pending wells move the carrier; if load order is cosmetic; if fewer than most tokens change actual geometry; if later casts forget; or if exact lifting fails.

## Deletion condition

Delete v044 if the blind tableau cannot show a single carrier re-forming under material memory without the labels and annotations, or if the p5.brush translation collapses into texture and atmosphere rather than a new causal rule.
