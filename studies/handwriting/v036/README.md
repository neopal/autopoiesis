# v036 — The sentence answers from its margins.

## Hypothesis

If handwriting is treated as a social syntax rather than a surface or a rack, a phrase can be offered to one place while the sentence decides that another, less-heard fragment must become its mouth. The first encounter should read as a dark, uneven typographic ecology: fifteen fragments hold their own weather, with absences latent inside the field.

## Cultural translation

The selected reference is [little-critters](https://github.com/GordenSun/little-critters). Its observed mechanism is situated code-drawn agents whose proximity to the pointer becomes reciprocal attention without a control panel. Mutine refuses animals, eyes, characters, paper, head-turns, palette, composition, source code, examples, and API surface. The translation is a language system: pointer or arrow attention increments a private ledger without moving a fragment; a complete typed phrase is redistributed to the least-heard margin as a new mouth, a real silence, and a chorus fragment.

## Changed rule

Abandon v035's pressure casting rack, v034's double register, and v033's material SVG plate. Attention is geometry-neutral. A phrase is not inserted at the place it is offered: the ecology chooses the least-heard fragment and changes actual text, position, rotation, tracking, and visibility elsewhere.

## Visible consequence

The blind field is a single asymmetrical typographic ecology, not a rack, register, route, or word cloud. After a complete utterance, one remote fragment receives a produced word, another becomes an actual absence, and a third carries a counter-utterance. Four utterances remain in memory; later speech inherits the altered slots and Delete reconstructs the previous frame exactly.

## Interaction

Move across a fragment or use Arrow keys to attend without geometry change. Type two or more letters and submit with the phrase field, Enter, Space, or the `speak elsewhere` control. Delete lifts the newest utterance. R or Escape releases the field. The pointer gesture and keyboard path are equivalent ways to select attention; the phrase field is the work-specific instrument, not a generic prettification control.

## Falsifier

Delete this direction if attention changes geometry, if the phrase appears where it is offered, if the least-heard fragment is not materially changed, if silence exists only in colour or readout, if the field reads as a generic word cloud or type specimen, if later speech resets, or if exact lifting fails.

## Deletion condition

Delete v036 if caption-free viewing cannot distinguish the phoneme ecology from v035's rack, v034's register, and v033's plate, or if the remote redistribution cannot be perceived without the annotations.

## Radical progression gate

The rupture is a new medium and encounter: raw Canvas 2D replaces the WebGL mold object, and typed language replaces pressure hold/release. The composition leaves depth-staggered blocks for an uneven social field of text and absences. The new state model is a collective attention ledger plus distributed utterance memory. This is not a palette, title, density, or texture change; the sentence's causal engine now decides where language becomes visible.

## Direction consequence

The handwriting current closes the pressure-as-manufacture family and opens social syntax: language is tested as a population of situated fragments whose least-heard margin can rewrite the sentence. The next viable rupture must leave the ecology rather than polish it.
