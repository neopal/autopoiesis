answers elsewhere.

ATTENTION IS A LAYOUT EVENT

Hold your pointer over one text panel. The attended panel stays exact; after a short dwell, two untouched panels answer by changing their writing direction, line-break rhythm, scale, and position. Touch commits on tap. The center control, ArrowRight plus Enter, and pointer path use the same deterministic grammar; Delete lifts the latest reply.

The room is quiet. Nine voices are holding.

ANNOTATIONS / v043

changed rule
Abandon v042's mouths, joins, and produced routes. A local attention is geometry-neutral while held; only a completed dwell reflows two untouched text panels elsewhere in the DOM. The attended panel never answers itself.
visitor action
Hold over a panel, tap on touch, or focus the field and use ArrowRight then Enter. Delete lifts the latest remote reflow; Escape or R returns to the deterministic quiet room. Four replies compound.
falsifier
Delete if attention changes the local panel, if the remote effect is only colour or a readout, if the work still reads as a route diagram or type specimen, or if later replies forget earlier layout changes.
deletion
Delete v043 if caption-free viewing cannot distinguish the attention fugue from v040–v042, or if the social rule is not visible in actual writing direction, line breaks, and panel geometry.
