# Handwriting v043 — Attention Fugue

## Hypothesis

A letter can be a route before it becomes a glyph: if a visitor stays with one typographic voice, the visited voice should remain exact while a distant voice changes how it can be read. The work should make attention a layout event, not a control over a local mark.

## Changed rule

v043 abandons v042's mouths, joins, and produced routes; v041's empty gaps; and v040's pressure chambers. Nine generated DOM text panels make an asymmetric typographic room. A local pointer dwell is geometry-neutral while held. Only a completed dwell reflows two untouched panels elsewhere by changing their writing direction, line-break order, scale, position, and spacing. The attended panel never answers itself.

The cultural mechanism is translated from little-critters: situated agents make proximity legible as reciprocal attention. Mutine refuses animals, eyes, characters, paper, head-turning, source palette, source composition, source code, examples, and API surface. Reciprocity becomes a social rule between text panels: attention is stored as a remote layout reply.

## Visible consequence

Blind first view: a pale, asymmetrical typographic room of nine large text panels, some horizontal and some vertical, with no route lines, glyph grid, or interface labels required to compose it. After attention, the visited panel stays exact while two distant panels visibly switch writing direction, reverse their token order, change size, and move their boundaries. Four remote replies compound and remain liftable.

## Interaction

- Pointer: hold over one text panel for a short dwell; the panel stays exact while two remote panels answer.
- Touch: tap a panel to commit the same deterministic attention event.
- Keyboard: focus the field, use ArrowRight to attend to a voice, then Enter or Space to commit.
- `attend center`: deterministic equivalent action.
- Delete / Backspace: lift the latest remote reply exactly.
- Escape / `R`: release to the deterministic quiet room.

## Falsifier

Delete if attention changes the local panel, if the remote effect is only colour or a readout, if the room reads as a route diagram or type specimen, if the writing direction and line-break changes are not structural, or if later replies forget earlier layout changes.

## Deletion condition

Delete v043 if caption-free viewing cannot distinguish the attention fugue from v040–v042, if the local-to-remote relation is only an instruction, or if the layout event does not survive reduced-motion and touch/keyboard paths.

## Direction consequence

This closes the route / pressure / negative-syntax / hinge-ligature family and opens **social typography**: handwriting is tested as a room of situated reading orientations, where a line is authored by the layout another voice is forced to inhabit.

## Provenance and anti-copy

Reference: [little-critters](https://github.com/GordenSun/little-critters).

Observed mechanism: situated code-drawn agents make pointer proximity legible as reciprocal attention; local behaviour answers the visitor without a dashboard.

Mutine translation: attention to one text panel leaves that panel exact and produces a deterministic writing-direction and line-break reflow in two untouched panels elsewhere. The source interaction is not copied as animals, eyes, characters, paper, head-turning, palette, composition, code, examples, or API.
