HANDWRITING / INLINE SVG / v041

The missing letter
makes the word.

A word can be altered by the space it refuses to fill.

ABSENCE IS A WRITING ACTION

Visit three empty gaps with a pointer or touch. The gaps remain empty while the sequence is pending. Complete the sequence and three untouched glyphs are recruited elsewhere: one thickens, one hollows, and one tilts. The read control, ArrowRight plus Enter, and pointer path use the same deterministic grammar; Delete lifts the latest reading.

The field is quiet. No gaps have been visited.

ANNOTATIONS / v041

changed rule
Abandon v040's pressure rack, v039's route traversal, and v038's typed offer. A sequence of three absences is geometry-neutral while visited; only its completion recruits three untouched glyphs as actual SVG geometry elsewhere.
visitor action
Visit three empty gaps in order, or use ArrowRight then Enter. The visited gaps stay open. Delete lifts the latest recruitment; Escape or R releases to the deterministic quiet field. Four readings compound.
falsifier
Delete if a glyph is altered at the visited gap, if an incomplete or repeated absence commits, if remote changes are only colour or readout, or if the first view reads as a decorative type specimen.
deletion
Delete v041 if caption-free viewing cannot distinguish negative syntax from v038–v040, if the absence sequence is only a control label, or if remote glyph geometry does not carry the reading.
