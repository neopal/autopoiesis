# Handwriting v041 — Negative Syntax

## Hypothesis

A letter can be a route made of absences: when the visitor attends to the spaces between glyphs instead of selecting a glyph, the syntax of the field should change elsewhere.

## Changed rule

v041 abandons v040's pressure rack, v039's topological traversal, and v038's typed offer. A sequence of three distinct empty gaps is geometry-neutral while pending. Only completion recruits three untouched glyphs elsewhere in the inline SVG field. The visited gaps remain empty and exact.

This is a structural change, not a style change: the work moves from Canvas glyph chambers to generated SVG text/path geometry, from holding or tracing to attending to absence, and from a source event that carries pressure or route memory to a completed negative syntax that recruits remote letter bodies.

## Visible consequence

The blind first view is a sparse, oblique constellation of oversized letters organized around a diagonal slit and an unfilled center. A valid three-gap reading leaves the gaps and their neighbouring letters exact, while one remote glyph thickens, another hollows, and a third tilts. Four readings compound in one field and can be lifted in reverse.

## Cultural translation

- **Reference:** [little-critters](https://github.com/GordenSun/little-critters)
- **Observed mechanism:** Situated code-drawn agents turn proximity into reciprocal attention; the visitor becomes part of a small local field without a dashboard.
- **Mutine translation:** Refuse animals, eyes, characters, paper scene, palette, source composition, source code, examples, and API surface. Translate situated attention into an absence field: the visitor does not touch a letter but attends to three gaps, and completion recruits an unobserved remote letter geometry.
- **Falsifier:** If the visitor only moves a decorative cursor or selects a visible letter, if the visited gaps change, or if remote glyph changes are only colour/readout, the translation fails.
- **Anti-copy:** No animals, eyes, head-turning scene, character design, paper style, source palette, source composition, source code, examples, API surface, or surface vocabulary is reproduced.
- **Direction consequence:** Closes the recent route / token / pressure sequence and opens negative syntax: handwriting tests whether a word can be authored by attending to its omissions rather than manufacturing or selecting marks.

## Radical progression gate

- **Representation / medium:** Canvas route and Canvas glyph rack become generated inline SVG `<text>` plus produced SVG paths.
- **Composition:** Distributed route/rack readings become one sparse diagonal absence with letters orbiting a central slit.
- **Encounter:** Trace, type, and hold are refused; the viewer must visit empty gaps in sequence and can never complete the reading by touching a glyph.
- **Temporal / memory model:** The pending sequence stays geometrically inert; completion creates a remote reading, and four readings persist with exact lifting.
- **Falsifier:** Delete v041 if the caption-free field reads as a generic type specimen, the gaps are merely controls, or remote geometry does not carry the reading.
- **Deletion condition:** Do not promote this trial if two caption-free observers cannot distinguish it from v038–v040 by both viewer task and visual grammar.
