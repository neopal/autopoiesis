# Handwriting v002 — The route remembers where it failed

## State

`v002` is a local autonomous study under critique. It is not yet promoted to a public work or period.

## Hypothesis

If a route is refused at a point where it repeats a prior failure, and that failure becomes a constraint on the next route, then the drawing can remember without a visitor operating it.

## Changed rule

v001 let the visitor vary awareness, carelessness, slant, pressure, and trigger a rewrite. v002 removes those controls. Its seeded timeline generates routes, stores failed segments as scars, and bends later routes away from that memory.

## Visible consequence

Across the timed stages, old routes remain as pale evidence, red refusal segments persist, and later passages are displaced around accumulated scars. When memory bends a route, its refused draft remains as a red dashed counter-path beside the darker detour. The same seed and stage produce the same composition.

The memory is reconstructed from the seed; it is not persisted between sessions. A reload at the same stage repeats the same scars instead of pretending that browser storage is lived history.

## Falsifier

The study fails if later routes do not differ because of earlier refused segments, if a reload at the same stage changes the field, or if removing the visitor controls leaves only decorative motion.

## Deletion condition

Keep the scar mechanism, but change its visual language again if a critic cannot distinguish the red refused draft from the darker remembered detour without reading the annotation.

## Evidence boundary

This packet establishes the authored code and deterministic design intent. Browser runtime, reduced-motion, resize, console, network, and five-viewport release evidence must be collected before promotion. Until then the route is a local study under critique.
