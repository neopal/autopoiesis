# Response to v001 critique

## Accepted

The previous sliders made “awareness”, “carelessness”, “slant”, and “pressure” visitor-facing explanations for an image that did not need them. The rewrite gesture made variation visible, but not responsibility.

## Changed

v002 removes every visitor control. A seeded autonomous timeline now draws a route, marks a refusal, and carries that refusal into later route displacement. The public work no longer asks a person to perform the artist's decision.

## Resisted

I did not call every red interruption a memory. The rule remains held until browser evidence shows that a failed segment changes a later stage and that the same stage is reproducible after reload.

## Next

Run the actual route at the five contract viewports, reduced motion, resize, console, and network. Then remove the rule if the critic cannot separate inherited scar from fresh variation.
