# Handwriting v046 — The alphabet grows a counterform.

## Hypothesis

If material pressure changes how a form is produced rather than decorating a finished mark, then language can make a structural void from a held span: a contiguous selection should stay provisional, and a committed cut should re-produce the entire phrase around the pressure it has spent.

## Changed rule

v046 abandons v045's collective reading axis, v044's load-bearing carrier, and v042's route fusion. The first encounter is a browser-native letter inventory: 24 DOM tokens arranged as a tall, uneven register, not a Canvas phrase or path. The visitor drags across a contiguous span of three to six letters. While the span is held, every token remains geometrically exact. On an explicit cut, the selected span becomes a vertical pressure fibre and an actual counterform; all remaining letters are re-packed around the new void. Four cuts compound through one replayable history.

This is a material rule, not an overlay: the engine's field contains the counterform apertures and the DOM tokens receive new positions, writing modes, scales, turns, and roles. The selected letters do not merely glow, and the void is not a dark patch placed over a fixed sentence.

## Visible consequence

The blind first view is a dark, three-column inventory spelling `LANGUAGE · MOVES · WHEN · HELD` through unequal letter bodies, faint register lines, and a central pressure field. After a valid cut, the held span turns into a vertical fibre and an actual aperture opens through the register; survivors re-pack along the two margins. Four counterforms remain visible as a changed typographic ecology and can be lifted exactly.

## Interaction

- Pointer or touch: drag across a contiguous span of 3–6 letters, then press `cut held span`.
- A pending selection is geometry-neutral. Short, occupied, or unknown ranges are refused.
- Keyboard: focus the field, use ArrowLeft / ArrowRight to choose a span, then Enter or Space to cut it. With no pending span, Enter performs the next deterministic cut.
- `cut held span`: explicit commit for the current range.
- Delete / Backspace: lift the latest cut exactly.
- Escape / `R`: release the archive to the quiet inventory.
- Static previews replay four disjoint cuts and remove furniture and controls.

- **Observed mechanism:** p5.brush treats pressure, density, directional behaviour, fills, and vector fields as programmable material rules that alter how geometry is produced rather than decorating a finished mark.
- **Mutine translation:** refuse brush presets, watercolor appearance, hatching, grain, source palette, source composition, source code, examples, and API surface. Translate material production into typographic counterform: a contiguous DOM span is held as pressure, then its cut changes writing mode and forces every other letter to be re-produced around an actual void.
- **Visible consequence:** pending selection leaves all geometry exact; a committed span becomes a vertical fibre and a real aperture while every survivor moves, turns, scales, and re-packs. Later cuts inherit earlier counterforms.
- **Falsifier:** If the cut only changes a local highlight, if the void is an overlay, if short or occupied spans commit, if later cuts reset the field, or if lifting is inexact, the translation fails.
- **Anti-copy:** No p5.brush brush preset, watercolor appearance, hatching vocabulary, grain treatment, source palette, source composition, source code, examples, API surface, or source imagery is reproduced.

## Radical progression gate

The last three real Handwriting records were v045's Canvas population and collective axis, v044's Canvas carrier, and v042's SVG route fusion. v046 makes a material and encounter switch rather than another ordered witness system:

1. **Representation / medium:** generated Canvas letters and SVG routes become actual browser DOM token nodes with CSS writing modes and layout state.
2. **Composition:** the stacked phrase, beam, and route body become a tall letter inventory with a counterform aperture and two re-packing margins.
3. **Encounter:** three explicit looks and material drags become one contiguous range selection followed by an explicit cut; the browser's selection-like gesture is itself the material input.
4. **Temporal behaviour:** witness order and route memory become occupied pressure ranges that accumulate as persistent voids; an overlapping cut is refused.
5. **Viewer task:** the visitor does not choose who comes first. They decide where a span can be removed from the sentence's stable inventory, and the rest of the language must find new coordinates.

The work can do something the previous three could not: it makes a selected *interval* become a typographic aperture that changes the production medium of the letters around it. The phrase is no longer a finished block taking attendance or a route carrying pressure; it is a material register that must re-pack around what it has cut.

## Falsifier

Delete v046 if caption-free viewing reads as a styled word grid, a recoloured selection, a generic column layout, or v045's collective-axis variant; if pending selection moves geometry; if a cut does not produce a real aperture and global reflow; if occupied ranges commit; if later cuts reset; or if exact lifting fails.

## Deletion condition

Delete v046 if the blind tableau cannot show that language has acquired a counterform-producing material rule, or if the p5.brush translation remains a texture reference instead of a changed causal engine.
