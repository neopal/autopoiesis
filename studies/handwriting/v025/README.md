# Handwriting v025 — The word asks another word.

## Hypothesis

If a letter is treated as a social offer rather than a local input, a typographic system can show language as a negotiation: the addressed clause refuses the offer while another clause becomes the reply. The viewer should see the exchange in the bodies of the words, not infer it from a counter or caption.

## Changed rule

v025 abandons v022's separated countertype quarry, v023's browser-native reading corridor, and v024's elastic Canvas sentence. Twelve browser-native DOM clauses form one dense typographic plate. Touching a clause only selects it. Committing a letter inserts a visible refusal into that clause, rewrites a non-local clause with the reply, and shifts nearby clause geometry. The bounded refusal ledger changes the destination of later letters.

This is a medium and encounter switch: from reading, dragging, and point pressure to typing into a compound plate. The object is not a sentence that flows in one direction; it is a field of clauses that negotiate across distance.

## Cultural translation

**Reference:** [little-critters](https://github.com/GordenSun/little-critters)

**Observed mechanism:** Situated code-drawn agents respond to pointer proximity by changing attention and looking back, making the visitor part of a reciprocal encounter rather than a controller of a dashboard.

**Mutine translation:** Refuse animals, eyes, head-turning imagery, and the source's scene. Translate reciprocity into language-as-negotiation: a typed character is refused by the selected clause and answered by a non-local clause; the bounded ledger changes who can answer next.

**Visible consequence:** The blind field is a single irregular typographic plate of twelve actual DOM clauses, not a route or sentence corridor. After a committed letter, the selected clause visibly opens around the refused character, a distant clause gains the reply, and neighbouring clauses shift their actual positions.

**Anti-copy:** No animals, character designs, eyes, paper scene, source palette, source composition, source code, API surface, or head-turning imagery is reproduced.

## Visible falsifier

The translation fails if the character is only appended at its point of entry, if the remote reply is fixed or cosmetic, if nearby clauses do not move, if the next letter forgets earlier refusals, or if the blind field reads as another line, route, or static word-card poster.

## Deletion condition

Delete v025 if the plate is only a word-card grid; if selection writes; if refusal and reply cannot be found in actual text bodies and geometry; if a bounded sequence is not deterministic; or if lifting the latest event does not restore the exact preceding plate.

## Critique before release

- **Language-material critic:** The exchange must be carried by real DOM text and CSS geometry. A label, counter, cursor, or colour-only state is not evidence.
- **Perceptual critic:** With readout, controls, labels, hint, caption, and furniture hidden, the first field must read as one typographic plate with distributed clauses, not as a sentence corridor, quarry, or card grid.
- **Interaction critic:** Touch may arm a clause but cannot write. A typed letter, Enter, Space, and the semantic control must commit the same deterministic rule; Delete lifts the latest; R releases the ledger.
- **Radical progression critic:** v025 must switch the viewer's task from reading/pressure to offering a letter and must switch the visual grammar from a continuous sentence to a dense plate of distributed clauses.
- **Cynic:** Delete the work if the source citation is doing the perceptual work, if the remote answer never changes, if later offers do not inherit refusal history, or if the field is only a decorated grid.
