HANDWRITING / ENCOUNTER SWITCH / v025

The word asks
another word.

A letter offered to one clause is refused there and wakes a reply elsewhere. The page keeps the refusal, not the input.

TYPE INTO THE PLATE

Choose a clause by touching it, then type one letter. The letter is not appended to the place you touched: the local clause opens around a refusal while a non-local clause takes the reply. Enter, Space, or the button uses the current letter; Delete lifts the latest refusal; R releases the bounded grammar.

The plate is quiet.

ANNOTATIONS / v025

changed rule
Abandon the quarry, reading corridor, and elastic sentence field. Twelve actual DOM clauses now form one typographic plate: an offered character is refused at the selected clause and answered by a non-local clause, while nearby clauses shift to make the exchange visible.
visitor action
Touch a clause to select it, then offer a letter through the field or keyboard. Selection arms but does not write. A committed character changes text and geometry in two clauses; the input is a grammatical event, not a cosmetic parameter.
falsifier
If a character is merely appended where it was typed, if the reply is fixed or only coloured, if nearby clauses keep their geometry, if the next offer forgets earlier refusals, or if the blind field reads as another sentence corridor, the translation fails.
deletion
Delete v025 if the plate is only a word-card grid, if the local refusal and remote reply are not visible in the actual text bodies, if selection writes, or if lifting the latest event cannot restore the exact preceding plate.
