# Handwriting v030 — The sentence refuses the offered letter.

## Status

Candidate / held. This is a real executable study with a deterministic semantic DOM engine, a bounded refusal stack, and a canonical daily record. It is not called exhibition-ready until the caption-free perceptual and production gates are observed.

## Hypothesis

If a sentence can refuse a character as a whole body, then typography can make language's negative space causal: the visitor's offer does not become a mark, it becomes an absence that forces every remaining glyph to find a new position.

## Changed rule

Abandon v029's population of word islands, v027's pressure duration, and v026's routed letter bodies. One sentence now occupies a single typographic sheet. A keyboard letter or letter-strip offer never inserts or echoes the character. If the character still exists, every occurrence is removed, the actual glyph spans become gaps, and the remaining sentence reflows. Repeated or absent offers refuse without changing geometry.

## Visible consequence

The blind first render is one oversized sentence-sheet with a diagonal fault and no word islands. After an accepted offer, actual character spans disappear into narrow red gaps and the remaining typography shifts around them. Later offers operate on the already refused sentence. Delete reconstructs the exact preceding sheet; the refusal stack never exceeds four events.

## Interaction

- Type any letter while the sheet is focused, or choose a letter from the offering strip.
- A present letter is removed everywhere; repeated or absent offers stay geometry-neutral.
- Enter and Space offer the next deterministic letter.
- Delete / Backspace lifts the latest refusal.
- R / Escape releases the sheet.

## Cultural translation

**Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)

**Observed mechanism:** programmable drawing tools expose pressure, density, grain, directional behavior, and vector fields as a material engine: the instrument changes how a mark is produced rather than merely styling a finished shape.

**Mutine translation:** refuse brush appearance, hatching, watercolor, and the source API. Translate material agency into language-as-matter: an offered letter becomes a resistance event that changes the sentence's production rule, removing every matching glyph and forcing the surviving body to reflow.

**Visible consequence:** the first view is one continuous typographic sheet. A valid offer removes all occurrences of the letter as actual glyph spans, opens structural gaps, and reflows the remaining sentence. Later offers start from the mutilated sentence, not from a seed reset.

**Falsifier:** if an offer only highlights a letter, if the actual text body keeps every occurrence, if a repeated letter creates a new event, if later refusals restart from the intact sentence, if lifting is inexact, or if the blind sheet reads as a keyboard panel or word cloud, the translation fails.

**Anti-copy:** no brushes, watercolor, hatching, pressure marks, vector-field drawing, source palette, source composition, source code, API surface, or surface vocabulary is reproduced.

**Direction consequence:** closes Handwriting's counter-topology / pressure-loom / depth-custody / attention-census sequence and opens a material-language direction: the current's unit is now a sentence-wide refusal whose material rule changes the next readable body.

## Radical progression gate

The last three typography records repeated non-local transfer inside a composed word/letter body: v026 moved route custody after withdrawal, v027 redistributed whitespace after a hold, and v029 rewrote three word islands after a collective census. v030 breaks that invariant in five visible ways:

1. **Representation:** from routes, bands, and word islands to one sentence-sheet with per-glyph absences.
2. **Composition:** from depth rack, stacked loom, and open archipelago to a single monolithic page with a diagonal fault.
3. **Encounter:** from withdrawal, duration, and wandering to a literal typed offer that the page can refuse.
4. **Temporal behavior:** from distributed transfer to cumulative mutilation: each new offer operates on the already missing sentence.
5. **Viewer task:** from navigating or counting attention to testing language by offering a character and observing a refusal.

The work can do something the previous three could not: it makes the input itself become a sentence-wide absence, so the page's answer is not another word or route but a changed reading surface.

## Deletion condition

Delete v030 if the blind sheet is only a typographic poster, if the offered letter does not remove actual glyph occurrences, if the reflow is cosmetic, if repeated offers mutate the state, if the fifth refusal forgets the changed sentence, if exact lift fails, or if the p5.brush translation is only a texture or keyboard-controlled parameter panel.
