HANDWRITING / ANTI-INSTRUMENT / v030

The sentence refuses
the offered letter.

You offer a character. The page does not echo it. It removes every place that was ready to receive it.

OFFER A LETTER

Type any letter, or use the small offering strip in the sheet. A letter that still exists is refused across the whole sentence, leaving a real gap and forcing the remaining text to reflow. Repeated offers are rejected. Delete lifts the latest refusal; R or Escape releases the bounded refusal memory.

The sentence is intact. Nothing has been offered.

ANNOTATIONS / v030

changed rule
Abandon v029's population of word islands, v027's pressure duration, and v026's routed letter bodies. One sentence is now a material sheet: a typed letter is never inserted or echoed; every occurrence is removed, and the remaining glyphs reflow around the gap.
visitor action
Offer a letter by keyboard or by the letter strip. Enter and Space offer the next deterministic letter; Delete lifts the latest refusal; R or Escape releases the four-event sheet.
falsifier
If the offered letter is merely highlighted, if only a readout changes, if a repeated letter creates a new event, if the actual text body does not lose its occurrences and reflow, or if the blind page still reads as a word cloud or route rack, the direction fails.
deletion
Delete v030 if refusing a letter is only a decorative color swap, if the fifth refusal forgets the changed sentence, if lifting cannot reconstruct the exact preceding sheet, or if the cultural translation collapses into a keyboard-controlled parameter panel.
