# Handwriting v028 — The word leaves a hollow.

## Hypothesis

If the typographic unit of memory is the counter — the opening inside a letter — then a sentence can remember a relation without drawing a route or adding a note. A visitor's two-place offer should close one actual letter body and open another elsewhere, so the reply is carried by the forms of the words rather than by a cursor, label, or meter.

## Changed rule

v028 abandons v025's browser-native clause plate, v026's extruded route rack, and v027's global pressure loom. Twelve oversized letter-bodies now overlap into one counter-field. A pointerdown near one letter only arms its counter; pointerup at a different letter commits a reply: the source changes to a closed form, the remote target changes to an open form, and a third relay letter shifts its actual position. Four counter replies remain in bounded memory and are replayed from the changed body. Delete lifts the latest reply exactly; R releases the field.

This is a structural rupture:

- representation: distributed clauses, routed letter skeletons, and word-bands → one dense body of actual letterforms whose counters are the state;
- encounter: typing, approach/withdraw, and hold/release → a two-place bridge between gaps, with contact only arming and the remote endpoint deciding the reply;
- memory: refusal, custody, and pressure ledgers → counter exchange, in which an opening migrates across the body and changes the next relay;
- medium: DOM, p5.js WEBGL, and p5.js Canvas 2D → deterministic inline SVG text geometry.

## Cultural translation

**Reference:** [little-critters](https://github.com/GordenSun/little-critters)

**Observed mechanism:** Situated code-drawn agents respond to pointer proximity with legible attention and reciprocal looking, making the visitor part of a relation rather than a controller of a dashboard.

**Mutine translation:** Refuse animals, eyes, faces, head-turning imagery, and the source scene. Translate reciprocal attention into typography's own material: a local letter can be armed but cannot answer itself. A second, distant gap completes the offer; the source closes its counter, the remote letter opens its counter, and a relay letter shifts to carry the relation forward.

**Visible consequence:** The blind field is one dense typographic body of large letterforms with real open and closed shapes. A valid two-place offer changes the source glyph, opens the remote glyph, moves a relay glyph, and leaves a visible bridge in the actual SVG geometry. Later offers replay from the inherited counter field.

**Falsifier:** If pointerdown writes, if a same-letter return commits, if the source and remote bodies do not change, if the relay is only a glow or line, if later replies restart from the seed body, or if the blind image reads as a decorative alphabet grid, the translation fails.

**Anti-copy:** No animals, characters, eyes, paper scene, source palette, source composition, source code, API surface, or head-turning imagery is reproduced.

**Direction consequence:** This closes the pressure / refusal / route family and opens a counter-topology direction: handwriting is an exchange of openings in one body, not a line, plate, or word-band. The next mutation must either abandon letters as visible objects or make the body remember a refusal as a new grammar.

## Critique and deletion condition

The artist's claim is falsified if the field is only an attractive alphabet poster, if the second endpoint does not matter, if the source and target changes are cosmetic, if the relay does not carry forward, or if lifting is not exact. Delete v028 rather than polish it if the caption does more work than the letterforms, if the blind body reads as a grid, or if its two-place relation is not visible.
