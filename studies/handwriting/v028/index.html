HANDWRITING / COUNTER EXCHANGE / v028

The word
leaves a hollow.

A letter can be addressed without being allowed to answer itself. The reply arrives as an opening somewhere else.

ARM, THEN CROSS

Press near one letter and release at another. Contact only arms the first gap. A distant release closes the source, opens the remote letter, and shifts a third relay. Same-gap contact is refused; Enter, Space, or the offer control makes the deterministic exchange. Delete lifts the latest reply and R releases the ledger.

The field is quiet.

ANNOTATIONS / v028

changed rule
Abandon the clause plate, route rack, and pressure loom. Twelve oversized letterforms now make one counter-field. The counter — not the glyph label or the pointer — stores the relation.
visitor action
Arm one gap and cross to another. The first endpoint cannot answer itself. Enter, Space, or the offer control supplies the deterministic two-gap reply; Delete lifts the latest event; R releases the four-reply ledger.
falsifier
If pointerdown writes, if same-gap return commits, if source and remote letter bodies stay unchanged, if the relay is only a decorative trace, or if the blind body reads as an alphabet grid, the translation fails.
deletion
Delete v028 if the two-place relation is not visible in actual letter geometry, if later replies forget the changed counter field, or if lifting cannot restore the exact preceding body.
