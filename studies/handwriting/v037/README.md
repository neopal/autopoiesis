# The line learns where to break.

## Hypothesis

A letter can become a material hinge without becoming a decorated mark. If pressure is stored as a directional force rather than drawn as a trace, then one continuous sentence can expose the place where its own syntax no longer carries its weight.

## Changed rule

v037 abandons v036's phoneme ecology, v035's pressure casting rack, and v034's double register. Thirty-two glyph positions now form one folded SVG sentence. A pointer or touch sweep is geometry-neutral while held. On release, a valid pressure interval cuts the sentence at a deterministic material hinge: one glyph opens, a second hollows, and a third drifts. Four cuts remain liftable and later pressure inherits the altered seam.

## Cultural translation

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** programmable pressure, density, and directional fields participate in producing geometry rather than styling a finished mark.
- **Mutine translation:** refuse brushes, watercolor, hatching, grain, source palette, source composition, source code, examples, and API surface. Translate the production logic into a sentence seam: a held sweep stores direction and force; release makes the line produce a cut, a hollow, and a drift at its own weak hinge.
- **Visible consequence:** the first blind view is one continuous folded sentence. A valid release changes actual SVG glyph positions, rotations, scale, tracking, opacity, and path scars at a hinge; later cuts stay in the sentence.
- **Falsifier:** if holding changes glyph geometry, if the input point is simply selected, if the cut is only colour or readout, or if later releases restart from the seed, the translation fails.
- **Anti-copy statement:** no brush appearance, watercolor fill, hatching vocabulary, grain, vector-field drawing, source palette, source composition, source code, examples, API names, or surface vocabulary is reproduced.

## Visible consequence

With furniture removed, the work is a single sentence bent across a dark field. The letters are not cards or a word cloud: they share one carrier, one changing pressure line, and one fragile hinge. A release leaves a real gap in the logic of the line: one glyph opens, one hollows, one drifts, and a small seam scar records the event. Four cuts compound.

## Interaction

- Drag across the sentence field; a short or overlong sweep is refused.
- Hold and move without release: the SVG glyph geometry remains exact while a temporary pressure probe follows the pointer.
- Release: the pressure interval becomes a produced sentence cut.
- Arrow keys, Enter, Space, and **apply pressure** make deterministic pressure sweeps.
- Delete lifts the latest cut; R or Escape releases the sentence to its quiet seed.
- Static previews replay four cuts but remove controls, readout, note, and hint.

## Radical progression gate

The primary rupture is a medium, composition, and encounter switch. v034's semantic fragments, v035's three-dimensional molds, and v036's Canvas ecology become one continuous inline SVG sentence. The viewer no longer attends, speaks, or holds a source block for a remote receiver. They drag across a latent seam and release a local structural break. The new work can do something the previous three could not: make the sentence's own weakest hinge, rather than a remote slot, become the produced consequence.

## Falsifier

Delete v037 if caption-free viewing reads as a generic type specimen, route, word cloud, or decorative SVG; if holding changes geometry; if the input site is merely selected; if the hinge cut is cosmetic; if later cuts forget; or if exact lifting fails.

## Deletion condition

Delete v037 if the browser cannot show the causal difference between a held pressure probe and a released sentence cut without labels or prose, or if the work needs the p5.brush reference to be intelligible as anything beyond surface imitation. Hold the work as `candidate / held` until local and production browser evidence and independent caption-free perceptual review exist.
