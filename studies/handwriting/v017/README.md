# Handwriting v017 — The sentence sets its own weight.

## State

`v017` is a daily work candidate, recorded as **candidate / held**. It is not a finished period or an exhibition-ready claim.

## Hypothesis

The previous handwriting studies moved through route relays, a social attention field, and a material capillary sentence. This version abandons the connected line entirely and asks whether a letter can become a piece of type: can material pressure change the setting of the next line rather than deform the current route?

## Changed rule

The artwork is an actual HTML text DOM, not an SVG route. Twenty-four letter tiles begin as a loose four-shelf setting. A bounded tap chooses the nearest tile. That tile locks onto its shelf, neighbours shift in the same setting, another tile is ejected into an impression rail, and the ejected tile's old slot becomes a real vacancy. Later taps replay through the same typographic setter. There is no drag path.

## Visible consequence

The blind first encounter is a dark typesetting plate of oversized letterforms, staggered shelves, and an uneven baseline. After a tap, the pressed glyph becomes heavier and settles, nearby type slips, a displaced glyph appears below the plate, and a dashed empty slot records what left. This is a field of actual text objects and missing positions, not a connected sentence, route, reservoir, or quorum grid.

## Cultural translation

- **Reference:** `p5-brush` — https://github.com/acamposuribe/p5.brush
- **Observed mechanism:** natural drawing tools treat pressure, density, grain, and vector fields as programmable material forces; material changes how geometry is produced and remembered rather than decorating finished geometry.
- **Mutine translation:** translate material pressure into typesetting pressure. The visitor does not steer a line; a tap changes the setting rule itself: one glyph is locked, local type is displaced, and another glyph leaves an impression that changes the next available plate.
- **Visible consequence:** the blind field changes from loose shelves to a pressed setting with heavier type, a shifted local arrangement, an ejected letter, and a true vacant slot.
- **Falsifier:** if tapping changes only colour, font weight, or a counter; if the ejected glyph is not visibly displaced; or if the blank is not a missing slot in the setting, the material rule is not embodied.
- **Anti-copy:** no p5.brush brushes, watercolor appearance, hatching vocabulary, palette, API surface, or compositional language is reproduced.

## Visitor action

In an interactive preview, tap the typographic field or use **press type**. Enter and Space repeat the last tap. **Lift latest** removes only the newest impression and reconstructs the preceding DOM setting; **release sequence** returns to the deterministic loose plate. The focused field also supports `Delete` or `U` to lift, `R` to release, and `S` to save the current tableau HTML.

## Falsifier

Hide the labels, readout, controls, captions, and editorial furniture. If the blind field still reads as a route bundle or a cosmetic font treatment instead of shelves, displaced type, and a real blank, the translation failed.

## Deletion condition

Delete v017 if the letters remain a decorative grid, if a press does not change composition and occupancy, if the impression rail is only a witness, or if lifting the latest impression fails to reproduce the exact earlier DOM setting.

## Direction consequence

This closes the handwriting current's v016 capillary sentence and opens a browser-native typesetting direction: handwriting is tested as setting, occupancy, and absence. It also closes the repeated drag-and-reroute encounter. The next viable handwriting experiment must either make the type setting more adversarial or abandon the plate before returning to another line system.

## Critique response

The progression critic demanded a new medium and encounter rather than another material route. The interaction critic demanded a tap with no drag path, a real occupancy change, and exact lifting. The perceptual and cynical critiques remain release gates, not claims: this record stays **candidate / held** until caption-free comparison, responsive browser evidence, production readback, and provider revision verification are observed.
