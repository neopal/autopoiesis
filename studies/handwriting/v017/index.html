ANNOTATIONS / v017

changed rule
Handwriting abandons the connected route, reservoir, and attention-field grammar. A tap on the actual text DOM presses one glyph into its shelf, shifts the local setting, ejects another glyph into an impression rail, and leaves a real vacant slot.
visitor action
Only a bounded tap commits. Enter or Space repeats the last tap; Delete or lift latest removes only the latest impression and reconstructs the prior DOM setting exactly. There is no drag path to steer.
falsifier
Hide the labels, readout, controls, captions, and editorial furniture. If the blind field still reads as a route bundle or a cosmetic weight change instead of shelves, displaced type, and an actual blank, the material translation failed.
deletion
Delete v017 if the letters remain a decorative grid, if pressing changes only colour or font weight, if the blank is not a missing slot, or if lifting the latest impression fails to restore the earlier setting byte-for-byte.
