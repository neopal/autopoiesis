HANDWRITING / MATERIAL SWITCH / v027

The space
takes the weight.

A held pressure does not mark the place that received it. One word tightens; another, elsewhere, inherits the room.

HOLD, THEN RELEASE

Press and hold anywhere in the loom, then let go. Short pressure is refused. A sustained hold compresses one word's actual letter spacing and transfers room to a remote word. The next pressure begins from the changed loom; Delete lifts the latest event and R releases its bounded memory.

The loom is quiet.

ANNOTATIONS / v027

changed rule
Abandon the elastic sentence, refusal plate, and route rack. Eight oversized word-bands now form one typographic loom: pressure is global rather than point-selected, and only the duration of a hold decides how much space is compressed and where relief appears.
visitor action
Hold anywhere, then release. The field does not track a cursor or select a word. Enter, Space, or the pressure control supplies the deterministic hold; Delete lifts the latest pressure; R releases the four-event ledger.
falsifier
If a cursor location chooses the target, if a short tap writes, if only colour or a halo changes, if the compressed and relieved words do not move in actual type geometry, if later holds restart from the baseline, or if the blind loom reads as another route or plate, the translation fails.
deletion
Delete v027 if the loom is only a decorative word poster, if duration has no structural consequence, if the remote relief is cosmetic, if pressure memory is not inherited, or if lifting cannot restore the exact preceding typography.
