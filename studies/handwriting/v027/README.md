# Handwriting v027 — The space takes the weight.

## Hypothesis

If pressure is treated as a production force rather than a mark or a point selection, a typographic system can make duration visible as a redistribution of whitespace. The work asks whether a word can tighten under pressure while another word, elsewhere, inherits the room that pressure displaced.

## Changed rule

v027 abandons v024's direct point pressure on an elastic Canvas sentence, v025's literal character offer to a distributed DOM plate, and v026's approach-and-withdraw route rack. Eight oversized word-bands form one browser canvas loom. The viewer holds anywhere and releases: a short hold is refused; a sustained duration compresses the actual tracking, scale, and slant of one deterministic keystone word, while a non-local word receives the released space. Four pressure events remain in bounded custody memory; later holds replay from the altered loom, and Delete reconstructs the exact preceding typography.

This is a structural rupture, not a palette or texture variation:

- representation: curved sentence, clause plate, and route sculpture → one stacked typographic mass of word-bands;
- medium: Canvas 2D, semantic DOM, and WebGL → deterministic p5.js Canvas 2D text with measured tracking;
- viewer task: point, type, or approach/withdraw → hold globally and release by duration;
- memory: resistance, refusal, and segment custody → pressure moves actual spacing between non-local words.

## Cultural translation

**Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)

**Observed mechanism:** programmable drawing tools treat pressure, density, grain, and directional fields as forces that participate in producing geometry rather than decorating finished geometry.

**Mutine translation:** refuse brushes, watercolor, hatching, and the library's API vocabulary. Translate material agency into typography's own variable: duration is pressure. A global hold compresses one word's production geometry and transfers the displaced room to a non-local word; the changed loom becomes the material for the next event.

**Visible consequence:** the blind first view is a stacked eight-band typographic mass, not a route rack or a sentence corridor. After a sustained hold, one word visibly tightens and leans while a distant word opens its tracking and changes its scale; nearby bands shift their baselines. Later holds act on the inherited geometry.

**Falsifier:** if cursor location selects the target, if a short tap commits, if duration only changes a halo or colour, if the compressed and relieved words do not change actual letter spacing and position, if later holds restart from baseline, or if the blind view reads as another route or refusal plate, the translation fails.

**Anti-copy:** no p5.brush brushes, watercolor appearance, hatching vocabulary, source palette, source composition, examples, or API surface is reproduced.

**Direction consequence:** this closes Handwriting's sentence / clause / routed-letter sequence and opens a pressure-as-whitespace direction: language is no longer addressed at a point; its material rule is distributed through time and space.

## Critique and deletion condition

The artist's claim is falsified if the loom is only an attractive word poster, if duration has no geometric consequence, if the remote relief is cosmetic, if the next pressure forgets its inherited typography, or if lifting is inexact. Delete v027 rather than polish it if those conditions are observed.
