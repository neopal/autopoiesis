# Handwriting v040 — The letter keeps its pressure debt

## Hypothesis

If a glyph is treated as a material chamber rather than a stable sign, pressure can become a transferable typographic event: the source remains still, but the next glyphs inherit what the visitor released. The work should show that debt in produced letter geometry before the explanation is read.

## Changed rule

v040 abandons v039's route traversal, v038's typed ratification, and v037's pressure seam. A pointer or touch hold on one glyph chamber is geometry-neutral until 640ms. A threshold release turns elapsed pressure into a deterministic event that changes three remote glyph chambers' position, scale, width, slant, counter, and ink. The source chamber remains exact. Four debts compound and can be lifted.

This is a new encounter and medium emphasis: one monumental Canvas 2D rack of actual rendered glyphs, with discrete pressure/release rather than route tracing or token entry. Pointer, touch, and keyboard offer equivalent access; duration is a structural input, not a label.

## Visible consequence

The first-render blind view is a warm, asymmetric rack of nine oversized glyph chambers, each surrounded by a measured counter and pressure halo. After release, three unvisited glyphs visibly open, compress, and lean; their geometry, not merely their colour or readout, carries the event. Longer holds produce stronger deformation. Four debts remain present; Delete reconstructs the preceding rack.

## Cultural translation

- Reference: [p5.brush](https://github.com/acamposuribe/p5.brush)
- Observed mechanism: programmable drawing instruments make pressure, density, directional behavior, and material state participate in producing geometry rather than sit on top of it as a skin.
- Mutine translation: refuse brush marks, watercolor, hatching, and grain. Make elapsed pressure a debt that migrates into remote glyph chambers; the material rule changes the next letter's geometry and remains in the rack.
- Anti-copy statement: no brush preset, watercolor appearance, hatching vocabulary, grain, palette, composition, source code, API surface, or source imagery is reproduced.

## Falsifier

Delete the direction if holding changes geometry before release, if a short release commits, if duration does not alter the produced geometry, if the source chamber answers itself, if remote changes are only colour/readout, or if later pressure forgets earlier debt.

## Deletion condition

Delete v040 if caption-free viewing reads as a generic letter poster, if a threshold release cannot be seen in the produced glyphs, or if the p5.brush translation collapses into decorative texture instead of a new causal rule.
