HANDWRITING / CANVAS PRESSURE RACK / v040

The letter keeps
its pressure debt.

A glyph can stay still and still make another glyph carry what was pressed into it.

PRESSURE IS A MATERIAL MEMORY

Press and hold any chamber with a pointer or touch. Nothing moves while the pressure is pending. Release after 640ms and the source remains exact while three remote glyph chambers open, compress, or lean under the transferred debt. ArrowRight plus Enter performs the deterministic keyboard path; Delete lifts the latest debt.

The rack is quiet. No pressure is held.

ANNOTATIONS / v040

changed rule
Abandon v039's route traversal and v038's typed ratification. A held glyph is geometry-neutral; only a threshold release transfers duration into actual remote glyph position, scale, width, slant, counter, and ink.
visitor action
Press and hold a glyph chamber with pointer or touch, release after the threshold, or use ArrowRight then Enter. Delete lifts the latest debt; Escape releases all history. Four debts compound and remain replayable.
falsifier
Delete if pressure changes the source or any geometry before release, if duration is only a timer label, if remote chambers change only colour, or if the rack forgets after a later debt.
deletion
Delete v040 if the blind rack reads as a generic letter poster, if a release cannot be seen in the produced glyph geometry, or if the pressure translation collapses into texture instead of a new causal rule.
