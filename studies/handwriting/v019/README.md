# Handwriting v019 — The letters answer elsewhere.

## State

`v019` is a daily work candidate, recorded as **candidate / held**. It is not a finished period or an exhibition-ready claim.

## Hypothesis

If a letter is a situated agent rather than a mark on a line, an address should change where the letter lives. Typing one phoneme should make every matching glyph leave its source slot, gather in a reply channel, and leave a findable vacancy behind. The work asks whether handwriting can remember a sound as a change in reading relation.

## Changed rule

The artwork abandons v016's capillary sentence, v017's four-shelf tile setting, and v018's single SVG lock-up. Twenty-four actual HTML glyph nodes form five irregular vertical reading channels. An address event is a phoneme, not pressure: E, I, O, or A. Every matching glyph is reclassified into a central response channel; its source slot is left empty and recorded as a vacancy. The latest four addresses are replayed from deterministic memory.

This is not a pointer-following scene. The visitor speaks to the field through a typed address or a work-specific address control. Pointer taps are refused so the relation is carried by language input rather than a generic cursor gesture.

## Visible consequence

The blind first encounter is a cold, vertical typographic field with a central void and irregular channels. After addressing E, the matching letters visibly gather toward the centre while outlined source vacancies remain where they left. The field is not a shelf grid, route bundle, masked lock-up, or decorative response layer.

## Cultural translation

- **Reference:** `little-critters` — https://github.com/GordenSun/little-critters
- **Observed mechanism:** situated code-drawn agents respond to pointer proximity by changing attention and looking back, making the visitor part of a reciprocal encounter rather than a controller of a dashboard.
- **Mutine translation:** remove the animals and look-back scene. Make each actual letter a situated listener: a typed phoneme summons matching glyphs away from their source positions into a reply channel, so attention is remembered as changed reading occupancy.
- **Visible consequence:** addressed letters move as real HTML nodes, the central channel fills, and their old slots stay visibly vacant; the result is a changed sentence-field rather than a recoloured word.
- **Falsifier:** if an address only changes colour, if the source positions remain occupied, if no reply channel forms, or if the relation reads as a decorated line or shelf without the caption, the translation fails.
- **Anti-copy:** no animals, eyes, characters, paper scene, source palette, source composition, or head-turning surface vocabulary is reproduced.
- **Direction consequence:** closes the recent pressure/setting/lock-up family and opens a language-as-address direction where handwriting is a distributed population of letters with local places and collective reply.

## Visitor action

Focus the field and type `E`, `I`, `O`, or `A`, then press Enter; choose an address button for the same deterministic event. A pointer tap is refused. **Lift latest** or `Delete` removes only the newest phoneme address. **Release sequence** or `R` clears the bounded address memory. `S` is intentionally not an export shortcut in this work: the viewer's meaningful action is language input, not capture.

## Deterministic state

- Seed: `0x48574919` (`mutine-handwriting-v019-address`)
- Renderer: deterministic HTML glyph DOM with CSS positions
- Stages: 5, final frame index 4
- Glyphs: 24 across 5 vertical channels
- Memory window: 4 phoneme addresses
- Default replay: `E → I → O → A`
- No external assets or image inputs

## Falsifier

Hide labels, readout, controls, captions, and editorial furniture. If matching letters do not leave actual source positions, if vacancies cannot be found in the field, or if the blind image still reads like a line/shelf refinement, the social-attention translation failed.

## Deletion condition

Delete v019 if address events only recolour letters, if the source vacancies are not real DOM absence, if typing does not change the reading relation, if the reply channel is only a decorative rail, or if lifting the latest address fails to restore the exact prior glyph signature.

## Direction consequence

This closes v018's subtractive counter lock-up and the preceding shelf/capillary grammars. It opens a distributed syntax direction: a sentence can be a population of situated letters, and an address can make the work move its own reading order. The next viable work must either make a reply alter the grammar itself or abandon the vertical-channel field before returning to pressure.

## Critique response

The progression critic demanded a new representation, viewer task, and memory model after three pressure-based forms. The interaction critic demanded a typed address with pointer refusal and exact lifting. The perceptual and cynical critiques remain release gates, not claims: this record stays **candidate / held** until caption-free comparison, responsive browser evidence, production readback, and provider revision verification are observed.
