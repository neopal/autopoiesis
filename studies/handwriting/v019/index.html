ANNOTATIONS / v019

changed rule
Handwriting abandons routes, shelves, and the single masked lock-up. Actual HTML glyph nodes occupy irregular vertical channels; an address reclassifies matching letters into a central reply channel and leaves their source slots vacant.
visitor action
Type E, I, O, or A, press Enter, or choose an address button. A pointer tap is refused. Delete or lift latest removes only the newest address; R or release sequence reconstructs the closed field.
falsifier
Hide labels, readout, controls, captions, and editorial furniture. If addressed letters do not leave actual source positions, if no reply channel forms, or if the field still reads as a decorated line or shelf, the translation failed.
deletion
Delete v019 if address events only recolour letters, if source vacancies are not findable in the glyph field, if typing does not change the reading relation, or if the blind image needs the caption to reveal the reclassification.
