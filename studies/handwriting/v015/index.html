ANNOTATIONS / v015

changed rule
Continuous route memory is replaced by a discrete attention quorum. A local cohort reorients toward the visitor, a second ring mirrors the look, and a third witness vacates one typographic slot; later events replay the same topology change.
visitor action
A pointer, Enter, or Space places one bounded attention event. The event changes mark positions, apertures, angles, roles, and occupancy. Lifting the latest event rebuilds the exact preceding field.
falsifier
Hide the labels, witnesses, readout, controls, captions, and editorial furniture. If the blind field still does not show a local turn, a distinct answering ring, and an actual blank in the sentence, the quorum is only an explanation.
deletion
Delete v015 if the marks still read as a softened route bundle, if the vacancy is only a coloured dot, if edge attention produces no structural cohort, or if removing the latest look does not restore the exact prior mark field.
