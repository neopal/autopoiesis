# Handwriting v015 — The letters choose a quorum.

## State

`v015` is a daily work candidate, recorded as **candidate / held**. It is not a finished period or an exhibition-ready claim.

## Hypothesis

The previous three handwriting studies used continuous route fields: a sentence was a bundle of lines that could relay, reflect, or carry cadence. This version asks whether handwriting can become a population of discrete typographic marks whose attention changes the sentence's topology rather than merely bending its paths.

## Changed rule

A visitor look creates a bounded attention quorum. The nearest marks turn toward the look and open their apertures; a second ring answers from the opposite orientation and closes its apertures; a third witness vacates one typographic slot. The event changes positions, angles, apertures, roles, and occupancy in the actual mark field. Later attention events replay the same structural memory. This is a deliberate rupture from v014's continuous route bundle, delayed counterphrase, and line-based explanation.

## Visible consequence

The first encounter is a warm paper field of 45 discrete marks arranged as a provisional alphabet, not a set of horizontal routes. A look produces a local cluster that points toward the visitor, a surrounding answer ring with reversed openings, and a real blank slot. The blank is not a badge: the mark is absent and its sentence must carry the gap. Multiple events accumulate vacancies and reorientation. Lifting the latest look reconstructs the exact earlier alphabet.

## Cultural translation

- **Reference:** `little-critters` — https://github.com/GordenSun/little-critters
- **Observed mechanism:** situated code-drawn agents respond to pointer proximity by changing attention and looking back, making the visitor part of a reciprocal encounter rather than a controller of a dashboard.
- **Mutine translation:** discrete typographic marks become a social grammar. A local cohort looks toward the visitor, an answering ring mirrors the attention, and a third witness yields a slot so the sentence remembers that someone was seen.
- **Visible consequence:** the blind field changes topology, orientation, and occupancy after a look; it does not merely move a cursor or decorate a fixed composition.
- **Falsifier:** if caption-free viewing sees only a regular grid with changed colour, or if the vacancy is not materially different from a missing label, the translation fails.
- **Anti-copy:** no animals, characters, paper scene, head-turning animation, palette, composition, or surface style from `little-critters` is reproduced.

## Visitor action

In an interactive preview, touch or click the field, or use **attend here**. Enter and Space repeat at the last pointer position. The latest attention is inserted into memory and the mark field is rebuilt. **Lift latest** removes only the latest event and reconstructs the preceding marks; **release sequence** returns to the deterministic empty sequence. The focused canvas also supports `P` pause, `R` release, `U` or `Delete` lift, and `S` still export.

## Falsifier

Hide the labels, witnesses, readout, controls, captions, and editorial furniture. If the blind field does not still show a local turn, a distinct answering ring, and an actual blank in the sentence, the quorum is only an explanation. If the attention event cannot be perceived at 320px-wide and 390px-wide viewports, this version fails its mobile test.

## Deletion condition

Delete v015 if the field still reads as a softened route bundle, if the vacancy is carried by a coloured marker rather than topology, if edge attention produces no structural cohort, or if lifting the latest look leaves the previous mark signature changed.

## Direction consequence

This closes the handwriting current's v010–v014 continuous route grammar for the next viable run and opens a discrete typographic ecology: letters are provisional agents, spacing is a social decision, and absence is part of the syntax. The next viable handwriting experiment must either push this topology into a new medium or abandon the quorum rather than polish another route bundle.

## Critique response

The structural critic demanded that a new rule alter what the marks are, not only where a line bends. The interaction critic demanded a bounded and reversible encounter; attention events are clamped, replayed through one deterministic builder, and removed through preserved prior memory. The perceptual and cynical critiques remain release gates, not claims: this record stays **candidate / held** until caption-free comparison, responsive browser evidence, production readback, and a fresh perceptual review are observed.
