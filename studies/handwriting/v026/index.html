HANDWRITING / MEDIUM SWITCH / v026

The margin
keeps the spare.

A route noticed up close does not answer where it was noticed. When attention withdraws, its spare segment is carried to another letter.

APPROACH, THEN WITHDRAW

Move toward one route to arm it without changing the rack. Move away across the threshold, or use the deterministic action, to make the route surrender a segment. A non-local route receives the spare and shifts its own geometry. Delete lifts the latest departure; R releases the bounded custody.

The rack is quiet.

ANNOTATIONS / v026

changed rule
Abandon the refusal plate, elastic sentence, and browser reading corridor. Seven extruded letter-routes now occupy a shallow depth rack: proximity arms a route, but only withdrawal produces a structural event; the local route loses a segment while a non-local route takes custody of the spare.
visitor action
Approach one route with pointer or touch, then withdraw across the distance threshold. The first relation is memory-neutral. Enter, Space, or the action button makes the deterministic departure; Delete lifts the latest custody event; R releases the rack.
falsifier
If proximity writes, if withdrawal only brightens a route, if the local gap and remote custody are overlays rather than changed route geometry, if the reply is local, or if the blind view reads as another text plate or card field, the translation fails.
deletion
Delete v026 if the 3D route sculpture is only a decorative font substitute, if the first encounter needs the caption to explain where the spare went, if later departures forget custody, or if lifting cannot restore the exact prior rack.
