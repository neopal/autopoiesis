# Handwriting v026 — The margin keeps the spare.

## Hypothesis

A letter can behave as a situated route rather than a finished glyph when the visitor's nearness is only attention, and withdrawal is the causal event. The work asks whether a typographic system can remember *where a route surrendered material* without turning that relation into a cursor mark or a caption.

## Changed rule

v026 abandons v023's browser-native reading fold, v024's elastic Canvas sentence, and v025's distributed refusal plate. Seven custom letter-routes are rendered as extruded WebGL line sculptures in a shallow depth rack. Proximity arms a route without writing. Crossing the withdrawal threshold commits a departure: one segment of the local route contracts, a non-local route receives a spare segment, and neighbouring routes make room. Four departures remain in bounded custody memory; Delete reconstructs the exact preceding rack and R releases it.

This is a material and encounter rupture, not a palette or texture variation:

- representation: DOM words and clauses → three-dimensional routed letter skeletons;
- medium: browser DOM / Canvas 2D / browser DOM → p5.js `WEBGL`;
- viewer task: offer, press, or read → approach, then withdraw;
- memory: refusal and pressure ledgers → distributed segment custody.

## Cultural translation

**Reference:** [little-critters](https://github.com/GordenSun/little-critters)

**Observed mechanism:** situated code-drawn agents respond to pointer proximity by changing attention and looking back, making the visitor part of a reciprocal encounter rather than a controller of a dashboard.

**Mutine translation:** refuse animals, eyes, head-turning imagery, and the source scene. Translate reciprocity into handwriting's own question: a route can notice the visitor, but it cannot answer locally. Only withdrawal makes the route surrender a spare segment to a non-local route, whose geometry then carries that custody forward.

**Visible consequence:** the first blind view is a sparse three-dimensional rack of seven letter-routes with actual depth and extrusion. Nearness alone leaves the geometry exact. After withdrawal, the local route has a contracted segment and the remote route has an added route segment; later departures inherit a changed rack.

**Falsifier:** if proximity commits, if withdrawal only changes colour or a glow, if the local gap and remote custody are overlays rather than route geometry, if the reply is local, if later departures forget custody, or if the blind field reads as another text plate or card field, the translation fails.

**Anti-copy:** no animals, eyes, paper scene, character designs, source palette, source composition, code, API surface, or head-turning imagery is reproduced.

**Direction consequence:** this closes the pressure / refusal / reading-corridor family and opens a depth-and-custody direction in which handwriting is a set of routed letter bodies that can relinquish material across distance. It forces a new medium and leaves the stable 2D typographic plate behind.

## Critique and deletion condition

The artist's claim is falsified if the sculpture is only a decorative font substitute, if the first blind encounter needs prose to reveal the transfer, if the local and remote route geometry does not change, or if lifting is not exact. Delete v026 rather than polish it if those conditions are observed.
