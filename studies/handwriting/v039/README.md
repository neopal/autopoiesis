# Handwriting v039 — The route forgets its first letter

## Hypothesis

If a letter is treated as a route through a topology rather than a drawable glyph, the visitor's meaningful act can be traversal: a path becomes evidence before it becomes an alteration. The work should make the route visible as a produced field, not use a word to explain it.

## Changed rule

v039 abandons v038's browser-native lexicon of word agents, v037's pressure seam, and v036's fragment ecology. The first four distinct junctions are only a pending route. While traced, every junction and edge remains geometrically exact. Only a complete commitment rewires three unselected junctions: one turns, one splices, and one stutters the surrounding paths. The selected route remains exact.

This is a medium and encounter switch: from a field of readable text and discrete keyboard tokens to a canvas topology whose legible units are junctions, curves, gaps, and route memory. Pointer, touch, and ArrowRight offer equivalent traversal paths; Enter commits the topological event.

## Visible consequence

The first-render blind view is a single asymmetrical route sheet: a dark ground carrying a continuous, braided path system with open junction collars, weak crossings, and fine echo lines. It has no words to read and no local glyph to edit. After a valid route, three remote path neighborhoods materially change bend, position, width, and phase while the four selected junctions remain exact. Four rewirings compound and Delete reconstructs the previous topology.

## Cultural translation

- Reference: [little-critters](https://github.com/GordenSun/little-critters)
- Observed mechanism: a population of situated code-drawn agents makes pointer proximity legible as reciprocal attention; the visitor enters a small field and local behaviour answers without a dashboard.
- Mutine translation: refuse animals, eyes, characters, paper scenes, and head-turning. Translate situated reciprocity into a route topology: the visitor's completed path is remembered, but the answer is displaced to three unvisited junctions that rewire the field.
- Anti-copy statement: no animal, character, eye, paper scene, source palette, source composition, source code, examples, API names, or surface vocabulary is reproduced.

## Falsifier

Delete the direction if tracing changes any geometry before commitment, if a repeated junction can complete a route, if a selected junction answers itself, if remote rewirings are only colour or readout, if the blind field reads as a generic route diagram, or if later routes forget.

## Deletion condition

Delete v039 if caption-free viewing cannot distinguish this topological route sheet from the preceding fragment ecology, pressure seam, and lexicon, or if a completed route does not materially change unselected path geometry.
