HANDWRITING / DIRECTION SWITCH / v020

The sentence takes
pressure.

Letters are not marks laid on a page. They are a material slab: a stroke compresses what it touches, and the weight left behind changes what the next sentence can become.

TRAVEL, DO NOT TAP

Drag across the type. A traveled stroke changes the geometry of the actual letters and leaves resistance in the slab; the next stroke meets the changed material. Enter or “press the type” uses a deterministic stroke. Delete lifts only the latest stroke.

The type is dry and uncommitted.

ANNOTATIONS / v020

changed rule
Replace v019’s situated glyph channels and phoneme address with one canvas typographic slab. A traveled pressure stroke deforms the letters it crosses and deposits resistance that alters the next geometry.
visitor action
Drag through the slab far enough to commit one bounded stroke. A tap is refused. Enter, Space, or the control uses the seeded default; Delete lifts the latest stroke; R releases the sentence.
falsifier
If the drag only paints a line, if the letter geometry stays fixed, or if the second stroke behaves like the first despite inherited resistance, the material translation has failed.
deletion
Delete v020 if the blind field reads as a decorative text poster, if pressure does not alter actual glyph proportions and positions, or if the work needs its caption to reveal that language has become material.
