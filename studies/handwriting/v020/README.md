# Handwriting v020 — The sentence takes pressure.

## State

`v020` is a daily work candidate, recorded as **candidate / held**. It is not a finished period or an exhibition-ready claim.

## Hypothesis

If language is material rather than a fixed inscription, a traveled pressure stroke should deform the actual letters it crosses and leave resistance in the slab. The next stroke should therefore produce a different typographic geometry without a caption explaining the relation.

## Changed rule

The work abandons v017's shelf occupancy, v018's subtractive SVG lock-up, and v019's situated glyph channels. It changes medium and encounter: a deterministic p5.js canvas renders one compact typographic slab, and a stroke that travels through the field becomes a pressure event. Letters near the stroke are compressed, displaced, tilted, and stretched; inherited resistance changes the force of later strokes. The bounded memory holds three strokes and can be lifted exactly.

This is not a brush mark painted over typography. The stroke is a geometry-producing event: it changes the parameters used to draw the letters themselves. A tap cannot commit because pressure must travel through the sentence.

## Cultural translation

- **Reference:** `p5-brush` — https://github.com/acamposuribe/p5.brush
- **Observed mechanism:** programmable drawing tools treat pressure, density, grain, and directional fields as material forces that change how geometry is produced and remembered rather than decorating finished geometry.
- **Mutine translation:** refuse brush appearance and translate material pressure into language-as-geometry. A traveled stroke compresses the touched glyphs and deposits resistance in one typographic slab; later strokes are computed through that changed material.
- **Visible consequence:** the blind field is a singular compact sentence-object. After a stroke, actual letters change width, height, position, and angle, while a later stroke produces a different response because the slab carries pressure debt.
- **Falsifier:** if the drag only paints a line, if glyph geometry remains fixed, if a tap commits, or if repeated strokes produce the same geometry, the translation fails.
- **Anti-copy:** no p5.brush brushes, watercolor appearance, hatching vocabulary, palette, API surface, source examples, or composition are reproduced.
- **Direction consequence:** closes the recent distributed-letter/lock-up/shelf family and opens a material syntax direction in which handwriting is a pressure-bearing object instead of a field of addressed marks.

## Visitor action

Drag across the typographic field. A traveled path commits one pressure stroke; a short tap is refused. **Press the type**, `Enter`, or `Space` uses a deterministic default stroke. **Lift latest** or `Delete` restores the exact preceding slab. **Release sentence** or `R` clears the bounded memory. `S` captures a PNG.

## Falsifier

Hide labels, readout, controls, captions, and editorial furniture. If the first field still reads as a decorative text poster, if letters do not visibly deform after pressure, or if a second stroke has no changed consequence, the material-agency translation is not embodied.

## Deletion condition

Delete v020 if pressure only creates a cosmetic trace, if the canvas text does not change its actual proportions and positions, if pointer taps commit, if lifting fails to restore the exact preceding signature, or if the blind encounter needs the explanatory prose to reveal that language became material.

## Direction consequence

This closes v019's phoneme-address/reply-channel grammar and the preceding shelf and counter lock-ups. It opens a pressure-syntax direction: a sentence can carry the force that produced it, and future letter geometry can inherit that force. The next viable work must either make the inherited material rewrite word identity or abandon the slab before returning to a distributed field.

## Critique response

The progression critic required a material rupture after three works that organized letters as shelves, a lock-up, or a situated population. The new work changes representation (HTML glyph field to p5 Canvas), composition (distributed channels to one slab), and viewer task (typed address to traveled pressure). The material and perceptual critiques remain release gates, not claims: this record stays **candidate / held** until caption-free comparison, responsive browser evidence, production readback, and provider revision verification are observed.
