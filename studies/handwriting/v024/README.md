# Handwriting v024 — The margin pushes back.

## State

`v024` is a daily work candidate, recorded as **candidate / held**. It is not a finished period or an exhibition-ready claim.

## Hypothesis

If handwriting is made by material pressure rather than placed on a neutral page, then the next word should be produced by the resistance left by the previous pressure. The sentence should not merely display a history of marks: its downstream words, angles, weights, and replies should be different because matter has become part of the grammar.

## Changed rule

The work abandons v021's orbital glyph population, v022's separated pressure stones, and v023's browser-native reading corridor. It switches to a deterministic p5.js Canvas field: eighteen words travel as one elastic sentence current through a dark material space. Each word is drawn as a weighted, angled body with a fine contour, not as an independent DOM tile.

A point press is causal immediately. The addressed place becomes an anchor, the downstream field bends through actual x/y/angle/scale geometry, the anchor is rewritten, and a distant reply changes text and weight. The pressure leaves residue in a bounded material field. A later press is computed from that residue rather than from the untouched sentence. Delete reconstructs the exact previous field; R releases all pressure memory.

The changed rule is not a glow or a cursor mark. Material resistance changes how the next letter-bearing form is made.

## Cultural translation

- **Reference:** `p5-brush` — https://github.com/acamposuribe/p5.brush
- **Observed mechanism:** programmable drawing treats pressure, density, grain, and vector fields as material forces; material changes how geometry is produced and remembered rather than decorating finished geometry.
- **Mutine translation:** refuse brushes, watercolor, hatching, and the library's API vocabulary. Translate material agency into handwriting: a pressure point changes the production rule of the sentence downstream, bending word geometry, increasing weight, rewriting an anchor, and sending a reply to a distant word.
- **Visible consequence:** the blind field is one elastic Canvas sentence current, not a card grid. After pressure, actual word positions, angles, scales, weights, and texts change; later pressure carries an accumulated resistance field.
- **Falsifier:** if a press adds only a glow or overlay, if the words do not bend in actual geometry, if the rewritten reply is cosmetic, if later pressure starts from the original sentence, or if the blind image reads as a static word poster, the translation fails.
- **Anti-copy:** no p5.brush brushes, watercolor appearance, hatching vocabulary, source palette, source composition, examples, API surface, or surface marks are reproduced.
- **Direction consequence:** closes Handwriting's orbital / slab / reading-corridor family and opens a material-language direction where a sentence is generated by resistance rather than read as a finished line. It abandons the stable DOM word as the next invariant.

## Visitor action

Click once inside the field. The nearest sentence pressure point is selected and commits immediately; there is no arming state. Enter or Space presses the deterministic centre. Delete lifts the latest pressure; R releases the bounded material memory. The same port can be pressed again: its residue makes the second answer materially different from the first.

## Radical progression gate

The rupture is structural, not cosmetic:

- **Representation:** orbital glyphs, pressure stones, and DOM word lanes become one curved Canvas sentence current with weighted bodies and contour arcs.
- **Composition:** population, quarry, and reading corridor become a single elastic vertical current with a material field around it.
- **Encounter:** approach/departure, drag, and reading reversal become a direct point press with immediate local consequence.
- **Temporal rule:** line debt and reply memory become carried resistance; the next form is generated from the changed material field.
- **Medium:** browser-native text/DOM is abandoned for p5.js Canvas 2D and an explicit replayable material engine.

The work can do something v021–v023 could not: a single pressure changes the production rule of downstream word geometry and text, and the following pressure inherits that changed material rather than merely adding another event to a line.

## Falsifier

Hide labels, readout, controls, caption, and editorial furniture. If the first field reads as a static word poster, if pressure only adds a halo, if anchor and reply text do not change, if later words ignore the field residue, or if the visual remains the same after pressure, the p5.brush translation is not embodied.

## Deletion condition

Delete v024 if the Canvas is only typographic decoration, if pressure does not change how later words are made, if the event is merely a generic selector, if lifting cannot restore an exact signature, or if the caption is needed to reveal that resistance became grammar.

## Critique response

The progression critic required a new visual grammar after three works that made language into an orbital population, a pressure quarry, or a browser reading corridor. This work changes medium, composition, encounter, and causal memory together. It remains **held** until browser matrices, interaction readback, production verification, and independent caption-free perceptual comparison are observed.
