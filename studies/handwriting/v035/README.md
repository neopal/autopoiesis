# The letter is cast elsewhere.

## Hypothesis

A letter can be material without becoming a decorated mark. If pressure changes the mold that produces the next letter, then typography can remember force as a change in depth, aperture, and extrusion somewhere other than the block that received it.

## Changed rule

v035 abandons v034's browser-native double register, v033's negative-space SVG plate, and v032's Canvas cadence score. Twelve irregular letter blocks now occupy a perspective casting rack rendered in WebGL. Pressing and holding is geometry-neutral. Release turns elapsed pressure into a production force: a remote receiver advances through depth and aperture, a second block loosens as an echo, and a third becomes a counterform. The source block stays exact. Four casts remain liftable and later casts inherit the altered mold field.

## Cultural translation

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** programmable pressure, density, and directional behavior participate in producing geometry; material is an engine rather than a surface placed over a finished form.
- **Mutine translation:** refuse brushes, watercolor, hatching, grain, vector-field marks, source palette, composition, code, and API surface. Translate material agency into typography as pressure casting: a held source only stores force, while release produces a remote block through actual depth, aperture, extrusion, and counterform.
- **Visible consequence:** the source block remains geometrically exact while held and after release. A remote receiver changes depth and opening, an echo loosens, and a third block becomes a real counterform; later casts rebuild from those altered blocks.
- **Falsifier:** if holding changes geometry, if the source answers itself, if depth/aperture/extrusion are only colour or readout, or if later casts restart from the seed, the translation fails.
- **Anti-copy statement:** no brush preset, watercolor appearance, hatching vocabulary, grain, vector-field drawing, palette, composition, source code, examples, API surface, or surface vocabulary is reproduced.

## Visible consequence

The first-render blind view is a dark, asymmetrical three-dimensional rack of twelve letter molds: slabs recede at different depths, glyphs sit inside apertures, and extrusion creates a physical shadow hierarchy. It is not a flat register, route, plate, or score. After a pressure release, the remote mold advances or recedes and opens, a second block loses its certainty, and a third splits into a counterform. The four most recent casts stay in the object.

## Interaction

- Press and hold a letter block; geometry remains exact while pressure is stored.
- Release to cast remotely; elapsed pressure becomes force.
- Arrow keys choose the source; Enter, Space, or **cast pressure** performs a deterministic release.
- Delete lifts the latest cast; R or Escape releases the rack.
- Static previews replay four casts but disable controls and furniture.

## Radical progression gate

The primary rupture is a medium, representation, and encounter switch: v034's semantic double register, v033's SVG plate, and v032's Canvas score become a WebGL depth object made from letter molds. The viewer no longer witnesses, loads a gap, or composes a cadence. They press a source, hold force in time, and release it into a remote production rule. The new work can do something the previous three could not: it preserves pressure as a spatially displaced manufacturing event in a three-dimensional typographic object.

## Falsifier

Delete v035 if caption-free viewing reads as a decorative 3D word wall or flat type specimen; if holding deforms the source; if the remote receiver does not visibly change depth, aperture, or extrusion; if the counterform is only a colour state; if later casts forget; or if lifting is not exact.

## Deletion condition

Delete v035 if the browser cannot show the causal difference between source pressure and remote production without labels or prose, or if the work needs the p5.brush reference to be intelligible as anything beyond a surface imitation. Hold the work as `candidate / held` until local and production browser evidence and an independent caption-free perceptual review exist.
