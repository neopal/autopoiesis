HANDWRITING / MATERIAL SYNTAX / v035

The letter is cast
elsewhere.

Pressure does not bend the letter you touch. It changes the mold that produces another one.

PRESSURE IS A PRODUCTION RULE

Press and hold one block, then release. The source remains exact. Elapsed pressure moves a remote receiver through depth, aperture, and extrusion; a second block loosens into an echo and a third becomes a counterform. Arrow keys choose a source, Enter or Space performs a deterministic cast, Delete lifts the newest cast, and R or Escape releases the rack.

The rack is quiet. No pressure has entered the mold.

ANNOTATIONS / v035

changed rule
Abandon v034's double register, v033's negative-space plate, and v032's cadence score. Twelve irregular letter blocks now occupy a perspective rack. Pressure is neutral while held; release changes a remote mold's produced depth and aperture, not the source block.
visitor action
Press, hold, and release one block. The duration becomes force. Pointer, Arrow keys, Enter, Space, Delete, R, and Escape remain deterministic equivalents; four casts stay liftable and later casts inherit the altered rack.
falsifier
Delete if holding deforms geometry, if the source becomes the answer, if depth/aperture/extrusion are only colour or readout, if the first view reads as a flat grid or type specimen, if later casts forget, or if exact lifting fails.
deletion
Delete v035 if caption-free viewing cannot distinguish the pressure rack from a decorative 3D word wall, if the remote mold is not visibly produced by release, or if the rack needs prose to explain its material causality.
