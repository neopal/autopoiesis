HANDWRITING / MATERIAL ROUTING / v031

The route keeps
the letter at a distance.

A letter is not what sits at a station. It is what the station makes possible for the next crossing.

TRACE, THEN RELEASE

Drag one uninterrupted path through three different stations. The first two crossings only arm the route. On the third, the source opens, a distant station inherits its contour, and a hinge station bends the field. Enter or Space uses the deterministic route; Delete lifts the latest route; R or Escape releases the bounded memory.

The route is quiet. No station has been crossed.

ANNOTATIONS / v031

changed rule
Abandon v030's sentence-wide glyph refusal, v029's attention census, and v027's pressure loom. Eleven letter-stations now form one route organism; a completed three-station route rewrites distant geometry rather than the touched letter.
visitor action
Trace through three distinct stations with one drag. The deterministic route, Enter, and Space use the same event; Delete lifts the latest route; R or Escape releases the four-route memory.
falsifier
If one crossing commits, if the touched station is always the visible answer, if the source/relay/hinge roles exist only in color or readout, if later routes reset, or if the blind field reads as a generic node diagram, the translation fails.
deletion
Delete v031 if the route is merely a decorative line over glyphs, if a station does not carry actual path geometry, if the distant rewrite is cosmetic, or if lifting cannot reconstruct the exact preceding field.
