# Handwriting v031 — The route keeps the letter at a distance.

## Hypothesis

If a letter is treated as a station in a route rather than as a character to be offered, then a completed crossing can change the production of distant letter-stations without making the touched station the answer.

## Changed rule

Abandon v030's sentence-wide refusal, v029's attention census, and v027's duration pressure. Eleven irregular letter-stations form one typographic route organism. A route is inert until it crosses three distinct stations; on release, the source station opens, a distant station inherits its contour, and a third hinge station bends the field.

## Visible consequence

The blind first view is a sparse SVG route chart of eleven oversized letter-forms and a thin connected field. After a valid route, actual station paths, positions, contours, roles, glyph inheritance, and connecting paths change. The first two crossings remain geometry-neutral. Later routes compound against the altered field, and the latest four routes can be lifted exactly.

## Interaction

Drag through three distinct stations in one uninterrupted route. Enter, Space, and the route control perform the deterministic equivalent. Delete or Backspace lifts the latest committed route. R or Escape releases the bounded route memory. The route itself is visible while it is being traced; no pointer hover is required to make the work meaningful.

## Cultural translation

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** Programmable drawing tools expose pressure, density, grain, and directional fields as a material engine: the instrument changes how a mark is produced rather than merely styling a finished shape.
- **Mutine translation:** Refuse brush appearance, watercolor, hatching, grain, and the source API. Translate material agency into route production: accumulated route load changes how later letter-stations are generated, while the visitor's local crossing is not itself the answer.
- **Visible consequence:** A completed route changes three actual station geometries and their connecting field; later routes inherit those changes.
- **Anti-copy:** No brush, watercolor, hatching, pressure mark, vector-field drawing, source palette, source composition, source code, API surface, or surface vocabulary is reproduced.

## Falsifier

Delete this direction if one crossing commits, if the touched station is always the visible answer, if source/relay/hinge roles are only color or readout, if later routes restart from the seed, or if lifting is not exact.

## Deletion condition

Delete v031 if the caption-free field reads as a generic node diagram, keyboard, or decorative SVG map rather than a singular typographic route organism.

## Direction consequence

This closes the recent sentence / word-field / pressure sequence and opens a route-as-language direction: handwriting is now a spatial production system in which the next letter is determined by a distant relation, not by a typed character or a local mark.
