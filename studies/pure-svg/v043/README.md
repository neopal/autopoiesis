# Pure SVG v043 — The loom spends the pressure.

## Hypothesis

If Pure SVG stops treating the visitor as someone who selects a body part or assembles a route, and instead makes the visitor supply an ordered crossing through a continuous material field, pressure can become a production rule for the next geometry. The work should read as a woven SVG object before it reads as a set of controls.

## Cultural translation

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** programmable drawing instruments make pressure, density, directional behaviour, and field logic participate in producing geometry rather than merely decorate a finished mark.
- **Mutine translation:** refuse brushes, watercolor, hatching, grain, palette, composition, source code, examples, and API surface. Translate material agency into a pressure loom: a visitor's ordered crossing through three zones is invisible and geometry-neutral until release, when the loom spends that pressure through the geometry of its own filled bands.
- **Visible consequence:** the blind view is an oblique field of eleven filled SVG bands, not chambers, holes, hinges, or a single contour. A valid release changes six or more band polygons' bend, thickness, and phase; successive passes alternate shear, split, buckle, and fold while retaining prior loads.
- **Falsifier:** if the crossing is painted, if geometry changes before release, if an incomplete or reversed pass commits, if pressure changes only colour or readout, or if the blind field reads as a generic linefield, the translation fails.
- **Anti-copy:** no p5.brush preset, brush appearance, watercolor, hatching vocabulary, grain, palette, composition, source code, API surface, or source imagery is reproduced.
- **Direction consequence:** closes Pure SVG's mass / contour / hinge / chamber sequence and opens a continuous material-agency direction: topology is no longer an object selected by the visitor but a field that spends an invisible load on its own geometry.

## Changed rule

An ordered crossing through zones 0, 1, and 2 is geometry-neutral. Only release after the full crossing commits a material pass. The pass is not drawn and does not answer at the pointer. It changes the generated filled bands across the loom as `pressure-shear`, `pressure-split`, `pressure-buckle`, or `pressure-fold`; four passes compound and can be lifted exactly.

This is a structural rupture, not a palette change:

- **Representation:** filled SVG bands replace the punctured mass, singular contour, paired hinges, and chamber polygons.
- **Composition:** an oblique woven field with a compression throat replaces the centered body, open register, and chamber cluster.
- **Encounter:** the viewer crosses three zones in order; no node is selected and no gesture trace remains.
- **Temporal behaviour:** pressure is spent through cumulative material states, so later loads inherit earlier deformation.

## Visible consequence

With labels, readout, controls, pressure zones, and prose hidden, the first view is a dark field of eleven overlapping filled bands with unequal edges, a central compression, and a pale internal selvedge. A full pass leaves no cursor trail. On release, the actual SVG `d` geometry of at least six bands changes. The first load shears the weave, the second splits its pressure, the third buckles it, and the fourth folds it. The quiet source and every lifted predecessor are deterministic.

## Interaction and replay

- Pointer/touch: press in the left pressure zone, cross the centre zone, continue to the right zone, and release.
- Keyboard: focus the artwork, press `ArrowRight` three times, then `Enter` or `Space`.
- Controls: `pass the pressure`, `lift latest`, `release loom`.
- Memory: four deterministic material passes compound. `Delete` lifts the latest pass. `Escape` or `R` releases to the quiet seed.
- Static blind preview: `?preview=1&static=1&blind=1` renders the four-pass state while hiding labels, readout, controls, zones, annotations, and caption.

## Deletion condition

Delete v043 if caption-free viewing cannot distinguish the pressure loom from v039–v042; if crossing changes geometry early; if an incomplete or reversed traversal commits; if pressure only changes colour, readout, or decoration; if the band field is merely a generic linefield; or if exact lifting fails.

## Critique handoff

The critic must inspect the blind loom first. Does the filled weave read as a produced material object rather than a diagram? Does the central compression make the bands feel constrained without becoming a decorative grid? Is the absence of the visitor's stroke legible as a rule, not a missing feature? Can the four material states be seen without labels? If not, this trial remains held or is deleted rather than explained into significance?
