# Pure SVG v041 — The hinge keeps two histories apart.

## Hypothesis

If Pure SVG stops making one body, one contour, or two margins carry the encounter and instead distributes nine paired joints across open ground, a relation can become a route rather than a mark. The work should read as sparse topological notation before it reads as a node chart: the selected hinges are a temporary offer, not the visible answer.

## Changed rule

v041 breaks v040's punctured mass, v039's singular winding contour, and v038's split-margin counterfold. The blind view is nine unequal paired hinge paths arranged around a broken diagonal channel. Selecting three distinct hinges is geometry-neutral. Only after the third hinge is selected can a verdict be committed; the three selected hinges remain exact while three *other* hinges receive remote roles: one turns, one pins its throat, and one slips its registration. Four route verdicts compound and can be lifted exactly.

The selected reference is [little-critters](https://github.com/GordenSun/little-critters). The source makes situated reciprocal attention possible: proximity lets a population answer the visitor without a dashboard. Mutine refuses animals, eyes, character design, paper scenes, head-turning, source palette, source composition, source code, examples, API surface, and surface vocabulary. It translates only the mechanism into Pure SVG: a route of separate hinges can be witnessed collectively, but the register answers at three unselected joints.

## Visible consequence

With labels and controls hidden, the first view is a sparse dark field of nine pale paired joints. They are unequal, slightly rotated, and separated by an open diagonal channel; there is no enclosing body, filled mass, grid, or single spine. A valid verdict changes the actual `d` of three remote SVG paths: one lengthens and leans, one narrows its gap and thickens, and one moves and rotates. The selected route stays path-exact. Four verdicts remain visible in the remote grammar.

## Interaction and state

- Click or touch three distinct hinges; each selection is a route offer and does not change path geometry.
- Press Enter or Space, or choose `commit verdict`, to commit the route. An incomplete route is refused.
- ArrowRight selects the next hinge in the deterministic route; Enter completes and commits it. This is the keyboard-equivalent encounter.
- Delete lifts the latest verdict; Escape or `R` releases the bounded register.
- The same seed and route sequence produce the same node paths and signatures.
- `?preview=1&static=1&blind=1` keeps only the final hinge register visible for caption-free inspection.

## Direction consequence

This closes Pure SVG's heavy-body / singular-contour / margin-fold family and opens a distributed hinge-register direction. Representation changes from compound body paths to nine produced paired paths. Composition changes from mass, void, and margins to sparse open ground and a broken channel. The viewer task changes from choosing an absence or drawing a turning path to assembling a three-node relation. Temporal behavior changes from one local selection with a remote answer to a collective route whose verdict is produced at three joints the visitor did not select.

## Falsifier

Delete v041 if the blind register reads as a generic node diagram, fold diagram, route map, or decorative mark set; if selecting a hinge changes geometry; if one selected hinge answers itself; if remote turn, pin, or register roles are only colour, labels, or readout; if later verdicts reset; or if exact lifting fails.

## Deletion condition

This remains candidate / held until independent caption-free comparison proves that the sparse hinge register is perceptually distinct from v038–v040 and that the three-node route feels like a causal relation rather than a button-controlled multi-morph.

## Critique handoff

The critic must inspect the blind register first. Does it read as nine joints holding a collective tension rather than a diagram of points? Is the empty diagonal channel a compositional pressure, not an illustration? Can a visitor understand that the route stays exact while the verdict arrives at unselected hinges? Does the work ask to be encountered differently from the recent body, contour, and fold grammars?
