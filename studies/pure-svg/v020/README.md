# Pure SVG v020 — The contour chooses a second mouth.

## Hypothesis

If a formal constraint is made visible as a changed contour and a new negative room, a small SVG can behave like a strange animal without drawing an animal or arranging a collection of plates.

## Changed rule

The previous Pure SVG works used local attention, radial occlusion, or a set of disjoint compound plates. v020 replaces those grammars with one large closed compound contour. The visitor chooses one of six named clauses. The chosen clause pulls an actual contour vertex inward while a second place receives a new even-odd pocket. The answer is therefore structural and displaced: the contour changes where it is touched and where it is not.

## Visible consequence

The blind first view is a singular, pale-ground compound silhouette with a blue contour echo, not a radial valve, route, loop, or plate board. After a rule change, the silhouette bends at one clause, a real negative pocket appears elsewhere, and the orange contour makes the displaced answer legible without a label. Four events are replayable; lifting the latest reconstructs the exact preceding geometry signature.

## Interaction

- Pointer movement and pointer taps are deliberately refused; the canvas has no location-based selector.
- Choose a clause, then use `change rule`, Enter, Space, `C`, or keys `1`–`6` to commit one bounded contour reply.
- Delete, Backspace, or `lift latest` removes only the latest rule.
- `R` or `release` restores the quiet contour.
- `S` downloads the currently rendered inline SVG.

## Falsifier

The translation fails if choosing a clause changes only colour, if the pocket is a decorative overlay rather than an even-odd cut, if the contour does not bend at the chosen clause, if pointer taps commit, or if the blind image reads as an annotated diagram, radial chart, or plate collection.

## Deletion condition

Delete v020 rather than polish it if the caption-free image cannot be distinguished from v019's radial valve or v018's disjoint plates, or if lifting the latest rule does not restore the exact preceding signature.

## Cultural translation

Reference: [little-critters](https://github.com/GordenSun/little-critters).

Observed mechanism: situated code-drawn agents respond to proximity by changing attention and looking back, making the visitor part of a reciprocal relation rather than a controller of a dashboard.

Mutine translation: remove the animals and the look-back scene. In Pure SVG, a selected clause is a situated formal witness. It makes the inhabited contour answer from elsewhere: one actual outer vertex folds inward and a new compound-path pocket appears at a displaced clause. Attention is translated into a constraint relation, not an animated face.

Visible consequence: the blind field is one irregular compound contour; after a clause is chosen, a changed silhouette and an actual negative pocket appear in different parts of the same body.

Falsifier: if a clause only changes a marker, if the negative pocket is not carried by the compound path, or if the relation is invisible without the caption, the translation fails.

Anti-copy statement: no animals, eyes, characters, paper scene, source palette, source composition, or head-turning surface vocabulary is reproduced.

Direction consequence: closes Pure SVG v017's remote relay, v018's disjoint negative alphabet, and v019's radial pressure valve. It opens a constraint-and-topology direction in which the work is one body with a non-local rule rather than a network of objects or a pressure stack.
