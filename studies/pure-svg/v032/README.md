# Pure SVG v032 — The room closes around a quiet facet.

## Concept

The first view is a constellation of twelve detached cut facets around one shared silence. It is not a line, a closed contour, a route, or a grid to decode: each shape is a separate decision, and the gaps between them are the authored subject.

The encounter is a closed winding. The visitor draws through the room rather than selecting an object. An open or narrow offer refuses. When the winding encloses enough field, the loop disappears and the code reorients four actual facet paths while a fifth facet withdraws. Three enclosures remain in bounded memory; lifting the latest reconstructs the exact preceding constellation; release returns to the deterministic seed.

## Radical progression

v032 breaks v031's articulated line, v030's singular negative-space contour, and v029's woven compound bodies. The representation switches to detached planar facets with no shared path. The encounter switches from two separated attentions and press-drag crossing to a closed loop whose *enclosure* is the event. The viewer's task is no longer to offer a place or carry a relation between places; it is to make a room and then notice which remote facets answer.

## Changed rule

A closed winding over the shared void is parsed as a field, not retained as a mark. Its winding, area, and current memory select a pivot, four answering facets, and one quiet facet. Those roles alter the actual SVG paths. The next enclosure starts from that altered constellation.

## Cultural translation

- **Reference:** [little-critters](https://github.com/GordenSun/little-critters)
- **Observed mechanism:** situated code-drawn agents respond to pointer proximity with legible attention and reciprocal looking, making the visitor part of a social field without a dashboard.
- **Mutine translation:** refuse animals, eyes, characters, paper, and head-turning imagery. In Pure SVG's cut-facet vocabulary, attention becomes enclosure: only a closed field over the shared silence can make several distant facets answer collectively, while one facet becomes quiet.
- **Visible consequence:** the blind first view is a detached constellation, not a population or contour. After a valid loop, the gesture vanishes; four actual facet geometries reorient and a fifth withdraws. Later loops inherit the changed arrangement.
- **Falsifier:** if an open or narrow gesture writes, if the loop remains as a decorative trace, if the result changes only colour or labels, if fewer than five actual paths change, if later enclosures restart from seed, or if the blind field reads as another line, ring, graph, or interface, the translation fails.
- **Anti-copy:** no animals, eyes, character designs, paper scene, source palette, source composition, source code, API surface, or head-turning image is reproduced.
- **Direction consequence:** closes the line / cavity / remote-reply sequence and opens a cut-field direction: relation is represented by enclosure and distributed reorientation rather than by objects looking back or paths answering.

## Hypothesis

If attention is represented as a closed field that disappears while its remote consequences remain, a viewer should perceive a changed constellation rather than a selected object with feedback decoration.

## Falsifier and deletion condition

Delete v032 if the blind view reads as a generic array, if open or thin gestures commit, if the loop is the visible artwork rather than a causal instrument, if the five roles do not alter real SVG paths, if later loops forget prior changes, or if lifting cannot restore the exact preceding constellation.

## Critique position

This is a **candidate / held** work. The engine is deterministic, closed-loop validation is structural, the gesture is not retained after commit, and bounded undo is testable. The unresolved artistic question is whether detached facet composition can carry authored presence without becoming an icon sheet, interface, or decorative array.
