# Pure SVG v047 — The glyph answers after you leave.

## Hypothesis

If Pure SVG leaves v044's skin, v045's counterfield register, and v046's pressure block behind, an unfilled line-built glyph can make attention visible as a topological relation rather than as a selected object. The work should read as one strange syntax suspended in negative space before it reads as a route diagram.

## Last-three refusal and radical rupture

The last three SVG works repeated a filled body or field, a central or distributed mass, and a gesture whose consequence was a changed elsewhere or cross-section:

- v044: an ordered escape split an untouched aperture in a closed skin;
- v045: a two-site handoff opened an untouched counterform in a tile register;
- v046: an alternating held pulse produced strata inside a singular block.

v047 breaks those invariants. It changes the representation from filled compound geometry to stroke-only SVG syntax, the composition from body/register/block to one edge-to-edge diagonal spine, and the encounter from selection, hold, and escape to proximity, duration, and departure. The visitor does not write a mark: absence completes the event.

## Cultural translation

- **Reference:** [little-critters](https://github.com/GordenSun/little-critters)
- **Observed mechanism:** situated code-drawn agents make proximity legible as reciprocal attention; a local relation changes how an agent looks back without a dashboard.
- **Mutine translation:** refuse animals, eyes, head-turning, paper scenes, source palette, source composition, source code, examples, and API surface. Translate situated reciprocity into one continuous SVG syntax: a visitor's dwell arms a port, departure lets a deterministic remote port answer through a new branch and a bent spine segment, while the looked-at source remains exact.
- **Visible consequence:** the blind view is one unfilled angular glyph with five ports and a single diagonal spine. A valid departure changes a remote port and one cubic segment; four replies compound without drawing the visitor's path.
- **Falsifier:** if a quick glance commits, if staying does, if the source changes, if the remote branch is only a halo/readout, if repeated attention resets the glyph, or if the first view reads as a generic route diagram, the translation fails.
- **Anti-copy:** no animals, eyes, head-turning scene, character design, paper style, source palette, source composition, source code, examples, API surface, or source imagery is reproduced.
- **Direction consequence:** closes Pure SVG's recent filled-object and remote-counterform grammar and opens absence as a topological material: the work changes only when the visitor's presence is no longer there.

## Changed rule

Proximity begins a look but does not alter geometry. A visitor must remain near one angular port for 560ms, then leave. Only that sequence commits a reciprocal reply: a deterministic different port gains a branch and the single spine segment between the relation bends. The looked-at port stays exact. Four replies compound and can be lifted exactly.

This is a structural rupture, not a palette change:

- **Representation:** stroke-only SVG paths replace the filled skin, tile counterforms, and block strata.
- **Composition:** one diagonal open syntax replaces the perimeter body, distributed register, and central weight.
- **Encounter:** approach, wait, and departure replace click handoff, rim escape, and alternating hold.
- **Temporal behaviour:** a provisional look becomes a committed topology only after absence; staying is inert.
- **Viewer task:** notice relation and consequence after leaving rather than select, cross, or press a material bank.

## Visible consequence

With labels, readout, controls, annotations, and prose hidden, the first view is one angular cream line suspended across a dark ground, interrupted by five blue ports. After a valid departure, a remote port becomes coral and branches, while one cubic span of the line bends away from its quiet route. Four different replies remain visible and cumulative.

## Interaction and replay

- Pointer/mouse: move onto a port, wait, and leave it or the field. A quick glance is refused.
- Touch: press a port, keep contact for the threshold, and lift. The control and keyboard paths provide an equivalent deterministic route.
- Keyboard: focus the artwork, use `ArrowLeft` or `ArrowRight` to choose a port, then `Enter` or `Space` to commit the same dwell-and-departure event.
- Controls: `attend, then leave`, `lift latest reply`, `release the glyph`.
- Memory: four reciprocal replies compound. `Delete` lifts the latest reply. `Escape` or `R` releases to the quiet seed.
- Static blind preview: `?preview=1&static=1&blind=1` renders the four-reply state while hiding labels, readout, controls, annotations, and caption.

## Deletion condition

Delete v047 if caption-free viewing cannot distinguish the reciprocal glyph from v044–v046; if a quick glance or staying commits; if the source port changes; if the remote branch is cosmetic; if later replies reset; if the first view reads as a generic route diagram; or if exact lifting fails.

## Critique handoff

The critic must inspect the blind glyph first. Does the single stroke carry a strange syntax without captions? Is the remote reply materially visible at phone size? Does leaving feel like a causal absence rather than a delayed button? Do four branches remain a composed form rather than a history overlay? If not, hold or delete the trial instead of explaining it into significance.
