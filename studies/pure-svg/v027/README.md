# Pure SVG v027 — The weight finds a seam.

## Concept

A dark stratigraphic field holds eleven long, irregular bands. They do not illustrate a landscape or a chart; they are a single material system whose seams carry its identity. A visitor punctures the field with pressure. The pointer is only the entry vector. The SVG material calculates which seam is weakest, then slips the stack around it. The next puncture inherits that altered resistance.

The visual story is not a mark appearing where a hand touched. It is a compact material event: a seam gives way, a fault crosses the whole stack, and the work keeps the altered geometry. Four slips remain in bounded memory. Lifting the latest reconstructs the exact preceding stack; release returns to the quiet seed.

## Changed rule

v027 abandons v024's compound witness-knot, v025's single open contour and drawn route, and v026's dispersed population of autonomous fragments. The representation changes to eleven continuous horizontal strata with stepped, uneven edges. The encounter changes from witnessing, departure, or travel to a single pressure puncture. The causal relation is inverted: the pointer does not select the visible place of change. A resistance field chooses the weakest seam, and the whole stack re-forms around that seam.

## Cultural translation

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** programmable pressure, density, grain, and vector fields participate in producing geometry rather than decorating finished geometry.
- **Mutine translation:** refuse brushes, watercolor, hatching, source palette, examples, and API. Make pressure an entry vector into a Pure SVG material: the material chooses its weakest seam, slips the complete stratified stack, and carries the changed resistance into the next event.
- **Visible consequence:** the blind field is eleven long SVG strata, not a mark field or tile scatter. After a puncture, actual path silhouettes bend across the stack at a calculated seam; later punctures choose against the inherited slips.
- **Direction consequence:** this closes the discrete-population and single-boundary sequence and opens a constraint-as-material direction where SVG economy is expressed through a small number of long, load-bearing paths.
- **Anti-copy:** no p5.brush brushes, watercolor surface, hatching vocabulary, source palette, source composition, source examples, or API surface is reproduced.

## Falsifier

The translation fails if pressure changes only a cursor, colour, readout, or local dot; if the pointer location directly selects the seam; if fewer than five strata change; if later punctures ignore prior slips; or if the blind field reads as a generic chart, waveform, or decorative polygon stack.

## Deletion condition

Delete v027 if the caption is required to discover that the material chooses the fault, if the bands read as a chart rather than a constrained substance, if the visible event is only a global transform, or if lifting the latest slip does not restore the exact prior geometry.

## Critique position

This is a **candidate / held** work. The causal engine is deterministic and the interaction is structural. The unresolved artistic question is perceptual: with labels, controls, readout, annotations, and editorial furniture removed, does the stack read as a material system with inherited resistance, or merely as an attractive stratified diagram?
