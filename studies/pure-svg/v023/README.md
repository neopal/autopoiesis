# Pure SVG v023 — The sheet refuses a quick touch.

## Hypothesis

If material resistance is translated into a time threshold instead of a brush surface, one economical SVG sheet can make duration alter topology: staying long enough seals the held void, opens another void elsewhere, and leaves that changed relation for the next hold.

## Changed rule

v023 abandons v020's singular compound contour, v021's pressure ribbon, and v022's six-face folding object. The work is one monolithic SVG sheet with five negative chambers inside an even-odd compound path. A press-and-hold above 520ms is the only committing gesture. The held chamber contracts and seals, a non-local chamber expands and opens, and a third chamber shifts as a material bridge. The memory of those voids is inherited by later holds.

## Visible consequence

The blind first view is a heavy warm sheet punctured by five dark chambers, not a line, ribbon, faceted object, or polygon diagram. After a committed dwell, the held void visibly closes while another void elsewhere opens. The image does not need a connecting line or explanatory label: the changed negative spaces are the event. Four dryings replay deterministically, and lifting the latest reconstructs the exact prior geometry signature.

## Interaction

- Hold a chamber for at least 520ms, then release. Time spent is the material input; a short tap and short hold are refused.
- The `dry this chamber` control, Enter, and Space commit the same deterministic 620ms drying event.
- Keys `1`–`5` choose a chamber without writing history.
- Delete, Backspace, or `lift latest` removes only the latest drying.
- `R` or `release` returns to the quiet sheet.
- `S` downloads the currently rendered inline SVG.

## Falsifier

The translation fails if the hold only changes a timer or colour, if the held and remote chamber silhouettes stay fixed, if a tap or short hold commits, if later holds ignore the altered topology, or if the blind image reads as a labelled diagram rather than one material sheet.

## Deletion condition

Delete v023 rather than polish it if a caption-free viewer cannot distinguish a monolithic sheet from a decorated plate, if sealing and opening are not legible in the voids, if the dwell threshold is cosmetic, or if lifting the latest drying does not restore the exact prior signature.

## Cultural translation

Reference: [p5.brush](https://github.com/acamposuribe/p5.brush).

Observed mechanism: drawing tools treat pressure, density, grain, and directional fields as programmable material forces; material changes how geometry is produced and remembered rather than decorating finished geometry.

Mutine translation: refuse p5.brush's brush surface, hatching, watercolor, and API. Translate resistance into a dwell threshold inside Pure SVG: time held above 520ms is a material force that seals one negative chamber, opens another elsewhere, and slightly shifts a third. The altered topology becomes material memory for the next hold.

Visible consequence: the blind field is one heavy compound sheet with five voids. After a long hold, one void narrows and another expands in their actual SVG silhouettes; no brush mark or overlay carries the event.

Falsifier: if dwell changes only a readout, color, or cursor, if the remote opening is not actual path geometry, if short touches commit, or if the next hold ignores the changed voids, the translation fails.

Anti-copy statement: no p5.brush brushes, watercolor appearance, hatching vocabulary, palette, API surface, source examples, or source composition is reproduced.

Direction consequence: closes the line-like pressure and faceted-body sequence of v019–v022 and opens a topology-as-material direction in which time changes the ontology of one SVG sheet's negative space.
