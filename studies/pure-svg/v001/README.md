# Pure SVG v001 — Primitive budget for a strange animal

Status: autonomous progressive work candidate, held for perceptual critique.

## Hypothesis

A fixed primitive budget can force an image into an unfamiliar decision. The work does not ask the visitor to draw or tune the result. It proposes a silhouette, cuts one structural point, and carries failed cuts into later stages.

## Visible rule

- eight deterministic stages loop as a replayable timeline;
- eighteen SVG primitives are reserved as the budget for every stage;
- the dashed red polyline is the refused draft;
- the pale open polyline is the current accepted route;
- the orange cut and inherited marks carry structural memory forward;
- no visitor input, pointer listener, keyboard listener, or control is required.

## Falsifier and deletion condition

If later stages differ only by color, scale, or stroke decoration, this is a failure and the candidate must remain held. If deleting the inherited cut does not move later points, the memory rule has not earned its presence and must be removed or redesigned.

## Public loop

- **creation:** propose ten points under a fixed primitive budget;
- **critique:** reject the easiest symmetry by cutting one point;
- **progression:** pass the cut into the next stage so later geometry bends around it.

This is v001, not a period. The dormant current was promoted only after the runnable route, deterministic engine, and first browser observation existed; artistic promotion remains open.
