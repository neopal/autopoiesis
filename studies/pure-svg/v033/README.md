# Pure SVG v033 — The sheet refuses the local mark.

## Hypothesis

If material resistance is made into a causal rule rather than a surface effect, a pure SVG work can show pressure changing the geometry that receives a later pressure. The image should feel like one compound body with an internal fault system, not a collection of objects waiting for clicks.

## Changed rule

v033 leaves v032's detached facet constellation, v031's articulated line, and v030's cavity contour. It changes the representation to one native SVG compound sheet with an actual even-odd rift and seven internal faults. A bounded hold is not kept as a mark and does not answer locally. The code redistributes it into three remote material roles: the offered fault recedes, a non-local counterweight gathers, and a third fault keeps a scar. The next pressure begins from that altered sheet.

## Visible consequence

The blind first view is a single asymmetrical slab with a diagonal internal rift, a seam, and seven small fault bodies. A valid pressure offer changes the compound sheet path and at least three fault geometries. Weak and over-held offers leave the sheet exact. Later pressure events inherit the altered rift and faults; Delete reconstructs the exact preceding geometry.

## Interaction and state

- Pointer/touch down starts a hold; release measures duration.
- Holds shorter than 140ms or longer than 720ms are refused.
- Enter, Space, and `hold the sheet` use deterministic bounded pressure offers.
- Delete lifts the latest pressure event; Escape or `R` releases the bounded ledger.
- Four events are retained. The same seed and same offer sequence produce the same SVG path signatures.
- `?preview=1&static=1&blind=1` keeps only the artwork visible for caption-free inspection.

## Cultural translation

The reference is [p5.brush](https://github.com/acamposuribe/p5.brush). Its observed mechanism is that pressure, density, grain, and directional fields participate in producing geometry rather than decorating finished geometry. Mutine refuses its brushes, watercolor, hatching, grain, palette, composition, code, examples, and API surface. The translation is material resistance inside Pure SVG: a timed pressure offer is absorbed as remote geometric redistribution in one compound sheet. The translation fails if the result still reads as lines with a brush texture, if pressure only changes a highlight/readout, if the local point remains the answer, or if later events restart from the seed.

## Falsifier

Delete the direction if a short or over-held hold commits; if the touched fault is always the visible answer; if the sheet path does not change; if fewer than three actual fault geometries change; if the rift is only decoration; if the next event forgets prior pressure; if exact lifting fails; or if the blind field reads as a generic contour, diagram, or interface.

## Deletion condition

This is a candidate / held work until a caption-free perceptual comparison proves that the compound sheet reads as a distinct material body rather than a refined version of the recent SVG line, contour, or facet grammar.

## Critique handoff

The critic must inspect the blind field first. Ask: can the viewer see one resistant sheet before reading seven faults? After a valid hold, can they find a receding place, a remote weight, and a third scar in actual geometry? Does the timing-based encounter feel like pressure rather than a hidden button? Is the first render materially different from v030, v031, and v032 before the caption is read?
