# Pure SVG v045 — The witness is absent elsewhere.

## Hypothesis

If Pure SVG leaves the single skin, band field, and chamber body behind, a sparse register of unequal counterforms can make the visitor's attention behave like a relation rather than a mark. The work should read as a field of withheld witnesses before it reads as a set of clickable tiles.

## Cultural translation

- **Reference:** [little-critters](https://github.com/GordenSun/little-critters)
- **Observed mechanism:** situated code-drawn agents make proximity legible as reciprocal attention; a local relation changes how an agent looks back without a dashboard.
- **Mutine translation:** refuse animals, eyes, head-turning, paper scenes, source palette, source composition, source code, examples, and API surface. Translate situated reciprocity into a two-site handoff: the first tile witnesses, the second receives attention, and only a completed handoff opens a third untouched counterform.
- **Visible consequence:** the blind view is a sparse field of fourteen unequal SVG tiles with small counterforms. A valid handoff leaves source and observer exact while a remote tile gains a larger absence, a displaced corner, and an actual fracture path; four openings compound.
- **Falsifier:** if a click edits the touched tile, if the receiver is only a halo/readout, if every handoff chooses the same receiver, or if the field reads as a generic grid, the translation fails.
- **Anti-copy:** no animals, eyes, head-turning scene, character design, paper style, source palette, source composition, source code, examples, API surface, or source imagery is reproduced.
- **Direction consequence:** closes Pure SVG's skin / loom / chamber sequence and opens a counterfield register: economy becomes a social constraint in which a relation is visible only as a missing part of a third form.

## Changed rule

A first attention is held without geometry. A second, distinct attention completes a handoff. Only the commit spends the relation by opening a remote untouched tile; the source and observer retain exact paths. Four handoffs compound and can be lifted exactly.

This is a structural rupture, not a palette change:

- **Representation:** sparse compound SVG tiles with internal counterforms replace the filled skin, pressure bands, and faceted chamber body.
- **Composition:** fourteen unequal islands around an unclaimed centre replace one membrane, one loom, or one heavy body.
- **Encounter:** two discrete situated attentions replace the drag-to-rim escape and ordered material crossing.
- **Temporal behaviour:** memory is a growing set of remote openings; later handoffs inherit already altered receivers without rewriting the visited tiles.

## Visible consequence

With labels, readout, controls, annotations, and prose hidden, the first view is a warm paper-like field of irregular coloured tiles. A valid handoff creates a true counterform expansion and fracture in an untouched tile. No path connects the hand; the event is legible only as a changed elsewhere. Four settled openings remain visible.

## Interaction and replay

- Pointer/touch: click or tap one tile, then click or tap a distinct tile to hand attention.
- Keyboard: focus the artwork, press `ArrowRight` to choose the first site, `ArrowRight` again to choose the second, then `Enter` or `Space` to commit.
- Controls: `hand attention`, `lift latest`, `release register`.
- Memory: four deterministic remote openings compound. `Delete` lifts the latest opening. `Escape` or `R` releases to the quiet seed.
- Static blind preview: `?preview=1&static=1&blind=1` renders the four-opening state while hiding labels, readout, controls, annotations, and caption.

## Deletion condition

Delete v045 if caption-free viewing cannot distinguish the counterfield register from v042–v044; if a touched tile changes; if two sites do not matter; if the remote opening is cosmetic; if later openings reset; if the blind image reads as a generic tile grid; or if exact lifting fails.

## Critique handoff

The critic must inspect the blind register first. Does the empty centre and unequal counterforms carry the composition without explanation? Is the remote opening materially visible at phone size? Does the two-site handoff feel like a relation rather than a hidden button? If not, hold or delete the trial instead of explaining it into significance.
