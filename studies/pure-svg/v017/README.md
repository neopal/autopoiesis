## Creative record

- **Hypothesis:** if a strange SVG can be a closed route rather than a body, being seen can make it remember the wrong neighbour instead of answering the visitor.
- **Repeated gesture refused:** v014 used horizontal gates, v015 moved owned voids between territories, and v016 made one articulated body sacrifice a joint. v017 changes the representation to one irregular closed loop and changes the viewer task to a two-point relay.
- **Changed rule:** pointer movement only locates a seal. A first point arms a source; a second, non-identical point commits a bounded relay: the source's actual local link disappears and a distant wrong-return link joins the two chosen seals. Later relays operate on the already cut loop.
- **Visible consequence:** the blind first encounter is one sealed, angular return around a warped central void. After a committed relay, a real seam is absent, a source seal narrows, and an orange cross-route carries the relation to a distant seal.
- **Deterministic state:** `SEED = 0x53564747`; `STAGES = 16`; `PRIMITIVE_BUDGET = 12`; memory is capped to four relays. The timeline uses four fixed distant pairs.
- **Interaction:** click one seal, then another. Same-seal taps and drags are refused. Enter or Space commits the next deterministic pair; Delete/Backspace lifts the latest relay; R or release returns to the seeded sequence.
- **Falsifier:** hide the labels, readout, controls, selection ring, and prose. If the viewer cannot find the missing local link and the new distant return in the loop itself, the translation fails.
- **Deletion condition:** delete v017 if the cut is only a coloured sticker, if the wrong return is only a glow or marker, if same-point taps commit, if dragging becomes the hidden control, or if undo does not restore the exact preceding topology.
