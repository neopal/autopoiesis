# Pure SVG v048 — The hole changes sides.

## Hypothesis

If Pure SVG leaves v045's counterfield register, v046's pressure block, and v047's reciprocal line glyph behind, a single compound SVG path can make winding itself into a material rule. The first view should read as a heavy, asymmetrical seal with three real apertures before it reads as an interaction surface.

## Last-three refusal and radical rupture

The last three SVG works repeated a filled object or line field, a composed centre or distributed register, and an interaction whose consequence arrived at a remote branch, receiver, or cross-section:

- v045: two situated attentions opened a third untouched counterform in a tile register;
- v046: an alternating held pulse produced strata inside a central block;
- v047: a timed look and departure bent a line spine and opened a remote branch.

v048 breaks those invariants. It moves from multiple visible parts or open strokes to one compound filled path governed by non-zero winding. It moves from a field, block, or diagonal route to a large centred seal with three apertures. It changes the encounter from hold, attend, or wait-and-leave to a continuous draw across the form. It changes time from additive remote memory to a parity rule: each accepted crossing flips the orientation of the next aperture and creases the enclosing contour. Four inversions compound, but the work does not paint a history trail over the object.

## Cultural translation

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** p5.brush treats drawing tools, pressure, directional behaviour, fills, and vector fields as a programmable material engine that changes how geometry is produced rather than decorating a finished mark.
- **Mutine translation:** refuse brush presets, watercolor appearance, hatching, grain, source palette, source composition, source code, examples, and API surface. Translate material production into SVG winding: a continuous gate-to-gate draw is accepted only in the seal's clockwise order, and the accepted event reverses the next aperture's contour orientation while creasing the outer path that contains it.
- **Visible consequence:** the blind view is one filled compound SVG seal with three angular apertures. A valid crossing turns one aperture from absence to mass by changing the generated compound path itself; the outer silhouette also takes a small structural crease. Four inversions remain visible as topology, not as a gesture overlay.
- **Falsifier:** if a short trace, a same-gate loop, or a counter-clockwise jump changes the seal; if only stroke, colour, readout, or labels change; if the aperture does not become materially filled/empty; or if later inversions restart the form, the translation fails.
- **Anti-copy:** no brush preset, watercolor, hatching vocabulary, grain treatment, source palette, source composition, source code, examples, API surface, or source imagery is reproduced.
- **Direction consequence:** closes Pure SVG's recent social attention, pressure, and reciprocal absence sequence and opens a topology-first period in which the viewer is allowed to change what counts as a hole, not where a response appears.

## Changed rule

A draw starts only at one of three gates. The visitor must cross the seal and release at the next gate clockwise. A short trace, a same-gate loop, or a counter-clockwise jump is refused. The accepted event flips the winding of the next aperture and slightly re-produces the outer contour around that aperture. The action is a construction rule: the path data changes, not a decorative mark placed on top. Four inversions compound and `Delete` rebuilds the exact preceding topology.

This is a structural rupture, not a palette change:

- **Representation:** one filled non-zero compound path replaces tiles, strata, and stroke-only syntax.
- **Composition:** a single large seal replaces the distributed register, central pressure block, and edge-to-edge spine.
- **Encounter:** continuous drag through the object replaces attention, sustained pressure, and departure.
- **Temporal behaviour:** accepted events toggle winding parity and preserve a changed contour; memory is topological, not additive annotation.
- **Viewer task:** trace a permitted route through the object and notice that a hole can become matter.

## Visible consequence

With labels, readout, controls, annotations, and prose hidden, the first view is a warm field carrying one dark, angular seal with three irregular apertures and a restrained pale crease. A valid clockwise crossing reverses one actual aperture contour, so the negative space becomes filled mass while a local outer edge shifts. Four events produce a changed silhouette and a different distribution of holes. Nothing draws the pointer path into the final image.

## Interaction and replay

- **Pointer/mouse:** press a gate, drag across the seal, and release on the next clockwise gate. The path must cross the middle of the form.
- **Touch:** use the same press-drag-release gesture; no hover is required.
- **Keyboard:** focus the artwork; use `ArrowLeft`/`ArrowRight` to choose a gate, `Enter` or `Space` to arm a draw, use the arrows again to choose the next gate, and press `Enter` to commit. The same order rule is used.
- **Controls:** `draw the next seam`, `lift latest inversion`, `release the seal`.
- **Memory:** four winding inversions compound. `Delete` lifts the latest inversion. `Escape` or `R` releases to the quiet seed.
- **Static blind preview:** `?preview=1&static=1&blind=1` renders the four-inversion state while hiding labels, readout, controls, annotations, and caption.

## Deletion condition

Delete v048 if caption-free viewing cannot distinguish the winding seal from v045–v047; if a short or counter-clockwise gesture commits; if the actual compound path does not change; if an aperture only changes colour; if later inversions reset prior topology; if the blind form reads as a generic logo, pressure diagram, or route map; or if exact lifting fails.

## Critique handoff

The critic must inspect the blind seal first. Does the object read as a strange topological thing before it reads as a puzzle? Is the first aperture-to-mass change visible at phone size? Does the draw feel like crossing a material constraint rather than activating a button? Does four-event parity produce a composed object rather than a history overlay? If not, hold or delete the trial instead of explaining it into significance.
