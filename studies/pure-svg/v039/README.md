# Pure SVG v039 — The contour refuses to close.

## Hypothesis

If Pure SVG stops presenting a field of independent forms and instead gives one compound contour a memory of turned pressure, a failed closure can become a visible change in winding rather than a copied gesture. The visitor should see one body keep its refusal, not a new mark appear.

## Changed rule

v039 abandons v038's split-margin counterfold, v037's cut-cell vacancy, and v036's open filament organism. The blind view is one compound inline SVG contour with a deep interior, a narrow gap, and no cells, agents, margins, or separate folds. A straight offer is flat and refused. A bounded sweep with a real turn is accepted as a closure attempt: the gesture disappears, one contour path is regenerated with a new winding and gap, and the body remains singular. Four turns compound and can be lifted exactly.

The selected reference is [p5.brush](https://github.com/acamposuribe/p5.brush). Its observed mechanism is that pressure, direction, density, and fields participate in producing geometry rather than decorating a finished mark. Mutine refuses brushes, watercolor, hatching, grain, source palette, source composition, source code, examples, and API surface. It translates the mechanism into a Pure SVG rule: a turned sweep changes the production of one compound path, so material tension becomes topology-like path deformation without a brush surface.

## Visible consequence

The caption-free first view is a single large winding contour in open ground. The only major object has an interior absence and a directional slit; it is not a cell constellation, route bundle, score, or two-column diagram. During interaction a dotted temporary turn is visible and then vanishes. A valid release changes the actual `d` of one SVG path: the gap migrates, the interior tightens, and the outer contour takes a new lean. Four changes remain in the same body.

## Interaction and state

- Press and drag through at least three points so the sweep contains a turn, then release.
- A one-edge/straight sweep, short sweep, long sweep, or incomplete sweep is refused without changing the compound contour.
- Enter, Space, and `try a turn` use deterministic turned sweeps at fixed positions.
- Delete lifts the latest closure attempt; Escape or `R` releases the bounded memory.
- Four turns are retained. The same seed and same sweep sequence produce the same path signature.
- `?preview=1&static=1&blind=1` keeps only the final singular contour visible for caption-free inspection.

## Direction consequence

This closes Pure SVG's proximity-tour / open-filament / counterfold family and opens a singular-contour direction. The current changes representation from a population of forms to one compound path, changes composition from distributed field to one body and one interior absence, changes the viewer task from offering or touring to making a turn, and changes temporal behavior from remote role assignment to accumulated winding. The next mutation should not polish this ring: it must either fracture the one-body invariant or abandon the contour medium.

## Falsifier

Delete v039 if the blind object reads as a generic logo, ring, polished ornament, or gesture diagram; if a straight sweep commits; if the pointer trace survives as the artwork; if the visible change is only colour, labels, or readout; if the path does not change at the contour's gap and interior; if later turns reset; or if exact lifting fails.

## Deletion condition

This remains candidate / held until an independent caption-free comparison proves that the singular contour is perceptually distinct from v036–v038 and that a turned sweep feels like a causal refusal rather than a disguised button, logo, or drag affordance.

## Critique handoff

The critic must inspect the blind field first. Ask: does the object read as one path under remembered tension rather than a logo? Is the interior absence active? Can a viewer see the old turn has disappeared while the contour keeps its consequence? Does the work ask to be encountered differently from the recent organism, cut-cell field, and counterfold field?
