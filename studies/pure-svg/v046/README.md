# Pure SVG v046 — The weight is made by waiting.

## Hypothesis

If Pure SVG leaves the recent tile field, topology skin, and traversed band field behind, a singular pressure block can make material resistance visible as a rule for producing the next cross-section. The work should read as one heavy object before it reads as a control surface.

## Last-three refusal and radical rupture

The last three SVG works repeated a visitor route or selection, a dark multi-part SVG field or body, and a non-local response that appeared elsewhere while the touched geometry stayed exact:

- v043: an ordered crossing through a pressure loom;
- v044: an escape from a compound skin;
- v045: a two-site attention handoff across unequal tiles.

v046 breaks that invariant. It changes the representation from field / skin / tile to one singular cutaway block, changes the encounter from traverse / escape / selection to sustained alternating hold-and-release, changes the temporal model from remote memory to local material cross-sections, and changes the shape vocabulary from bands / apertures / counterforms to one mass, one void, fixed banks, and produced strata.

## Cultural translation

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** a programmable material engine treats pressure, density, directional behaviour, and vector fields as production rules that alter how geometry is generated rather than decorating a finished mark.
- **Mutine translation:** refuse brush presets, watercolor appearance, hatching vocabulary, grain treatment, source palette, source composition, source code, examples, and API surface. Translate material agency into an alternating pressure block: a held pulse from one fixed bank is accepted only when it comes from the opposite bank next; accepted pressure changes the block's body, inner void, and produced strata, while the banks remain exact.
- **Visible consequence:** the blind view is one dark singular SVG block with a deep central cut, two fixed rust/gold banks, and six internal produced strata. Four alternating loads visibly change the cutaway mass itself; no hand path or remote receiver is required to explain the event.
- **Falsifier:** if a short pulse commits, if same-side pressure commits, if the pressed banks deform, if the body change is only colour/readout, if later loads overwrite earlier geometry, or if the blind image reads as a generic pressure diagram, the translation fails.
- **Anti-copy:** no p5.brush preset, brush appearance, watercolor, hatching vocabulary, grain treatment, source palette, source composition, source code, examples, API surface, or source imagery is reproduced.
- **Direction consequence:** closes Pure SVG's remote witness / remote topology / remote counterform sequence and opens local material ontology: pressure changes what the SVG block is allowed to become next, not where an answer is displaced.

## Changed rule

The two pressure banks are fixed. A pulse must be held long enough to pass a resistance threshold, and each accepted pulse must alternate sides with the previous one. The pulse itself disappears; the next material cross-section is produced in the central block. The engine cycles through `crease`, `lean`, `cleave`, and `settle` modes, each changing actual SVG `d` geometry for the body, void, and internal strata.

This is a structural rupture, not a palette change:

- **Representation:** one compound cutaway SVG object replaces the tile register, compound skin, and band loom.
- **Composition:** a singular vertical weight between two banks replaces the sparse field and perimeter body.
- **Encounter:** sustained hold and alternating release replace pointer route, escape, and two-site attention.
- **Temporal behaviour:** local load memory changes the object's next cross-section; no remote receiver is edited.
- **Viewer task:** wait, release, switch sides, and notice resistance rather than find, connect, or escape a site.

## Visible consequence

With labels, readout, controls, annotations, and prose hidden, the first view is a single mineral-blue block with a dark vertical void and two coloured pressure banks. A valid pulse changes the block's silhouette, the void's width and lean, and the internal stratum paths. The banks and the unrendered hand route remain exact. Four alternating loads compound and can be lifted exactly.

## Interaction and replay

- Pointer/touch: press inside the left or right bank, hold, and release. A short press is refused.
- Keyboard: focus the artwork, hold `ArrowLeft` or `ArrowRight` and release, or press `Enter` for the deterministic alternating pulse. `Space` provides the same hold/release gesture.
- Controls: `hold the material`, `lift latest load`, `release the block`.
- Memory: four alternating loads compound as `crease`, `lean`, `cleave`, and `settle`. `Delete` lifts the latest load. `Escape` or `R` releases to the quiet seed.
- Static blind preview: `?preview=1&static=1&blind=1` renders the four-load state while hiding labels, readout, controls, annotations, and caption.

## Deletion condition

Delete v046 if caption-free viewing cannot distinguish the pressure block from v043–v045; if a short or repeated-side pulse commits; if the banks mutate; if body and void geometry do not change; if the modes only recolour the object; if later loads erase earlier structure; or if exact lifting fails.

## Critique handoff

The critic must inspect the blind block first. Does the singular object carry the encounter without the controls? Is the fixed-bank / changing-core relation visible at phone size? Does waiting feel like a material threshold rather than a delayed button? Are the four cross-sections visibly cumulative? If not, hold or delete the trial rather than explaining it into significance.
