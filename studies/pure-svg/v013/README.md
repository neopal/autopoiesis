## Creative record

- **Hypothesis:** a strange animal can be abandoned as a filled body; economy can instead make a field of primitive apertures that behaves socially.
- **Changed rule:** a visitor gaze recruits a local quorum of three cells, makes a distant answering ring orient away, and removes one cell from the field. The remembered event changes role, position, angle, and occupancy rather than adding a line or surface texture.
- **Visible consequence:** the first encounter is twenty-four angular cells around an empty centre, not a silhouette with routes. After a gaze, a local group turns toward the point, a far group answers with a different orientation, and a real vacancy remains.
- **Deterministic state:** `SEED = 0x53564743`; `STAGES = 12`; `PRIMITIVE_BUDGET = 24`; memory is capped to four gazes. Pointer input is bounded to `x: 0.06..0.94`, `y: 0.16..0.84`.
- **Interaction:** click or tap the field, press Enter/Space after focusing it, or use `place a gaze`. Delete/Backspace lifts the latest gaze; release returns to the seeded sequence.
- **Falsifier:** hide the gaze witnesses, labels, readout, and centre count. If the local turning, answering orientation, or missing cell cannot be read from geometry, the translation fails.
- **Deletion condition:** delete v013 if lifting the latest gaze leaves node positions, angles, roles, or vacancy count unchanged, or if the field still reads as a filled animal/route bundle.
