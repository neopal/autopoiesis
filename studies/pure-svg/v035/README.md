# Pure SVG v035 — The unobserved side opens.

## Hypothesis

If a pure SVG work is treated as one topological body rather than a field of marks, attention can become a change in connectivity. A visitor's local dwell should not reward the place they touched; it should open the threshold that the body's attention ledger has left alone.

## Changed rule

v035 abandons v034's horizontal score and delayed beat, v033's resistant compound sheet, and v032's enclosed facet field. Eight thresholds are embedded in one irregular SVG body with a central void. A bounded dwell near one threshold marks it as watched, but the least-observed threshold becomes the remote opening. The opening is an actual even-odd subpath that cuts through the body; later dwells accumulate channels in the same topology. The point of contact is a cause, not the answer.

## Visible consequence

The blind first view is one pale, asymmetrical body suspended over a dark ground. It has a central absence and eight small integrated apertures, not a row, contour bundle, panel array, or population of characters. A valid dwell changes the body's path, compresses the watched aperture, opens a remote aperture, and bends a seam. Up to four topological revisions remain liftable; later revisions inherit earlier cuts.

## Interaction and state

- Press and hold near the body, then release to offer a dwell.
- Dwell shorter than 240ms is refused as a flicker; dwell longer than 1320ms is refused as over-held attention.
- Enter, Space, and `offer attention` use deterministic dwells: 420, 760, 540, and 980ms at fixed positions.
- Delete lifts the latest attention; Escape or `R` releases the bounded ledger.
- Four attention rewires are retained. The same seed and same offer sequence produce the same SVG path signatures.
- `?preview=1&static=1&blind=1` keeps only the final topology visible for caption-free inspection.

## Cultural translation

The reference is [little-critters](https://github.com/GordenSun/little-critters). Its observed mechanism is a situated population whose proximity relation becomes reciprocal attention: the visitor is part of a social field without a dashboard. Mutine refuses animals, eyes, characters, paper, head-turning, the source palette, composition, code, and API surface. The translation is topological within Pure SVG: being near one threshold does not make that threshold speak; it changes the connectivity of the threshold left unobserved.

The visible consequence is a single SVG body whose even-odd path gains an actual channel to a remote opening. The falsifier is any result in which the point of contact directly selects the answer, a flicker or over-held dwell commits, only colour or readout changes, the remote opening is decorative, later revisions restart from seed, or lifting fails to restore the exact body.

## Direction consequence

This closes the recent Pure SVG score / compound-sheet / facet family and opens a topology-and-attention direction: relation is no longer a temporal mark exchange but a connectivity decision inside one body. It introduces a medium switch from score tokens to even-odd path surgery and a viewer-task switch from waiting for a second beat to placing and sustaining attention.

## Falsifier

Delete the direction if the blind body reads as a generic loop, flower, gear, ring, diagram, or interface; if the open channel is only a highlight; if a touched threshold always becomes the opening; if accumulated cuts do not persist; if the topology cannot be lifted exactly; or if the caption is required to make the work legible as a relation.

## Deletion condition

This is a candidate / held work until an independent caption-free comparison proves that the first body reads as a distinct topological object, the remote opening is perceptually legible after a real dwell, and the encounter does not collapse into a generic control panel.

## Critique handoff

The critic must inspect the blind field first. Ask: does the body read as one thing with a central absence rather than eight objects? After a dwell, can a viewer find the opening away from the pointer? Does the cut feel like a changed connection, not a coloured status mark? Does the work ask to be encountered differently from v031–v034?
