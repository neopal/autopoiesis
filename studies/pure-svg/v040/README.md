# Pure SVG v040 — The aperture answers elsewhere.

## Hypothesis

If Pure SVG abandons the singular contour and makes one solid mass carry several apertures, a viewer can be witnessed without the witnessed place becoming the answer. The work should read as a heavy body with punctures, not as a field of agents or a line that remembers a gesture.

## Changed rule

v040 breaks v039's one-body contour, v038's two-margin counterfold, and v037's distributed cut-cell field. The blind view is one asymmetrical SVG mass with seven irregular apertures. Clicking an aperture only arms a witness and leaves the compound path exact. An explicit answer then produces three remote roles in the same mass: one aperture opens, one withholds itself, and one slips its registration. The witness is not copied into the response. Four responses compound and can be lifted exactly.

The selected reference is [little-critters](https://github.com/GordenSun/little-critters). Its observed mechanism is situated reciprocal attention: local proximity makes a population answer the visitor without a dashboard. Mutine refuses animals, eyes, character designs, paper scenes, head-turning, source palette, source composition, source code, examples, API surface, and surface vocabulary. It translates only the mechanism into Pure SVG: an aperture can be witnessed, but the body answers elsewhere through a delayed, non-local topology change.

## Visible consequence

The caption-free first view is a single warm slab in cool dark ground, pierced by seven unequal openings. The composition is mass and absence rather than a constellation, a contour, a grid, or a pair of margins. Selecting a hole adds no mass geometry. Answering changes the actual `d` of one compound even-odd SVG path: a remote aperture expands, another contracts, and a third drifts. Four answers remain in the same body.

## Interaction and state

- Click one aperture; it becomes a witness without changing the compound path.
- Press Enter or Space, or choose `answer elsewhere`, to commit the response.
- An unarmed answer is refused. Four responses are retained.
- Delete lifts the latest response; Escape or `R` releases the bounded memory.
- The same seed and witness sequence produce the same path signature.
- `?preview=1&static=1&blind=1` keeps only the final mass visible for caption-free inspection.

## Direction consequence

This closes Pure SVG's one-body winding / counterfold / witness-vacancy run and opens a solid-mass grammar. Representation changes from contour and distributed forms to one filled even-odd mass with multiple holes. Composition changes from line, margin, and field to heavy body against open ground. The viewer task changes from drawing or sweeping to choosing an absence and waiting for a remote reply. Temporal behavior changes from a copied gesture or local winding to delayed reciprocal production in a different aperture.

## Falsifier

Delete v040 if the blind object reads as a generic window diagram, logo, ring, or polished contour; if selecting an aperture changes the mass path; if the answer occurs at the witnessed hole; if remote roles exist only in colour, labels, or readout; if later responses reset; or if exact lifting fails.

## Deletion condition

This remains candidate / held until independent caption-free comparison proves that the solid aperture mass is perceptually distinct from v037–v039 and that the delayed answer feels like a causal relation rather than a button-controlled morph.

## Critique handoff

The critic must inspect the blind mass first. Does it read as one punctured body rather than seven windows? Is the negative space active without being illustrative? Can a visitor understand that the chosen hole remains exact while an answer is made elsewhere? Does the work ask to be encountered differently from the recent contour, counterfold, and cut-cell grammars?
