# Pure SVG v022 — The nearest edge moves.

## Hypothesis

If a viewer's nearness is translated into an edge relation rather than a selected object, one economical SVG sculpture can remember attention through changed adjacency: the face approached turns away, and a face elsewhere inherits the changed plane.

## Changed rule

v022 abandons v019's radial occlusion valve, v020's singular compound contour, and v021's pressure ribbon. The image is a single folded object built from six solid quadrilateral faces arranged as an irregular faceted body. Proximity only arms a face. Leaving the field commits an edge exchange: the approached face turns away, a non-adjacent face answers through changed coordinates, and the hinge between them shifts. Later departures inherit the accumulated exchanges.

## Visible consequence

The blind first view is a dark, faceted folded object with depth, seams, and one coherent silhouette, not a line, ribbon, contour, plate board, or radial chart. After an approach-and-depart event, two actual face silhouettes move: the local edge withdraws and the distant answer leans into a new plane. The state remains visible without labels or controls. Four exchanges are replayable, and lifting the latest reconstructs the exact preceding geometry signature.

## Interaction

- Pointer proximity arms a face; leaving the artwork commits an approach-departure edge exchange.
- A short pointer tap is refused; it cannot write memory.
- The `leave a trace` control, Enter, and Space commit the same deterministic exchange.
- Keys `1`–`6` arm a face without writing history.
- Delete, Backspace, or `lift latest` removes only the latest exchange.
- `R` or `release` returns to the quiet folded object.
- `S` downloads the currently rendered inline SVG.

## Falsifier

The translation fails if pointer proximity or a tap commits, if the local turn or distant answer is only a colour badge, if the blind image reads as six unrelated polygons, if later events ignore inherited edge changes, or if the caption is needed to see that a face moved elsewhere.

## Deletion condition

Delete v022 rather than polish it if a caption-free viewer cannot distinguish one folded body from a polygon diagram, if the local and remote silhouette changes are not visible, if the approach-departure relation is merely a cursor effect, or if lifting the latest exchange does not restore the exact prior signature.

## Cultural translation

Reference: [little-critters](https://github.com/GordenSun/little-critters).

Observed mechanism: situated code-drawn agents respond to pointer proximity by changing attention and looking back, making the visitor part of a reciprocal encounter rather than a controller of a dashboard.

Mutine translation: refuse animals, eyes, head-turning imagery, paper scene, source palette, composition, and API. Translate reciprocal attention into topology: nearness arms one face, departure makes its edge turn away, and a non-adjacent face answers by inheriting the altered plane. Memory changes the next exchange.

Visible consequence: the blind field is one faceted SVG body. After departure, the approached face has a moved silhouette and a distant face has a different lean; the response is geometric, not a marker or character animation.

Falsifier: if proximity writes, if a tap writes, if the answer is only a glow, if the remote face does not move, or if the first view reads as a polygon diagram, the translation fails.

Anti-copy statement: no animals, eyes, character design, paper scene, source palette, composition, surface style, or head-turning vocabulary is reproduced.

Direction consequence: closes the line-like pressure family of v019–v021 and opens a reciprocal topology direction in which Pure SVG tests attention as an exchange of planes inside one faceted body.
