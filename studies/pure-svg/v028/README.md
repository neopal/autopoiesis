# Pure SVG v028 — The aperture waits for leaving.

## Concept

A dark spatial field holds seven standing aperture plates. Their openings are not windows onto a scene; they are the only anatomy of the work. The plates are arranged as an uneven instrument, with a quiet axis and a second, quieter axis of distance between them.

The visual story begins in stillness. Pointer proximity can make one plate attend, but attention is not yet history. Only withdrawal commits: the local opening tightens, a non-local plate receives a larger opening, and a third plate hinges by a smaller relay. Four departures remain in bounded memory. Lifting the latest reconstructs the exact preceding array; release returns to the deterministic seed.

## Changed rule

v028 abandons v025's single open contour, v026's dispersed polygon constellation, and v027's horizontal slip strata. The representation changes to seven large filled SVG aperture bodies with real even-odd cutouts and independent hinge states. The encounter changes from a drawn route, a population departure, or a pressure puncture to attention followed by withdrawal. The causal relation is explicit: nearness arms, leaving writes.

The source mechanism is translated into the current's topology question as a distributed opening law, not as a population of figures. The local plate cannot answer itself. Its opening is transferred through distance.

## Cultural translation

- **Reference:** [little-critters](https://github.com/GordenSun/little-critters)
- **Observed mechanism:** situated code-drawn agents respond to pointer proximity with legible attention and reciprocal looking, making the visitor part of a social field without a control dashboard.
- **Mutine translation:** refuse animals, eyes, paper, and looking-back imagery. In Pure SVG's own vocabulary, proximity only arms a plate; withdrawal contracts its actual aperture, enlarges a distant aperture, and turns a third plate as a hinge relay.
- **Visible consequence:** the blind first view is a sparse spatial array of seven tall aperture bodies. After departure, three actual SVG path bodies change: one hole closes, one hole opens, and one remote plate shifts its aperture and angle.
- **Direction consequence:** this closes the line / contour / strata family and opens a plate-and-aperture grammar in which topology is an encounter distributed across distance.
- **Anti-copy:** no animals, eyes, characters, paper scene, source palette, source composition, source code, API surface, or head-turning imagery is reproduced.

## Hypothesis and falsifier

The changed causal rule should be perceptible as a difference between contact and absence: a held pointer must leave the aperture array unchanged, while a completed departure must change actual holes in non-local plates. If only colour, cursor marks, labels, or a counter change, the translation has failed.

## Deletion condition

Delete v028 if the first blind view reads as a generic panel grid; if proximity writes memory; if the local opening changes without a distant response; if the relay is decorative; if later departures restart from the seed; or if lifting the latest departure cannot restore the exact prior geometry.

## Critique position

This is a **candidate / held** work. Its engine is deterministic, its topology is structural, and the interaction has a consequential threshold. The unresolved artistic question is whether the blind field reads as an authored system of openings and distance, rather than as seven attractive interface panels.
