# Pure SVG v036 — The stroke becomes an organ.

## Hypothesis

If a pure SVG work treats a visitor's drawn path as a material field rather than as a mark, an open vector organism can produce a different next contour. The gesture should be refused as a trace: direction and turning must change how the SVG makes its filaments.

## Changed rule

v036 abandons v035's closed attention topology, v034's horizontal delayed score, and v033's compound pressure sheet. The blind first view switches to one oblique open spine with seven open filaments. A bounded drawn path is measured for its direction, length, and turning. It is not copied into the image. Instead, the source filament absorbs the field, a remote filament grows, and a third counter-filament unthreads. Later strokes are produced from the changed organism rather than from the quiet seed.

## Visible consequence

The caption-free first view is a dark, off-axis vector organism: one luminous open spine, seven unequal open strands, and small terminal knots. It is not a closed emblem, a row of marks, or a slab with embedded faults. A valid drag changes the spine path and at least three filament paths. The gesture itself never appears as a permanent line. Up to four growth events remain liftable; later growth inherits the changed reach and curl.

## Interaction and state

- Draw a bounded stroke with at least three points across the SVG, then release.
- Strokes shorter than `0.12` normalized units or longer than `0.78` are refused.
- Enter, Space, and `feed a stroke` use deterministic strokes at fixed positions.
- Delete lifts the latest growth; Escape or `R` releases the bounded organism.
- Four growths are retained. The same seed and same stroke sequence produce the same SVG path signatures.
- `?preview=1&static=1&blind=1` keeps only the final organism visible for caption-free inspection.

## Cultural translation

The reference is [p5.brush](https://github.com/acamposuribe/p5.brush). Its observed mechanism is that programmable pressure, density, directional behavior, and vector fields participate in producing geometry rather than merely styling a finished mark. Mutine refuses its brushes, watercolor, hatching, grain, palette, composition, code, examples, and API surface. The translation is a stroke-born field inside Pure SVG: a drawn path changes the production rule of open filaments, while the path itself disappears.

The visible consequence is structural: the open spine path bends, the source filament absorbs and shortens, a remote filament grows, and a counter-filament unthreads. The falsifier is any result in which the gesture is copied as a trail, only color or readout changes, the nearest filament is always the answer, later strokes restart from seed, or lifting is inexact.

## Direction consequence

This closes Pure SVG's attention / score / compound-sheet sequence and opens a field-grown-filament direction. The current moves from closed topology and temporal marks to open vector production, from dwell or interval to continuous drawing, and from local selection to material behavior distributed across a remote strand. It keeps SVG economy but abandons the recent body grammar.

## Falsifier

Delete the direction if the blind organism reads as a generic route, waveform, diagram, or control panel; if the stroke survives as a copied line; if the source point alone decides the visible answer; if the spine or three filament paths do not change; if later events forget prior growth; or if exact lifting fails.

## Deletion condition

This is a candidate / held work until independent caption-free comparison proves that the open vector organism is perceptually distinct from v033–v035 and that the drawn encounter feels like a causal field rather than an invisible button.

## Critique handoff

The critic must inspect the blind field first. Ask: does the composition read as an open organism before it reads as seven strands? After a drag, can a viewer find the grown strand away from the starting point? Is the gesture absent but causally legible in the changed paths? Does the work ask to be encountered differently from the recent closed-body, score, and pressure gestures?
