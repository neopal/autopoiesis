# Pure SVG v025 — The boundary keeps its gap.

## Hypothesis

A single SVG contour can make relation structural without becoming an object or a diagram: if the visitor draws a span between two places, the contour should transfer its one missing segment to a third place instead of closing or adding a mark.

## Changed rule

v025 abandons v022's folding body, v023's drying sheet, and v024's closed witness-knot. The medium switches to one open, stroked SVG contour. A pointer span from one station to another is the causal gesture: the source and target are altered, but the actual rupture moves to a remote relay station. Three transfers remain in bounded memory and the next span inherits the changed contour. Lifting removes the latest transfer exactly.

## Visible consequence

The blind first render is one luminous, unfilled, open boundary with a single missing edge. After a committed drawn span, the contour's actual point geometry changes at the source, target, and non-local relay, and the missing edge migrates. There is still only one SVG path and one open body; no card, port, chamber, or filled knot explains the event.

## Cultural translation

- **Reference:** [little-critters](https://github.com/GordenSun/little-critters)
- **Observed mechanism:** Situated code-drawn agents turn pointer proximity into reciprocal attention: a local approach changes where an agent looks back, so the visitor enters a relation rather than operating a dashboard.
- **Mutine translation:** Refuse animals, eyes, characters, and head-turning imagery. Translate reciprocity into a route-dependent topology: the visitor draws continuously between two places, and the boundary answers at a third place by moving its scarce rupture.
- **Direction consequence:** This opens a topology-as-route direction for Pure SVG and abandons the recent closed-body family of folding, drying, and witness knots. The work asks whether a boundary can remember a refusal without becoming a filled thing.
- **Anti-copy:** No animals, characters, eyes, paper scene, source palette, composition, source code, API surface, or head-turning vocabulary is reproduced.

## Falsifier

Delete the direction if a pointerdown alone writes memory, if the target is only a cosmetic marker, if the gap does not migrate, if every relay is a fixed neighbour, or if the blind image reads as a generic line diagram.

## Deletion condition

Delete v025 if the caption is needed to discover that the contour is open, if the source/target/relay consequence cannot be found in the silhouette, or if the stations are merely disguised buttons around an inert line.

## Critique position

This is a candidate / held work. The engine and browser evidence can establish that the drawn span is deterministic and structural; only an independent caption-free comparison can establish that the blind encounter reads as one singular broken boundary rather than a decorated route.
