# Pure SVG v044 — The cut changes its elsewhere.

## Hypothesis

If Pure SVG stops presenting the visitor with a route, chamber, hinge, or band field, and instead makes the visitor attempt an escape from a closed skin, a cut can become a topological production rule. The work should read as one negative-space body before it reads as an interaction surface.

## Cultural translation

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** a programmable material engine treats pressure, directional behaviour, and field logic as rules that alter how geometry is produced rather than decorating a finished mark.
- **Mutine translation:** refuse brush presets, watercolor, hatching, grain, palette, composition, source code, examples, and API surface. Translate material agency into a topology skin: an invisible cut starts in one interior aperture and must escape the perimeter; only then does an untouched remote aperture split into a new SVG opening.
- **Visible consequence:** the blind view is one closed irregular skin with six negative apertures. An escaped cut leaves its source aperture exact and creates a second actual remote aperture contour; four cuts compound as persistent topology.
- **Falsifier:** if the cut paints a path, if geometry changes before escape, if re-entry commits, if the remote split is only colour/readout, or if the blind skin reads as a generic blob, the translation fails.
- **Anti-copy:** no p5.brush preset, brush appearance, watercolor, hatching vocabulary, grain, palette, composition, source code, API surface, or source imagery is reproduced.
- **Direction consequence:** closes Pure SVG's route / chamber / pressure-loom grammar and opens a boundary-topology direction: material agency becomes a change in what counts as an opening.

## Changed rule

A cut begins inside an existing aperture and remains geometry-neutral. It must reach one of four perimeter exits. Only release after that escape commits a topology split in an untouched remote aperture. The touched aperture keeps its exact path. Re-entering the source refuses the event. Four cuts compound and can be lifted exactly.

This is a structural rupture, not a palette change:

- **Representation:** one compound even-odd SVG skin replaces filled bands, chambers, hinges, and route traces.
- **Composition:** a single asymmetric membrane organized by negative apertures replaces a field of selectable or traversable parts.
- **Encounter:** the viewer attempts an escape from inside to outside; there is no visible cursor path and no route to complete.
- **Temporal behaviour:** the skin stores topology at a remote opening, so subsequent cuts inherit a changed set of absences.

## Visible consequence

With labels, readout, controls, rim markers, and prose hidden, the first view is one dark mineral membrane with six unequal apertures. A valid escape leaves no scar at the hand. The remote aperture gains actual SVG path structure and a second split opening. Four settled splits remain visible; the source aperture and all lifted predecessors are deterministic.

## Interaction and replay

- Pointer/touch: press inside an aperture, drag to a perimeter rim, and release.
- Keyboard: focus the artwork, press `ArrowRight` twice, then `Enter` or `Space`.
- Controls: `tear the skin`, `lift latest`, `release skin`.
- Memory: four deterministic topology cuts compound. `Delete` lifts the latest cut. `Escape` or `R` releases to the quiet seed.
- Static blind preview: `?preview=1&static=1&blind=1` renders the four-cut state while hiding labels, readout, controls, rim markers, annotations, and caption.

## Deletion condition

Delete v044 if caption-free viewing cannot distinguish the topology skin from v041–v043; if crossing or re-entry changes geometry; if the hand path is visible; if the remote split is cosmetic; if the blind image reads as an undifferentiated blob; or if exact lifting fails.

## Critique handoff

The critic must inspect the blind skin first. Does one negative-space body read before its apertures become a parts diagram? Is the remote split materially legible without labels? Does the refusal of a re-entry make the boundary feel causal rather than decorative? Can the four topological states be seen without controls? If not, this trial remains held or is deleted rather than explained into significance.
