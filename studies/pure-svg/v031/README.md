# Pure SVG v031 — The line mishears the second touch.

## Concept

The first view is a single spare SVG line held by nine irregular joints. It is not a population, a panel array, a route bundle, or a closed body. Its composition is an articulated sentence without glyphs: the line exists as the order of its joints and the tensions between them.

The encounter is discrete attention. A first joint can be attended but does not write. A distant second joint causes the line to mishear both offers: it reroutes through a third, unoffered witness joint. The witness is not a cursor marker or a label; it becomes part of the actual SVG path order and bends the line. Four mishearings remain in bounded memory. Lifting the latest reconstructs the exact preceding line; release returns to the deterministic seed.

## Radical progression

v031 breaks v028's distributed aperture plates, v029's woven compound bodies, and v030's singular negative-space contour. The representation switches from filled bodies and cavities to one thin articulated line with discrete joints. The encounter switches from press-drag crossing to two separated attention events. The viewer's task is no longer to carry a relation continuously; it is to attend, offer again, and notice that the line answers through what was not offered.

## Changed rule

The first attention is geometry-neutral. Only a distant second attention commits. The line then reorders its actual path through an unoffered witness joint and changes the tension of all three joints. The witness, not the offered pair, carries the visible reroute.

## Cultural translation

- **Reference:** [little-critters](https://github.com/GordenSun/little-critters)
- **Observed mechanism:** situated code-drawn agents respond to pointer proximity with legible attention and reciprocal looking, making the visitor part of a social field without a dashboard.
- **Mutine translation:** refuse animals, eyes, characters, paper, and head-turning imagery. In Pure SVG's economy, attention becomes a temporary state on a joint; two distant attentions make one unoffered joint become the line's witness, changing the path order itself.
- **Visible consequence:** the blind first view is one thin asymmetrical line. After two distant offers, the line visibly takes a new articulation through a joint the visitor did not offer; three joint paths carry tension, rather than a decorative highlight appearing on top.
- **Falsifier:** if the first attention writes geometry, if an adjacent pair commits, if the offered pair is always the visible answer, if the witness is only a label or glow, if later events restart from the seed, or if the blind field reads as a graph/interface, the translation fails.
- **Anti-copy:** no animals, eyes, character designs, paper scene, source palette, source composition, source code, API surface, or head-turning image is reproduced.
- **Direction consequence:** closes the cavity / body / singular-contour sequence and opens a line-as-social-mishearing direction: relation is carried by path order and an absent witness rather than by bodies looking back.

## Hypothesis

If a relation is represented as an economical line whose order can be rewritten by an unoffered joint, a viewer should perceive the work as a new articulation after the second attention rather than as a selected object with feedback decoration.

## Falsifier and deletion condition

Delete v031 if the blind view reads as a generic graph, if first attention changes the line, if nearby attention commits, if the witness joint is not materially visible in the path, if the work needs its labels to explain consequence, if later mishearings ignore memory, or if lifting cannot restore the exact prior line.

## Critique position

This is a **candidate / held** work. The engine is deterministic, the first attention is inert, the second distant attention changes actual path order, and the memory/undo rules are testable. The unresolved artistic question is whether a thin line can carry enough authored presence to survive a caption-free first encounter without becoming a diagram.
