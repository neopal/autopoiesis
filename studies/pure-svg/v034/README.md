# Pure SVG v034 — The score delays its answer.

## Hypothesis

If a pure SVG work is treated as a temporal score rather than a spatial field, the viewer's timing can become a structural event. The image should ask for a second beat before it changes, and the change should travel to marks the viewer did not touch.

## Changed rule

v034 abandons v033's single compound sheet and timed local pressure, v032's enclosure of detached facets, and v031's two-place path negotiation. It switches from a spatial gesture to a temporal pair: a first tap only starts an appointment; a second tap between 180ms and 840ms rewrites the horizontal score through three non-local roles. The source mark narrows and tilts, a distant echo rises or lowers, and an unoffered witness turns. The next beat starts from that altered score.

## Visible consequence

The blind first view is one dark horizontal SVG score carrying nine irregular invented marks, a dotted rail, and a faint registration field. It is not a contour, compound slab, facet constellation, or panel grid. A valid second beat changes at least three actual mark paths and the score rail. A stutter or late answer leaves the geometry exact. Later beats inherit the changed marks; Delete reconstructs the exact preceding score.

## Interaction and state

- Tap once on the score to start a measure; tap again to submit the interval.
- Intervals shorter than 180ms are refused as a stutter; intervals longer than 840ms are refused as a missed appointment.
- Enter, Space, and `offer a second beat` use deterministic intervals: 320, 540, 760, and 420ms.
- Delete lifts the latest beat; Escape or `R` releases the bounded ledger.
- Four beats are retained. The same seed and same interval sequence produce the same SVG path signatures.
- `?preview=1&static=1&blind=1` keeps only the final artwork visible for caption-free inspection.

## Cultural translation

The reference is [little-critters](https://github.com/GordenSun/little-critters). Its observed mechanism is that situated agents respond to proximity with reciprocal attention, making the visitor part of a social field. Mutine refuses animals, eyes, characters, paper, head-turning, the source palette, composition, code, and API surface. The translation is temporal and typographic within Pure SVG: the first tap is inert, and only a second beat makes three distant marks answer. Relation is carried by interval and non-local rewrite, not by a pointer target or a looking figure.

The visible consequence is a one-dimensional score whose actual SVG paths change in three roles after a valid interval. The falsifier is any result in which a tap location selects the answer, a first tap writes geometry, a late or stuttering interval commits, only colour/readout changes, the unoffered witness is decorative, or later beats restart from seed.

## Direction consequence

This closes the recent Pure SVG line / contour / facet / compound-body family and opens a temporal-score direction: economy becomes a small syntax of marks whose relation is heard as delay rather than drawn as a field. It also abandons pointer locality as the current's default encounter.

## Falsifier

Delete the direction if the blind image reads as a familiar linefield, contour, diagram, panel array, or interface; if timing is only a disguised button; if a first tap commits; if the point of contact determines the changed mark; if fewer than three actual paths change; if the next beat forgets prior rewrites; or if exact lifting fails.

## Deletion condition

This is a candidate / held work until an independent caption-free comparison proves that the horizontal score is perceptually distinct from v031–v033 and that the interval encounter feels causal rather than like a generic control panel.

## Critique handoff

The critic must inspect the blind field first. Ask: does the row read as a temporal specimen rather than a set of nine objects? Can the viewer sense the waiting in the first encounter without labels? After a valid second beat, can they locate a changed source, a remote echo, and an unoffered witness in actual geometry? Does the work ask to be encountered differently from the recent spatial gestures?
