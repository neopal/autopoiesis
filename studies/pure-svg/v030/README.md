# Pure SVG v030 — The contour answers from far away.

## Concept

A single irregular SVG contour carries eight cavities and one central silence. The cavities are not figures, panels, or independent marks: they are holes in one body. The first view is a quiet negative-space organism with no route, grid, or population to decode.

The encounter is a drag across distance. A local crossing only arms a cavity. A second, distant gate must reply before the contour changes: the source cavity contracts, the target opens, and a remote relay bends. Four replies remain in bounded memory. Lifting the latest reconstructs the exact preceding contour; release returns to the deterministic seed.

## Radical progression

v030 breaks the last three Pure SVG grammars: v027's horizontal slip strata, v028's standing aperture array, and v029's woven cluster of compound bodies. The representation switches from multiple visible bodies to one filled negative-space topology. The encounter switches from click/offer/answer state changes to a press-drag crossing. The viewer's task is no longer to select a place and wait for a label; it is to carry a boundary between near and far gates and discover whether distance can make a hole reply.

## Changed rule

A local crossing is memory-neutral. Only a distant reply writes. The reply changes three actual cavity paths and the shared even-odd contour, so the event is carried by geometry rather than by a marker, counter, or caption.

## Cultural translation

- **Reference:** [little-critters](https://github.com/GordenSun/little-critters)
- **Observed mechanism:** situated code-drawn agents respond to pointer proximity with legible attention and reciprocal looking, making the visitor part of a social field without a dashboard.
- **Mutine translation:** refuse animals, eyes, characters, paper, and head-turning imagery. In Pure SVG's topology vocabulary, local contact only arms a cavity; a distant cavity must reply before three holes and one shared contour re-form.
- **Visible consequence:** the blind first view is one large negative-space contour, not a population. A near crossing leaves it exact; a far reply changes the source, target, relay, and even-odd contour paths.
- **Falsifier:** if a local crossing writes, if a same-gate return commits, if only a highlight or label changes, if the reply does not alter three cavity paths, or if the blind field reads as a decorative ring, the translation fails.
- **Anti-copy:** no animals, eyes, characters, paper scene, source palette, source composition, source code, API surface, or head-turning imagery is reproduced.
- **Direction consequence:** closes the population / aperture / woven-body sequence and opens a topology of distributed reply: relation is no longer represented by agents, but by holes in one body that can answer across distance.

## Hypothesis

If the field is authored as one contour rather than a set of objects, a visitor should feel a change in topology when a remote reply arrives: the image should become a different body, not a highlighted selection.

## Falsifier and deletion condition

Delete v030 if the blind view reads as a decorative ring or interface diagram; if proximity writes memory; if same-gate contact commits; if the remote reply changes only stroke or colour; if later replies restart from the seed; or if lifting cannot restore the exact previous geometry.

## Critique position

This is a **candidate / held** work. The engine is deterministic, the drag gesture has a causal threshold, and topology is encoded in real SVG paths. The unresolved artistic question is whether the singular contour reads as a compelling new body without captions, controls, readout, or annotations.
