# Pure SVG v042 — The body knots a second opening.

## Hypothesis

If a visitor crosses two openings in one continuous gesture, a body can answer without changing at the crossing: its own remote chambers will knot, exposing a relation that is not a cursor trail or a selected node.

## Cultural translation

- **Reference:** [little-critters](https://github.com/GordenSun/little-critters)
- **Observed mechanism:** situated code-drawn agents make proximity legible as reciprocal attention; the visitor enters a small social field and local behaviour answers without a dashboard.
- **Mutine translation:** refuse animals, eyes, characters, paper scenes, head-turning, source palette, source composition, source code, examples, and API surface. Translate situated reciprocity into a single faceted SVG body: a continuous crossing through two skin gates is remembered only when released, and the answer is produced in three unvisited chambers.
- **Visible consequence:** the blind view is seven filled polygon chambers around a dark internal seam. A crossing is geometry-neutral. A valid release changes remote chamber size, position, notch, and rotation while the crossed gates' chambers stay exact; four knots persist.
- **Falsifier:** if a gate changes geometry before release, if a repeated gate commits, if remote changes exist only in colour or readout, if crossed chambers answer themselves, if the blind field reads as a panel diagram, or if later knots reset, the translation fails.
- **Anti-copy:** no animals, eyes, head-turning scene, character design, paper style, source palette, source composition, source code, examples, API surface, or surface vocabulary is reproduced.
- **Direction consequence:** closes the Pure SVG mass / contour / hinge-register sequence and opens chamber-body: reciprocal attention becomes a continuous crossing whose consequence is a remote reconfiguration of filled SVG facets.

## Changed rule

A single continuous crossing is geometry-neutral. Only release after two distinct gates knots three unvisited chamber polygons as `unseal`, `fold`, and `seal`; the crossed gates remain exact.

## Interaction and replay

- Pointer/touch: press a gate, drag through a second distinct gate, release.
- Keyboard: focus the artwork, press `ArrowRight`, then `Enter` or `Space`.
- Controls: `cross two gates`, `lift latest`, `release body`.
- Memory: four deterministic knots compound. `Delete` lifts the latest knot. `Escape` or `R` releases to the quiet seed.
- Static blind preview: `?preview=1&static=1&blind=1` renders the four-event state while hiding labels, readout, controls, annotations, and gate marks.

Delete v042 if caption-free viewing cannot distinguish the chamber body from v039–v041, if the crossing changes geometry early, if a selected/crossed chamber answers itself, if the remote role is cosmetic, or if exact lifting fails.
