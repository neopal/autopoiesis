# Pure SVG v002 — The animal steps sideways

Status: daily candidate, held for independent perceptual critique.

## Concept

The previous SVG work cut a point from a polygon but left the animal premise too diagrammatic. This version changes the rule: a cut becomes a hinge, and every later point downstream of that hinge is pulled sideways. The animal is not decorated with memory; its weight has to route around it.

## Visible rule

- nine deterministic stages loop from one seeded contour;
- eighteen SVG primitives are reserved as the visible budget;
- the dashed bone contour is the refused proposal;
- the filled mineral contour is the current body;
- inherited cuts bend later contour points and the four legs;
- clicking or touching the field creates a normalized `visitor-cut` and pauses the sequence;
- `delete latest` removes the newest scar so the downstream change can be compared;
- reduced motion and `static=1` show the settled terminal stage without animation.

## Art gate

- **Changed rule:** cut points become downstream hinges rather than surface annotations.
- **Expected consequence:** later body weight and limbs step sideways around the kept cut.
- **Falsifier:** if deletion changes only color, scale, or annotation, the work remains held.
- **Deletion condition:** remove the work if an independent caption-free observer cannot name the same downstream correspondence twice.
