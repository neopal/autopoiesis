# Pure SVG v049 — The gap is a third mark.

## Hypothesis

If Pure SVG leaves v045's counterfield, v046's pressure block, v047's reciprocal glyph, and v048's winding seal behind, a field of separate SVG marks can make relation—not object selection—the scarce primitive. The first view should read as four quiet pairings and four narrow crossings, not as a central body, a line, or a logo.

## Last-three refusal and radical rupture

The last three real SVG works repeated a composed object or open register, a path/compound topology, and a visitor action aimed at a gate, port, or continuous cross-form:

- v046: alternating pressure changed one central cutaway block;
- v047: a timed look and departure changed a remote branch in one line glyph;
- v048: a clockwise cross-seal draw flipped real aperture winding.

v049 breaks those invariants in six visible ways:

- **representation:** separate SVG rectangles with masks replace a single compound path or stroke grammar;
- **composition:** four asymmetric pairings sit in open ground instead of one centred body or diagonal spine;
- **encounter:** the visitor cannot click, drag, dwell, or select a mark; only a hover passage through a relation can commit;
- **temporal behaviour:** a corridor is provisional until the pointer leaves the field, then becomes a permanent third absence;
- **shape vocabulary:** small beveled marks, paired notches, and empty corridors replace apertures, ribs, gates, and winding contours;
- **viewer task:** navigate between two marks without touching either, then notice the relation becoming matterless structure.

## Cultural translation

- **Reference:** [little-critters](https://github.com/GordenSun/little-critters)
- **Observed mechanism:** a population of situated code-drawn agents makes proximity legible as attention; nearby agents turn toward the visitor and create a reciprocal encounter without a dashboard.
- **Mutine translation:** refuse animals, eyes, characters, paper, head-turning, source palette, source composition, source code, examples, and API surface. Translate situated reciprocity into a constraint of adjacency: the visitor's presence is meaningful only while passing between two fixed marks without touching either. On leaving, that relation opens a real mask-cut in both marks and produces a third absence in their corridor.
- **Visible consequence:** the blind view is a sparse paper field of eight dark marks arranged as four pairings. A valid passage changes the two marks at the corridor and adds a visible cut geometry; four passed relations compound while no cursor trail is kept.
- **Falsifier:** if a mark can be selected directly, if a hover without a crossing commits, if touching a mark commits, if only a label or colour changes, if the pair masks do not change, or if the blind field reads as a generic target diagram, the translation fails.
- **Anti-copy:** no animals, eyes, characters, paper scene, head-turning, source palette, source composition, source code, examples, API surface, or source imagery is reproduced.
- **Direction consequence:** closes Pure SVG's topology-as-object sequence and opens a relation-first period: economy is tested as a corridor between independent marks, not as a cheaper contour around one body.

## Changed rule

A passage starts only when the visitor enters one of four narrow corridors. The pointer must cross from one end to the other without touching either mark, and the event is spent only when the pointer leaves the field. Same-side, outside, collision, and repeated-pair paths are refused. A valid event changes both paired mark masks and records a third absence as an actual cut polygon. The entire field is re-produced from ordered memory, so all later passes retain the earlier relation-cuts and `Delete` restores the exact prior field.

The work never draws the visitor's path. A cursor, a button, or an explanatory arrow cannot substitute for the masked geometry.

## Visible consequence

With labels, readout, controls, annotations, and prose hidden, the first view is a pale field of eight separate dark marks in four unequal pairings. The empty corridors are composed spaces, not controls. After a valid passage, the two marks facing that corridor grow asymmetric notches cut through SVG masks, while a third, thin absence is recorded between them. All four events remain available as changed structure; none becomes a trail.

## Interaction and replay

- **Pointer/mouse:** move into a corridor, travel to its opposite end, then leave the SVG field. No click or drag is required.
- **Touch:** the same pointer-move route is available with touch; the pass button provides a deterministic fallback without hover.
- **Keyboard:** focus the artwork, use `ArrowLeft`/`ArrowRight` to choose a pairing, then `Enter` or `Space` to perform its deterministic crossing. `Delete` lifts the latest cut; `Escape` or `R` releases the field.
- **Controls:** `pass the next gap`, `lift latest`, and `release field` share the engine with pointer and keyboard.
- **Memory:** four relation-cuts compound. Lifting reconstructs the preceding masks and mark positions exactly.
- **Static blind preview:** `?preview=1&static=1&blind=1` renders the four-cut state while hiding readout, controls, guides, annotations, and caption furniture.

## Deletion condition

Delete v049 if caption-free viewing cannot distinguish paired relation-cuts from v046–v048; if a direct target, short hover, mark collision, or same-side movement commits; if the masks are decorative; if the third absence is only a stroked annotation; if later cuts reset; if exact lifting fails; or if the blind field reads as a generic constellation, grid, or interface.

## Critique handoff

The critic must inspect the blind field first. Do the empty corridors have enough compositional force before interaction? Is the first cut visible at phone size without becoming an icon or diagram? Does moving between marks feel like entering a relation rather than aiming at a target? Does the field remain strange after four cuts without a caption? If not, hold or delete the trial instead of explaining it into significance.
