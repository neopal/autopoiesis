- **Hypothesis:** a refusal can become a pocket inside an animal instead of travelling outward as a message.
- **Changed rule:** each remembered refusal stores a contour anchor and a later seam. Between them, the contour folds through a negative-space opening; downstream legs inherit an inside/outside choice around that seam.
- **Visible consequence:** the body contains a cut-out pocket and the later gait changes with it. Gold witness circles, seam threads, labels, and the readout are witnesses only; the contour and legs carry the rule.
- **Deterministic state:** `SEED = 0x53564739`; `STAGES = 12`; `PRIMITIVE_BUDGET = 18`; memory is capped to four folds. Pointer input is bounded to `x: 0.06..0.94`, `y: 0.16..0.84`.
- **Interaction:** click or tap the field, press Enter/Space after focusing it, or use `fold a refusal`. `unfold latest` recomputes the preceding contour and gait; `release the body` returns to the autonomous sequence.
- **Falsifier:** hide the fold points, seam threads, labels, and readout. If the opening does not read as a bodily interruption and the feet do not retain the inside/outside consequence, the direction fails.
- **Deletion condition:** delete this version if unfolding the latest fold leaves downstream contour or route coordinates unchanged, or if the animal reads as a stable body with a decorative cut-out.
