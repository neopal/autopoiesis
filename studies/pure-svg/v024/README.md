# Pure SVG v024 — The contour takes attendance.

## Hypothesis

A single SVG body can make social attention structural without drawing a social scene: the contour should remain unchanged while one place is merely witnessed, then change topology only when a second distinct place answers.

## Changed rule

v024 replaces v023's one-sheet dwell threshold with a two-witness relation. The first port arms latent attention without writing geometry. A second, distinct port commits a topological splice: the first negative mouth seals, the second opens, and a third port carries a shear. Four relations remain in bounded memory and the next pair inherits the changed body.

## Visible consequence

The blind first render is one asymmetrical, closed SVG knot with a central absence and seven peripheral ports. After a committed pair, actual compound-path subshapes change scale, position, and winding-space: one mouth contracts, another expands, and a third shifts. The response is non-local and survives without labels, controls, or readout.

## Cultural translation

- **Reference:** [little-critters](https://github.com/GordenSun/little-critters)
- **Observed mechanism:** Situated code-drawn agents make pointer proximity legible as reciprocal attention: a local approach changes where an agent looks back, so the visitor enters a relation rather than operating a dashboard.
- **Mutine translation:** Refuse animals, eyes, characters, and head-turning imagery. Translate situated reciprocity into a topological witness relation: one port can be attended without consequence, but a distinct second port answers and changes the compound path at three places.
- **Direction consequence:** This opens a constraint-as-relation direction for Pure SVG and abandons the recent single-gesture sequence of pressure, approach/departure, and dwell. The work asks whether topology can require another place before it changes.
- **Anti-copy:** No animals, characters, eyes, paper scene, source palette, composition, source code, API surface, or head-turning vocabulary is reproduced.

## Falsifier

Delete the direction if the first click writes memory, if same-port touches commit, if the remote change is only a marker or colour, if later pairs ignore earlier topology, or if the blind image reads as a control diagram rather than one altered body.

## Deletion condition

Delete v024 if a caption is needed to discover the two-place relation, if the three changed ports cannot be found in the silhouette, or if the knot is only a decorative container for seven UI targets.

## Critique position

This is a candidate / held work. Structural and browser evidence may establish that the event is deterministic and real; only an independent caption-free comparison can establish that the blind encounter reads as a single topological body rather than a decorated control surface.
