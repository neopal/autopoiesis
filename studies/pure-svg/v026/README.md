# Pure SVG v026 — The chorus rehearses absence.

## Hypothesis

A pure SVG work can make social relation visible without drawing a body, a route, or a contour: a dispersed population of irregular fragments can carry attention as a temporary state and absence as the irreversible event.

## Changed rule

v026 abandons v023's negative chamber sheet, v024's witness-knot, and v025's single open boundary. The representation switches from one enclosing SVG path to seventeen autonomous filled polygons in an asymmetrical constellation. The encounter also inverts the recent little-critters translation: the field does not look back at the visitor. Attention only arms a fragment; leaving withdraws that fragment and makes a non-local fragment carry the reply, with a third echo carrying the residue.

Four departures remain in bounded memory. Later geometry inherits every withdrawal, so the population is not a resettable collection of decorative tiles. Delete lifts the latest absence exactly; R releases the choir to its quiet deterministic state.

## Cultural translation

- **Reference:** [little-critters](https://github.com/GordenSun/little-critters)
- **Observed mechanism:** Situated code-drawn agents make pointer proximity into reciprocal attention: local approach changes where an agent looks back, so the visitor becomes part of a social field rather than operating a dashboard.
- **Mutine translation:** Invert looking-back into looking-away. The visitor's attention is temporary and non-committing; only departure writes. The attended fragment withdraws, a distant fragment becomes overheard, and a third fragment carries an echo. No character, eye, or agent illustration is needed.
- **Visible consequence:** The blind first render is a distributed constellation of filled geometric fragments rather than a body or line. After departure, the source actually contracts and shifts, while non-local relay and echo fragments change their polygons; later departures inherit the altered population.
- **Direction consequence:** This opens a discrete-population grammar for Pure SVG and closes the enclosing-body / single-boundary family. It also abandons the prior direct reciprocity metaphor in favour of absence as the only committed social act.
- **Anti-copy:** No animals, characters, eyes, paper scene, source palette, source composition, source code, API surface, or head-turning surface vocabulary is reproduced.

## Falsifier

Delete the direction if attention itself changes memory, if departure only changes colour or a marker, if the source is the only changed fragment, if the reply is a fixed neighbour, or if the blind image reads as a generic polygon scatter with no visible population grammar.

## Deletion condition

Delete v026 if the caption is needed to discover that departure is the event, if the source/relay/echo geometry cannot be found in the altered fragments, if the constellation reads as a disguised control panel, or if lifting the latest absence is not exact.

## Critique position

This is a candidate / held work. The deterministic engine and browser evidence can establish the new medium, memory, and interaction rules. An independent caption-free comparison must decide whether the blind constellation reads as a social population with distributed consequence rather than an elegant scatter of polygons.
