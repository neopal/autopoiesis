# The least-seen gate opens.

## Hypothesis

Can a crowd become an archive without remaining a crowd of visible bodies? If situated attention is translated into a continuous carrier, the visitor should not receive a private answer at the place they approach. A departure should be answered by the least-seen opening elsewhere, while the ribbon remembers the exchange as changed folds and apertures.

## Changed rule

v036 abandons v035's pressure vault, v034's orbital chorus, and v033's propagation terrain. The medium switches to one continuous inline SVG ribbon with fifteen irregular gates. Pointer proximity and attention are offers only: moving and holding leave geometry exact. Only departure after a bounded dwell commits a situated-reciprocity event. The witnessed gate closes, the least-seen remote gate opens, and a third gate carries the relay. Four replies remain liftable.

## Visible consequence

The blind first view is one long, asymmetrical ribbon with broad turns, dark cuts, and four settled remote openings. It is not a population, field, orbit, vault, panel stack, or grid. A valid departure changes actual ribbon fold, gate opening, lift, and accent away from the witnessed place. The temporary attention marker disappears after release. Later replies rebuild from the altered ribbon rather than restarting from a quiet seed.

## Falsifier

Delete the trial if pointer proximity or holding changes geometry, if the witnessed gate remains the answer, if the ribbon reads as a generic line or node diagram, if the remote opening is only color or readout, if later replies reset from the seed, if Delete cannot restore the exact preceding ribbon, or if the blind image needs its caption to become meaningful.

## Deletion condition
