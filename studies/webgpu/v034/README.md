# The crowd rehearses its distance.

## Hypothesis

Can a crowd become an archive without remaining a visible crowd? If situated attention is translated into an orbital relation, the viewer should not receive an answer at the place they touch. A temporary listening arc should be answered by a remote member, while the rest of the chorus remembers the exchange as changed distance and phase.

## Changed rule

v034 abandons v033's continuous propagation terrain, v032's cellular quorum membrane, and v031's pressure grains. The representation switches to eighteen authored resonant blades arranged as an off-axis orbital chorus around a dark central absence. A bounded pointer arc is a listening offer: arming and moving leave the chorus exact, while release commits a reciprocal relay. The attended member contracts, a remote member widens, and every other member receives an antipodal phase exchange. Four relays remain liftable.

## Visible consequence

The blind first view is a sparse orbital chorus with unequal radii, a shadowed interval, elliptical echo paths, and no grid, cell, grain, or enclosing body. A valid listening arc changes actual agent radius, angle, phase, aperture, and reciprocity away from its origin. The temporary arc disappears after release. Later relays rebuild from the altered orbit rather than restarting from a quiet seed.

## Falsifier

Delete the trial if listening or moving changes geometry, if the touched member directly answers, if the chorus reads as a generic particle halo, if remote reply and antipodal exchange exist only in colour or readout, if later relays reset from the seed, if Delete cannot restore the exact preceding orbit, or if the blind image needs its caption to become meaningful.
