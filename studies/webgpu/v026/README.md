# The crowd files the witness.

## Hypothesis

WebGPU's collective question can leave spatial mass and become a document: if attention requires two non-local places to agree, the archive should keep their disagreement as missing and shifted geometry in one printed register.

## Changed rule

v026 abandons v023's continuous membrane, v024's vertical procession, and v025's spatial crown. The representation becomes one pale typographic register made from six rows of interrupted record bars. The encounter changes from token sealing, measured hold, and immediate address to a two-place handshake: the first witness arms without history; a second non-local witness seals a pair. The source record is actually excised, the target record shifts its break as a reply, and the corridor between them is re-set. Memory is bounded to four pairs; Delete lifts the latest pair and R releases the register.

## Visible consequence

The blind first view is a printed sheet with unequal bars, missing intervals, and a dark surrounding field, not a body, loop procession, mesh, radial crown, or node lattice. After a pair, one bar loses a real section, another moves its break, and the records between them tilt and offset. The relation is carried by the register's changed segments rather than by a cursor, glow, or counter.

## Cultural translation

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** pressure, density, grain, and directional fields participate in producing geometry rather than decorating finished geometry.
- **Mutine translation:** invert p5.brush's immediate local production rule. Refuse brushes, marks, watercolor, and hatching; defer pressure until a second non-local place answers the first witness by creating a material excision, a shifted reply, and a re-set corridor in the register.
- **Visible consequence:** one tap remains memory-neutral; a non-local pair changes actual record segments at both ends and actual offsets in the corridor; four pairs compound and can be lifted exactly.
- **Anti-copy statement:** no p5.brush brushes, watercolor appearance, hatching vocabulary, source palette, source composition, examples, or API surface is reproduced.
- **Direction consequence:** closes the WebGPU current's solid-body / loop / membrane family and opens a document-computation direction where material agency is held as contested registration and absence.

## Falsifier

Delete the trial if a first tap writes history, if a pair only changes colour or a readout, if the source gap and target reply are cosmetic overlays rather than missing record segments, if the corridor does not inherit the pair, if Delete cannot restore the exact prior register, or if the blind image reads as a generic bar grid.

## Deletion condition

After two independent labels-off and controls-off comparisons, delete v026 if viewers cannot find an actual excision and a displaced reply after the first pair, or if the two-place handshake is indistinguishable from selecting two decorative highlights. Do not rescue a failed document rule with captions, counters, or extra texture.

## Evidence method

The engine is deterministic from `SEED`, replays a four-pair memory window, stores an exact entry-and-segment signature, and rebuilds the prior register on lift. The tableau requests a WebGPU device and submits a WGSL paper veil when available; the Canvas layer is the deterministic typographic fallback and remains the source of causal register geometry on machines without WebGPU.
