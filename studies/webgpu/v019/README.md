# The crowd borrows a phase.

## Hypothesis

If situated attention is translated into timing rather than visible agents, one cube can carry a phase it did not originate and force a remote cube to echo the error. The loom should remember the transfer as geometry, not as a counter.

## Changed rule

v019 abandons the prior crowd's broadcast field and makes a compact cube loom the medium. Arrow selection arms a signal lane without writing history. A broadcast commits a borrowed phase: the carrier cube changes its seam and tilt, a non-adjacent cube shifts as an echo, and the bounded archive changes the next phase debt. Delete lifts only the latest broadcast; Escape or R releases the loom.

## Visible consequence

The blind view is a spatial loom of faceted cubes with faint tension paths, not a point cloud or text label. After a broadcast, a carrier receives an orange seam and a remote cube receives a violet echo; repeated broadcasts alter the phase and placement of later responses.

## Cultural translation

- **Reference:** [little-critters](https://github.com/GordenSun/little-critters)
- **Observed mechanism:** situated agents respond through proximity and reciprocal attention.
- **Mutine translation:** translate reciprocal attention into borrowed timing: a selected signal is carried by one cube and returned through a non-adjacent cube as a phase echo.
- **Visible consequence:** the carrier and remote echo move actual cube geometry and later transfers inherit phase debt.
- **Anti-copy statement:** no animals, eyes, characters, source palette, scene, composition, API, or head-turning imagery is reproduced.
- **Direction consequence:** opens the WebGPU period's signal/material direction, then closes its cube grammar for the subsequent sheet experiment.

## Falsifier

Delete the trial if selection writes history, if a pointer tap commits, if the seam or echo is only a line overlay, if later broadcasts ignore phase debt, or if the blind view reads as a decorative cube wall whose meaning requires the caption.

## Deletion condition

If two labels-off comparisons cannot distinguish the carrier's seam and remote echo from decoration, delete v019 rather than polishing its readout.

## Evidence method

The engine is deterministic from `SEED`, stores four broadcast events, returns a geometry signature, and reconstructs the prior loom exactly when the latest event is lifted. A WebGPU pipeline is requested when available; the Canvas cube rendering remains the deterministic visual fallback.
