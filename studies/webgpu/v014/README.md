# WebGPU v014 — The crowd compacts into a pressure map.

## Hypothesis

A crowd can become an archive without remaining a crowd. If pressure compacts many independent positions into one continuous surface, the field can remember where force entered as height, crease, and displaced geometry rather than as a route or a label.

## Changed rule

v014 abandons the last three WebGPU grammars: route strata, deferred arrival, and discrete reciprocal marks. A bounded pressure path acts on a tessellated surface. Nodes near the path compact and rise, their tilt and grain change, and a crease remains in the mesh. The archive is the surface state itself.

## Visible consequence

The first blind render is a continuous topographic object: a translucent tessellated plane with raised ridges, shallow valleys, and a nonuniform horizon. It is not a field of separate agents. After a drag, actual node positions, height, tilt, grain, and crease load change along the pressure path; lifting only the newest pressure reconstructs the exact previous surface.

## Interaction and reversibility

- Drag across the field: register one bounded pressure path; path length and pressure alter the deformation.
- Enter or Space: register the canonical deterministic pressure path.
- Delete or Backspace: lift only the latest pressure.
- Release current: clear visitor memory and restart the autonomous sequence.

The engine is pure and deterministic. Visitor paths are clamped, copied into bounded memory, and replayed from the same stage.

## Cultural translation

- **Reference:** `p5-brush` / p5.brush.
- **Observed mechanism:** programmable material tools make pressure, density, grain, and directional fields alter how geometry is produced rather than being a skin applied after geometry.
- **Mutine translation:** pressure is promoted from a property of an individual stroke to a collective topological event: a crowd compacts into one surface, lifts a crease, and stores load in the mesh.
- **Falsifier:** if the blind field still reads as independent marks, if the pressure only changes colour, or if the crease is a witness painted above unchanged nodes, the translation fails.
- **Anti-copy:** no brush library, watercolor appearance, hatching vocabulary, palette, composition, or API surface is reproduced.
- **Direction consequence:** closes WebGPU v009–v013's route and agent grammar and opens a pressure-surface period in which the crowd becomes a material record.

## Falsifier

If caption-free viewing sees a decorated grid rather than a continuous surface, if the path does not produce a visible height/crease event, or if lifting the latest pressure does not restore the exact prior geometry, v014 is a technical effect rather than a new WebGPU direction.

## Deletion condition

Delete v014 if a labels-off, controls-off, readout-off comparison still reads as the previous angular crowd field, or if the pressure path is only an annotation and not a causal change in the surface.

## Determinism

Seed: `0x57475040`. The engine uses a local seeded PRNG for base topology and autonomous pressure bands. Repeated state and lift sequences produce identical surface signatures.
