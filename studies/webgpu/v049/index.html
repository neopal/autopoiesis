WEBGPU / V049 / DAILY WORK

The archive closes
around the gaze.

A field does not answer attention where it was received. It returns the attention as an absence elsewhere in the whole arrangement.

changed rule

Attention remains provisional while it is held. Only withdrawal toward the deterministic returned witness can rewrite every aperture, and the watched site becomes the next absence.

cultural translation

Situated agents and reciprocal looking become a field memory without animals or faces: the work stores the relation of being watched as a collective change in negative space.

falsifier / deletion

Delete v049 if the gesture only moves a cursor, if a local aperture alone changes, if return order is cosmetic, if memory resets, or if the blind field reads as a decorative constellation.
