# WebGPU v049 — The archive closes around the gaze.

## Concept

The continuous 3D pressure shell is abandoned. In its place is a flat, dark field
of listening apertures: not a population of bodies, not a mesh, and not a route
surface. The work is a negative-space instrument that stores the relation between
being watched and withdrawing.

## Hypothesis

If reciprocal looking is translated into a collective memory of absence, then
attention must remain provisional while it is held. Only a withdrawal toward the
field's returned witness should re-produce every aperture, while the watched site
becomes the next absence. The change must be visible in the field, not in a cursor,
status message, or selected target.

## Changed rule

The visitor attends to the lit witness and then withdraws toward its deterministic
return. A repeated gaze, wrong witness, incomplete hold, or wrong return is
geometry-neutral. A valid return changes the gap, aperture, echo, and attention of
every site. The entry becomes an absence and the reply becomes the only next
witness. Four returns compound. Delete lifts the latest return; Escape releases the
field back to its quiet seed.

## Cultural translation

The source is [little-critters](https://github.com/GordenSun/little-critters), whose
observed mechanism is a situated population whose local proximity changes attention
and produces a reciprocal look-back. Mutine refuses animals, faces, paper style,
head-turning scenes, source composition, source code, and surface vocabulary. The
translated mechanism is a collective attention debt: the field remembers being
watched by changing negative space, not by drawing an agent that looks back.

## Visible consequence

The caption-free first view is a flat constellation of angular apertures with a deep
central quiet and no 3D surface. A valid return rotates and widens the openings
across the whole field, lays a new counter-axis through the arrangement, and closes
the watched witness into an absence. Four returns leave four absence sites and a
field that can be lifted exactly.

## Interaction

- Pointer or touch: press the lit witness, then release near its returned witness.
- `Enter` / `Space`: make the next deterministic return.
- `Delete` / `Backspace`: lift the latest return.
- `Escape` / `R`: release the complete absence memory.
- The three visible controls expose return, lift, and release without hover.

`?preview=1` removes editorial furniture. `?preview=1&static=1&blind=1` removes
readout, controls, status, hint, caption, and prose while retaining the settled
four-return field.

## Falsifier

Delete v049 if the gesture only moves a cursor, if one aperture alone changes, if
return order is cosmetic, if later returns reset the field, if exact lifting fails,
or if the blind field reads as a decorative constellation or generic particle demo.

## Deletion condition

Delete this direction if caption-free viewing cannot distinguish reciprocal absence
from v046's folded cadence, v047's social absence arch, and v048's pressure shell,
or if the return rule is only legible through explanation.

## Direction consequence

This closes WebGPU's material-topology sequence and opens a negative-space period:
the crowd question is tested without a crowd, through a field that stores being
seen as a changed arrangement of openings. The abandoned rule is that WebGPU must
be represented by a surface with depth or a route across a body. The next rupture
must decide whether absence can become a spatial computation without reverting to
agents or mesh.

## Medium and reproducibility

The executable tableau uses deterministic Canvas 2D geometry. `navigator.gpu` is
reported only as a capability signal, so the work remains viewable on browsers
without WebGPU while retaining a truthful capability boundary. The same seed,
return sequence, and memory state produce the same field signature.
