# WebGPU v043 — The material changes where it resists.

## Concept

One suspended membrane is made from twelve unequal cells. It is not a crowd of
objects and it does not illustrate a pressure meter: the cells are a single
material sentence whose internal facets can be produced again elsewhere.

## Hypothesis

If material behaviour is treated as a production rule rather than as a skin,
then a grain-aligned trace can spend resistance in a remote facet. The trace
should remain geometrically quiet while incomplete or misaligned; a valid
passage should leave its touched cell exact and change how an untouched cell is
made.

## Changed rule

The viewer does not select a witness, wait on a site, or close a circuit. A
pointer or touch trace begins a provisional passage. It remains geometry-neutral
until its span crosses `0.58` and its alignment with the local grain crosses
`0.62`. Only then does a `resistance-transfer` event commit. Its material
resistance is transferred to a remote cell: the remote facet gains actual
triangulation, warp, depth, and ridge geometry while the source remains exact.
Four transfers compound and can be lifted in reverse order.

## Cultural translation

The source is [p5.brush](https://github.com/acamposuribe/p5.brush), whose observed
mechanism treats pressure, density, direction, and field logic as production
rules that change how geometry is generated rather than decorating a finished
mark. Mutine refuses its brush presets, watercolor appearance, hatching, grain,
palette, composition, source code, examples, and API surface. The translated
rule is material resistance inside a 3D membrane: a directional passage changes
the construction of an unobserved remote facet.

## Visible consequence

The caption-free first view is one oblique, suspended 3D membrane of twelve
unequal facets with a dark underside and a cool mineral edge. An incomplete or
misaligned trace leaves every cell exact. A valid passage leaves the source
cell exact while a remote cell gains new triangular planes, depth, warp, and a
raised ridge. Direction and resistance change which remote facet is produced;
four transfers remain visible and can be lifted exactly.

## Interaction

- Pointer or touch: trace a long passage across the membrane, following its grain.
- `Enter` / `Space`: make the next deterministic grain trace.
- `Delete` / `Backspace`: lift the latest resistance-transfer event.
- `Escape` / `R`: release the material memory.
- The three visible controls expose the same trace, lift, and release paths.

The first render appears before explanation. `?preview=1` removes editorial
furniture; `?preview=1&static=1&blind=1` removes readout, controls, status,
caption, and notes while retaining the settled four-transfer membrane.

## Falsifier

Delete v043 if an incomplete or misaligned trace changes geometry, if the
traced cell changes, if the remote response is only colour or readout, if every
receiver is identical, if later transfers reset, if the blind image reads as a
generic 3D tile object, or if lifting is inexact.

## Deletion condition

Delete this direction if caption-free viewing cannot distinguish the resistance
membrane from v040's depth accord, v041's waiting fossil, and v042's shadow
quorum, or if the material threshold is only an explanation rather than a
visible change in remote facet production.

## Direction consequence

This closes WebGPU's recent sequence of witness agreement, waiting, and remote
shadow. It opens material computation as a spatial rule: the current is no
longer a population that answers the visitor, but one body whose resistance
changes the ontology of a place the visitor did not touch. The abandoned rule is
that the archive must be carried by a selected, held, or moving witness.

## Medium and reproducibility

The tableau is produced by p5.js 1.11.3 WEBGL custom triangular faces and
extruded side planes. `engine.mjs` is pure, seeded, and deterministic. Browser
capability is reported with `navigator.gpu` without making the work depend on a
proprietary GPU path. The same source, trace direction, span, and alignment
sequence produce the same resistance-membrane signature.
