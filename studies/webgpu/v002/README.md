# WebGPU v002 — The crowd arrives out of order

## State

`v002` is a daily work under critique. It is recorded as a candidate, not as a finished period.

## Creative hypothesis

A crowd becomes an archive when a remembered point changes the order in which later bodies arrive. The past should be carried as latency in the field, not as a pin, a caption, or a separate history panel.

## Changed rule

The WebGPU current asked whether a crowd could become an archive. v002 changes v001's spatial-bend rule into an arrival rule: each archived point creates a bounded latency debt for agents that cross its lane. Debt shifts the agents' phase and arrival coordinate, so downstream rows shear into staggered bands. Up to four debts are inherited. The renderer remains WebGPU-ready and keeps a deterministic Canvas fallback so the causal experiment survives without an adapter.

## Visible consequence

At the opening state, 432 agents cross a dark topographic field in three signal layers. As autonomous debts enter the timeline, later bodies no longer arrive in one shared cadence: luminous rows split into fine bands, with short timing threads showing the displaced return. The coral witnesses are deliberately quieter than the changed crowd geometry. The final state contains four inherited debts.

## Visitor action

In an interactive preview, click the field or focus it and press `Enter`/`Space` to commit a delay. `Delete`/`Backspace` lifts the latest debt. `release crowd` clears the visitor state and restarts the autonomous sequence. Capturing and deleting rebuild agent coordinates through the engine; they do not merely toggle a marker.

## Determinism

The fixed numeric seed is `0x57475032` in `engine.mjs`. The same stage and debt memory return the same agent coordinates, archive ledger, and aggregate arrival values. No browser history or local storage is used.

## Falsifier and deletion condition

Delete this direction if a caption-free viewer cannot identify a staggered arrival band when the coral debt witnesses and readout are hidden, or if lifting a debt does not change the downstream field. The direction is also deleted if the latency threads read as decorative rays rather than evidence of changed arrival.

## Evidence boundary

The structural tests prove deterministic latency, bounded input, and exact restoration. Browser preview, adapter availability, interaction, reduced-motion, resize, console, network, and five-viewport evidence are recorded separately; an unobserved or blocked browser run must not be described as a release pass.
