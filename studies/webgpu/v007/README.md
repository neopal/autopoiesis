## State

## Creative hypothesis

A crowd becomes an archive when an absence changes not only where bodies go, but how closely they return. The record should be a wake in the mass, not an annotation placed beside it.

## Changed rule

v006 made a remembered encounter split downstream agents into paired near/far routes and rejoin them. v007 changes the rule: a remembered absence opens opposing routes, draws them back toward a common line, then compresses the returning bodies into a shared downstream census wake. The finite memory window retains five absence records. Near the right edge, the available runway is shortened so a bounded visitor absence still produces a visible wake rather than falling off the field.
