# WebGPU v037 — The mass stores the pause.

## Hypothesis

If a collective is rendered as one material volume rather than as a population of agents, a viewer's turn can become a change in the body's internal load. The visible archive should be a changed object, not a route diagram.

## Artistic direction

The last three WebGPU works used a population/field grammar: v034's orbital chorus, v035's pressure vault, and v036's reciprocal ribbon. They all asked the visitor to arm a bounded pointer relation and release it into a remote answer. v037 makes a material and encounter rupture: the crowd is replaced by one oblique 3D sediment prism, and the visitor rotates the object through a complete sweep instead of attending a gate, measuring a delay, or departing a ribbon.

The p5.brush reference is translated at the level of production logic only. A turn is not a texture or a camera filter. It is a load event that changes how the next geometry is produced: the layer under the gesture stays nearly quiet while a remote layer shears, deepens its cut, and draws neighbouring strata into settlement.

## Changed rule

A preview rotation is view state and cannot write memory. Only a bounded complete turn commits. The source layer under the beginning of the gesture remains almost exact; a remote layer receives the material shear, and the prism stores up to four remote turns.

## Visible consequence

The blind first view is a single p5.js WEBGL sediment prism: fourteen stacked strata, an oblique silhouette, an internal cut, weighted depth, and a dark field of particulate matter. After a valid turn, a remote stratum visibly displaces and shears while the approached layer remains close to its quiet geometry. Later turns inherit the previous block, and lifting reconstructs the exact preceding volume.

## Interaction

- Pointer/touch: drag across the prism and release after a bounded sweep.
- Keyboard: Arrow keys preview a turn; Enter/Space commits the deterministic turn; Delete/Backspace lifts the latest turn; Escape/R releases the archive.
- Buttons: deterministic turn, lift latest, release mass.
- `?preview=1` removes editorial furniture. `?static=1` shows the settled deterministic timeline. `?blind=1` hides labels, readout, controls, annotations, and prose for caption-free review.

## Falsifier

Delete v037 if the preview deforms the prism before release, if a short or overlong sweep commits, if the touched layer remains the answer, if the remote shear exists only in colour or readout, if the blind object reads as a generic 3D stack, if later turns reset, or if exact lifting fails.

## Deletion condition

Delete this work if caption-free viewing cannot distinguish a load-bearing material volume from the previous WebGPU population grammars, or if the remote material rule is not visible in the produced geometry.

## Direction consequence

This closes the WebGPU sequence of orbit, vault, terrain, and ribbon relations as a field of situated agents. It opens a spatial-computation direction in which the collective is compressed into a volume and memory is a material shear in a layer the visitor did not touch.
