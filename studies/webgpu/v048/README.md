# WebGPU v048 — The surface chooses the next mouth.

## Concept

A single continuous faceted shell replaces the recent WebGPU stratigraphic mass,
folded chorus, and absence arch. It is deliberately not a crowd of cells or
witnesses: one produced surface carries the question, with five ports that act
as material mouths around its edge.

## Hypothesis

If pressure is treated as a production rule rather than as a mark, then a
source-to-exit route should re-produce the whole shell and hand its exit to the
next route. The shell must change in curvature, depth, torsion, facet pressure,
and seam lift, not only in a status message or colour. A wrong origin or exit
must fail because the material field remembers where it last left the surface.

## Changed rule

The viewer presses the lit source port and releases at its deterministic exit.
An incomplete route, repeated source, wrong origin, or wrong exit is
geometry-neutral. A valid route changes the continuous shell itself; its exit
becomes the only valid source for the next pressure event. Four routes compound.
Delete lifts the latest route and reconstructs the preceding shell; Escape
releases the material archive to the quiet seed.

## Cultural translation

The source is [p5.brush](https://github.com/acamposuribe/p5.brush), whose observed
mechanism treats pressure, density, directional behaviour, fills, and vector
fields as a programmable material engine that changes how geometry is produced.
Mutine refuses its brushes, watercolor appearance, hatching, grain, palette,
composition, source code, examples, and API surface. The translated mechanism is
pressure routing: a gesture is not drawn; it changes the field that produces the
next shell and hands its exit forward.

## Visible consequence

The caption-free first view is one dark, asymmetrical, faceted surface in an
open void. Five small ports sit on its edge, but there is no grid of bodies, no
arch rail, and no diagonal chorus. A valid route makes a raised seam and changes
curvature, depth, torsion, and facet weight across the whole shell. The next
source visibly migrates to the route's exit. Four routes persist as a cumulative
material state.

## Interaction

- Pointer or touch: press the lit port, then release at the chosen exit.
- `Enter` / `Space`: make the next deterministic pressure route.
- `Delete` / `Backspace`: lift the latest route.
- `Escape` / `R`: release the complete material archive.
- The three visible controls expose route, lift, and release without requiring hover.

`?preview=1` removes editorial furniture. `?preview=1&static=1&blind=1` removes
readout, controls, status, hint, caption, and prose while retaining the settled
four-route shell.

## Falsifier

Delete v048 if a route only adds a decorative line, any port can begin the next
event, wrong exits commit, the shell remains fixed, memory resets, lifting is
inexact, or the blind work reads as a generic mesh demo.

## Deletion condition

Delete this direction if caption-free viewing cannot distinguish the pressure
shell and its stateful handoff from v045's stratigraphic mass, v046's folded
ledger, and v047's absence arch, or if the route rule is only legible through
explanation.

## Direction consequence

This closes the WebGPU sequence of load, cadence, and social absence. It opens a
material-topology period: the crowd question is tested through one continuous
body whose next possible event is constrained by where the last event exited.
The abandoned rule is that the current must be represented by discrete witnesses,
voices, or slabs. Here the archive is carried by production itself.

## Medium and reproducibility

The executable tableau uses p5.js 1.11.3 WEBGL with a seeded surface mesh,
pressure-dependent facet fills, and generated route seams. `engine.mjs` is pure
and deterministic; `navigator.gpu` is reported only as a capability signal. The
same seed, route sequence, and memory state produce the same shell signature.
