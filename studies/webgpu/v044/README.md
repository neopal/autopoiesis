# v044 — The field answers elsewhere.

## Hypothesis

If a collective field remembers being seen, it should not make the approached object perform. The memory should be spent as a topological change in a portal the visitor never entered.

## Changed rule

An approach is inert. A handoff from one aperture to a distinct second aperture opens a third, unvisited aperture. The approached pair stays geometrically exact. The field can hold four reciprocal handoffs; lifting removes only the latest one and release reconstructs the deterministic quiet field.

## Visible consequence

The first encounter is a sparse orbit of eleven apertures around one dark negative centre, not a body, shard field, or faceted membrane. A valid handoff changes the opening, depth, and nested aperture geometry of a remote portal. The source and observer do not answer locally. The same state is reachable by pointer drag, touch control, keyboard, or the relay button.

## Falsifier

Delete this direction if an incomplete approach changes geometry; if the source or observer portal changes; if the remote aperture is only a colour, label, cursor, or readout; if four handoffs fail to compound; if lifting is inexact; or if the blind image reads as a generic orbit diagram instead of a collective topology.

## Deletion condition

Delete v044 if caption-free viewing cannot distinguish its negative-aperture grammar from v041's fossil, v042's moving witness field, or v043's resistance membrane, or if the remote change is not visible without prose.
