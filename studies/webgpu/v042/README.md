# WebGPU v042 — The crowd leaves an unobserved shadow.

## Concept

Eighteen witness shards drift through a broken current. They are not a crowd
of selectable objects; they are a moving population whose after-images appear
only when an encounter completes a circuit and returns to its beginning.

## Hypothesis

If situated attention is translated into a closed relation rather than a local
selection, then the visitor's circuit can make the unobserved part of a field
carry the archive. The open circuit should remain geometrically quiet, while a
closed return should cast a remote shadow whose direction and tension change
actual witness geometry.

## Changed rule

The visitor does not select a witness and does not hold a site. A pointer or
touch drag begins a provisional circuit. The circuit remains geometry-neutral
until it has travelled at least `0.78` turns and returns within the closure
threshold. Only then does a `shadow-quorum` event commit. Its direction sends a
remote cast to a different witness; four quorums compound and can be lifted in
reverse order.

## Cultural translation

The source is [little-critters](https://github.com/GordenSun/little-critters),
whose observed mechanism makes situated proximity legible as reciprocal
attention: local agents notice the visitor and answer without a dashboard.
Mutine refuses its animals, eyes, characters, paper scene, head-turning,
palette, composition, source code, examples, and API surface. The translated
rule is a closed circuit of attention: the visitor returns to the beginning,
but the archive appears in an unobserved witness as a directional shadow.

## Visible consequence

The caption-free first view is a wide, kinetic population of eighteen irregular
shards with faint wakes and a dark center of unclaimed space. An open or
incomplete circuit leaves every witness exact. A valid return leaves the source
witness exact while a remote witness gains a real cast: its position, angle,
scale, phase, opacity, and wake change. Clockwise and counter-clockwise returns
produce different remote shadows; four changes remain visible and can be
lifted exactly.

## Interaction

- Pointer or touch: drag a circuit around the field and release near its start.
- `Enter` / `Space`: make the next deterministic closed circuit.
- `Delete` / `Backspace`: lift the latest shadow-quorum event.
- `Escape` / `R`: release the archive.
- The three visible controls expose the same circuit, lift, and release paths.

The first render appears before explanation. `?preview=1` removes editorial
furniture; `?preview=1&static=1&blind=1` removes readout, controls, status,
caption, and notes while retaining the settled kinetic field.

## Falsifier

Delete v042 if an open circuit changes geometry, if a local witness answers the
visitor, if direction is cosmetic, if the remote cast is only a trail or
readout, if the blind image reads as a generic particle demo, if later quorums
reset, or if lifting is inexact.

## Deletion condition

Delete this direction if caption-free viewing cannot distinguish the kinetic
shadow-quorum grammar from v039's pressure reservoirs, v040's depth accord,
and v041's waiting fossil, or if the closed return does not produce a remote
material consequence.

## Direction consequence

This closes WebGPU's recent stationary-body and chosen-witness sequence. It
opens a social-circuit direction: collective computation is tested as a moving
population, a completed return, and an archive carried by the witness that was
not where the visitor acted. The abandoned rule is that the archive must begin
with a selected or held site.

## Medium and reproducibility

The tableau is produced by p5.js 1.11.3 Canvas 2D and an offscreen graphics
buffer. `engine.mjs` is pure, seeded, and deterministic. Browser capability is
reported with `navigator.gpu` without making the work depend on a proprietary
GPU path. The same source, circuit direction, and closure sequence produce the
same shadow-quorum signature.
