# The archive changes the weather.

## Hypothesis

A collective archive can be represented as one adaptive material field rather than a wall of entries: if a released sweep crosses the field, the cells it encounters should bend and open, a distant return should reroute, and the residue of that event should alter the next available route.

## Changed rule

v022 abandons v019's broadcast loom, v020's oblique crease sheet, and v021's chorus lattice. It changes the representation and encounter together: a single irregular field of joined cells replaces cubes, slices, and bands; a real pointer sweep is measured and committed on release instead of selecting a carrier or sending a call. The sweep changes cell coordinates, bend, opening, and swell, then opens a non-local cut and shifts a return cell. Residue changes route selection for later sweeps. Delete lifts the latest sweep; R releases the untouched field.

## Visible consequence

The blind first view is a dark adaptive weather body made from irregular filled cells, not a grid, voxel wall, line field, or score. After a sweep, actual silhouettes bow and open along its path, a remote cell returns with a changed bend, and a distant cut becomes a material absence. Repeated sweeps do not redraw the same route: they inherit residue and produce different geometry. The rule lives in coordinates and polygon construction, not in a counter or caption.

## Cultural translation

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** p5.brush treats natural drawing tools, pressure, density, grain, and vector fields as programmable material forces; vector fields bend strokes and material changes how geometry is produced rather than decorating a finished mark.
- **Mutine translation:** refuse brushes, watercolor, hatching, and the library's surface vocabulary. Translate the mechanism into WebGPU's collective question: a released sweep becomes a field force that reroutes actual cells, opens a non-local cut, and leaves residue that changes the next route.
- **Visible consequence:** dragging is not a paint overlay. Release changes the field's polygonal bodies, makes a wake of bent/open cells, moves a remote return, and leaves a visible absence; later sweeps inherit the altered field.
- **Anti-copy statement:** no p5.brush brushes, watercolor appearance, hatching vocabulary, source palette, API surface, example composition, or source mark-making is reproduced.
- **Direction consequence:** closes WebGPU's cube / sheet / lattice family and opens an adaptive-topology direction in which collective memory is a weather-like field force rather than a population of visible agents.

## Falsifier

Delete the trial if a short tap commits, if the sweep only draws a line over fixed cells, if the remote return or cut is decorative, if later routes ignore residue, or if the blind field reads as decorative polygon tiles that need the caption to become collective.

## Deletion condition

After two independent labels-off and controls-off comparisons, delete v022 if viewers cannot find a continuous adaptive body, a wake, a changed remote return, and a materially open cut in the silhouettes themselves. Do not polish the controls or prose to rescue a failed visual grammar.

## Evidence method

The engine is deterministic from `SEED`, replays a four-sweep memory window, stores a geometry signature, and rebuilds the exact preceding state on lift. The tableau requests a WebGPU device and submits a minimal WGSL field pass when available; the Canvas layer is the deterministic contour fallback and remains the source of the causal cell geometry on machines without WebGPU.
