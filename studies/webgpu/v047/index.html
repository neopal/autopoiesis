WEBGPU / V047 / DAILY WORK

The crowd keeps
an empty seat.

The arch does not answer the gaze. It stores it as a missing body somewhere else.

changed rule

Three distinct looks make a remote witness leave. The attended witnesses turn, the untouched arch reorients, and the remote geometry becomes an actual gap.

cultural translation

Situated agents and reciprocal attention become a social refusal: being seen is remembered as defection, not as a decorative cursor or a local reply.

falsifier / deletion

Delete v047 if repeated or incomplete looks commit, if the attended site changes alone, if a gap is only colour, or if the blind arch reads as a generic gate or diagram.
