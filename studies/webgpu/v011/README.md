## Creative hypothesis

A crowd becomes an archive when an absence changes not who arrives next, but when. The record should be a finite pocket of held mass, a downstream release, and a late echo in the field—not a caption beside an unchanged crowd.

## Changed rule

v010 made a remembered absence exchange neighboring lanes through a finite crossing. v011 changes the rule: a remembered absence holds a cohort in a bounded pocket, releases it downstream, and leaves a staggered arrival trace. The memory window retains eight delay records. Visitor coordinates are clamped to the inner field so edge gestures still create a real delay.
