# WebGPU v040 — The crowd agrees on a missing depth.

## Concept

A continuous fragment field shows nine translucent depth sheets around a dark,
vertical absence. It is not a set of bodies, a grid, or a route diagram. The
field is a cross-section of a collective decision whose missing layer is the
subject.

## Hypothesis

If situated attention is translated into a collective depth computation, then
three distant witnesses can form an accord without deforming their own sites.
The answer should be produced by a remote layer: its depth, aperture, phase,
and order change in the shader field while the selected witnesses stay exact.

## Changed rule

Choosing one, two, or three witnesses is geometry-neutral. Only a completed
three-witness accord writes history. The accord reorders the depth stack and
changes a remote sheet plus the shared missing channel. Four accords compound
from retained events; the viewer can lift them in reverse order.

## Cultural translation

The source is [little-critters](https://github.com/GordenSun/little-critters),
whose observed mechanism is situated agents responding to visitor proximity
with reciprocal attention. Mutine refuses its animals, eyes, characters, paper
scene, head-turning gesture, palette, composition, code, examples, and API
surface. The translation is a three-site accord: local witnesses remain still,
while collective attention changes an unselected depth layer.

## Visible consequence

The caption-free first view is a continuous, luminous cross-section with a dark
missing channel and layered spectral edges. Selecting witnesses leaves the
shader geometry exact. A valid accord changes actual remote sheet depth, width,
phase, aperture, and draw order; four changes remain visible in the settled
field and can be lifted exactly.

## Interaction

- Pointer or touch: tap three distinct sites in the field, then make an accord.
- `Enter` / `Space`: make the next deterministic three-witness accord.
- `Delete` / `Backspace`: lift the latest accord.
- `Escape` / `R`: release the archive.
- The three visible controls expose the same accord, lift, and release paths.

The first render appears before explanation. `?preview=1` removes editorial
furniture; `?preview=1&static=1&blind=1` removes readout, controls, status,
caption, and notes while retaining the settled depth field.

## Falsifier

Delete v040 if choosing a witness changes geometry, if a repeated site counts,
if fewer than three sites can commit, if the selected sites are the answer, if
the remote depth response exists only in colour or text, if the blind field
reads as a generic shader or diagram, if later accords forget, or if lifting
does not reconstruct the exact prior field.

## Deletion condition

Delete this direction if caption-free viewing cannot distinguish the depth-accord
grammar from v037's prism, v038's lattice, and v039's pressure reservoir, or if
the unselected layer does not materially change its position in the field.

## Direction consequence

This closes the WebGPU sequence of prism, lattice, and reservoir objects. It
opens a continuous spatial-computation grammar in which a crowd is not a set of
parts but a changed ordering of depth. The abandoned rule is that memory must
be painted into a touched body, cell, or reservoir; v040 stores it in the layer
that no witness touched.

## Medium and reproducibility

The tableau is produced by p5.js 1.11.3 WebGL and an inline GLSL fragment
shader. `engine.mjs` is pure, seeded, and deterministic. Browser capability is
reported with `navigator.gpu` without making the work depend on a proprietary
GPU path. The same source, witness sequence, and pressure sequence produce the
same field signature and depth order.
