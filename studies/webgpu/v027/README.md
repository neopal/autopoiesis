# The volume keeps what attention misses.

## Hypothesis

Can a crowd become an archive without becoming a register? If situated attention is gathered as a trace and only departure commits it, the least-witnessed basin should receive a visible collective wake rather than the place the visitor touched.

## Changed rule

v027 abandons v024's vertical procession, v025's pressure crown, and v026's interrupted witness register. The representation becomes a shallow projected volume: nine irregular basins overlap in depth and are joined by translucent current channels. Proximity is observational. Pointer travel records a trace, but release after three distinct basins elects the least-witnessed basin away from the source. The elected basin swells, the source contracts, and a remote relay inherits the wake through opened and bent channels. Memory is bounded to four wakes; Delete lifts the latest wake and R releases the volume.

## Visible consequence

Later wakes inherit the altered current field.
