# WebGPU v010 — The crowd keeps a switched order

## State

`v010` is the WebGPU daily candidate for 2026-09-15. It remains `candidate / held`: the deterministic and browser gates must pass, then an independent caption-free perceptual review must decide whether the crossing survives without its annotations.

## Creative hypothesis

A crowd becomes an archive when an absence changes the order of who arrives next. The record should be a crossing inside the mass, followed by an altered downstream order—not a caption placed beside an unchanged field.

## Changed rule

v009 made a remembered absence reverse a bounded packet against the main flow and rejoin downstream. v010 changes the rule: a remembered absence makes neighboring cohorts exchange lanes through a finite crossing interval, then carry that exchanged order into the downstream settle. The memory window retains seven switch records. Visitor coordinates are clamped to the inner field so edge gestures still create a real crossing.

## Visible consequence

Eighteen deterministic states carry 480 agents through a blue-black field as signal, body, and dust strata. The underlying agent coordinates contain an entry response, a crossing displacement, and a persistent post-crossing handoff. In the final seeded state, the engine measures 249 crossing agents, 170 switched agents, 232 settled agents, switch strength `0.04622637170922601`, and a latest-record lifted-field delta of `2.9002623868148483`.

## Visitor action

In an interactive preview, click the field or focus it and press `Enter`/`Space` to mark a bounded lane switch. `Delete`/`Backspace` or **lift latest** removes the newest record and rebuilds the crowd. **release current** clears visitor state and restarts the seeded sequence. Pointer and keyboard use the same engine path; neither is a marker-only toggle.

## Determinism

The fixed seed is `0x5747503a` in `engine.mjs`. The same stage and memory return the same agents, route records, switch ledger, and aggregate values. No browser history or local storage is used.

## Falsifier and deletion condition

Delete this direction if a caption-free viewer cannot identify a crossing and changed downstream order when switch witnesses, labels, and readouts are hidden. Delete it if the effect is only a glow, if the cohorts return to their original order, if edge clicks produce no bounded crossing, or if lifting the latest record does not restore the exact prior field.
