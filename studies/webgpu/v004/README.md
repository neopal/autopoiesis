# WebGPU v004 — The crowd replays what it crossed

## State

`v004` is a daily work under critique. It is recorded as a candidate, not as a finished period.

## Creative hypothesis

A crowd becomes an archive when a later cohort replays the local order of an earlier crossing. Memory should be carried by a repeated arrangement inside the mass, not by a marker, a counter, or a GPU label.

## Changed rule

v004 replaces v003's vacancy braid with a delayed rehearsal rule. Each remembered point stores a small signed gesture. Downstream agents enter an echo band where neighboring rows compress, inherit a phase fingerprint, and open back into the field as a displaced copy of the earlier local rhythm. Up to four rehearsals are inherited; a visitor rehearsal enters the same memory path as an autonomous one.

## Visible consequence

At the opening state, 432 deterministic agents cross a mineral-dark topography in signal, body, and dust strata. Later cohorts briefly gather into repeated pale/cyan rhythms before releasing. The echo witnesses, route threads, labels, and readouts can be hidden with `blind=1`; the underlying agent coordinates still change. The final state contains four inherited rehearsals and a measurable echo population.

## Visitor action

In an interactive preview, click the field or focus it and press `Enter`/`Space` to rehearse a place. `Delete`/`Backspace` lifts the latest rehearsal. `release crowd` clears visitor state and restarts the autonomous sequence. Rehearsing and lifting rebuild agent coordinates through the engine; they do not merely toggle a marker.

## Determinism

The fixed numeric seed is `0x57475034` in `engine.mjs`. The same stage and rehearsal memory return the same agent coordinates, archive ledger, and aggregate values. No browser history or local storage is used.

## Falsifier and deletion condition

Delete this direction if a caption-free viewer cannot identify a repeated cohort rhythm when the echo witnesses, threads, labels, and readouts are hidden, or if lifting a rehearsal does not change downstream coordinates. Delete it also if the repeated bands read as decorative waves rather than a later crowd replaying an earlier local order.

## Evidence boundary

Structural tests prove deterministic bounded input, replay metrics, and exact restoration. Browser preview, adapter availability, interaction, reduced-motion, resize, console, network, and five-viewport evidence are recorded separately; an unobserved or blocked browser run must not be described as a release pass.
