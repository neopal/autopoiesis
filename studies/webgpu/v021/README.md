# The field learns to answer.

## Hypothesis

A crowd can become a reciprocal instrument without being depicted as bodies: if a tuned call meets situated local phases, some places should answer, some should withhold their material, and a distant layer should return the call as a changed spatial relation.

## Changed rule

v021 abandons v020's continuous oblique sheet, v018's situated witness field, and v017's temporal score. It changes representation and encounter together: a three-layer WebGPU-ready lattice of solid nodes replaces slices and bands; pointer motion only arms a place, while keys 1–4 tune a carrier before Enter or Space sends a call. Each committed call is evaluated by local phase and distance. Resonant nodes lift and turn, mismatched neighbours open real low-activity vacancies, and a distant layer receives a relay. Carrier resistance alters later replies. Delete lifts the latest call; release reconstructs the untouched lattice.

## Visible consequence

The blind first view is a suspended block lattice with depth, not a line field, radial constellation, score, or sheet. After a call, the selected node becomes a caller, answering nodes lift and rotate, withheld nodes become visibly broken/quiet, and an offset layer returns the carrier through a real bridge. Repeated carriers meet accumulated resistance and produce a different geometry. The evidence lives in node transforms and activity, not in a counter or caption.

## Falsifier

Delete the trial if pointer motion or a tap writes history, if a carrier changes only colour, if withheld places remain geometrically occupied, if the remote bridge is a decorative overlay, if repeated calls ignore resistance, or if the blind field reads as a generic voxel wall that needs the caption to become reciprocal.

## Deletion condition

If two independent labels-off comparisons cannot distinguish caller, replies, withheld vacancies, and distant return from decorative cubes, delete v021 and abandon this chorus-lattice direction instead of polishing the controls or explanation.
