# WebGPU v038 — The archive wakes after the room empties.

## Concept

A flat computational plate holds a low-resolution lattice of cells. It is not a
crowd illustration and it is not a chart: each cell is a small state-bearing
fragment whose phase, load, gap, and tilt are recomputed from the same seeded
field.

## Hypothesis

If situated attention is translated into a synchronous collective decision,
then the visitor's first contact can stay geometrically quiet while a later
release produces a legible remote response. The work should make absence and
non-local memory visible without drawing a pointer trail or a local avatar.

## Changed rule

A probe is view-only. A release runs one deterministic consensus step: the
source cell stays quiet, while a displaced receiver basin changes actual cell
load, phase, gap, and tilt. Four releases are retained as state; later releases
rebuild from the altered lattice rather than replaying a decorative animation.

## Cultural translation

The source is [little-critters](https://github.com/GordenSun/little-critters),
whose observed mechanism is situated code-drawn agents responding to visitor
proximity with reciprocal attention. Mutine refuses its animals, eyes, paper
scene, head-turning gesture, palette, composition, code, and API surface. The
translation is a signal lattice: attention arms a probe, release invokes a
remote consensus update, and cells that were never touched become the archive.

## Visible consequence

The caption-free first view is a flat, staggered, low-resolution signal plate
with voids and skewed cell fragments. A committed probe does not leave a mark
where it landed; a remote region gains denser, more open, and differently tilted
cells. The four remote responses remain visible in the static timeline and are
liftable exactly in reverse order.

## Interaction

- Pointer or touch: press a cell to arm a probe, move if desired, release to
  commit one signal.
- `Enter` / `Space`: commit the next deterministic signal.
- `Delete` / `Backspace`: lift the latest signal.
- `Escape` / `R`: clear the archive.
- The three visible controls expose the same broadcast, lift, and clear paths.

The first render is intentionally shown before explanation. `?preview=1` removes
editorial furniture; `?preview=1&static=1&blind=1` removes readout, controls,
status, caption, and notes while retaining the settled lattice.

## Falsifier

Delete v038 if the probe changes geometry before release, if the local source
cell is the answer, if the remote change exists only in colour or text, if the
blind plate reads as a generic chart or cellular automaton, if the archive
forgets earlier releases, or if lifting does not reconstruct the exact prior
field.

## Deletion condition

Delete this direction if caption-free viewing cannot distinguish the signal
lattice from v035's pressure vault, v036's continuous ribbon, and v037's
material prism, or if the synchronous remote consensus is not materially
produced in the canvas.

## Direction consequence

This closes the WebGPU sequence of vault, ribbon, and prism objects and opens a
new temporal-computation grammar: WebGPU becomes a question of collective state
and absence, not another spatial volume. The abandoned rule is that the viewer
must turn, drag, or depart through a continuous object; v038 instead asks for a
single discrete release whose consequence is computed elsewhere.

## Medium and reproducibility

The tableau is produced by p5.js 1.11.3 Canvas 2D. `engine.mjs` is pure,
seeded, and deterministic; browser capability is reported with
`navigator.gpu` without making the artwork depend on a proprietary GPU path.
The same source and input sequence produces the same cell-state signature.
