# WebGPU v001 — The crowd keeps the gap

## State

`v001` is a daily work under critique. It is recorded as a candidate, not as a finished period.

## Creative hypothesis

A crowd becomes an archive when a captured absence changes the path of bodies that arrive later. The missing point should be carried by the downstream mass, not explained by a mark placed on top of it.

## Changed rule

The WebGPU current asked whether a crowd could become an archive. v001 changes the field rule from a deterministic braided grid to a memory field: each archived capture bends only agents downstream of its point, with a proximity falloff. Up to four captures are inherited. The renderer is WebGPU-ready and keeps a deterministic Canvas fallback so the causal experiment remains inspectable when the adapter is unavailable.

## Visible consequence

At the opening state, 384 agents cross a dark field in three signal layers. As autonomous captures enter the timeline, the later crowd opens a real lane around each absence: mesh rows kink, signal points leave their origin, and the next agents occupy the changed route. Coral archive witnesses are deliberately quieter than the mint/cyan crowd geometry. The final state contains four inherited channels.

## Visitor action

In an interactive preview, click the field or focus it and press `Enter`/`Space` to commit a capture. `Delete`/`Backspace` lifts the latest capture. `release crowd` clears the visitor state and restarts the autonomous sequence. Capturing and deleting rebuild agent coordinates through the engine; they do not merely toggle a marker.

## Determinism

The fixed numeric seed is `0x57475031` in `engine.mjs`. The same stage and capture memory return the same agent coordinates, archive ledger, and aggregate values. No browser history or local storage is used.

## Falsifier and deletion condition

Delete this direction if a caption-free viewer cannot identify a downstream bend when the coral archive witnesses are hidden, or if removing a capture does not change the later agent field. The next mutation should test one isolated channel before adding more agents or a GPU-specific shader.

## Evidence boundary

The structural tests prove deterministic displacement, bounded input, and exact restoration. Browser preview, adapter availability, interaction, reduced-motion, resize, console, network, and five-viewport evidence are recorded separately; an unobserved or blocked browser run must not be described as a release pass.
