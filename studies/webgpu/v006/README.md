## Creative hypothesis

A crowd becomes an archive when the bodies that follow an encounter carry both the road taken and the road refused. The trace should live in the mass's route topology rather than in an annotation placed beside it.

## Changed rule

v005 inserted a signed rank slip. v006 replaces that with a paired detour: each remembered encounter opens a bounded near/far separation downstream, alternates the lane force across crowd strata, and pulls the lanes back together through a delayed rejoin. The finite memory window retains five encounter records.
