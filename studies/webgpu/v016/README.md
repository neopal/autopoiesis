# The crowd ties itself elsewhere.

## Hypothesis

A crowd can become an archive without accumulating more bodies: if the visitor changes a relation between distant strands, the work should preserve that topological mistake as a visible knot.

## Changed rule

v016 abandons v012's hinge, v013's reciprocal look, and v015's remembered cavity. It also abandons the Canvas 2D wall. The work is one braided WebGL2 scaffold. A meaningful drag between distant strands removes two actual local edges and installs two cross-links between those strands. The archive is a bounded stack of graph mutations. A short click is refused; Delete lifts only the latest knot; release reconstructs the untouched lattice.

## Visible consequence

The blind first view is an interlaced spatial object, not a crowd grid, pressure surface, or room. After a drag, two gaps open in the original strands and two long diagonal bridges make a visible knot elsewhere. Repeated drags keep the topology changes in the object rather than adding a counter or changing a colour field.

## Cultural translation

- **Reference:** little-critters — https://github.com/GordenSun/little-critters
- **Observed mechanism:** situated agents respond to proximity by changing attention and looking back, making the visitor part of a reciprocal relation.
- **Mutine translation:** remove the agents and invert reciprocity into a topological relation. A drag between distant strands makes the scaffold exchange two edges, so the crowd remembers a wrong connection rather than looking back.
- **Anti-copy statement:** no animals, characters, eyes, paper scene, source palette, composition, or head-turning surface vocabulary is reproduced.
- **Direction consequence:** closes WebGPU v012's hinge, v013's social orientation, and v015's cavity grammars; opens a graph-and-medium direction in which the archive is a remembered change in adjacency.

## Falsifier

Delete the trial if a short click changes the lattice, if pointer movement commits before release, if the original edges remain and the bridges are only glowing overlays, or if the blind field reads as a generic wireframe rather than one woven object.

## Deletion condition

If two independent labels-off comparisons cannot distinguish the removed edges and distant cross-links from a decorative overlay, delete v016 and abandon the knot direction rather than polishing the readout.

## Evidence method

The engine is deterministic from `SEED`, replays a four-event memory window, records removed and bridged edge pairs, and exposes a geometry signature for exact reversal. The browser tableau uses a deterministic WebGL2 renderer and a Canvas fallback label for machines without WebGL2.
