# WebGPU v039 — The archive keeps the pressure between bodies.

## Concept

A singular collective body is made from seventeen closed, low-resolution pressure
reservoirs around one irregular void. It is not a grid, a route, or a volume:
each body is a produced contour, and the space between bodies is part of the
archive.

## Hypothesis

If p5.brush's material logic is translated into collective computation, then a
visitor can offer pressure as a relation between two bodies rather than as a
mark. The selected bodies should remain exact while a displaced body and the
shared void are re-produced, making memory legible in what the visitor did not
touch.

## Changed rule

Two distinct bodies can be paired, but choosing a pair is geometry-neutral.
Compression accepts the pair's pressure and routes it to a remote reservoir. The
selected bodies remain geometrically exact; the remote body's scale, aspect,
rotation, notch, and pressure change, and the shared void is regenerated. Four
compressions compound from the same retained events.

## Cultural translation

The source is [p5.brush](https://github.com/acamposuribe/p5.brush), whose observed
mechanism is that pressure, density, directional behaviour, and fields
participate in producing geometry rather than merely styling a finished mark.
Mutine refuses its brushes, watercolor appearance, hatching, grain, palette,
composition, source code, examples, and API surface. The translation is a
pressure reservoir: a pair's material evidence changes the production of a
remote body and the negative space shared by the collective.

## Visible consequence

The caption-free first view is one asymmetrical field of closed polygonal bodies
around a large cut-out void. Selecting one or two bodies leaves the produced
field unchanged. Compressing a valid pair changes actual remote contours and
re-opens or tightens the central void. Four responses remain visible in the
settled timeline and can be lifted exactly in reverse order.

## Interaction

- Pointer or touch: tap two distinct reservoirs, then compress the pair.
- `Enter` / `Space`: compress the next deterministic pair.
- `Delete` / `Backspace`: lift the latest compression.
- `Escape` / `R`: release the archive.
- The three visible controls expose the same compress, lift, and release paths.

The first render is shown before explanation. `?preview=1` removes editorial
furniture; `?preview=1&static=1&blind=1` removes readout, controls, status,
caption, and notes while retaining the settled pressure body.

## Falsifier

Delete v039 if selecting a body changes geometry, if the selected bodies answer
themselves, if the remote response exists only in colour or text, if the blind
field reads as a node diagram, cellular chart, or decorative polygon field, if
later compressions reset, or if lifting does not reconstruct the exact prior
body.

## Deletion condition

Delete this direction if caption-free viewing cannot distinguish the pressure
reservoir from v036's ribbon, v037's prism, and v038's lattice, or if the shared
void is not materially regenerated by the pair.

## Direction consequence

This closes the WebGPU sequence of continuous carrier, material prism, and signal
lattice. It opens a collective-material grammar in which pressure is not a local
stroke or a remote signal: it is a conserved relation between selected bodies
that changes the topology of the unselected space. The abandoned rule is that
the visitor must move through a continuous object or release a probe; v039 asks
for a discrete pair and a deliberate compression.

## Medium and reproducibility

The tableau is produced by p5.js 1.11.3 Canvas 2D. `engine.mjs` is pure, seeded,
and deterministic; browser capability is reported with `navigator.gpu` without
making the artwork depend on a proprietary GPU path. The same source, pair
sequence, and pressure sequence produce the same body and void signatures.
