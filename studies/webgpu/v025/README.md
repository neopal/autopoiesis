# The crowd cures the pressure.

## Hypothesis

WebGPU's collective question can leave the surface and become a spatial material body: if pressure changes how one part of a crowd is produced, the next pressure should meet a crown whose cavity and mass have already been altered.

## Changed rule

v025 abandons v022's adaptive cell field, v023's continuous membrane, and v024's vertical procession of separate loops. The representation becomes twelve broad spatial fins arranged as one broken crown around a dark, deliberately off-centre cavity. The encounter changes from sweep, token, and measured hold to an immediate address: pointer travel only selects a tooth; release commits one pressure strike. The strike shears and lifts the addressed fin, then cures a distant fin into vacancy. Memory is bounded to four strikes; Delete lifts the latest event and R releases the crown.

## Visible consequence

The blind first view is a sculptural pressure crown with broad planes, depth, and an empty centre, not a linefield, tile sheet, membrane, or ring procession. After a strike, one fin leans and rises while a non-local fin narrows and drops; later strikes inherit both the shear and the vacancy. Pressure is visible as changed vertices and cavity balance, not as a counter or temporary mark.

- **Visible consequence:** an immediate release changes actual three-dimensional fin vertices, creates a non-local opening, and leaves later strikes acting on the changed crown; Delete rebuilds the exact preceding geometry.

## Falsifier

Delete the trial if a strike only adds a glow or counter, if the addressed fin does not change actual vertices, if the distant vacancy is fixed or cosmetic, if later strikes restart from the baseline crown, if Delete cannot restore the exact preceding crown, or if the blind image reads as a generic radial chart.

## Deletion condition

After two independent labels-off and controls-off comparisons, delete v025 if viewers cannot find a single spatial crown and a changed cavity after the first strike, or if the pressure gesture is indistinguishable from a generic click-to-highlight control. Do not rescue a failed material rule with captions, counters, or extra grain.

## Evidence method

The engine is deterministic from `SEED`, replays a four-strike memory window, stores an exact sector-and-vertex signature, and rebuilds the prior crown on lift. The tableau requests a WebGPU device and submits a WGSL grain veil when available; the Canvas layer is the deterministic 3D projection fallback and remains the source of causal crown geometry on machines without WebGPU.
