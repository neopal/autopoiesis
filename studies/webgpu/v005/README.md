# WebGPU v005 — The crowd miscounts itself

## State

`v005` is a daily work under critique. It is recorded as a candidate, not as a finished period.

## Creative hypothesis

A crowd becomes an archive when a later body inherits the wrong number. Memory should be carried by the order of the mass itself, not by an annotation placed beside it.

## Changed rule

v005 replaces v004's delayed rehearsal rule with a rank-slip rule. Each remembered encounter inserts a signed index error at a bounded point. Bodies downstream of the point inherit a row-specific phase fingerprint: their x/y coordinates and route order shear together before settling back into the field. Up to five encounters are inherited; a visitor index enters exactly the same memory path as an autonomous one.

## Visible consequence

At the opening state, 480 deterministic agents cross a mineral-dark register in signal, body, and dust strata. Later horizontal routes acquire a staggered seam: some rows advance, some lag, and their fine return threads expose a changed order. Archive cuts, route threads, labels, and readouts can be hidden with `blind=1`; the underlying coordinates still change. The final state contains five inherited indices and 309 re-indexed agents.

## Visitor action

In an interactive preview, click the field or focus it and press `Enter`/`Space` to index a place. `Delete`/`Backspace` lifts the latest index. `release census` clears visitor state and restarts the autonomous sequence. Indexing and lifting rebuild agent coordinates through the engine; they do not merely toggle a marker.

## Determinism

The fixed numeric seed is `0x57475035` in `engine.mjs`. The same stage and index memory return the same agent coordinates, archive ledger, and aggregate values. No browser history or local storage is used.

## Falsifier and deletion condition

Delete this direction if a caption-free viewer cannot identify a rank seam when archive cuts, route threads, labels, and readouts are hidden, or if lifting an index does not change downstream coordinates. Delete it also if the field only reads as coloured waves, if the horizontal routes remain interchangeable, or if the prose explains more order than the mass can show.

## Evidence boundary

Structural tests prove deterministic bounded input, replay metrics, and exact restoration. Browser preview, adapter availability, interaction, reduced-motion, resize, console, network, and five-viewport evidence are recorded separately; an unobserved or blocked browser run must not be described as a release pass.
