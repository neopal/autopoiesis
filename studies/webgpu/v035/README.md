# The pressure enters elsewhere.

## Hypothesis

Can a material instrument change a spatial archive without leaving a picture of the instrument? If pressure is an interval rather than a mark, the first beat should remain geometrically silent; the delay between two beats should alter a remote panel's depth, aperture, and slip in a single vault.

## Changed rule

v035 abandons v034's orbital chorus, v033's propagation terrain, and v032's cellular quorum membrane. The representation switches to twelve vertical panels receding through a dark architectural depth. A first tap is a pressure sample, not a deformation. A second tap closes the interval: its duration becomes force, and the response is made elsewhere. The source panel compresses, a remote panel advances and opens, and a third panel splits its slip. Four pressure decisions remain liftable.

## Visible consequence

The blind first view is one deep vault of unequal panels, inset apertures, side planes, and a broken perspective. It is not a field of agents, orbit, grid, membrane, or crowd. A valid double tap changes actual panel depth, position, aperture, yaw, pitch, tension, and slip away from the tapped surface. The gesture itself leaves no trace. Later pressure intervals rebuild from the altered vault rather than from a quiet seed.

## Cultural translation

- **Reference:** [p5.brush](https://github.com/acamposuribe/p5.brush)
- **Observed mechanism:** a programmable drawing instrument makes pressure, density, directional behaviour, and fields participate in producing geometry rather than merely styling a finished mark.
- **Mutine translation:** refuse brushes, watercolor, hatching, grain, vector-field marks, source palette, composition, code, examples, and API surface. Translate material agency into an interval instrument: the delay between two taps changes the production rule for a remote depth panel, its aperture, and a third panel's slip.
- **Visible consequence:** the first tap is geometrically neutral; the second does not draw a local mark. A remote panel advances through depth, opens, and changes its angle while the source recedes and a third panel splits.
- **Anti-copy statement:** no brush appearance, watercolor, hatching, grain, vector-field drawing, source palette, source composition, source code, examples, API surface, or surface vocabulary is reproduced.
- **Direction consequence:** closes WebGPU's terrain / membrane / orbital family and opens material-depth archive: the current moves from populations and continuous fields to an authored architectural object whose future geometry is produced by elapsed pressure.

## Falsifier

Delete the trial if the first tap changes geometry, if waiting or pointer movement changes geometry, if the touched surface is the answer, if pressure only changes colour or readout, if the vault reads as a generic card stack or control grid, if later decisions reset from the seed, if Delete cannot restore the exact preceding vault, or if the blind image needs its caption to become meaningful.

## Deletion condition

After two labels-off, readout-off, controls-off, and caption-off comparisons, delete v035 if viewers cannot identify one architectural vault and a materially different remote response, or if the work is indistinguishable from a decorative stack of panels. Do not rescue a failed causal rule with counters, labels, or a cursor trail.

## Evidence method

The engine is deterministic from `SEED`, rebuilds all panels from a bounded four-pressure ledger, stores an exact geometry signature, and reconstructs the preceding vault on lift. The tableau requests a WebGPU device and submits a WGSL veil when available; the Canvas 2D renderer remains the deterministic authored surface on machines without WebGPU. Reduced-motion and static states use a four-pressure settlement so blind capture exposes depth, aperture, and slip memory without an animation race.
