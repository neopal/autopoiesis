# WebGPU v003 — The crowd keeps a place open

## State

`v003` is a daily work under critique. It is recorded as a candidate, not as a finished period.

## Creative hypothesis

A crowd becomes an archive when a missing body changes who passes whom. The remembered point should be carried by a change in local order, not explained by a marker, a counter, or a GPU label.

## Changed rule

v003 replaces v002's latency debt with a vacancy rule. Each archived point reserves an open place in the agents' local sequence. Bodies downstream queue around it in two lanes, then rejoin with an order offset carried by their coordinates. Up to four vacancies are inherited. The renderer is WebGPU-ready and keeps a deterministic Canvas fallback so the causal experiment remains inspectable when the adapter is unavailable.

## Visible consequence

At the opening state, 432 agents cross a dark topographic field in three signal layers. As autonomous vacancies enter the timeline, later rows split into a pocket and braid back together. Gold/coral order threads connect a displaced body to its prior slot; the quieter coral witnesses are not the only carrier of the change. The final state contains four inherited vacancies and a measurable order shear.

## Visitor action

In an interactive preview, click the field or focus it and press `Enter`/`Space` to reserve a place. `Delete`/`Backspace` lifts the latest vacancy. `release crowd` clears the visitor state and restarts the autonomous sequence. Reserving and lifting rebuild agent coordinates through the engine; they do not merely toggle a marker.

## Determinism

The fixed numeric seed is `0x57475033` in `engine.mjs`. The same stage and vacancy memory return the same agent coordinates, archive ledger, and aggregate values. No browser history or local storage is used.

## Falsifier and deletion condition

Delete this direction if a caption-free viewer cannot identify a braid or changed order when the coral vacancy witnesses, threads, labels, and readouts are hidden, or if lifting a vacancy does not change the downstream field. The direction is also deleted if the two lanes read as a decorative split rather than a remembered place in the crowd.

## Evidence boundary

The structural tests prove deterministic order displacement, bounded input, and exact restoration. Browser preview, adapter availability, interaction, reduced-motion, resize, console, network, and five-viewport evidence are recorded separately; an unobserved or blocked browser run must not be described as a release pass.
