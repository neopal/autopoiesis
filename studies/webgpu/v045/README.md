# WebGPU v045 — The weight arrives after you leave.

## Concept

A broad stratigraphic mass replaces the recent WebGPU orbit and membrane. The
image is a cross-section of 72 stacked cells, not a population of witnesses:
small differences in height, layer count, porosity, and shear make one dense
material field that can be read as a body of accumulated time.

## Hypothesis

If pressure is treated as a production rule rather than as a mark, then a
sustained charge should alter the way later strata are compacted around the
source, while the source itself remains exact. A tap must fail. A long release
must produce a visible change in height, layer count, shear, ridge, and porosity
across the mass. Reversing the release direction must produce a different
compaction grammar.

## Changed rule

The viewer holds one cell. Until the dwell threshold is crossed, the tableau is
geometry-neutral. On release, the load is translated into a deterministic
compaction wave over the other cells; the loaded cell is not rewritten. Four
loads compound in the same mass. Delete lifts one load and reconstructs the
preceding geometry; Escape releases the entire archive to the quiet seed.

## Cultural translation

The source is [p5.brush](https://github.com/acamposuribe/p5.brush), whose
observed mechanism treats pressure, density, directional behaviour, and fields
as production rules that change how geometry is generated. Mutine refuses its
brush presets, watercolor, hatching, grain treatment, palette, composition,
source code, examples, and API surface. The translated rule is a timed load:
pressure changes the next 3D stratum's compaction law, not the appearance of a
finished mark.

## Visible consequence

The caption-free first view is an oblique, dark mineral cross-section: a wide
rectangular mass of unequal stacked cells with copper seams, cool upper layers,
and a few quiet voids. A short touch changes nothing. A sustained charge leaves
the source cell geometrically exact while many untouched cells gain or lose
height, layers, shear, ridge, and porosity. Alternating release direction makes
the next fold read differently. The state can be rebuilt from the seeded event
list.

## Interaction

- Pointer or touch: hold one cell, then release after the load builds.
- `Enter` / `Space`: make the next deterministic sustained charge.
- `Delete` / `Backspace`: lift the latest load.
- `Escape` / `R`: release the strata archive.
- The three visible controls expose charge, lift, and release without requiring hover.

`?preview=1` removes editorial furniture. `?preview=1&static=1&blind=1` removes
readout, controls, status, caption, and prose while retaining the settled
four-load stratigraphy.

## Falsifier

Delete v045 if a short or cancelled charge changes geometry, if the source cell
is rewritten, if the compaction is only a colour or readout change, if direction
does not alter the generated structure, if later loads reset earlier layers, if
lifting is inexact, or if the blind work reads as a generic 3D tile grid.

## Deletion condition

Delete this direction if caption-free viewing cannot distinguish the stratigraphic
mass from v042's moving witnesses, v043's faceted membrane, and v044's negative
apertures, or if the sustained charge is only legible through explanation.

## Direction consequence

This closes WebGPU's recent witness-led sequence: waiting, shadow, resistance,
and reciprocal orbit. It opens a temporal material period in which the visitor's
presence is measured by duration, then spent in the production rule of a dense
cross-section. The abandoned rule is that the current must answer with an
aperture, facet, or remote witness; now the mass changes how it can settle.

## Medium and reproducibility

The executable tableau is generated by p5.js 1.11.3 WEBGL boxes, thin strata
caps, seams, and seeded ambient marks. `engine.mjs` is pure and deterministic;
`navigator.gpu` is reported as a capability signal without making the work
depend on a proprietary GPU path. The same seed, source cell, dwell band, and
release direction produce the same stratigraphy signature.
