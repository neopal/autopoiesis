# WebGPU v041 — The crowd gives weight to waiting.

## Concept

A single raster mineral body carries thirteen dark apertures around a tense
central seam. The apertures are not a crowd of objects; they are the negative
spaces left by a collective archive that has stopped moving.

## Hypothesis

If material agency is translated into duration rather than a brush gesture,
then a held pause can become a measurable pressure fossil. The held site should
remain exact while the archive hardens an aperture elsewhere, and the duration
of waiting should change the material consequence rather than a label or colour.

## Changed rule

The pointer never paints and no site is selected. A press begins a provisional
hold whose geometry is neutral. Only release after a 640ms threshold commits a
`fossil-hardening` event. Its elapsed duration becomes hardness and changes a
remote aperture, the central seam, and nearby cut geometry. Four events compound
and can be lifted in reverse order.

## Cultural translation

The source is [p5.brush](https://github.com/acamposuribe/p5.brush), whose
observed mechanism treats pressure, density, direction, and material state as
rules that produce geometry instead of decorating a finished mark. Mutine
refuses its brush presets, watercolor appearance, hatching, grain, palette,
composition, source code, examples, and API surface. The translated rule is a
pause that hardens a remote cut in a raster fossil; the hand supplies duration,
not a mark.

## Visible consequence

The caption-free first view is a singular mineral relic with thirteen negative
apertures, a warm seam, and granular raster depth. Arming and moving remain
geometrically exact. A valid hold-release leaves its source aperture exact while
a distant aperture changes position, width, height, tilt, notch, edge, and
density. Brief and long holds produce different remote fossils; four changes
remain visible and can be lifted exactly.

## Interaction

- Pointer or touch: press and hold inside the fossil, then release after the threshold.
- `Enter` / `Space`: make the next deterministic hold with a recorded duration.
- `Delete` / `Backspace`: lift the latest fossil-hardening event.
- `Escape` / `R`: release the archive.
- The three visible controls expose the same harden, lift, and release paths.

The first render appears before explanation. `?preview=1` removes editorial
furniture; `?preview=1&static=1&blind=1` removes readout, controls, status,
caption, and notes while retaining the settled raster fossil.

## Falsifier

Delete v041 if the blind body reads as a grid, particle field, or decorative
texture; if a hold changes geometry before release; if a short hold commits; if
duration changes only colour or prose; if the held site is the answer; if the
remote cut is cosmetic; if later hardenings reset; or if lifting is inexact.

## Deletion condition

Delete this direction if caption-free viewing cannot distinguish the singular
pressure-fossil grammar from v038's lattice, v039's reservoirs, and v040's
depth sheets, or if waiting does not produce a material remote consequence.

## Direction consequence

This closes WebGPU's recent field-of-sheets and chosen-witness sequence. It
opens a fossil-ledger direction: collective computation is tested as duration,
negative space, and a singular raster body. The abandoned rule is that the
archive must be assembled by selecting multiple locations; v041 asks whether
waiting alone can make a crowd leave a remote material trace.

## Medium and reproducibility

The tableau is produced by p5.js 1.11.3 Canvas 2D and an offscreen raster
buffer. `engine.mjs` is pure, seeded, and deterministic. Browser capability is
reported with `navigator.gpu` without making the work depend on a proprietary
GPU path. The same source, hold sequence, and duration sequence produce the
same fossil signature.
