# WebGPU v046 — The crowd remembers the wrong rhythm.

## Concept

A diagonal ledger of 27 folded planes replaces the recent WebGPU cross-section,
membrane, and aperture field. The crowd is not a grid or a pile: it is a shared
hinge line whose individual leaves remain visibly separate while their folds
compose one body.

## Hypothesis

If the material rule is inverted from pressure accumulation to pressure refusal,
then a regular three-beat phrase should leave the tableau exact, while an uneven
release should create a visible crease across the whole chorus. The cadence must
change actual fold, lean, height, opening, crease, and ink geometry, not only a
status message or colour. The viewer's tapped voice is not privileged: the
whole ledger re-creases.

## Changed rule

The visitor taps three beats. One beat or a regular three-beat rhythm is inert.
Only an irregular ratio between the first and second interval commits a
`cadence-crease` event. That event is replayed over every folded voice, producing
one remembered hinge pattern. Four broken rhythms compound. Delete lifts one
crease and reconstructs the preceding ledger; Escape returns to the quiet seed.

## Cultural translation

The source is [p5.brush](https://github.com/acamposuribe/p5.brush), whose observed
mechanism makes pressure, density, directional behaviour, and fields participate
in producing geometry. The previous WebGPU work translated that mechanism into a
sustained load and compaction wave. This work explicitly inverts it: pressure and
duration are refused, and only an uneven *release cadence* alters geometry. Mutine
refuses brush presets, watercolor appearance, hatching, grain, source palette,
source composition, source code, examples, and API surface.

## Visible consequence

The caption-free first view is a suspended diagonal chorus of folded planes:
plum, paper, violet, copper, and mint faces hinge around a thin broken spine.
There is no rectangular cell mass, radial orbit, aperture, or membrane. A regular
three-beat tap leaves this body unchanged. A broken rhythm makes the entire
ledger lean and crease, with a new physical hinge band at its cadence anchor;
additional rhythms accumulate distinct crease bands. The state is rebuilt from
the seeded event list.

## Interaction

- Pointer or touch: tap the canvas three times with an uneven rhythm.
- `Enter` / `Space`: make the next deterministic broken cadence.
- `Delete` / `Backspace`: lift the latest crease.
- `Escape` / `R`: release the whole archive.
- The three visible controls expose cadence, lift, and release without hover.

`?preview=1` removes editorial furniture. `?preview=1&static=1&blind=1` removes
readout, controls, status, caption, and prose while retaining the settled
four-crease ledger.

## Falsifier

Delete v046 if a single tap or regular rhythm changes geometry, if the crease is
only colour or readout, if one tapped voice remains the only source of change,
if four events do not compound, if lifting is inexact, or if the blind image
reads as a decorative fan, generic WebGL demo, grid, orbit, membrane, or mass.

## Deletion condition

Delete this direction if caption-free viewing cannot distinguish the folded
chorus from v043's resistance membrane, v044's reciprocal orbit, and v045's
stratigraphic mass, or if the missing beat is only legible through explanation.

## Direction consequence

This explicitly abandons WebGPU's recent material-load rule: duration no longer
makes a dense body compact. It opens a cadence/archive direction in which the
crowd stores a collective failure as a crease pattern. The source is no longer
protected while a remote receiver answers; the whole chorus is implicated by the
same broken rhythm.

## Medium and reproducibility

The executable tableau uses p5.js 1.11.3 WEBGL custom triangular folded planes,
seeded material faces, a broken spine, and generated crease bars. `engine.mjs` is
pure and deterministic; `navigator.gpu` is reported only as a capability signal.
The same seed, cadence beats, anchor, and direction produce the same ledger
signature.
